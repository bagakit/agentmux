# Topics directory and Files

Owning behavior: [Topic navigation](../../../../../docs/design/behavior/spaces-and-layout.md#topic-导航与成员范围).
Owning presentation: [Topics hierarchy](../../../../../docs/design/presentation/spaces-and-layout.md#topics-知识库的导航与内容层级).

`node apps/desktop/scripts/capture-topics-navigation-quality.mjs [evidence-directory]`
compiles the original App, Topics/Files assembly, File workface and full stylesheet cascade.
The private transport supplies eight Topics, a category, file entries and Markdown source;
initialization is isolated, and Agent lifecycle calls are rejected and counted. This is
Renderer evidence, not a real provider or filesystem authority proof.

The scene expands Files, drags its divider to its limit, reveals another Topic through
the original object menu, and checks the original selection/workface/draft remain.
Knowledge query survives Files collapse and expansion. A short narrow light window
checks a long category title and distinct keyboard focus. Empty and unavailable
category states finish the scene. The unavailable description keeps all eight Topics
and the original file body. Refresh consumes the original public category reader and
keeps the selection, Tabs, Regions and draft. Full unedited PNGs and source hashes go into the
evidence directory; `captureOnly` does not sign aesthetic acceptance.

The separate `verify-topics-layout-restart.mjs` runs the original App initialization,
Core spatial persistence and UI preferences in two real Electron processes. Only the
first seeds a private original file workface; the second restores the same Tabs, Regions,
split layout, selection, unsaved file annotation, composer draft and explicit Files
preference from the original owners. This layout proof has no Session or Run and does
not claim Agent recovery. Metadata and file transport are controlled private facts.
The restored process also uses the original Focus navigation at 320px, then returns to
Space; the same file workface, topology and unsent work must remain. Focus has no execution
contexts in this proof, but its borrowed original file workface remains visible beneath
the scan area. This does not stand in for an Agent workface or its recovery.
