# Original external input waiting control

Actual SessionMailbox -> controlled external journal detail -> OriginalInputWaitingControl,
with the original shared AgentComposer, theme and production CSS. The API leaf returns
typed synthetic input/Stop observations; it is not a Core, Host, authorization or live-platform proof.

Native pointer input opens the mailbox, chooses Inputs, selects the original external
record and explicitly stops that wait. Capture waiting wide/narrow, then each original
Stop outcome at narrow width. Mount, selection, read and reopen must have no write.
No input/rejoin/recovery/Run stop is permitted. Preserve the independent unsent draft.

Capture is not aesthetic approval. An independent reviewer opens every complete PNG.
Private compiled output and Electron profile are removed after their original process exits;
the receipt, loaded hashes, native events, observations, errors and images remain.

`--repair-results` recaptures only the already-settled and stale-generation narrow
results after their presentation repair. Earlier snapshots and receipts remain unchanged;
the capture handoff explicitly joins unaffected earlier frames with the repaired pair.
