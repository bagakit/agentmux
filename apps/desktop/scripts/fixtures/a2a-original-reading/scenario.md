# A2A original reading: private production Renderer scene

This fixture compiles the production `DesktopClientUiProvider → api.sessions.readMessage` adapter and the actual shared `ConversationMessage → ConversationInputText → ConversationA2AReferences → ConversationMessage` reading chain, including the product Markdown renderer and Desktop styles. The [conversation behavior contract](../../../../../docs/design/behavior/conversation-mode.md) and [conversation presentation contract](../../../../../docs/design/presentation/conversation-mode.md) own the user-facing requirements.

`captureA2aOriginalReading({ root, evidence })` in `capture.mjs` builds privately with Vite and opens only its own hidden Electron window. Both `userData` and `sessionData` live under a unique temporary directory. The private API replaces only `api.sessions.readMessage`; the preview build never connects to user Hosts, Agents or Runs. The original adapter still validates the returned Host before the shared reader consumes the exact MID. The separate registered bridge checks own real preload/IPC/Main/Core evidence.

The scene contains one qualified system notice (`notice-original`, `probe-host`, `probe-recipient`) with a Core-rendered reference to `probe-mid` from `probe-sender`, one ordinary unqualified wire record and a private host-owned unsent textarea. It uses Chromium pointer input to open and close the ordinary record, then opens the qualified notice. Opening the ordinary record must perform zero reads. Opening the qualified notice automatically reads at the exact receiving Host/Session/MID. That first controlled read fails visibly and preserves the original reference and an explicit Retry original message button. Clicking Retry reads the same exact object and renders the complete Chinese Markdown body, including a long MID-like token and the original tail. The controlled promise settles while the unsent textarea holds focus; both asynchronous failure and success must retain its original text and focus. This bounded textarea continuity does not certify the full workbench composer or Session lifecycle.

Each scenario runs at 960px and 332px viewport widths in both dark and light themes. Eight complete screenshots capture failure/Retry and successful original reading. Assertions check the full original body, long token and action remain within the native viewport, with no horizontal content loss. `capture.json` binds actually consumed source/style hashes, compiled artifact hashes, exact screenshot paths, private process cleanup and the complete `render.json` receipt. Capture success is not independent aesthetic approval; an independent Agent must open the actual full screenshots and review them according to [the visual review guide](../../../../../docs/guides/agent-visual-e2e-review.md).

This evidence is limited to the controlled real Renderer and Desktop adapter. It does not establish live Agent delivery, original-body acceptance, installed App behavior, full App/Core operation or durable Session recovery, and it never operates user Sessions.
