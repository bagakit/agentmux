# Message Tool 右侧失败提醒场景

Owning 约束：[等待与失败说明](../../../../../docs/design/presentation/agent-capabilities-and-messaging.md#message-tool-的等待与失败说明)，相邻输入行为只引用该合同。

运行 `node apps/desktop/scripts/verify-agent-region-identity-menu.mjs --visual-only --message-feedback-owning`，使用原 WorkspaceWorkbench → SessionPane → AgentSessionComposer、共享 MessageDeliveryFailure 与产品样式。私有 Electron userData/sessionData 与 preview API 隔离用户工作面；不证明 Native 投递、权限、重启或安装包。

640px/320px 原 Region 下，实际输入短草稿，点击文件工具制造原 API 失败；依次收回一行、打开工具行和长文本，检查右侧提醒不挤压输入、不偷焦点。展开完整长诊断，操作拒绝及成功的原剪贴板出口，重试原工具。用原队列投影逐条读取失败、结果未知及等待消息，保留完整正文、原标识、原等待取消动作。每个状态采完整画面，必须由独立 Agent 实际打开本批 PNG 判断美感与可读性；几何断言仅为功能守护，不代替图审。
