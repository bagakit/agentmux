# Mote companion origins

Owner: [user story](../../../../../docs/design/behavior/companions-from-work.md) and [presentation](../../../../../docs/design/presentation/motes-and-coordination.md#伙伴从哪里来用户故事板与教程-banner).

The production SettingsPanel opens its original Mote pane. Change the avatar and directory draft, then select each tutorial chapter and explicitly save the same draft. Source mutations break chapter selection and disconnect the production consumer; both must fail behavioral assertions.

The existing settings-home native Renderer probe captures all three chapters in dark/light themes at normal and compact widths, including a trusted Tab/Enter transition. Read the full frames, not image contact sheets. Inspect organization/member distinction, two independent origins, recognizable members and artifacts across Topic/promotion, text legibility, original configuration access, and no implicit save.

Illustrations depict fictional Agents and work. Preview API supplies isolated settings data. Evidence proves Renderer consumption and tutorial interaction; it does not prove Topic promotion, real Agent work, native runtime recovery, installation or release.
