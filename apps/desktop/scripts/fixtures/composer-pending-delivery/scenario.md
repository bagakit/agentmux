# Composer pending delivery native scene

This bounded preview runs the production WorkspaceWorkbench, SessionPane, AgentSessionComposer, maintained editor, original Mailbox, queue Store and two real xterm instances. It supplies known private terminal bytes, holds actual preparation and submit separately, and never contacts, submits to, restarts or stops a user Run. The clipboard sink goes through the production Clipboard helper; successful, rejected and held writes retain their exact original body and outcome.

Run `node apps/desktop/scripts/verify-composer-pending-delivery.mjs --native`. Its Electron controller receives `[html, privateRoot, evidence, capture]`. Complete page PNGs and `render.json` bind actual Renderer facts, trusted native actions, exact operation identities, source/compiled hashes and actual terminal paint. Collection success is not aesthetic approval.

Four scenes use 1280px or 640px viewports with approximately 640px or 320px owner Regions and an unchanged neighbor, in both dark and light themes. Each scene captures 27 states, 108 complete frames total: the original empty, queued/history, preparation, submission, permission waiting, unknown and Outbox flows; short/two/100-card idle states; trusted head/middle/tail hover and Copy; exact middle header Outbox; keyboard and long-body states; editing, Mailbox draft preservation, CAS rejection and unknown locking; normal/reduced-motion Copy success, clipboard failure and a late old-body write; and collapse. An independent reviewer actually opens the new complete images before visual delivery.
