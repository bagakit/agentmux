# Composer pending delivery native scene

This bounded preview runs the production WorkspaceWorkbench, SessionPane, AgentSessionComposer, maintained composer, original Mailbox, Store drain and two real xterm instances. The preview API supplies known terminal bytes and holds the actual Store preparation refresh and submit calls separately. It does not contact, submit to, restart or stop a user Run.

Run through the owning `verify-composer-pending-delivery.mjs --native` launcher. The Electron controller accepts `[html, privateRoot, evidence, capture]`; `capture` records complete page PNGs. Its `render.json` records actual Renderer facts, operation identities, trusted input and terminal paint receipts. Collection failure is a failed scene, never an aesthetic approval.

Four scenes use a 1280 px or 640 px viewport, each with two neighboring Regions: approximately 640 px or 320 px for the owner, in both dark and light themes. Each scene records eight complete screenshots: empty, queued while reading terminal history, preparing, sending, waiting for the existing request, unconfirmed result, original Outbox detail and original Info. Six additional full captures per scene cover short content, two entries, a 25-entry bounded stack, trusted hover, keyboard focus with reduced motion, and long clipped content. All 56 originals require independent visual review.
