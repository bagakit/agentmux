# Provider context details scene

Run `node packages/client-ui/scripts/capture-content-actions.mjs context-details` from the repository root. The isolated scene consumes actual AgentContextUsage, AgentComposer and Desktop theme tokens. Controlled Host observations distinguish reported context from a turn whose capacity is not reported; the actual Core decoder, preload and Store publication chain is verified separately by the headroom integration tests. The preview Host only supplies the existing overlay lease; no real Agent, user file or Runtime is operated.

Trusted Chromium pointer, mouse, keyboard and touch input verify hover focus, crossing the gap, click pinning, Escape, unknown data, same-source compaction and source replacement. Original wide/narrow light/dark images, owning source hashes and private-process cleanup are recorded locally; capture does not approve aesthetics or certify an installed Host.
