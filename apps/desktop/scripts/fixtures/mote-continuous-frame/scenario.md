# Mote 共同框架去重

## 交流面常驻身份与证据层级

专项运行 `node apps/desktop/scripts/fixtures/mote-continuous-frame/capture.mjs --conversation-only`，只运行本轮交流面场景，不重复下述八页。消费[搭档界面与共享工作面](../../../../../docs/design/behavior/motes-and-coordination.md#搭档界面与共享工作面)和[消息、输入与持续状态层](../../../../../docs/design/presentation/motes-and-coordination.md#消息输入与持续状态层)。

沿原 `mote-discussion-threads` bootstrap 提供准确 Main 与历史关联，Core 原 conversation projector/严格 page parser 消费有限 typed native 与 captured 记录。合成输入包括已确认 native 与 captured 人类消息、准确 same-event 提交关联、送达待核实输入、原生系统记录和可展开的历史 Main。实际操作原 Info、历史展开/收回、Composer 临时编辑并还原草稿、Open in Space 与原浮窗入口；宽深色、640px 浅色长名及原 Run 退出和原生来源 unavailable 组合各有完整图。

九张图保留当前头像/名称、两路 Info、历史、完整 Space、窄面、退出/读取失败的摘要与原详情，以及初始读取状态。采图期间逐次核对原 Region/Session、Run control 与全部未发送草稿；观察失败前后检查同一 Reader/Composer/正文 DOM 和选区，无 submit/write/launch/stop/respond。source unavailable 通过原 observer 回调和原 read 失败表达，不靠 CSS 或替换产品组件制造。第一条延迟读取完成后仍读取同一原 Session。

专项 Electron 以 accessory 模式和 showInactive 展示，输入只定向该私有 webContents，不请求系统焦点或使用全局输入。原 App、Store、Reader、Composer、头像、Info、状态 disclosure 与全部 CSS 不替换。该证据只证明本批真实 Renderer 消费与呈现，不证明实际 Provider/CLI、用户原会话重启恢复、飞书机器人或已安装包。

## 原共同框架场景

从候选工作树运行 `node apps/desktop/scripts/fixtures/mote-continuous-frame/capture.mjs`。

本场景消费 [Mote 共同框架与页面职责](../../../../../docs/design/presentation/motes-and-coordination.md#共同框架与页面职责)及[合作资料与工作入口](../../../../../docs/design/behavior/motes-and-coordination.md#合作资料与工作入口)。复用已有 `mote-cooperation` 完整 App bootstrap，仅补本轮 Profile 的准确原 Files resource/path、已保存行为、确认目录、空 Goal 与安排的有限公开 API 数据。产品 App、Store、原框架、内容组件、共享 Modal/Portal、文件解析和全部 CSS 不作替换。

实际 Chromium 点击 Open in Space，再依次切 Profile、Ideas、Calendar，打开并关闭团队；切至 640px 长名和浅色，最后引入明确的资料/成员观察 unknown。每次采图都核对全部原 Region/Session、原 Run 引用及原未发送草稿；读取和导航无 submit/write/launch/stop/respond。团队只含该 Mote 的两个原成员。

八张完整图包含正常 Profile/Ideas/Calendar、协作浮层、窄窗长名 Ideas/Profile、浅色窄窗 Calendar 和 unknown 团队。读取失败与空资料保持区别；Ideas 的空笔记不铺两份空态。正常 Profile 数据为明确的合成已保存偏好，不声称真人偏好或模型采用。

产物写入 ignored `.bagakit/mote-frame-rethink/frame-ui/capture-<id>/`，包括源码/编译 hash、真实操作、完整 PNG、receipt 和 review 入口。代码变化后重新采图；采集仅标 `captureOnly`，独立 Agent 实际完整看图并明确可交付才算图审通过。本场景不证明连续主对话、工作事件关联、心跳、真实 Provider/CLI/模型、跨 Host、用户原 Session 生命周期或安装交付；这些由各 owning Task 验收，不能以此代签。
