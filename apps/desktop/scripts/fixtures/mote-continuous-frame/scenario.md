# Mote 共同框架去重

从候选工作树运行 `node apps/desktop/scripts/fixtures/mote-continuous-frame/capture.mjs`。

本场景消费 [Mote 共同框架与页面职责](../../../../../docs/design/presentation/motes-and-coordination.md#共同框架与页面职责)及[合作资料与工作入口](../../../../../docs/design/behavior/motes-and-coordination.md#合作资料与工作入口)。复用已有 `mote-cooperation` 完整 App bootstrap，仅补本轮 Profile 的准确原 Files resource/path、已保存行为、确认目录、空 Goal 与安排的有限公开 API 数据。产品 App、Store、原框架、内容组件、共享 Modal/Portal、文件解析和全部 CSS 不作替换。

实际 Chromium 点击 Open in Space，再依次切 Profile、Ideas、Calendar，打开并关闭团队；切至 640px 长名和浅色，最后引入明确的资料/成员观察 unknown。每次采图都核对全部原 Region/Session、原 Run 引用及原未发送草稿；读取和导航无 submit/write/launch/stop/respond。团队只含该 Mote 的两个原成员。

八张完整图包含正常 Profile/Ideas/Calendar、协作浮层、窄窗长名 Ideas/Profile、浅色窄窗 Calendar 和 unknown 团队。读取失败与空资料保持区别；Ideas 的空笔记不铺两份空态。正常 Profile 数据为明确的合成已保存偏好，不声称真人偏好或模型采用。

产物写入 ignored `.bagakit/mote-frame-rethink/frame-ui/capture-<id>/`，包括源码/编译 hash、真实操作、完整 PNG、receipt 和 review 入口。代码变化后重新采图；采集仅标 `captureOnly`，独立 Agent 实际完整看图并明确可交付才算图审通过。本场景不证明连续主对话、工作事件关联、心跳、真实 Provider/CLI/模型、跨 Host、用户原 Session 生命周期或安装交付；这些由各 owning Task 验收，不能以此代签。
