# README elements

Inline marks read like GitHub: press <kbd>Ctrl</kbd> + <kbd>K</kbd>, write H<sub>2</sub>O and x<sup>2</sup>, keep <mark>one highlight</mark>, and <ins>insert</ins> or <del>remove</del> text.

> [!TIP]
> Open a Topic from any Region with the same shortcut.

> [!IMPORTANT]
> Promotion keeps the original agents and their history.

> [!WARNING]
> Closing a worktree retains its directory until every Session leaves it.

> [!CAUTION]
> Deleting a Space removes only its presentation; Sessions keep running.
