# Mesh homepage and cluster machines

This fixture mounts production SettingsPanel, MeshSettingsPane, path explorer, machine rows and themes in a private Electron window. Network and physical samples in entry.tsx are controlled observations, not live devices, actual Farm deployment or proof of networking. Behavioral tests independently join production UI/Main/original Core/Native and public CLI.

Review the default Overview with the map, local and advertised gateways, saved targets and the machine resource table visible on one page; exercise the Mesh children in the sidebar and narrow Settings picker. Compare the open graph, compact actions, shared directory selection and selected inspector directly against the user's home-net-console image. Cover wide/narrow dark/light, available endpoint and different adopted circuit, selected scope, equivalent list and exact source detail. Record before/during/after frames of real private-browser pointer input through ReactFlow, and a short window. Capture the disabled world-map state with saved targets and the machine table accessible. Machines covers mixed private/published-withheld/unavailable Hosts and its original CPU/memory/reported-volume measures. Gateway and exact original Host drafts are authored, then retained after returning through the homepage and Machines. Add device uses the existing Host creation function. No user App, Session or Run is operated; screenshot values remain controlled observations, not live Farm telemetry.

Read docs/design/behavior/mesh.md and docs/design/presentation/settings-and-observation.md#mesh-网络工作面. The capture script is capture-only. Independent review must open every complete PNG, compare actual object/task/readability against the user's two reference images, and state limits before approval. Screenshot success is not aesthetic approval.
