# Mesh paths and cluster machines

This fixture mounts production SettingsPanel, MeshSettingsPane, path explorer, resource cards and themes in a private Electron window. Network and physical samples in entry.tsx are controlled observations, not live devices, actual Farm deployment or proof of networking. Behavioral tests independently join production UI/Main/original Core/Native and public CLI.

Review wide/narrow dark/light paths, available endpoint and different adopted circuit, selected scope, equivalent list and exact source detail. Machines covers mixed private/published-withheld/unavailable Hosts, two compatible counters, CPU/memory/reported storage volume, status filtering and source details. Gateway draft is authored and retained after Machines/Paths switching; original Connection writer is not modified here. No animation or installed-App mutation is introduced by this fixture.

Read docs/design/behavior/mesh.md and docs/design/presentation/settings-and-observation.md#mesh-网络工作面. The capture script is capture-only. Independent review must open every complete PNG, compare actual object/task/readability against the user's two reference images, and state limits before approval. Screenshot success is not aesthetic approval.
