# Bounded task Native scope

Run `verify-browser-task-bounded-native.mjs --candidate <published-main-commit> --out <owned-evidence-directory>` from the repository. It consumes immutable Main Source, existing dependencies and a private stock Electron profile; it neither builds the Desktop product nor changes the user's application, Runtime or clipboard.

The first hidden, unfocused process exercises two item batches through the actual typed control socket on two generic form shapes, forward URL/element conditions with true/false/unknown results, and Agent Continue refusal plus Stop at original human checkpoints. The original Main task owner, runner, SDK, journal and native WebContents perform the actions. Fresh invocation values stay outside durable task assets. The two sequential private processes preserve the same Browser/profile, Main state, public state and page results without automatic replay. Public typed run fields intentionally exclude Main-owned human approval facts; compare each representation with its own actual predecessor.

Original WebContents PNGs, exact compiled Source bytes, process reports and durable files accompany the receipt. Independent review must inspect the actual images; DOM facts or capture success alone do not prove pixels. The 30 MiB bound applies to the owned temporary Source closure, bundle and profile. All failures are retained before that private directory is removed.

This is private Main/page/profile evidence. It does not test complete Desktop Tab/Region/keyboard focus recovery, a real healthy Core Run, physical human input, operating-system window capture or a positive trusted human approval. The 120 second hard-limit exhaustion remains a Source clock/host-boundary test; these short real actions only verify actual elapsed costs stay within that budget. The formal batch/branch receipt commands return pending after consuming a valid private proof. A complete Desktop adapter requires real external producer evidence, never manually filled success flags.
