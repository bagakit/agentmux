# Host identity capture

Run `node apps/desktop/scripts/capture-host-identity.mjs` from this isolated worktree.
Evidence goes to `.tmp/host-identity/<capture-id>/`; capture never signs aesthetic acceptance.

Owning constraints: [shared host identity](../../../../../docs/design/presentation/spaces-and-layout.md#共享机器身份标识), [Focus presentation](../../../../../docs/design/presentation/focus-context.md), [independent visual review](../../../../../docs/guides/agent-visual-e2e-review.md).

Actual production GlobalFocusSurface (including FocusProjectLanes) is rendered at 1280 and 640 CSS px. WorkspaceSidebar (including ProjectGroupsTree) is rendered at the existing 300px rail width in 1280px and 640px windows, including mixed-host Folders section headings. TopRowLeadingChrome/TopBreadcrumb is rendered for local, SSH, unconfigured and long-name hosts. The local breadcrumb omits a redundant machine badge; the other three retain the original Host ID in the accessible name and distinguish unknown configuration from SSH. Local and SSH configuration labels both read Studio; a third host is deliberately not configured. Long branch and machine names exercise truncation. Native Electron captures the complete viewport after fonts and paint settle; capture.json records visible host identities and accessible descriptions.

Production CSS is imported unchanged. Only data and outer mounting containers belong to this fixture; no host markup or styling is reproduced. Store state and the production web-preview API supply synthetic config, sessions and icons. No App.initialize, user profile, Main IPC, SSH, real CLI, PTY or Run is used. Runtime mutation API calls are rejected within this private preview. This does not prove full App navigation, real session lifecycle, native menu tooltip display, actual Header/cwd preservation or performance. Those require their owning evidence.

Source proof: `node apps/desktop/scripts/verify-host-identity.mjs --source-only` mounts the actual HostBadge, Focus, breadcrumb, Group and Folder consumers and kills nine identity mutations, including wrong configuration identity, display Host substituted for execution Host, hidden unknowns and an opaque breadcrumb label. Four discovered production HostBadge callers remain after the unreachable Board is removed. Source proof and independent image review retain their distinct boundaries; capture does not claim a retired toolbar's Refresh or pixel-width assertion as current product behavior.
