# Settings action buttons

Owning presentation: [Settings action buttons](../../../../../docs/design/presentation/settings-and-observation.md#动作按钮) and [shared controls](../../../../../docs/design/presentation/shared-rules.md#控件语言).

Run `pnpm --filter @agentmux/desktop verify:settings-actions`. The command prints a receipt with complete screenshots from the actual SettingsPanel and original page components. Compilation, Electron data and mutated styles are private and removed after the run. It does not install or package the application.

The product scenario edits My Profile, visits another section, returns to the retained draft, saves through a pending result, receives a controlled error, and retries successfully. It opens Mobile device records, copies the exact fingerprint, and revokes only the displayed fixture device. Appearance compares secondary cancellation with the dangerous theme-removal confirmation. Toolkit and Discord consume their real footer/refresh controls. Hosts waits during both the original precheck and checked upgrade without changing the action's presentation role.

Configuration, clipboard, device, toolkit and upgrade ports are controlled preview data. Discord deliberately exercises an unavailable transport and its retained refresh/recovery surface. These results do not prove remote deployment, live device access, platform authorization or Runtime continuity. Shift-Tab checks the actual focus target; Electron injected input does not establish human input modality, so the focus screenshot explicitly forces Chromium's `focus-visible` state on that same node to inspect the actual CSS.

The verifier mutates the original emitted Settings stylesheet for scale, disabled appearance and focus spacing, and recompiles the actual HostUpgradePanel with the previous busy-role branch. Each mutant must fail its corresponding consumer assertion. Screenshot capture and green assertions do not constitute aesthetic approval: an independent reviewer must open the complete light/dark and wide/compact PNGs, assess hierarchy, legibility, alignment and visual quality, and record any corrections against the same candidate.
