Owning contract: [module icon identity](../../../../../docs/design/presentation/settings-and-observation.md#模块图标身份) and [standard icon integration](../../../../../docs/guides/semantic-icons.md).

The probe renders the actual SettingsPanel, compiled contributions, original Profile editor and shared theme runtime in private Electron. Existing preview configuration/API ports provide a controlled workspace; no live Session, device, deployment or installed-app qualification is claimed.

Compare all 27 destinations in the real sidebar and Overview, including its original three shortcuts and the lower channel/Mote groups. Capture complete viewport segments in light/dark and wide/332px windows. Search uses the original input and module links; individual field rows keep their original icons. Open the original narrow menu, show independent selected and keyboard-focused entries, scroll to channel brands and choose a destination. Edit Profile before navigating and verify that its original draft remains.

Apply glyph and bounded paths through the original previewTheme owner to the exact Capsule semantic ID; compare the adjacent Browser identity and original Lark/Discord artwork, then restore. This qualifies actual icon projection, not the theme editor save workflow. Reassign original recovery binding, remove the real Search icon, or remove the real narrow-menu icon in Vite source transforms; each must fail its corresponding product assertion, not compile or process startup.

Complete PNGs require independent actual image review. Source and private runtime receipts bind the candidate. Private profiles and compiled bundles are removed; necessary PNGs and receipts remain local.
