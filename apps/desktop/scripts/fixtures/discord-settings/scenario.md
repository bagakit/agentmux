# Discord Settings

Use the actual SettingsPanel contribution and production editor/styles. Select Discord from Conversation Channels, connect a bot, type an Application ID and a masked Bot token, save once, explicitly check the native connection, read channel setup guidance, and inspect a failed credential check while the independent live connection remains confirmed. Capture full wide and narrow windows, keeping the exact application, check result, primary action and recovery readable.

This private preview supplies controlled typed DTOs and never sends a live token or changes a platform permission. The separate mounted Settings consumer crosses trusted IPC, the real Core service, the credential vault, native Discord SDK REST/Gateway I/O and original Core input. The owning behavior and presentation are the external application and Conversation Channels sections of `docs/design/behavior/settings-and-observation.md` and `docs/design/presentation/settings-and-observation.md`.

Capture success is not aesthetic approval. An independent Agent must open all complete images, judge clarity, density, hierarchy and narrow layout, then request corrections or explicitly approve the actual candidate.
