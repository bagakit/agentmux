# Native Profile environment

`node apps/desktop/scripts/verify-browser-profile-environment.mjs --scope` uses the
current worktree's production Profile manager, session environment owner, native
page application, CDP connection and BrowserViewManager. A real compiled CLI calls
the private public RPC endpoint. It checks current-page configuration, original
input and Viewport, the independent website location permission, new documents,
later navigation, an unaffected sibling Profile, DevTools coexistence and actual
detach, clearing with another native consumer, responsive screen settings, and a
real process restart with the same saved Profile and Browser identities.

`--scope --mutations` compiles the actual locale and screen application omissions
into separate private candidates. Each must fail its native business assertion;
the restored candidate must pass. `--scope --screen-and-release-proof` bounds a
follow-up to the screen mutation and restored current-page/native release proof:
a second program lease retains its clean page, while the sole background
environment lease permits release and restoration of that original Browser.
`--scope --cold-target` isolates original new-target initialization and reports its
actual application scope. These bounded scenes do not claim the full scenario.

Without `--scope`, the retained session-default scenario checks public edits,
request headers, a failed native session setter's Profile-scoped service notice,
retry, release/restore and restart. Its warning mutation must fail the real public
target assertion rather than a source-symbol check.

All scenes use a private Electron application and explicit private owner paths;
they do not change `HOME`, the installed app, a user Profile or an Agent Run.
The verifier records the actual engine/caller binaries, source and loaded bundle
hashes, original process exit and remaining-process observations. A timeout,
interruption or missing observation is unknown, not a successful mutation.
Native field ACKs do not certify first-script, subdocument or Worker consistency;
their actual observations remain separate from the explicit unknown scopes.
