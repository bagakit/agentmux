# 本地 Toolkit 扩展包工作面

需求来自设置/Toolkit owning SSOT。同一级 Custom/Built-in列表，包文件提供身份/源码，设置只保存参数/显示偏好。

私有 Electron普通进程加载实际完整CSS、ToolkitSettingsPane和原ConfigOwner/Store。读取真实manifest/script；可信点击包详情、源码、参数保存、Built-in与窄屏返回，刷新改为不相关用途后的真实文件身份。第二普通进程读取原保存偏好和原文件，证明不会重新预装覆盖。六张完整宽窄深浅截图留本机并交独立Agent实际打开评审。

不运行Auth查询、不修改用户App或Run，不打包；Core/CLI真实执行由同Feature独立auth-gate提供。这个组件与配置场景不能替代整产品或用户安装事实。
