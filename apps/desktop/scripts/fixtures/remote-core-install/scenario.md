# First remote Core installation
Run `node apps/desktop/scripts/capture-remote-core-install.mjs`.

Uses production SettingsPanel → HostSettingsPane → HostCorePanel → HostInstallPanel and the shared theme.
Controlled Host and install DTOs do not prove SSH or real installation. No user Session is changed.
At normal and narrow widths, explicitly check installation, review the machine and startup choices,
select the user service, confirm, observe a running stage, then completion. Separately retain an unknown original operation.
Review full images for hierarchy, selected radio clarity, path wrapping, steps, status and next action.
Behavior and presentation: docs/design/behavior/remote-management.md and docs/design/presentation/settings-and-observation.md.
