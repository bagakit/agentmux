# Quick switch consumer

Actual `QuickSwitcher`, `QuickOpenFiles`, typed index, Store, shared mode control, Desktop stylesheet and theme in one private Electron Renderer. Native config and file discovery use controlled preview IO; this does not operate the installed App, user Sessions or Runtime.

Open the original overlay, move the keyboard-active row, switch into project files, filter and show empty results, cancel back to the retained draft. Capture full wide/dark and narrow/light views. Check exact Browser/File/Git/Launcher glyphs, current-option IDs, readable empty copy, row overflow, mode layout and reduced-motion behavior. The owning consumer suite separately proves ranking, IME, original navigation targets, request count and closed/file-mode cost.

Rules: `docs/design/presentation/shared-rules.md` (controls, motion, focus and density), `docs/design/presentation/session-recovery.md` (quick switch), `docs/design/behavior/shared-rules.md` (independent image review). Capture is not aesthetic approval.
