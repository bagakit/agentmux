# Agent collaboration source capture

Run `node apps/desktop/scripts/capture-agent-collaboration-graph.mjs --evidence <new private directory>` from the repository root. Keep previous captures; the directory must be empty.

This scene loads current source App, its original initialization and Store, the Focus and Space entries, Graph, shared Focus card and the sole window Reader host. It supplies four private synthetic Sessions through the typed platform snapshot and original spatial API before initialization: two Agents in one Project's root/worktree, one in a classified Topic, and one in a Mote. The Mote also has a confirmed binding to the worktree Zone, so one original Agent appears in two areas. Original protocol parsers validate event and conversation pages. Only unrelated PTY and unused Monaco painting are isolated. It does not launch a Provider, send or consume a real message, control a user Run, build a package, install an app or prove native recovery.

The native Electron scene exercises direct and broader scope, same-area communication in both directions, cross-area communication, creation and supervision, original card hover, keyboard reading and focus return, separate Open workface, relation filters, explicit body disclosure, source failure and Retry, finite live pulses, catch-up without pulses, actual Focus departure and canceled reading, dark/light and narrow presentation. A separate native window records visibility capability through show/hide/minimize; it does not prove the same Graph window's hidden behavior. Document-visibility inputs are verified by component tests. Original drafts, selection and workface identities are checked across read-only operations. Path samples check nonempty actual SVG geometry against card interiors; they do not judge visual quality.

Space checks use the original focus control action to reach each accurate object, then real pointer input to open its attached Graph. They verify the Project root/worktree union, one read per original participant across overlapping areas, folded internal relation IDs without a false self-edge, the opening choice retained after later navigation, the same Mote observed from its home and linked worktree position, and Category membership from its original Topic binding. Scope checks preserve the original Tabs, layouts, drafts, execution focus and opening selection; explicit navigation is checked separately from read-only viewing.

Receipt hashes bind product inputs, capture inputs, compiled assets and complete screenshots. Source compilation and native capture have independent finite process boundaries; `compilation.json` and `actual.json` preserve the last observed phase when a process cannot complete. A changing candidate or failed interaction remains a failed capture with its original evidence. The capture reports `aestheticReview: not-performed`; another Agent must open the complete frames and review the actual scene under the [independent visual review contract](../../../../../docs/guides/agent-visual-e2e-review.md). Behavior and presentation remain owned by the existing [A2A collaboration](../../../../../docs/design/behavior/a2a-collaboration.md) and [capability presentation](../../../../../docs/design/presentation/agent-capabilities-and-messaging.md) SSOTs.
