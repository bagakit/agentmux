CSS imports need their own actual reader proof: Vite's PostCSS import loader reads files directly and does not pass imported sheets through the ordinary Vite `load` hook. The bounded CSS overlay writes only the changed, import-free, asset-URL-free CSS leaves into the invocation's private root and redirects their import nodes with the original PostCSS AST/parser and Vite resolver. It never overwrites shared source files or alters declarations. Unsupported leaves fail qualification instead of guessing asset rebasing. A PostCSS `OnceExit` observer binds actual `input.css` bytes to the original Git digest and requires the private mirror reader; a stored blob or an emitted CSS filename alone is not proof. `cssSourceProof.loaded/rewrites/outputs` preserves this join, including actual emitted packet/disclosure rules and keyframes.

This is a compiler preflight, not Native motion or rendering-cost qualification. The original Focus baseline additionally checks the actual first Native packet animation name against emitted original CSS, original circle duration, and native offset-distance progress before continuing the matrix. Historical captures without this actual CSS-reader join are not qualified original-CSS cost baselines.

Observer and tracing costs are declared, partly measured and never subtracted.
