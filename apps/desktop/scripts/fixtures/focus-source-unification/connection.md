# Original source connection recovery

Run `node apps/desktop/scripts/capture-focus-source-unification.mjs --evidence <private-directory> --source-connection` from the repository root.

This scene exercises the real App, Focus, shared Source readers, retained projection and service notice. Only original Host transport/events and terminal painting are controlled preview leaves; it does not operate a user Run, install an App or establish a historical incident cause.

The scene first reads an original project, then ends its two observation streams. Only one existing Recent Focus control signals the retained source issue. Open it, publish that Host's ready event while holding its replacement reads, and release the real renderer read receipts. The original tasks and drafts stay available during recovery.

Next deliver unsupported Agent location lookup replies from two Hosts and a timeout from a third. Use the single toolbar hint to select a Host and verify its actual Core settings panel. Dismiss the hint while the chooser is open and verify the text and menu close, focus returns to the shortcut, and a reread of the same Runtime keeps the hint collapsed. The timeout keeps its existing scoped check. Confirmed lookup clears the corresponding upgrade shortcut. Review the wide dark toolbar, chooser, settings destination and dismissed state, along with the narrow light toolbar before and after dismissal.

The companion Focus source unification test drives the actual RPC failure through Main and Desktop IPC and distinguishes a missing location method from a missing identity method. Set `AGENTMUX_FOCUS_SOURCE_MUTATION=ignore-core-update-dismissal` to check that the Electron scene rejects a hint that cannot be dismissed. Set `AGENTMUX_FOCUS_SOURCE_MUTATION=omit-location-issues` to check that the scene detects an omitted source indicator.

The collector checks original Run references and drafts before/after and records loaded source identities and cleanup. Independent review must open the complete frames and judge hierarchy, density, wrapping and reachable recovery. Capture success alone is not visual approval.
