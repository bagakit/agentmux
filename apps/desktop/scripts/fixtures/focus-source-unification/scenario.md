## Original Session observation states

Run the same entry with `--member-state` to follow an unavailable original task from its actual ordinary Focus card into the shared Region stage. The controlled original Source delivers an authority-qualified `missing`, then real `pending` after the visible Check again action; a source IO error changes pending to parked, another check clears that error, and the exact same original target returns as observed. There is no create, resume, restart or input port in the scene.

This mode retains a one-Agent original Tab so the connecting state is readable independently of another resource. It captures an empty-draft missing stage, the original nonempty private draft at wide/narrow dark/light sizes, actual pending, stationary check failure and the returned original member workface. The draft is entered through the actual textarea and original Store action, is never auto-sent, and remains in its existing owner. The controlled typed Source delivery is only the IO leaf; App/Global/cards/selection/Workbench/state primitive/refresh/UI persistence remain production. It is not proof of a remote network failure, native semantic recovery, restart continuity or user installation.
