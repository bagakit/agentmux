Use `--unconfirmed` to capture two original positions with the same Agent reference but no confirmed execution identity in the common list, at wide and narrow sizes in both themes. Their identifiers are source references, not recovered names or proof of Runtime ownership.

It does not start a real CLI, install the app, mutate a user workspace, or prove native recovery. That original Source Tab contains both the Agent and a Browser Region; primary selection must preserve both and keep Focus open. Every Agent must reside in an ordinary project lane/card; no source-only list/grid is allowed. It checks local deduplication/name/recap, foreign same-SID isolation, document geometry, unchanged original Run/draft values and source Region membership.
