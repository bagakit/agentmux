# Agents 查找与检查工具行

相关 SSOT：交互《设置页的信息架构》与密度《Settings 控制工作面》。

命令：`node apps/desktop/scripts/verify-settings-agents-toolbar.mjs`。

真实入口：原 SettingsPanel 经原 Search settings 进入 Agents；展开原第一个 Executor，键入 Name 和 Command 草稿，再以鼠标与 Tab 到原 Filter executors。分别使用原短 Host 和普通长 Host 标签，在320／420／640／1480输入、清除同一短查询，按原生 select 切 Host，点击原 Refresh，最后明确 Save、关闭与status入口重开。

观察：窄正文主查找有完整一行，长Host检查范围与Refresh下一行、宽正文同排；短Host按实际可用空间自然排列。输入完整可读，工具组与保存栏清楚；正文和32px底栏不互遮。实际稳定editor／draft／focus与原检测target另由行为断言检查。独立评审逐张打开control目录16张完整PNG，不能以几何或采图成功代替判断。

这是原Preview API与真实产品Renderer/CSS的受控场景。检测结果是Preview事实，Host标签准备沿原Preview config owner，既有空工作面未模拟健康Run；没有真实CLI、远端Runtime、Core构建、重启或安装结论。日志与两个actual CSS source bundle AssertionError／exactrestore留同轮证据，captureOnly与aestheticReview原字段不改写。
