# Mote continuous dialogue

Owning requirements: docs/design/behavior/motes-and-coordination.md and docs/design/presentation/motes-and-coordination.md.

The private full production App uses the existing original conversation projector and native reader. Finite public ports describe one original main, a subsequent main role, two sourced work events, a paused heartbeat and an unavailable source history. Trusted Chromium navigation opens the same work thread and event history, checks settings, switches to the new main, then retains the prior source through an unknown read. Every unsent draft, original workface/Run identity and zero input/lifecycle effects are checked.

This proves actual Renderer consumers against controlled protocol records. It neither operates user Agents nor proves live Providers/Host maintenance. Source, compiled identity, complete PNGs and controls are in the capture receipt; capture success does not sign aesthetic review.
