# Mote collaborator directory visual scene

The original App, WorkspaceSidebar, SpaceTopicsTree, SettingsPanel and floating
workbench consume current production Source. Run `node
apps/desktop/scripts/fixtures/mote-collaborator-directory/capture-directory.mjs`.

The scene has five active original Motes, one archived Mote, a pinned long name,
the original primary dragon, saved face variants and an unsent Launcher draft.
Capture both directory views at 1180 and 720 CSS pixels, in light and dark themes.
Use Chromium mouse input to reveal archived objects, open the original object's
More menu, select and save the list preference, and open the floating roster.
Keep the original selection and draft. Inspect every complete PNG independently.

The private Renderer uses controlled filesystem replies and no Executor. It
proves original UI consumption and input targeting, not a model, live Runtime,
native lifecycle, installed user app or packaging. The floating shot may use
the original entry click; it does not qualify hover. Compiled output is removed
after capture, while raw images and receipts remain for review.

Behavior and presentation belong to the Space collaborator-directory sections
in `docs/design/behavior/motes-and-coordination.md` and
`docs/design/presentation/motes-and-coordination.md`. Test receipts prove the
original durable config/CLI owner and archive/navigation semantics separately.
