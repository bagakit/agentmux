# Mote collaborator directory visual scene

The original App, WorkspaceSidebar, SpaceTopicsTree, SettingsPanel and floating
workbench consume current production Source. Run `node
apps/desktop/scripts/fixtures/mote-collaborator-directory/capture-directory.mjs`.

The scene has five active original Motes, one archived Mote, a pinned long name,
the original primary dragon, saved face variants and an unsent Launcher draft.
It projects a Club with mixed waiting, failed and working Agents alongside
single working, failed and unobserved cases. Capture both directory views at
1180 and 720 CSS pixels, with 252 and 180 pixel sidebars respectively. Theme
changes go through the App's appearance selection and the capture checks the
rendered light and dark color schemes and palette.

Use Chromium mouse input to inspect the original Agent Activity menu from each
directory view, reveal archived objects, open the original object's More menu,
select and save the list preference, and open the floating roster. Keep the
original selection, draft and Run references. Inspect the complete PNGs
independently.

The private Renderer uses controlled directory and Agent observations without
an Executor. It proves original UI consumption and input targeting. A live
Runtime, native lifecycle, installed user app and packaging each need their own
evidence. The floating shot exercises the original entry click. Compiled output
is removed after capture, while raw images and receipts remain for review.

Behavior and presentation belong to the Space collaborator-directory sections
in `docs/design/behavior/motes-and-coordination.md` and
`docs/design/presentation/motes-and-coordination.md`. Test receipts prove the
original durable config/CLI owner and archive/navigation semantics separately.
