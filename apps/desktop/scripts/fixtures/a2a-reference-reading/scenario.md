# A2A reference reading in production components

`captureA2aReferenceReading({ root, evidence })` uses the existing primary-reading capture engine. It compiles the current `ActivityView`, `SessionMailbox`, shared message components and product styles into one private Renderer. It does not build or copy Desktop. The focused primary-reading exporter supplies notification, message and native/captured contribution DTOs from the real private journal and public Core Reader. Renderer transport is a controlled API leaf.

The original seven faces remain: Conversation at wide/narrow widths in dark/light themes, followed by Inputs, the selected Inbox original and the selected Outbox original. Conversation opens directly on two independent right-side Agent originals, with the platform notification folded below. Native pointer and keyboard actions exercise exact original-body Copy, notification-wire Copy, source JSON disclosure and Inbox-body Copy. A failed original read retains the other sender; Retry targets the same original Host, receiving Session and MID while preserving an unsent draft and its focus. Measured sender identity and notification timing rectangles must not overlap.

Inputs mounts the real `SessionMailbox` input inventory projection with controlled valid human, unknown and typed-platform items. The codec validates this page before the product projects it; human and unknown originals remain, while the typed platform input is excluded. This is a controlled inventory projection, not a claim that live Provider histories were read. Inbox and Outbox consume the same original message objects, preserving body and notification status separately. Reading never invokes the guarded input or notification API leaves. Clipboard writes stop at the private in-memory adapter; no system clipboard is read or written.

The capture receipt records actually consumed source identities, exact frames, operations, controlled-data boundaries and private process cleanup. It does not establish installed-App operation, live-model adoption or durable Session recovery. The public CLI and registered preload/IPC/Main/Core bridge remain separate focused proofs. Independent review must actually open the seven complete images under the [conversation behavior](../../../../../docs/design/behavior/conversation-mode.md#a2a-引用通知中的原信阅读), [presentation contract](../../../../../docs/design/presentation/conversation-mode.md) and [visual review guide](../../../../../docs/guides/agent-visual-e2e-review.md); capture success is not aesthetic approval.

For the specific identity/timing regression, `styleMutation: 'timing-fixed-row'` (or `AGENTMUX_A2A_REFERENCE_STYLE_MUTATION=timing-fixed-row`) changes only the actual product stylesheet's timing grid row from `auto` to `2` during PostCSS. The unchanged native scene must reject that compiler input with its nonoverlap assertion. Shared source files remain unchanged, and a mutated capture cannot serve as ordinary acceptance evidence.
