# Desktop Agent location entry capture

Run `node apps/desktop/scripts/fixtures/agent-locations/capture-ui.mjs` to capture the actual GlobalFocusSurface, WorkspaceAgentRow and AgentRoster location buttons, original Store navigation and QuickSwitcher in a private Electron Renderer. The maintained typed preview spatial API accepts the original desktopSpatialGraph, then Store.initialize observes and projects that owner; no source-known resolver is overridden.

Real mouse and keyboard events open all three entries, select keyboard-active candidates, cancel and retain a stale highlighted target after its original Region is rebound through the same typed spatial owner. Fourteen full frames cover wide/narrow, dark/light, short viewport, zero/one/many, same-name Tabs, multiple Regions, Space alias contexts, an opening intermediate frame and reduced motion. Initialization first observes a valid unbound graph, then the existing controlled Sessions receive their display bindings through that owner; the fixture does not ask startup recovery to execute. The original private draft and Store Session/Run references remain intact; lifecycle and input methods fail this fixture if invoked.

Controlled discovery and spatial facts are not a real Runtime, durable recovery, installed application or a human workface. Source and style hashes, compiled identity, private-process cleanup and PNG receipts accompany the captures. An independent Agent must view and review the complete images; capture success alone is not aesthetic approval. Root separately verifies a new installed application process, public app.inspect and original Run preservation.
