# 图标语义工作台

长期开发入口，从仓库根目录运行：

```sh
pnpm icons:dev
```

打开输出的 `http://127.0.0.1:4186/` 即可预览当前源码。修改目录、字形、共享呈现或消费源码会自动刷新，沿原语义 ID 恢复草稿；存储失败时保留内存修改并提示先导出。`--open` 可打开系统浏览器，`--port` 可指定端口（占用时不自动漂移），`--context` 仅提供旧注释；`--help` 查看入口。进程停止后该开发 URL 暂不可用，重新运行同一命令即可继续。

开发使用和扩展步骤见[语义图标指南](../../../../docs/guides/semantic-icons.md)。`catalog.mjs` 的 `createReviewCatalog` 同时供开发服务和静态构建投影当前共享 owner；Vite 加载原生预览与主题运行时，不维护第二目录。

构建可分享的静态快照：

```sh
pnpm icons:build
```

指定输出路径：

```sh
node apps/desktop/scripts/icon-review/build.mjs --out .local/icon-review/site
```

静态浏览器构建显式固定生产 `NODE_ENV`，让 React 的 JSX runtime 不依赖 Node 全局变量；不在页面注入 `process`。发布前执行真实产物的无 Node 启动回归，并在发布地址实际核对目录就绪和交互，资源请求成功不能替代页面启动。

构建消费共享 `getSemanticIconCatalog`，页面使用 `createSemanticIconElement`、共享 sprite、根主题 runtime 和原主题文件 schema。生成文件留本机，用 Pageville 原 `agentmux-icon-matrix` 页面身份发布新版本。

可选 `--context <先前 catalog.json>` 只保留同语义 ID 的中文审阅说明；图形、默认映射、目录与当前引用重新取自源码。静态引用是审阅线索，不证明某一 Run 状态或全部动态消费。

页面草稿仍用 `agentmux.icon-review.v1`：修改包保存用途、备注和历史，完整主题导出用于 Settings 导入。预览只作用在演示页，不写入产品配置。

实例模拟提供共享 `animation` 预设与颜色参数，默认静态。它只改变上方样例：基础五组之外，按共享设计补充所选预设的适用用途。目录、标题和历史保持静态；模拟参数不保存进草稿或主题文件。动效样式直接复制共享 owner，遵循系统减少动画设置。

“静止与动效”从共享 `AUTHORED_ICON_DESIGNS` 自动列出全部项目自绘，包括尚无语义用途的图形。可搜索名称、设计说明或用途；选择后查看 12/16/24px 静止轮廓与同源动效设计。仅所选图形播放：循环可暂停，单次反馈可重播，关闭预览即停止。保持静止的图形说明原因，不强行加动画。

预览将“目录原图”与“当前主题与草稿”分开：目录演示复用原可信几何、部位及共享样式；真实语义用途使用原 native 主题投影，可跳回用途编辑。演示不会替换用户选用的 glyph/paths，也不表示业务动作已发生。选择、播放、暂停与重播只保留在内存，不调用草稿保存，不改变修改记录、主题文件或存储 key。

工作台以图标概览、用途矩阵、自绘与动效、Mote 交互和设计储备组织同一入口；实例参数实验默认收起，给目录留出空间。当前视图保存在 URL fragment，源码刷新后仍可回到相同视图。Mote 演示挂载原 `MoteIcon` 和 `observeMoteMotion`，离开视图即释放；主题明确覆盖的图形与路径沿原解析保持。已绑定自绘的动态演示通过真实语义投影呈现当前主题，包括书写图标的局部模型。

`future-designs.json` 只保存尚未采用的设计草案与定义来源，不属于产品图形库，不进入选择器或主题文件。采用草案须另沿真实语义、消费者及验收流程推进；工作台中的拟议 ID 不是已注册语义。
