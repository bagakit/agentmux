## 更新与保全

新约束原位合入所属专题，同一事实只定义一次，其他正文链接到 owner。入口只维护主题导航，不按日期、Task 或聊天轮次追加完整需求。

修改时同步受影响引用，保留原要求的权限、恢复、健康 Run、工作面、相关成本及交付责任；纯文档证据不替代产品行为验收。过程资料只留本机，其 Git 与留存边界见 [过程目录](../process-directories.md)。
