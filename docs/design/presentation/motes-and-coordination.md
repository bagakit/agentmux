# Mote 与协调面的呈现

本文定义 Mote 作为持久工作搭档的视觉目标、阅读节奏与交互表达。行为、身份、操作资格和恢复由[同主题交互](../behavior/motes-and-coordination.md)持有；呈现目标不代签当前实现、安装或视觉验收。

## Profile 中的飞书聊天

Profile 将飞书聊天作为直接可见的小分区，先展示开关和准确机器人，再展示“会话更新时间”及带单位的输入、陌生人默认额度和按人分配。说明贴近字段，用一句话解释空闲后下一条消息新开对话；保存区显示未保存、保存中、已保存、冲突或未确认，查询与保存保持内容和焦点稳定，进行中使用有含义的局部进度，不闪烁替换整块内容。

机器人选择以名称、App ID 和原初始化状态区分同名应用；已保存但不可用的引用仍可辨认和管理。全局同步暂停单独呈现，不遮盖身份问题，也不将聊天开关打开画成已送达。用户列表以人和使用情况为主，创建者明确标明，其他人使用“已用／总额度”和剩余说明；姓名无法取得时保准确平台身份与未确认说明，额度编辑和原目标相邻。宽窗保持紧凑对齐，窄窗按同一阅读顺序换行；使用原设置控件、正文与间距语言，不为每个参数增加大卡片。业务身份、额度与会话边界只由[飞书私聊与会话更新](../behavior/motes-and-coordination.md#飞书私聊与会话更新)定义。

私聊活动与配置编辑分区，先用短句说明最近消息是否到达、卡在哪一步，再提供查看原对话的动作。历史以人、最后活动和准确会话为主体，技术标识按需展开；准备完成不使用暗示已回答的成功状态。首次读取使用局部进度，刷新时保留旧内容，空记录与读取失败分开。原输入详情中的“停止等待”紧邻该条等待说明，结果说清影响；不提供重建机器人或无条件重发作为恢复入口。

## 伙伴从哪里来：用户故事板与教程 Banner

Mote 设置中的教程 Banner 用三幕故事说明伙伴如何建立。产品路径和晋升结果只由[《伙伴从哪里来》](../behavior/companions-from-work.md)定义；本节负责让组织层与成员层同时可见。前一幕是一条独立的画像创建路径，后两幕是从 Topic 工作到 Mote 的成长路径，排版不能把三幕画成每个用户必须依次完成的升级流程。

| 幕 | 用户处境与画面 | 短文案方向 | 必须读出的关系 |
| --- | --- | --- | --- |
| 按画像建立 Mote | 用户已有明确专家需求；外层呈现 Mote 的团队名字与人格标识，内部 Agent 带着不同工作工具共同处理事情。 | 带着专长，开始合作。 | Mote 是团队的持久身份，Agent 是实际成员；专家画像不是单个模型或一次会话。 |
| 在 Topic 中开始做事 | 一个清楚的工作方向包围日常任务、笔记与成果；内部 Agent 从具体小任务开始，有可辨的工作动作和逐渐形成的分工。 | 从每天一起做的一件事开始。 | Topic 内已有 Agent 与积累，尚未建立 Mote 人格也可以真实工作。 |
| 将 Topic 晋升为 Mote | 保留上一幕可辨的成员、笔记和成果，新建立的团队人格与名称包围同一份工作；成员继续专业工作或协调合作。 | 让重要的方向，成为长期伙伴。 | 改变的是组织身份与长期责任；原成员及积累连续，成员成长仍可被看见。 |

| 画像创建：按画像建立 Mote | 从事情成长：在 Topic 中开始 | 从事情成长：晋升为 Mote |
| --- | --- | --- |
| ![专家画像引入团队，Mote 标识下有三位分工的 Agent](../../../apps/desktop/src/renderer/src/assets/mote-origin/role-team.png) | ![开放的 Topic 工作区里，三位 Agent 处理图表、任务与笔记](../../../apps/desktop/src/renderer/src/assets/mote-origin/topic-work.png) | ![同一组 Agent 和成果延续，工作区建立 Mote 团队人格](../../../apps/desktop/src/renderer/src/assets/mote-origin/grown-team.png) |

三幕沿用当前 Mote 角色家族与原主题的形体、材质和配色语言。Mote 的形象承担团队对外的人格标识，内部 Agent 通过独立位置、动作、工具及适量标签被辨认；代表团队的形象不能被读成其中某一位成员的放大版。跨第二、三幕保留足够相同的成员特征和成果线索，让用户一眼看见延续；不同职责以正在做的事表达，不靠更多光效、体积或虚构职级证明成长。画面人数服务叙事，不成为产品人数限制。

Banner 以插图、一句标题和必要的简短说明组织，保留设置本身的阅读与操作空间。宽面能看清两条来源的关系，窄面按同一阅读顺序展开，角色、成员、成果和文案仍可辨；具体尺寸、并排或逐张呈现由实际设置预览比较后收敛。说明使用真实文字并提供等价的可访问叙述，关键信息不只藏在插图里。预览中的示意人物与成果明确属于故事，不混入用户的真实成员、运行状态或工作回执。

看图评审先回答：用户是否愿意继续了解这个伙伴；能否分别指出 Mote／Topic 与内部 Agent；能否认出画像创建与从事情成长两条路径；第三幕是否保留第二幕的人和积累。原设置的主要配置动作应仍易找到。静态教程的吸引力和可理解性通过，不代签晋升行为或真实成员能力已经交付。

## Mote 快捷入口与当前协调上下文

### 正向目标与界面层级

Mote 的气质是有辨识度、沉着、灵动而专业的持久搭档。沿 Graphite / Mint 的主题与材质，交流面让用户先认出正在合作的 Mote，再理解当前事情、阅读交流并继续输入。紧凑指动作距离短、层级清楚和有效阅读空间充足；身份感、合适留白及有目的的动态是质量的一部分。

浮窗与 Space 中的 Mote 使用同一搭档界面语言：对象导航、一个清楚的身份与当前事情区、消息阅读区、原输入。身份区用准确头像和名称建立存在感，真实短状态与当前讨论各自可辨；资料和完整工作面沿局部动作可达。Mote／讨论／实际执行者的关系由交互合同定义，头像、标题或状态不能互相冒充。

来自 Goal 巡查的准确 Agent 对话使用同一浮窗语言，具体目标与反馈只见[巡查呈现](goals-and-demand.md#执行者责任告警与巡查反馈)；不是 Mote 成员的原 Agent 仍显示自己的身份，不借主 Mote 头像、名称或名册选中态冒称归属。

快捷面沿公共 Zone／Tab／Region 工作面呈现，每个真实 Group 只有一排 Tab；选中项沿同一 Tab 控件语言明确可辨。空对象显示原初始页，不叠加讨论导航或无选中态的第二排标签。真实 Group 分割仍各自保留原工作面与导航。

共享的是原空间模型、讨论、消息、Composer、Core 生命周期与宿主能力。Mote 的交流呈现可以组合这些能力形成自己的外壳；通用 IDE 的 Tabbar、Split、Region 标签、时间尺和全部工具不因此同时成为交流首屏的固定层。进入原完整工作面后，全部 Group、Tab、Region、分屏、文件、终端和编辑能力继续可用；呈现不能删改布局或藏掉唯一恢复路径。

### 常驻入口、对象导航与状态

常驻入口是固定可记忆的 Mote 功能锚点，品牌与已选对象的边界由交互合同定义。收起、临时预览、固定展开和键盘焦点在静止画面中各自可辨：使用完整 Surface／轮廓、稳定固定标识和清楚焦点，运行状态另有自己的形状与描述。真实状态来自准确目标；头像原色和展开边界不代称 Working、在线或恢复成功。

左侧导航保宽卡片与仅头像两态及原用户偏好。头像承担身份，名称在宽态易读，在头像态可由 hover/focus 与无障碍描述完整取得。所选对象以整体 Surface 和形状表达，避免同时堆叠背景、外框、勾号来重复同一选择；非颜色线索、键盘焦点和真实状态分别保留。对象多时有界纵向滚动；所有原对象、长名称、管理和归档／恢复动作可达，读取局部失败不拿走已确认身份。

名册底部按同一操作意图组织对象管理、呈现切换和收起。零数量保持安静，读取未知保持明确；可访问名称、开关状态、按需说明和准确原动作完整。Space 的协作者／列表名册使用同一身份和用户保存的头像尺寸；可读字号遵守[字号阶梯](shared-rules.md#字号阶梯)的下限，完整名字按需可读，名称列自然省略，不以硬裁字形或缩小已保存头像凑列数。

### 消息、输入与持续状态层

明确关闭原 Tab 后的继续与空态资格沿交互合同“关闭 Tab 按明确意图继续”；同一 Mote 仍有已确认成员时，事情导航保全部原讨论及正文，不以没有当前选择冒称零成员。完整工作面的新建沿同一 Tab 组末尾的纯 + 图标动作，悬停与无障碍名称表达新建讨论，窗口可拖拽区内仍可点击；Mote 的事情呈现映射同一原 Tab／Group／Region。真正零成员的引导以一处克制原主操作、自然短说明和准确身份形成交流氛围；Profile／Open in Space 与新建各自可达，宽窄中不挤压新建与正文；未知／失败仍保原服务状态和恢复选择。

消息是交流面的主要内容。作者、时间、正文及原记录顺序清楚，准确 Mote 作者消费原持久名和头像，外来或未知作者保其真实表达。时间尺、投递受据、运行过程和 Provider／Session 详情属于按需证据；当前事情和必要动作先可读，详细检查沿原数据 owner 进入。历史阅读、Trace、结构化权限／问题与原生输入能力保持完整。

Composer 使用原草稿、附件、Send／Queue／Interrupt 和 typed response 语义。常用动作靠近输入，运行中与待回复的必要动作在对应状态可发现，其余按原意图进入工具菜单；不能为简洁丢失队列、回答、原生终端、取消资格或投递未知说明。短草稿和长文本都有完整可用宽度，作者与输入不会被 chrome 或资料栏挤成竖排。

同一 Mote 工作面有一处持续可见的服务状态层，先说哪项能力需要注意以及当前可用事实，展开后保每个原失败步骤、对象、已知受据与恢复动作。多条相关观察可以在呈现层组织为短摘要与详情，事实仍逐项来自原 owner，不合成新的健康判断。状态层可收拢但未解决事实持续可发现；用户收起详情、刷新请求已发出或动画结束都不等于恢复成功。完全健康且已确认时安静。

服务提示使用与界面一致的语言、具体能力名和短动作，例如“历史读取待核实 · 重试”，详情解释原阅读窗口保留及未知范围。操作确实被拒绝或未应用时，原因贴近该动作；权限／问题保原显式回答面。严重程度与可用能力真实对应，持续状态层不能遮住健康正文、禁用原生输入或把错误隐藏成一个无解释的小点。原始错误、技术标识和英文来源可在详情完整取得。

### Profile 与完整 Space

机器人以准确 Mote 对应的身份关系呈现为一条紧凑资料行：已选身份的可辨名称与真实简短状态为主，默认标记从属；未选择时提供创建机器人和选择已有身份，已选择时以同步资料为相关主动作，更换身份、查看原结果与进入设置按需展开。它不抢占头像／名称和当前讨论，不再铺一面凭证、权限或技术字段。同步前以本次名称、简介和原保存头像的简短预览说明目标与共享影响，缺失字段与待发布如实可辨，不用一个绿勾概括创建、保存、资料写入和线上生效。

从 Mote 进入原机器人接入工作面时，准确来源保持可辨，返回后仍是原 Profile、草稿与讨论；通用 Settings 保原导航，不嵌套第二套名片或身份管理页。正常、长名、未知与失效默认在 332px 及短屏沿单列自然展开，身份、当前说明、明确下一步和返回／关闭可达；沿原字号、控件、材质与键盘焦点语言，不缩字、堆卡片或加入常驻连接工具栏。事实和操作边界只见[机器人身份与公开资料](../behavior/motes-and-coordination.md#机器人身份与公开资料)。 扫码、核对账号和明确创建各自只突出当前原任务的一项主动作；换码／换账号为次级出口，原申请结果、完整阶段和本地恢复在同一具名详情中可达。普通查询以短、中性反馈表达，真实错误贴近当前动作，不让旧进度或泛告警遮住当前账号与下一步。

完整 Space 以 Profile、Discussion、Ideas 和 Calendar 形成稳定的共同导航，页签次序、选中形态与切换方式一致；进入资料与回到原讨论都沿这组导航，不在身份行另叠一组互相反向的长动作按钮。Profile 以可读的搭档档案建立人物感：原头像、可完整查看的名称和保存简介组成一张完整身份名片；主要阅读区先展示该 Mote 的合作资料，再接紧凑的原讨论列表、当前工作、下一步安排与原点子。讨论条目以原标题和少量可确认状态形成连续行，提供清楚的完整 Discussion 入口，不铺消息卡片或重复统计；原成员与近期事实边界见[日常合作](../behavior/motes-and-coordination.md#mote-的日常合作)。四项行为偏好用清楚的字段名称、已保存选择和具体行为说明组织，自定义补充独立可读，MBTI 风格标签从属于同一保存事实；不压成缺少字段含义的碎标签，也不将主要资料藏在工作清单之后。宽面以自然收束的身份卡和主要内容两列组织，不用少量身份信息铺满高空栏；窄面按同一阅读优先级纵向展开。原记忆直接提供按需入口，不藏在连接设置内。成果和成长由可打开的原记录表达，不铺重复任务计数、空图表、推测的能力分数或无来源的人事字段。Quick mode 的 Executor、默认讨论和恢复时机在按需偏好面编辑，主对话的固定资格和原保存事实仍可读；缺省配置保简短可达入口。明确保存、草稿、冲突、未确认与失败沿原 owner 表达。

身份名片用原主题低对比材质和一处原头像形成稳定轮廓，字号与资料行的对齐建立层级；不为人物感新增必填资料或封面配置。当前讨论状态与持久 Mote 身份各自可辨。布局以任意长度名称为前提：名称保有独立可读的横向空间，不被按钮、摘要或页签挤成逐字竖排，也不要求改短名称或缩小字号。紧凑身份可自然省略，完整名称通过鼠标、键盘与无障碍入口取得；Profile 中可按需展开完整名称。长简介与补充约定在身份之后有界预览并可展开原文，不改写内容或挤掉导航、正文与输入。

完整 Mote Space 的共同导航与一句话发起入口共用主内容顶栏。宽面页签居左、原输入居右，窄面输入自然换到导航下方，导航仍在同一容器、同一位置，只改变选中态与所属内容；长名称、Profile 名片、输入正文和日历展开都不能推动页签换位。导航有自身空间，内容超过可用宽度时可横向滚动，页签不拆成单字。Discussion、Ideas 与 Calendar 使用紧凑身份，名称、真实状态、头像编辑和页签焦点保持可读可达，浮层关闭另有独立空间。页签以内容所需宽度和清楚选中形态表达当前位置，不以满宽厚底板抢占内容。Profile、Discussion、Ideas 与 Calendar 始终呈现同一个一句话发起入口，明确用于新讨论，与当前讨论的正文输入可辨；输入保有可编辑的完整宽度，长文、多行、准备中、失败及原来源反馈仍可阅读，不用重复标题、装饰框或大色块增加顶栏高度。打开和切页时导航、已知身份与可用输入先就位，迟到材料在所属区块补齐，避免全页空白、整页加载遮挡或来回重排。草稿、读取和原请求保全沿[日常合作](../behavior/motes-and-coordination.md#mote-的日常合作)。空资料保清楚字段语义和一个明确原动作，未读取与失败不冒充未设置或默认人格。

完整 Mote Space 只在 Discussion 呈现 Files／Agents 工作工具切换，以及原文件树的目录标题、工具和调整区域；Profile、Ideas、Calendar 为各自内容提供完整空间，不留下隐藏工具选择或文件树的占位、工具条与空分隔。文件浏览与原工作面相邻，四个共同页签的位置不随工具选择、文件树显示或展开改变；独立的 Space 导航与边栏开合仍可操作。原人格与资料编辑、打开文件及 Ideas 新建笔记的入口继续就近可达，资料打开后仍能辨认被操作的 Mote 与原文件；精确目标、资源与展示位置及切页状态保全沿[日常合作](../behavior/motes-and-coordination.md#mote-的日常合作)。

主页的近期安排用紧凑日期、原消息短题和准确状态展示有限条目，浏览时区可辨；点击进入 Calendar 中的同一原安排。尚未读取、读取失败和已确认无安排分别表达，失败不遮住原工作与输入。

原 SOUL、topic 摘要、笔记、资料和来源仍各有准确入口，按需展开、定位和编辑；已保存摘要及非空事项不会被视觉重排删除。记忆短索引以一处紧凑入口按需展开原Markdown，原文件、更正动作及保存版本可发现；展开正文有合理阅读空间，长文沿现有内容滚动，不挤压名字、当前工作或对话输入。原保存内容、未保存草稿和读取未确认清楚区分，不把版本标识与机制说明堆成名片主体。空区保一个明确原动作。读取未确认和失败进入持续状态层与相关局部说明，文案说明实际发生的事和下一步，而非把工程正确性声明铺成名片主体。

浮窗与完整 Space 共享同一 Profile、讨论与文件能力。资料按实际正文宽度展开；横排会损害输入或阅读时，明确切换或纵向排列，收回后继续同一正文与草稿。进入完整 Space、切讨论、看资料和回到交流保持准确原展示引用，资料迟到不抢晚焦点。共同 Space 框架、普通 Topic 范围及文件资源归属沿交互合同。

Ideas 以原笔记列表和所选正文构成可扫描、可阅读的资料浏览面。宽面列表与正文分栏，窄面顺序呈现并保明确返回；标题、已确认的更新时间和当前选择清楚可辨，未知时间不伪造“最近”。页签已经说明的页名和泛化说明不再叠成高占位，原笔记标题和正文拥有主要阅读层级。查找只过滤当前已发现的原笔记，完整文件树由 Discussion 承接并保明确进入路径。新建笔记和提出方向各有清楚动作，围绕所选正文的继续讨论、安排、反馈和原 Editor 更正就近可用；原来源、保存版本与读取未知按需检查，不把机制说明堆成默认正文。列表为空、筛选无匹配、尚未选择与原文读取失败分别表达，已确认正文和草稿保留。

### Mote 安排日历

Calendar 沿前述共同导航进入，名片和完整 Space 沿同一组件与原对象范围呈现；Profile 可直接进入 Calendar，不要求用户先理解邮箱或执行 Session。Month、Week 与 Upcoming 的视图选择、月份或周范围、前后导航、Today 和新建入口合为紧凑的日历工具栏，浏览时区与原数量紧邻并清楚从属；宽面同排，窄面按操作组自然换行，不另铺重复大标题、宣传说明或多层工具底板。默认 Month 的七列日期格形成主要画布；Week 按七个自然日呈现时间点安排，保日期与相对次序；Upcoming 按原截止时间先后排列。宽面日期格可读时间和短标题，选择安排后就地阅读完整详情，选中日期有明确议程。展开的完整 Space 为日历画布与所选安排详情分配相称的可读宽度，不把长正文、编辑字段和控制动作锁进狭窄边栏。可用宽度不足时将议程与详情置于完整阅读区，不同时挤压日期、列表和详情；窄面收为日期、克制数量标记和下方完整议程，模式、日期、所选安排、草稿、焦点与原对象不因宽度改变重置。日期格不过载控制按钮，不绘制虚构时长或暗示可拖拽改期。

统一浏览时区在日期导航附近可辨，详情保原规则时区和准确绝对到期。倒计时兼有相对时长与绝对时间；计划发生、输入已接受、暂停、已到期、结束与投递待核实用文字及非颜色线索区分，不以活动色冒称已执行。日期选择用整体 Surface／形状及焦点表示，键盘能选日、切月并回到列表；长标题可完整阅读，日期和动作不互相挤压。多个倒计时共用可见面的展示时钟，隐藏时停止更新。

每行先回答何时、做什么、属于哪段讨论和当前状态；规则、原请求及检查细节按需展开，控制保持准确原安排。空日、尚无安排和读取未确认有不同反馈，保已知条目与原草稿；模式切换和返回原对话不改写输入或另开替代 Session。日历外壳不重复资料编辑器或后台任务面板。行为、范围、推导与权限唯一见[同主题日历合同](../behavior/motes-and-coordination.md#mote-安排日历)。

### 材质、阅读密度与动态

一层轻而完整的外缘和克制深度连接入口与浮窗。对象导航与交流通过 Surface 差和留白自然分区，内容共享连续基线；外缘在同色背景仍可辨，内容不被不对称空边缩入另一层框。精致感由细线、稳定对齐、字号与字重层级及少量必要 Surface 差形成，避免连续厚底板、重复圆角容器和大段空泛说明。身份区、消息与输入有清楚节奏，信息压缩优先整理层级和动作、合并工具栏并缩减重复内外留白，不以持续减小正文文字、压窄阅读宽度或缩小必要命中区取得“紧凑”；触控、键盘焦点、长名、短屏与未知状态仍沿原能力完整表达。

Mote 阅读目标与 IDE 工具栏密度分别评估。主题值仍归 tokens.css；阅读角色与新增 token 的边界见[字号阶梯](shared-rules.md#字号阶梯)，本页不手写第二套主题。方向稿可比较更舒适的正文字号、行距、头像尺寸和停顿；具体数值需在正常、窄窗和长内容实拍中成立，再进入原主题 owner，不把单张方向稿数字升级为永久要求。

入场、收起、对象切换及宽卡片／头像切换有目的地保持空间连续，静止后呈现稳定。动态帮助辨认入口、对象与动作结果，不承担唯一状态信号；不移动命中区、不改变输入焦点、模式、草稿或终端几何。减少动态下即时得到相同可操作状态。hover 时机仍遵守交互合同；意图延迟或轻量预览须另核行为效果，不能通过 CSS 动画暗中改变打开资格。

尺寸边缘／角部的正面积命中、cursor、悬停与焦点明确，锚点、尺寸记忆、取消和视口夹紧沿行为合同。正常、窄、矮、长名与两种名册呈现均保身份、全部必要动作、正文和输入；临时收窄不篡改原偏好。浮窗随入口建立短距离联系，尺寸手势不成为自由移动或第二套布局 owner。

### 正向视觉验收

看图首先判断：第一眼能否认出搭档及当前事情；消息和输入是否拥有主要阅读空间；身份、材质与动态是否形成同一产品气质；用户能否从短状态判断受影响能力并进入准确恢复动作。功能命中、无遮挡和键盘可达是必要条件，单独不代称审美完成。

同轮方向稿与真实正常、窄窗、未知／失败、待回复、长名及多讨论场景一起评审。动态亲看打开、切换和收束过程，小尺寸头像可察觉、停止后安静；静态图不证明连续运动。独立 Agent 实际看完整图并给出可交付或需要修正结论，修正后复拍；本机方向稿不代签真实产品和原身份恢复。

## Mote 头像与主 Mote

对象外观、主身份保护、头像编辑、保存／取消／恢复默认及失败保全唯一见[同主题交互](../behavior/motes-and-coordination.md#mote-头像与主-mote)。对象头像在名册、身份区、Profile 和准确 Mote 发言中保持同一已选原色、比例与裁剪；品牌入口、类型 glyph、动作插画和 Provider 标记分别承担自己的语义。

角色系统沿[共同美术语言](shared-rules.md#ui-现代化的独立评估边界)，以清楚轮廓、可记忆的神情、克制运动感与精确材质建立搭档身份。自动默认与微小装饰徽标的分工唯一见[共同 Mote 身份规范](shared-rules.md#mote-默认身份与装饰徽标)，图库与捏脸是同一系统的不同外观来源；用户图片和旧图标选择保持原内容。统一的是新候选的造型质量与呈现规则，已保存角色仍准确显示原色、比例和部件。

`Icon or image` 的内置 Mote 图库先从当前默认身份的单侧抬起安定轮廓、圆润头壳与两枚偏置眼孔负空间建立同族关系，再让十二种风格的设计思想参与轮廓、负空间、体量、比例和节奏：复古未来的流线与引力、lowpoly 的体积分面、达达的拼贴冲突、波点的圆单元关系、浮世绘的浪势与版画留白、赛博朋克的装配与通道、平面主义的块面互补、新古典的稳定比例与涡卷张力、蒸汽波的错层曲带、水墨的笔压与开放留白、Klei 的有机长弧和尖拙纸口、辐射四的厚壁冲压和旧工业印刷。各款是独立静态头像，不能只在同一个 clip 内贴纹理或换色，也不复制品牌角色或 Logo；单色草图用于检视构成，不要求缺少材质与颜色时猜中所有风格。图库以 4×3 紧凑圆形缩略图呈现，与实际小头像和中心预览均保持可辨身份，候选标题、选中信号、图库标题行内联上传动作与 7×3 严整语义图标网格清楚可达。深浅主题与窄窗沿原焦点、预览及保存／取消层级，不以预览冒充保存。默认剪影配色只见[共同身份规范](shared-rules.md#mote-默认身份与装饰徽标)，用户选用的图像保原色。

`Icon or image` 的图库加入 low-poly 角色图片：用大块几何形成可辨头形，面片转折与镜面反射共同表达体积，局部眼神和少量色彩建立个性，包含结合项目翡翠低多面龙角与青翠折面特征、并向 Mote 单耳双目搭档比例靠拢的 `Dragon` 角色及动物搭档候选。候选之间共享光线、裁剪与材质尺度，角色轮廓在实际小头像里仍易区分；大预览可看清层次，图库缩略图直接展示所选角色。具体角色名单不成为永久合同；上传图片和原图标入口仍可明确选择。

现有二维 `Make a face`、图片与图标继续可选；二维捏脸的五种头壳轮廓同样向 Mote 默认搭档标志性的单侧抬起耳尖、顶部高光折边与柔和面罩眼窝靠拢，使默认图标、艺术剪影、低多面龙与二维捏脸共享一致的角色家族辨识与关节动态。系列把相同造型语言的候选组织在一起，同一系列的图像与可捏脸方式均清楚可达，系列名称与缩略图帮助辨认来源，不冒充 Mote 身份或运行状态。新的 3D 捏脸方向基于真实可组合的头形、五官和配饰建立风格化面孔，并优先探索伪二维的 shader 表达。头形在正面与侧面都有稳定剪影，眉眼嘴有精确比例、独立形态和清楚的前后关系；图形化神情与立体体积共同成立，目光和表情变化沿真实关节或形态能力表达。镜面铬、局部色块与非写实明暗按形体安排，材质帮助辨认角色和神情，姿态自信、友好、安静；成人感不以逼真皮肤、机械镀层或更多高光代称。造型与渲染先核成熟参考及原模型／shader 能力，再以实际角色比较方向；中心预览能看清头形、材质与组合结果，小头像仍易区分五官和选项，连续运动保持同一角色。原配色、部件和已保存组合完整保留，五官仍独立可编辑，新增选项沿原外观 owner 判断；风格调整不把旧组合换成新默认。二维描线、渐变或整张图片不能代签真实 3D 模型、表情与可编辑部件；具体造型、材质、非写实效果及动态幅度由方向稿和真实编辑面验收收敛。

新选择的内置二维捏脸统一从 `Make a face` 进入；复用同一脸型与部件系统的内置系列预设不作为另一种风格重复列出。已保存的系列预设仍按原准确来源读回、展示和编辑；用户素材目录中的二维预设及混合系列继续可选。入口去重不改变原外观、来源、参数或 PNG 的保存事实。

系列选择旁的「＋」提供添加自定义系列的清楚入口。添加弹窗用短教程说明一目录一系列、普通图片直接发现及混合示例，主动作创建初始系列；完成后提供打开目录、复制路径和返回选择的动作。完整路径、声明格式和更多部件说明按需展开，不占用头像编辑首屏。尚未创建用户素材目录是正常的未开始状态，不呈现为告警或堆叠工程诊断；真实读取或创建失败仍在相应步骤提供准确说明与恢复动作。创建与头像保存语义沿[同主题行为](../behavior/motes-and-coordination.md#mote-头像与主-mote)。

原色约束限对象身份头像，菜单／工具 glyph 继续消费[控件语言](shared-rules.md#控件语言)。选择、真实状态和键盘焦点有独立形状与文字；错误、停止、待用户、断连和未知不被笑脸、日常动作或品牌色盖掉。

Mote 的日常眨眼、轻姿态和附近指针回应表达持久身份，与思考、工具调用等工作型表演分开。工作型表演只消费准确原 Session、Host 和 Run 上由 Core 确认、仍有效的当前活动；在同一活动期间，工具表情还须有原 Timeline owner 确认的同一 Run、同一活动轮次的真实在途调用。保留的 Working、旧工具记录、目录中的角色身份或头像本身都不证明正在工作。当前活动为空闲、未知、过期、不支持，进程不在运行、原 Run 已到终态或等待用户处理时，停止工作型表演并保留准确原状态的可辨表达；中性日常动作不冒充运行事实，也不覆盖待用户、错误或未知说明。活动事实与输入资格沿[工作状态合同](../behavior/agent-capabilities-and-messaging.md#工作状态与-executor-叠加标记)，表情变化不停止健康 Agent、不改变权限、输入、原 Session 或 Run。

工作型表演在活动证据到期时自动重算并停止，不等待下一条工具记录、无关 Session 更新或用户重新打开。新证据只更新对应原对象的展示时限；身份或 Run 改变、活动观察读取失败及事实缺失时，旧工作表情不能沿用。Desktop 与连接设备消费同一原活动呈现来源与有效范围，连接设备不根据文案或头像另判活性，也不假定不同设备时钟同步；延迟或迟到的观察不能延长旧工作表情。已保存的图片、图标和五官选择保持。到期更新只服务准确的展示消费者，不引入全局轮询、逐帧状态时钟或第二份活动 Store；关闭、隐藏与减少动态继续沿原头像可见性规则释放工作型动态，重新可见时核对原事实。

头像的小尺寸动态有可读的预备、响应和收束，幅度随实际槽位可辨且保稳定命中；大预览用于看清部件和连续过程。捏脸沿五官关节组合视线、眉眼和嘴的变化，附近指针回应与真实状态同时可读，日常短动作之间有停顿，各实例不整齐同步。用户选择的角色图片和图标可有不损害辨识的轻姿态，来源和状态语义仍遵守行为合同。隐藏、离屏、页面不可见和减少动态时静止；历史作者头像继续静态，成本随准确可见消费者增长。

自动默认搭档在对象头像槽内沿同一动作 owner 回应交互：附近指针引出小幅视线与朝向，悬停或键盘聚焦给一次短眨眼，按下轻收身、释放平稳回位；离开后安定。眼孔保持真实透明，形体、槽位与原命中区不变，不让整列头像持续整齐弹跳。主题切到其他字形或自定义路径时立即回到该主题资产，不把搭档部件覆盖上去；用户已选头像继续沿原外观来源。类型入口、历史作者和导出不带这组动作，交互动作不表示启动、在线或成功，隐藏、离屏、页面不可见和减少动态时保持原静态轮廓。

可见头像的原生动画同样遵守[动态视觉的渲染边界](shared-rules.md#动态视觉的渲染边界)。部件、姿态和指针回应共同由原头像 owner 承担局部成本，保留同文档 Terminal 与编辑交互的响应；隐藏停活和槽位不变的证据不代签这一边界。同一边界覆盖可编辑五官与系列剪影，以及普通入口、常驻快捷入口、目录和预览／裁切中的真实槽位；宿主的尺寸与居中规则不能重新打开部件动画向无关工作面的布局传播。修正保原头像、裁切、部件连续运动、指针与状态组合、命中和可见性策略，不以某一种外观或单一预览通过代签其余消费者。

Change Avatar 沿原局部编辑面，以一处稳定的中心角色舞台（中心圆预览 + `45px` 名册与 `24px` 对话实时小尺寸样张 + 当前来源说明）为重心；顶部 `Icon or image`／`Make a face`／`Series` 方式切换使用 `LiquidSelectionSurface` 单一选中信号，不叠加右上角勾选角标，三种方式共享同一弹窗宽度预算而不发生跳变。捏脸按「轮廓与配色／五官神情／配饰与印记」三组切换并提供快捷预设与随机组合，选项按钮以局部部件图样或色板呈现选择，中心预览负责完整脸的组合结果，小尺寸样张负责核对实际辨识，避免每个选项都重复一张微缩全脸。`Icon or image` 依次组织 4×3 同族剪影图库（标题行内联上传图片动作）、4 列 low-poly 角色候选及带分组标题的 7×3 通用语义图标网格。`Restore automatic` 位于页脚左缘（`margin-right: auto`），与右侧 `Cancel`／`Save` 同行。复用已有原生选择、焦点机制；正常与窄窗、失败与草稿状态保预览、必要动作和键盘路径。图审亲看小尺寸、中心预览、近／远指针和真实运行分支的动态过程，采图成功不代称动画品位通过。

## PMO Teams 快捷面的定位与密度

临时与固定面沿[主节](#mote-快捷入口与当前协调上下文)贴近入口和适配视口；身份、阅读和动作在尺寸变化后仍可辨。锚点、尺寸拖拽及记忆、取消、无自由位置及原工作面保护唯一见交互合同，视觉层不持有第二份坐标或空间布局。

## PMO Teams 浮窗的参考驱动简约规则

参考强交流产品的对象、事情、消息与输入分层，同时保 AgentMux 的工业调性与真实执行语义。参考用于判断阅读、辨识、操作和连续性，具体按钮数量、角色造型或像素值不成为另一产品的副本。

每个主要表达有自己的职责：身份和情感联系、事情导航、原内容、执行反馈或下一步操作。整理重复操作和无作用层级，保有助于辨识、信任、记忆与阅读的头像、标题、留白及动态；信息也出现在 hover 或 Tab 中，不自动成为删除首屏表达的理由。简约以合作任务完成和阅读质量衡量。

工具命中区、可访问名称、完整职责／Session 详情和原工作面都可达；首屏优先身份、当前事情、正文与输入，证据与低频动作按需。一个内容边界和一致材质表达层次，功能反馈与情感表达都要在正常、窄窗和分支状态的完整画面中成立。

### 名册密度与读取提示

名册的身份、字号、截断与全名提示只见[主节](#mote-快捷入口与当前协调上下文)。列数随实际宽度及保存的头像尺寸自然变化；局部读取失败在相关对象或统一服务层可读，不塞进头像格、覆盖邻居或原输入。

Quick mode 显示保存的 Executor for new chat、默认讨论和恢复时机，编辑沿原公共选择、配置 owner 与草稿。主对话启动时的固定资格紧邻对应配置，实际会话身份与新对话预选分开；保存冲突、恢复中与失败保原事实和可行动状态，不扩成第二套会话控制面。

Mote 资料中的机器人入口以原 Mote 名字、头像和默认身份关系辨认准确对象，创建、同步与管理沿设置中的同一身份工作面；进入设置后仍能看清来源，不丢回到原 Mote 的路径。身份卡、任务层级与宽窄窗状态的共同呈现唯一见[设置页现代化密度](settings-and-observation.md#设置页现代化密度)，默认引用与解绑行为仅见[机器人身份与公开资料](../behavior/motes-and-coordination.md#机器人身份与公开资料)。
