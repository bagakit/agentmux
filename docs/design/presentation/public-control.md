## Agent-first 的 Space 工作入口

Space / Zone / Tab / Region、Project 与 Workspace 的统一含义只定义在交互 SSOT[《统一概念与空间寻址》](../behavior/spaces-and-layout.md#统一概念与空间寻址)；`agent open` 与 `space mv` 的行为只定义在[《Agent-first 的 Space 工作入口》](../behavior/public-control.md#agent-first-的-space-工作入口)。工作面、原执行目录与失败说明沿用现有 Tab/Region、服务窗和身份展示语言；本轮统一合同并闭合 CLI，不新增 Renderer 控件或视觉层，不把全仓改名当成概念统一。


## 手机版 Relay 连接的呈现

行为、分层、连接、工作面与恢复唯一见交互 SSOT[《手机版 Relay 连接》](../behavior/public-control.md#手机版-relay-连接)。手机独立外壳适配触摸、软键盘和窄/矮视口，共用原对话组成与终端阅读语言；身份、输入能力、请求与unknown清楚可达，不仅缩小Desktop。真实操作采图与独立审美沿既有视觉E2E，采图成功不代表通过。

手机整体沿 AgentMux 的安静、紧凑工具语言。底栏五个主入口等宽，Mote 正中作为身份锚点，不做浮起的创建按钮；选中态同时用表面填色、图标或文字强调以及可访问的当前页面事实。辅助菜单与返回动作分开、就近可达，五主入口组完整保留；辅助能力沿原菜单揭示，原工作面保持挂载。

目录、对话、资料与结果的卡片、底部面板及服务说明共享[原主题与语义 token](shared-rules.md#主题与样式-ssot-规范)，保留 Amux 原可配置的字体、圆角、层次阴影与语义图标表现；触屏几何沿本页适配，不用手机固定绘制值盖过原样式选择，也不为这些表面另造偏色材质。状态色与主动作只表达各自语义。资料标签与恢复动作使用普通工作用语，原始配置名、技术身份及诊断全文按需可读。

Mote 对话是日常工作中心；顶部原头像揭示 Profile，结果、终端及其他当前对话动作在同一上下文中就近可达。Profile 用原资料、当前工作和相关对象分层，身份与进展不重复堆进标题栏。Focus 以待回应、执行和结果的原状态组织可扫读行；进入后当前对象及返回来源清楚。对话正文、交互请求、投递反馈和输入区形成连续信息流，长诊断完整可读且不挤掉编辑器。目录、对话、资料和结果共用导航、字号、间距与控件语言；以完整实际画面和操作序列评审。

非顶层工作面的返回入口直接出现在当前上下文，名称或来源提示说明返回哪里，与菜单动作清楚区分。终端以原内容为阅读主面，本地缩放与触摸滚动可发现且不中断历史；本地阅读比例与会改变原 Run 网格的 PTY 尺寸控制明确分开，完整当前值、焦点与 unknown 恢复保持可达。

Topics 的 Category 与 Topic 子项、Mote 与展开的二级 Tabs、Space 的原项目分组及目录后代共用紧凑连续树行；名称为主扫描轨道，原 recap 为次，层级用缩进和明确 disclosure 表达，不逐项套大卡片或放大头像。当前行、hover、展开与键盘焦点分别可辨，折叠控制保完整可访问名与 `aria-expanded`；无子项的行不留空箭头槽。手机层级沿[同主题行为](../behavior/public-control.md#手机对象身份与工作面)，对象与分组语言引用[《对象树与知识层级》](spaces-and-layout.md#对象树与知识层级)，不照搬 Desktop 三栏宽度。目录标题、搜索与尾部操作对齐，“更多”不拆成单字换行；原完整名称和详情按需可读。

同一连接或目录观察事实在当前画面只保留一处主要说明，相关能力与恢复动作贴近受影响对象，不在标题、正文和输入区重复铺告示。目录发现未确认等服务说明默认收成一句可理解的摘要和就地展开入口，先说明哪里未确认以及仍可用的原能力；展开后完整失败步骤、观察范围、原诊断与准确恢复动作可读，不让全页长诊断抢占目录首屏。连接中断与消息投递未知是不同事实，仍分别说明准确状态、原请求和恢复入口；短屏也保留草稿、编辑区与关键操作。

比原手机外壳缩小标题、正文、元信息与段落留白：标题约17px、正文13px、元信息11px，内容横向留白12px，行和章节优先用轻分隔表达结构，避免每段都套卡片。标题、身份槽和底栏不靠大面积空白表达重要性；搜索、筛选与新建沿紧凑工具布局，Goals 刷新使用有准确可访问名的轻图标动作，主次清楚。搜索、筛选、服务摘要和目录行的绘制面应轻薄，避免把完整触摸范围都铺成连续的大块实心圆角底板；压缩重复的品牌／页面标题层次和容器内留白，让名称与内容先于外框。目录与正文不以逐项描边、层层线框或装饰阴影组织内容；优先用对齐、字重、段距和必要表面层次表达关系，输入边界、当前选择、键盘焦点及服务未知仍清晰。现代紧凑感由一致比例、清楚对齐和克制表面形成，不以整体缩放取得，也不以竞品材质或布局取代自身主题。视觉尺寸与点击范围分开，主要触摸目标至少44px；编辑字段保持16px以避免iOS聚焦自动缩放。五入口在320px宽度仍完整可读，菜单、长名称、未知回执和软键盘不挤掉编辑器或关键操作；减少重复身份标题和终端切换按钮。安全区、键盘收起底栏与矮视口滚动沿原viewport owner。
