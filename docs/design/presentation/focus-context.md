## Agent 焦点历史与 PMO 隔离的空间密度

Agents 表面在工具栏下提供一条低高度的“最近执行 Agent”上下文 rail：只显示当前与少量最近 Session 的头像、显示名和状态，允许直接回到对应工作面；没有历史时用一行短空态，不占用卡片首屏。PMO 浮窗不复用这条 rail，也不在执行 Agent 卡片中混入 PMO 身份。PMO 的当前 Session 只在自己的标题和工作面中表达，避免两个焦点在同一条视觉层级竞争。

焦点历史是导航事实，不额外创建卡片、Region 或对话。rail 使用现有 Agent 头像与状态语言，最近项按轻微叠压和紧凑间距排列；完整 Session、Workspace 和恢复状态放入 tooltip/可访问名称。

## Focus 执行台与底部视频编辑器式音轨

用户要求的成熟产品水准、完整使用流程自行体验与竞品比较边界，统一归交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)。本节的密度、可读性与控件命中须在该完整流程的宽窄窗口和鼠标、键盘操作中成立。

Focus 首屏只显示交互 SSOT 同节确认的 Agent 集合；普通 Terminal 不占泳道、筛选、空列或预览行，不使用 Terminal 图标充当 Agent 身份。手动启动且已核的 Agent 使用现有 Provider 身份图形、原上下文名与克制状态；缺少任务信号仍读中性状态，不伪装成 Working／Results。识别未确认的说明留在原 Terminal 的就地服务提示，不添加全局名册、常驻探测条或阻断浮层；原右侧 Terminal 和历史密度保持。识别、控制权和保留边界只定义在交互 SSOT 的 Terminal Agent 资格段。

Focus 入口的动态预览使用紧凑、非交互的浮层：名称与短状态计数在上，最多三条双层上下文摘要在下；当前关注项清楚标注，紧接需处理和工作事实。Disconnected 只保留短计数，当前关注离线项也不占摘要行；行为边界见交互 SSOT 对应 Focus 章节。长任务名与活动摘要截断，项目归属低对比度显示，不重复绝对路径、Session 标识或完整正文。空态使用简短说明；不为零值类别添加显眼状态色。浮层锚定在入口上方并限制在 viewport 内，沿用窗口级 tooltip 层与 Browser 让位机制，保持原按钮命中区，状态栏密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)。交互与事实来源只定义在交互 SSOT 的对应 Focus 章节。

用户反馈 Focus 不够现代化，卡片信息看不出区别且空间利用率低；用户要求时间音轨参考视频编辑软件并放到最下面。交互、事实与连续性规则归交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)。

### 项目扫描与泳道

Focus 上方为紧凑的项目扫描区与原 Tab 工作面，底部为横跨整个 Focus 的 Recent Focus 音轨，再下面是全局状态栏，其密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)。当前完整泳道、仅离线标题入口与已观察历史项目共用紧凑项目语汇；没有当前卡片时不绘制空状态身体或大空态，轻量标题保短名、必要归属和原准确离线入口。历史访问用低强调的历史标识与可区分日期的 Last focused 表达，不能借当前 Working／Results 色暗示状态；较早或时间未知的已保留项目可集中收起，折叠处仍有准确项目数量、可见键盘焦点与展开入口。原日期窗口回顾入口可辨，长名称和窄宽度下不叠压计数、离线命中或动作；事实、筛选与保留边界只定义在交互 SSOT 对应项目近期活动段。

主工作面保留可调整比例；各泳道按相同状态顺序排列，内容列按本泳道实际非空状态与可读卡宽有界分配空间，只有确实不足才按同序必要换行；不能在统一宽度断点把五状态全部纵排。单非空泳道在常见窄栏仍横排，零态收成紧凑状态带而不各占整行，避免多个泳道各自横向滚动。

零态图标与 Disconnected 在项目标题带组成一个紧凑状态入口组，分别保 24px／32px 的原图标／命中单元，不再作为身体窄轨扣减卡片列宽；非空状态不在标题带重复列头或数量。数量大于零时作为图标旁的小角标，随原图标单元呈现，不另占数字一行；数量超过 99 时角标显示 99+，原 tooltip／可访问名称仍表达准确总数；数量为零时只保低强调图标，不显示 0、不绘制显眼状态色背景。图标、角标与原命中区在同一紧凑组头高度内可辨，多位数不遮住图形、名字或相邻状态。

完整名称、准确计数与必要 Unknown 说明保在原可访问标签与 tooltip，Disconnected 有内容时的原摘要与点击入口保持；零态不造额外 tabstop，标题名字与入口各有边界，确实不足只作必要换行，不用整宽彩色空行。列头与本泳道实际列宽对应，列宽不同不暗示跨项目位置对齐。

有内容状态组的宽度与真正子列数对应，减少最高卡片堆叠；单卡保持可读宽度下界与现有上界，达到上界后组头背景不继续拉长，不制造空子列或宽间隙。原名称与最多两行工作信息仍可读，不能靠裁掉 recap、动作或必要说明换取低高度；实际高度和操作稳定性沿交互 SSOT 对应 Focus 合同，不把相近行高当作固定等高事实。

项目不再占固定列或独立大标题行：紧凑组头用既有项目图标、Project / Branch / Topic 路径、Topic 一句短说明、活跃数和必要恢复标记表达归属。列头保短名字，并以现有状态 token 的克制色和非颜色标识区分，不反复绘制彩色框。

列头表达分组，卡片状态形状表达原 Run／活动事实，整面中性 surface 表达选择与键盘焦点；Idle／Unknown 与 Results 不因共用圆点或近似颜色混读，不重分类或改全局状态色。已销毁 worktree 的泳道使用中性虚线标记与明确文字，不以错误色代替事实。图标、Topic 说明与状态事实边界见交互 SSOT 对应 Focus 段。

已确认 Topic 的组头使用既有 notebook 语汇，Mote 使用现有 Mote 专属身份图形与实际对象名；首屏不重复 Scratch / Project 父图标、父名称或无意义面包屑。普通项目仍使用原项目图标与必要 Branch 路径；完整 Host / 路径 / 身份进入按需来源，未知分类使用中性提示。既有用户图标选择优先，Focus 专属 Topic 字形不改变 Space / Rail 原自动 monogram 默认，不新增第二份图标账本或读取；身份与精确导航边界见交互 SSOT 的 Topic / Mote 段。

Mote 待处理条带保留一个紧凑入口和原注意色：身份图形与名称、待处理数量、打开动作有清楚的可读边界。长名称可有界省略，完整名仍由原可访问名称和上下文按需阅读；数量与动作完整可辨，实际条带宽度不足时只作必要换行，不能相叠、裁掉动作或把名称压至不可辨。鼠标命中与可见键盘焦点沿原整面按钮，不拆成新的导航控件；不增加全局工具行，也不改变泳道卡片或 Composer 密度。事实与精确导航规则见交互 SSOT 的 Mote 待处理入口段。

Focus 固定消息的正文外观引用交互合同《共同对话的用户默认外观与协作来源》；标记与来源说明仍区别真实作者事实，不增加图例或常驻身份栏。

### 时间轴与历史回顾

Recent Focus 的紧凑工具栏提供日期时间入口、前后窗口、窗口大小与回到当前时刻的动作；窗口范围始终可扫描，窄宽度下仍为单行，工具组可以横向浏览；滚动反馈不能盖住按钮的可见命中区，也不增高工具带或挤掉轨道。当前时刻使用一条细竖线与标尺上的短标识贯穿时间区域，不占 Context 身份列；选中 Context 仍沿用已有柔和 surface。用户与 Agent 发言使用轻量、可键盘到达的标记，与 focus 片段在同一条轨道里可区分；沿共同身份图形与按需说明区分输入、回复及作者事实，不另加常驻图例或身份墙。同刻多条以原锚点上的紧凑数量入口呈现，完整数量可访问，沿现有记录列表选择各条，不拉长标记、不增高轨道。正文进入原共同阅读预览，避免展开消息撑高每条轨道；缺时间发言沿原记录入口可读，不画猜测坐标。窗口、取消高度调整与事实边界只定义在交互 SSOT 对应 Recent Focus 段。消息沿既有身份图形、tooltip 和可访问名区别已核 Agent、明确人类与未知作者；发送者与项目信息在单条查看时出现，执行关联复用原轨道事实，不增高轨道、不增加占行卡片、常驻工具条或多条跨泳道连线。发送者、当前归属与执行关系的行为边界只定义在交互 SSOT 对应消息段。

Recent Focus 的悬停卡采用清楚的身份与一条任务/消息主信息，项目/Topic、状态与记录来源为次级辅助；头像、字重、留白和图标各有语义，不堆叠表格、重复姓名、聊天气泡外再套相同标题或长段空字段。快速预览保持紧凑，固定阅读保原共同正文完整可读；进入/退出应克制地表达同一对象连续性，不跳动工具带/轨道、不盖控制区，减少动效时保持同样信息与操作。行为与事实边界只定义在交互 SSOT 对应 Recent Focus 检视段。

鼠标平移与＋／－缩放沿交互 SSOT 同节[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)的新增窗口约束；原数字范围两侧加入紧凑的＋／－图标按钮，边界禁用与 tooltip／可访问名称明确。仍共用原一条工具带，正常、窄和短窗口保留日期、Now 与至少一条完整轨道，不增高状态栏或另加缩放工具行。

项目分组与关闭后历史回顾：项目分组的行为与历史保留边界见交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)同名段。用项目图标、短名与折叠控件组成紧凑组头，Branch／Topic 只在区分必要时作为次级路径或 Session 行辅助信息，不强制每组展开四层标题。折叠时展示本窗口内已有片段的聚合轮廓与有事实的 Session 数，明确为项目汇总，不冒单条 Run 或精确执行时长。已关闭工作面的轨道使用克制的中性身份标记，状态和历史缺口可按需读取，不大量常驻“已关闭／Disconnected”文字；沿现有标尺、约 24px 单轨、可调高度和独立滚动边界呈现。默认只显示本窗口有事实的项目，不列出所有过去 Session，也不加一块常驻历史墓地。字节与事件双重保留边界只定义在交互 SSOT 同名段；沿既有范围／覆盖说明按需可读，不为该边界增加常驻 banner。

Recent Focus 横向浏览期间，项目与轨道沿交互 SSOT 同节的本次进入顺序稳定呈现；窗口事实显隐不以动画重排已读条目，名称相同仍可用原身份区分。保既有紧凑组头、约24px轨道、可调名称列和独立滚动，不另加排序工具带、固定空行或历史墓地；行为和活动事实仅引用上述交互合同。

已读发言与已观察 Context 项目的关系只见交互 SSOT 同节的新补充；保留紧凑项目组、约 24px 轨道和中性的未知组。用组头 tooltip／按需详情解释「已观察 Context 归属，消息发生时项目未记录」，不为每条消息增加常驻项目徽章或长说明。

同一条约 24px 轨道区分低饱和的已保留历史／当前工作状态带、当前时刻处的在线小标记与细的关注片段；工作带按所选窗口裁剪，来源、准确 Run、起止与开放／未知边界可按需读取，已关闭 Session 不改成当前在线。形状、位置与 tooltip/可访问名共同表达含义，不只靠颜色；缺记录与保留裁切沿原覆盖入口说明，不画虚构长条。未知起点不画虚构长条，在线标记与当前时刻竖线保持对齐，访问与消息仍可键盘到达。标尺按轨道可用宽度减少时间标签，窄窗口保留两端，标签不得彼此重叠。新增事实不增加每轨高度、工具带或全局状态栏高度；工作、在线与访问的事实边界只定义在交互 SSOT 对应 Recent Focus 段。

用户反馈时间轴大片空白、灰绿线难懂。Now 当前时刻、Working 工作状态、Focused 关注访问与 Running 当前 Run 在线在原 Recent Focus 工具带/标尺同高度内使用短文字和不同形状可辨；当前时刻使用非工作 accent，working 保低饱和带，关注保持中性短片，在线为独立空心点。宽窗可见短图例，窄窗沿同一入口可读可达；图例、tooltip 与可访问名称使用同一含义，当前状态与历史覆盖分别可辨；真实已读来源数和覆盖说明可见可达，不新增常驻 banner 或增高全局状态栏。该图例只解释时间图形，不修改作者/共同正文的“不增加图例”条款；多来源保留与未知边界统一见交互 SSOT 同节时间轴覆盖约束。

当前发言的观察提醒沿原消息记录／覆盖入口与紧凑阅读面可读可达，使用已有服务说明和动作语言，区分「自动更新不可用」与「保留当前阅读窗」；不另占工具带、全局状态栏或常驻横幅，不把服务提醒画成输入标记，行为唯一见交互 SSOT 同节对应约束。

大数量下的滚动与加载沿用这些自然窗口边界，保持原工作面可读与输入命中；性能资格、数据来源及同一工作面交还规则归交互 SSOT 的对应 Focus 章节，不以隐藏内容、额外 loading 屏或另一套列表解释资格结果。长期不活跃泳道后置的依据与稳定次序也归该章节；后置仍使用原紧凑泳道，不增加占行的空闲分区或每项计时标签，不以动画移动打断阅读。

### 卡片、预览与状态

卡片使用统一两层条目：首行是身份图标、可识别任务名与静态状态形状；Working 用紧凑活动波形、Results 用完成勾、Idle 用暂停、Unknown 用问号，配合原辅助色，在无颜色时仍可辨。Attention 保原警告／请求语义，状态不持续动画。完整状态与按需时间说明通过同一 hover、父行键盘 focus 的 tooltip 和可访问名称安静读取；时间与关闭事实只定义在[同主题交互合同](../behavior/focus-context.md#卡片内容预览与-agent-操作)。次行是最近已知动作或真实状态说明，必要请求与失败事实不只藏在 tooltip。Provider 已由身份图标表达，完整绝对路径和内部标识进入 tooltip/详情；缺少任务事实时保留真实可识别身份。行高约 48–60px，组头约 28px；空分组不放大卡片。选中用整行柔和 surface 与字重表达，需处理与错误只在状态标识承载颜色，普通项不反复绘制彩色框。悬停与键盘聚焦都可发现动作，不通过浮动位移表达 hover。

卡片的信息层级须以可读工作内容为中心：活动正文使用可读的次级正文对比，允许在窄列占最多两行，保住工具动词与具体文件/命令，不把全部识别信息藏进 hover。首层名称与短状态各有边界，长名称、中文和未知状态不得互相撑出行框；完整内容仍可按需查看。两层结构不新增常驻第三行、进度装饰、重复的项目/Provider/路径标签，也不挤高全局状态栏。内容来源与请求/结果/失败优先级只在交互 SSOT 的对应 Focus 段定义。

Focus 卡片 recap、预览与 Agent 菜单沿交互 SSOT 同节合同。身份与工作内容保持两个层级；普通卡片内容区以最多两行带来源的会话摘录承担主体，不再把正文压成一行并常驻工具／Stop／transport副行；无摘录沿原活动摘要，紧急与必要服务说明直接可读，完整活动和原摘录按需。已识别的包装声明与来源安静表达，不挤掉具体正文；解析和事实边界只沿交互合同。缺摘录沿现活动／空态，不增加常驻第三层、重复项目／Provider／路径或进度装饰；执行泳道内的断连只保紧凑入口；完整离线目录的正文密度沿本节 Disconnected 目录段，不沿旧 28px 姓名砖块限制。悬停、选中与键盘聚焦使用层次不同的整面 surface、字重或完整焦点轮廓，不用状态颜色或单侧细条冒充选择；不以位移表达悬停。

完整预览采用不透明的阅读 surface，在窗口内保持可读宽度与有界高度，长正文可滚动，任务、具体活动、摘录和来源各表达一次，减少动效时同样可用。回复与最近输入使用清楚分区，共同 Markdown 的段落、列表、强调与代码保持阅读层次，长行／表格仅在自身边界滚动；来源与原文资料降低视觉权重，不叠重复姓名、SID、路径或包装标题。预览只读模式把链接、资源引用、文档锚点和脚注前后跳呈现为可选文字，不留可聚焦的无动作控件，不以 inert 换取只读而破坏选择；普通共同正文的既有控件保持。

最近输入作为回复摘录之外的轻量阅读分区，标题可简为 Recent inputs，可访问名称仍表达最近用户消息；回复／输入标题简短，正文承担主体。作者与完整记录日期／时间放在同一紧凑行，确实不足时只必要换行，日期不能被省略成只有时分；来源进入该时间的 title／可访问说明，不再每条另占来源行。正常窗口不绘制冗余说明；缺时和服务／覆盖问题沿交互合同保持可见。

输入采用平面列表与轻分隔，减少嵌套卡盒、标题与重复底色；原正文对比、代码／段落和尾部可读性保持。

footer 为一行安静的项目名与有界省略路径，完整来源身份在同处按需读取，不重复常驻 origin／SID 多行。共同用户外观沿交互合同，不重复身份墙或常驻工具栏。长中文、长行与代码在窄窗可读、可选取，数量与排序、缺时及服务说明只由同节交互合同定义；不因增加输入阅读区提高常驻卡片行高。

Agent 菜单沿原 ContextMenu、图标与 Portal 语汇，菜单头用单行省略的对象名称确认目标、降低视觉权重，不堆状态与 SID 说明；改名动作在前，准确 Session 地址复制不重复同义分享入口，`Stop Agent` 置于独立分隔的停止动作组；动作目的通过原菜单语汇表达。行内名称输入保持原卡片几何与正文层级，焦点可见；菜单与编辑不冒称卡片已选中。宽窄窗口的完整名称、来源、命中区和键盘入口均可达，不新增常驻动作栏或增高全局状态栏；动作、复制和焦点保全只定义在上述交互合同。

同 Tab 多个 Terminal 在原两层条目中使用已有 Region 同名视觉编号和原工作面名区分，项目名不在每格重复，机器地址留在 tooltip/可访问说明，不加第三行或常驻徽章；事实和归属规则见交互 SSOT 对应 Focus 段。

失败或结束终端的次行优先显示可读的退出事实，沿用两层条目与原有错误/中性色；完整说明按需查看，不新增常驻失败栏。当前泳道与历史 Run 的边界、原工作面和恢复事实只定义在交互 SSOT 对应 Focus 段。恢复接续后的选中呈现沿用本节既有选中态与工作面边界，行为只归上述交互合同。

Needs you 与 Error 共用一个紧凑待处理分组。严重性由单项状态图标与可读说明表达，授权/回复采用注意色、真实失败采用错误色，不用两块空状态框维持区别。所有状态分组统一轻量组头；泳道组头的零态和数量沿上文标题带入口约束，原过滤入口仍保名称与计数，不在项目条目下面重复一排零；已确认 Idle、活动 Unknown 与恢复上下文在原中性组内以共享字形、准确可访问名称和完整按需说明区分，组头与计数不得把 Unknown 冒称 Idle。

中性组中的已确认闲置、活动未知与待恢复保持可扫读区别；现共享状态字形、hover/键盘说明及可访问名称表达 Run 存活、活动确定性与就绪，计数说明区分 Unknown 与 Idle，不能用 Idle 总数吞掉未知。活动缺口直接用原可读次级说明表达，保任务摘录与操作入口；不把未知涂成 Working、不新增常驻第三行或服务横幅，原注意/真实结果语汇保持。

失败 Agent 的原 Attention 处理面直接显示已有失败事实与可操作的关闭入口，动作名称清楚区分关闭失败 Session、关闭请求面和收起 Focus 投影；沿原紧凑动作组与服务窗，不增加常驻失败横幅或第二套确认面。进行中和未确认结果在原位置可读，健康或未知 Run 不被画成已结束。资格、准确对象与确认后收尾只定义在交互 SSOT 的对应 Focus 失败关闭合同。

Results 条目以真实结果摘要承担次行内容，并有可发现的查看入口；Idle 使用独立、中性的分组和短状态，不与 Working 共用运行中的视觉信号。分组数量与样式来自实际可观察内容；无产出的 Results 空分组只保留可理解的计数入口，不占一整列空白。

结果查看与原上下文交还只归交互 SSOT 的对应 Focus 章节。当前工作面的阅读、输入与几何保持稳定；未展示的保留工作面及其编辑器内容不能绘制到 Focus 泳道、音轨或输入区，也不能占用命中。目标工作面显示后沿用原内容边界与操作控件。

输入框引用沿既有 Space 与文件工作面查看，不增加预览浮窗或第二套导航控件；显式查看和后台准备的行为边界统一见上述交互章节。

### 操作栏与原工作面

顶部使用横跨左右的同一条 32–36px 操作栏，过滤区与当前上下文区沿主工作面比例对齐，使用一条连续背景与底边界。右侧工作面标题与身份区域可唤出 Focus 菜单，长名称截断并按需查看全文；必要动作与系统窗口控件始终可操作，不堆叠大标题、副标题和第二条工具栏。下面直接延续完整的 Region 工作面；调整布局无进入动画、白屏或 loading 闪烁。所有子区保留 min-width/min-height 的溢出边界与可操作 resize handle。More 沿既有共享菜单的视觉与命中区，不另画菜单工具条；标题与改名的对象归属、悬停、键盘入口、改名取消与显式继续/关闭后的第一键归属见交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)的操作栏合同，不新增焦点提示条。

`View in Space` 与 `Chat about this tab with Mote` 在右侧同一操作栏直接可发现，沿原紧凑按钮与图标语言；宽窗可显示短文字，窄分栏保留可辨图标、完整 tooltip、可访问名和独立键盘命中，不只藏回 More。长 Tab 名、Review、More、关闭投影及系统窗口控件仍可操作，不增加第二工具行或压住 Region 内容。讨论的准确 Tab 和 Mote 目标、草稿与投递事实只定义在交互 SSOT 的对应操作栏合同。

Chat 采用同一紧凑 split button：原明确 Chat 动作与相邻当前 Mote 名／下拉各有独立命中；宽时短名可扫读，窄时保 Mote 图形、chevron、完整当前目标 tooltip／可访问名与键盘入口，不能挤掉 More、关闭和原 Region 内容。选择菜单复用现共享 HoverDropdownMenu／RadioItem 和原 Mote 身份图形，选中、归档、未知以可读名称和说明区分，不按颜色猜身份，不新增标题行或第二工具栏。菜单 Escape 回本次仍可用触发器，较晚输入焦点优先；收件与记忆、选择不发送的行为仅定义在交互 SSOT 同段。

右侧操作栏以当前 Tab 名称为主，Space 与 Chat 为常用动作；Chat 收件 Mote 与原 Region 的执行 Host 分开成组。Host 保安静的资料层级，Region 菜单与 Focus 视图菜单各有明确作用范围。长收件名称按实际分栏宽度收紧，不挤掉可辨的当前工作面名称、原菜单和独立收起入口；仍使用同一条操作带，不增加控制或资料 owner。

操作栏菜单中的 `Stop Agent` 以明确选中的 Agent 为对象，原确认框展示准确对象名与停止当前 Run 的后果，不能让 Tab 改名或独立收起图标冒 Agent 停止。沿现菜单入口，不增加常驻按钮、工具行或挤掉长名称和原关闭命中区；未知身份说明与确认取消／失败沿同一可读服务语汇。停止与退休事实边界只定义在同主题交互合同。

同一收起投影动作只留最右侧常驻快捷入口，Focus 菜单不再重复图标和文案；快捷入口仍可见、可命中和可键盘操作。本格菜单与 Focus 菜单按已有作用范围区分，原 Rename／显示级别／Review／Stop 仍用原菜单语言，不新增按钮或工具行。行为与焦点资格只定义在同主题交互合同。

单格预览的身份与既有控制合带按交互合同[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)执行；不再保留重复身份的空行，原菜单和模式仍清楚可达。多格保各格局部控制与原关闭命中区，合带不以 overlay 压住正文、首行输出、History 或输入。

Focus 过滤区收窄时以可识别的搜索与当前筛选摘要保留层次，完整值按需可读，不把两个筛选都裁成无法区分的 All；沿本段 32–36px 单操作栏与系统窗口让位，不加第二工具行，行为只见交互 SSOT 的操作栏合同。

### 离线目录与导航

混合执行泳道中的 Disconnected 保项目标题带内的独立中性图形与 32px 图标／角标入口；无论数量、当前选中或搜索命中，不分配身体卡片列宽，不在各泳道铺开名册。入口摘要仍沿既有 tooltip 层，完整内容进入同一个离线目录；不是再建一套状态页面。目录是可浏览的紧凑分组列表，使用原左主内容可用高度和一个明确的内部纵向滚动面，不能在只有离线项时固定占 45% 留下空看板，也不能靠嵌套裁切隐去后续组。组头以现 Project 图标、Branch 或 Topic 专属图形、准确名称和数量表达归属，不堆四层标题；条目以两层信息呈现名称与来源清楚的已有摘录，最近已知活动和明确查看／原工作面动作作为克制辅助，完整名称和未知说明可按需读取。32px 紧凑入口不等于目录正文仍压成 28px 姓名砖块。320／640／宽窗口均保可读条目、完整过滤值、末组可滚动到达和命中；不新增全局标题行、工具栏或横向滚动，不改变 Recent Focus 用户高度、原分栏比例和状态栏。资格、真实过滤、查看／恢复及准确返回只定义在交互 SSOT 同名段。

不为 Focus 另留一行标题或冗余说明脚注，必要过滤控件使用紧凑内容行。左下角 Focus 导航项吸收原 status bar 的 Agent 摘要，名称后只保留有值的短运行数与待处理数；注意色只用于待处理，详细类别按需读取，不增加箭头组、独立名册或第三层 chrome。Focus 的入口、观测与定位共用一个紧凑命中区；全局状态栏密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)。PMO 提醒沿用现有紧凑入口，更新不重排执行卡片；请求更新与原 Region 定位合同归交互 SSOT 的对应 Focus 与 PMO 焦点段。提醒收起后不留下占位控件；浮窗的焦点交还遵守同一交互段，不增加第二个入口。恢复打开时的键盘返回也复用常驻入口，不新增返回按钮或占位。

### 音轨几何与刻度

原工作面的顶部 Activity 标尺沿[共同密度预算的 Activity Ruler](shared-rules.md#密度预算)；下文只定义底部 Recent Focus。

Recent Focus 的刻度模式与时区设置沿原紧凑单工具带按需展开，不增加常驻控件行或挤掉轨道；四级整时间刻度以长度与强度可辨，文字按实际时间区域宽度减少且不重叠。查询范围两端仍可读，不为填满窄窗口伪造整时间刻度；重复本地时间的偏移可发现。三模式、十一档窗口、时区与历史事实边界只定义在交互SSOT对应Recent Focus段。

底部音轨参考视频编辑器的水平标尺、细分刻度、固定轨道身份头、低饱和片段与竖向播放头。顶部一条约 28px 工具带提供历史范围、缩放与展开/收起；初始整体约 96px，高度可从顶边拖拽调整，边界有可发现的横向拖拽柄与键盘焦点。收起态只留工具带，展开恢复用户高度；音轨至多占主内容的一半，避免挤掉原工作面。单轨约 24px，轨道数量增加时在该区独立纵向滚动，水平缩放拥有同步标尺与轨道视口；精确时间通过 tooltip 与可访问名称读取。选中片段用柔和填充与清晰边界标示，键盘可定位已有 Context；播放头与选中标识的语义统一归交互 SSOT 对应 Recent Focus 段。不画装饰性波形或虚构时长。无历史时只用短的就地说明。

色彩沿用现有中性 surface 和状态 token；采用清晰的字号、对齐、单一内容边界与 restrained motion。减少重复背景、胶囊、边框和同义标签；项目、任务、动作、状态、历史各自只承担自己的语义。
