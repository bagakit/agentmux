## Agent 焦点历史与 PMO 隔离的空间密度

Agents 表面在工具栏下提供一条低高度的“最近执行 Agent”上下文 rail：只显示当前与少量最近 Session 的头像、显示名和状态，允许直接回到对应工作面；没有历史时用一行短空态，不占用卡片首屏。PMO 浮窗不复用这条 rail，也不在执行 Agent 卡片中混入 PMO 身份。PMO 的当前 Session 沿[原 Mote 对象导航、Tab 与 Region 工作面](motes-and-coordination.md#mote-快捷入口与当前协调上下文)表达，避免两个焦点在同一条视觉层级竞争。

焦点历史是导航事实，不额外创建卡片、Region 或对话。rail 使用现有 Agent 头像与状态语言，最近项按轻微叠压和紧凑间距排列；完整 Session、Workspace 和恢复状态放入 tooltip/可访问名称。

## Focus 执行台与底部视频编辑器式音轨

用户要求的成熟产品水准、完整使用流程自行体验与竞品比较边界，统一归交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)。本节的密度、可读性与控件命中须在该完整流程的宽窄窗口和鼠标、键盘操作中成立。

Focus 首屏只显示交互 SSOT 同节确认的 Agent 集合；普通 Terminal 不占泳道、筛选、空列或预览行，不使用 Terminal 图标充当 Agent 身份。手动启动且已核的 Agent 使用现有 Provider 身份图形、原上下文名与克制状态；缺少任务信号仍读中性状态，不伪装成 Working／Results。识别未确认的说明留在原 Terminal 的就地服务提示，不添加全局名册、常驻探测条或阻断浮层；原右侧 Terminal 和历史密度保持。识别、控制权和保留边界只定义在交互 SSOT 的 Terminal Agent 资格段。

Focus 入口沿原低高度按钮使用共享状态字形与准确数量：Working 使用工作图形，需回复与明确错误分别使用各自图形，零值不占位。原 Focus 主图标保持；聚合组头不是单个 Agent 的状态，中性组不能统一画成 Idle。

入口预览保持紧凑、只读、非交互的 tooltip：顶部为短状态概览，下面最多三条复用标准 Agent 身份、状态与摘录的双层摘要。待处理和必要原因优先，Project／Topic／Executor 归属低强调但可辨；未知、中断、连接和恢复沿卡片同一图形，不自绘第二套映射。长名称与摘要有界，必要服务原因允许短换行，不重复完整路径、Session 标识、身份标题或整段回复。无状态类别不铺显眼色块；空态简短，剩余数量按需说明。执行 MRU 不显示为当前关注，完整归属与准确状态保可访问名称。

浮层锚定在入口上方、限制在 viewport 内，沿窗口级 tooltip 与 Browser 让位协议，保持原按钮命中区；不在不可移入的 tooltip 内塞入点击、回答或 Pin 动作。关闭、失焦、隐藏后不留旧动态或迟到预览。状态栏密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)，事实与排序只见[Focus 入口行为](../behavior/focus-context.md#项目归属任务状态与恢复)。

用户反馈 Focus 不够现代化，卡片信息看不出区别且空间利用率低；用户要求时间音轨参考视频编辑软件并放到最下面。交互、事实与连续性规则归交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)。

### 项目扫描与泳道

Focus 上方为紧凑的项目扫描区与原 Tab 工作面，底部为横跨整个 Focus 的 Recent Focus 音轨，再下面是全局状态栏，其密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)。当前完整泳道、无当前 Context 的历史项目标题入口与已观察历史项目共用紧凑项目语汇；没有当前卡片时不绘制空状态身体或大空态，轻量标题保短名、必要归属和对应的准确历史回顾入口。历史访问用低强调的历史标识与可区分日期的 Last focused 表达，不能借当前 Working／Results 色暗示状态；较早或时间未知的已保留项目可集中收起，折叠处仍有准确项目数量、可见键盘焦点与展开入口。原日期窗口回顾入口可辨，长名称和窄宽度下不叠压计数、历史回顾入口命中或动作；事实、筛选与保留边界只定义在交互 SSOT 的[项目近期活动规则](../behavior/focus-context.md#项目归属任务状态与恢复)。

当前所在泳道标题用克制淡底、细边线与名称强调，在宽窄和明暗外观中都可辨；不扩卡片背景或添常驻说明，不借 Working/Results 色表达选择。当前标定与筛选/键盘焦点视觉职责分开，原标题、计数和动作边界不变。

主工作面保留可调整比例；各泳道按相同状态顺序排列，由实际非空状态、条目密度与可读卡宽共同决定行与子列。不能因所有状态勉强各容一列就强制单排长堆叠，也不能在统一宽度断点把四组状态全部纵排。单非空泳道在常见窄栏仍横向利用空间，零态收成紧凑状态带而不各占整行，避免多个泳道各自横向滚动。

整个 Focus 窄到无法同时容纳可读扫描区与原工作面时，扫描区在上方有界滚动，原工作面在下方使用完整宽度，底部音轨沿原边界保留。临时纵向呈现不改原 Tab、Region、草稿或当前分栏比例；回到足够宽度恢复原比例。只在左右分栏时呈现对应的宽度调节柄，避免窄面出现无效的横向拖拽；泳道内部仍按实际内容密度布局。

零态图标在项目标题带组成紧凑状态组，保留原 24px 图标／命中单元，不再作为身体窄轨扣减卡片列宽；非空状态不在标题带重复列头或数量。数量大于零时作为图标旁的小角标，随原图标单元呈现，不另占数字一行；数量超过 99 时角标显示 99+，原 tooltip／可访问名称仍表达准确总数；数量为零时只保低强调图标，不显示 0、不绘制显眼状态色背景。图标、角标与原命中区在同一紧凑组头高度内可辨，多位数不遮住图形、名字或相邻状态。

完整名称、准确计数与必要 Unknown 说明保在原可访问标签与 tooltip，恢复与未知的准确状态按需可读；零态不造额外 tabstop，标题名字与入口各有边界，确实不足只作必要换行，不用整宽彩色空行。列头与本泳道实际列宽对应，列宽不同不暗示跨项目位置对齐。

有内容状态组的宽度与真正子列数对应，行归属和列预算沿同一结果呈现，减少整个项目的无谓高度；同一实际行的子列在可读上下界内均分该行可用宽度，状态组按自己的子列数占宽。分行后重新使用该行的完整预算，末行多卡组可用多个子列，不能仍以单卡宽长堆叠并留下大块可用空间；只有达到单卡既有上界或没有更多真实卡片可排才保留必要余量。组头背景与实际内容对齐，不制造空子列、宽间隙或随宽度边界反复跳动。原名称与最多两行工作信息仍可读，不能靠裁掉 recap、动作或必要说明换取低高度；预算与稳定性沿[泳道行为](../behavior/focus-context.md#项目归属任务状态与恢复)，不把相近行高当作固定等高事实。

宽度尚未有效测得不代表真实空间不足，可见泳道仍保可读列宽、名称与摘要，不能将非空状态和卡片压成零宽。历史项目标题先出现、执行 Context 随后到达，以及隐藏后重新可见时，即使窗口尺寸未变也须得到正确布局，不依赖用户先调整窗口才恢复；原 Context、选择、菜单、草稿与工作面保持。

项目不再占固定列或独立大标题行：紧凑组头优先完整显示 Project／Topic／Mote 对象名、类型与必要来源位置、状态与准确计数、最近活动时间及原动作。Host 默认只保既有可辨图标，完整名称在同处 hover／键盘 focus 的说明和可访问名称中读取，不常驻 This Mac 等重复文字。Topic 说明默认使用短摘录，只占上述关键信息之后的剩余宽度；指针移到对应泳道或键盘聚焦其入口时可读完整原说明，长文不撑开组头或重排泳道，必要时使用有界按需阅读。不能让说明占据整行而把对象名、类型、位置或活动时间挤成几个字。实际空间仍不足时沿原组头只作必要换行，保持关键信息可辨和动作完整命中，不增加独立工具行。

最近真实活动以低强调的完整相对时间直接可读，按需说明可读准确时刻；缺事实明确未知，Last focused／历史访问保持不同名称，不把访问写成活动。时间与名称、状态、动作在宽窄窗口中不叠压，不为计时固定新增一行；排序、合并更新与时间事实只见[同主题交互约束](../behavior/focus-context.md#项目归属任务状态与恢复)。列头保短名字，并以现有状态 token 的克制色和非颜色标识区分，不反复绘制彩色框。

卡片当前活动未知时显示准确的过期或未确认原因，沿原服务说明呈现最后确认状态、可区分日期的观察时刻及当前进程／输入情况；缺失事实不补造，不用超时或错误色代替未知。短状态留在原状态位置，较长说明按需可读，并保持名称、摘要与窄宽卡片的可读性；不新增常驻状态栏。判据沿[当前活动合同](../behavior/agent-capabilities-and-messaging.md#hook-配置隔离与非-agentmux-会话)。

列头表达分组，卡片状态形状表达原 Run／活动事实，整面中性 surface 表达选择与键盘焦点；Idle／Unknown 与 Results 不因共用圆点或近似颜色混读，不重分类或改全局状态色。已销毁 worktree 的泳道使用中性虚线标记与明确文字，不以错误色代替事实。图标、Topic 说明与状态事实边界见交互 SSOT 对应 Focus 段。

已确认 Topic 的组头使用既有 notebook 语汇、明确 Topic 类型与对象名，必要 Category 作为次级位置；Mote 使用现有专属身份图形、Mote 类型与实际对象名，必要工作上下文仍可辨。首屏不重复 Scratch / Project 父图标、父名称或无意义面包屑；普通项目保原项目图标与必要 Branch 路径。Survey 沿原项目泳道集中表达明确来源，原探索／Zone 名称按需可读，不为每个探索新增泳道，也不增加打断近期项目顺序的全局来源分段。完整 Host / 路径 / 多处合法位置进入同一按需来源，未知分类使用中性提示。既有用户图标选择优先，Focus 专属 Topic 字形不改变 Space / Rail 原自动 monogram 默认，不新增第二份图标账本或读取；身份、关系与精确导航边界见[同主题交互约束](../behavior/focus-context.md#项目归属任务状态与恢复)。

普通项目、Topic、Mote 与 Survey 来源使用克制且彼此可辨的低对比度背景层次，范围限原泳道／组头，不为每卡叠加彩色框、侧边色条或新增图例。来源底色只辅助类型与名称，明暗外观和无颜色感知时仍可辨；不借 Working、Results、注意色或当前选择色表达来源。选中、hover、键盘焦点及必要服务说明保持足够对比度，来源变化不遮盖真实状态。

Mote 待处理条带保留一个紧凑入口和原注意色：身份图形与名称、待处理数量、打开动作有清楚的可读边界。长名称可有界省略，完整名仍由原可访问名称和上下文按需阅读；数量与动作完整可辨，实际条带宽度不足时只作必要换行，不能相叠、裁掉动作或把名称压至不可辨。鼠标命中与可见键盘焦点沿原整面按钮，不拆成新的导航控件；不增加全局工具行，也不改变泳道卡片或 Composer 密度。事实与精确导航规则见交互 SSOT 的 Mote 待处理入口段。

Focus 固定消息的正文外观引用交互合同《共同对话的用户默认外观与协作来源》；标记与来源说明仍区别真实作者事实，不增加图例或常驻身份栏。

### 时间轴与历史回顾

Recent Focus 的紧凑工具栏提供日期时间入口、前后窗口、窗口大小与回到当前时刻的动作；窗口范围始终可扫描，窄宽度下仍为单行，工具组可以横向浏览；滚动反馈不能盖住按钮的可见命中区，也不增高工具带或挤掉轨道。当前时刻使用一条细竖线与标尺上的短标识贯穿时间区域，不占 Context 身份列；Current 用整行弱对比 surface、名称字重和非色目标标记表达，与 Now 时间线独立；仅收起工作面仍保主标定。消息使用轻量、可键盘到达的标记；与工作状态及关注片段在原轨道内分层，正文进入按需预览，不展开为占行消息卡片。窗口、取消高度调整与事实边界只定义在交互 SSOT 对应 Recent Focus 段。消息沿既有身份图形、tooltip 和可访问名区别已核 Agent、明确人类与未知作者；发送者与项目信息在单条查看时出现，执行关联复用原轨道事实，不增加占行卡片、常驻工具条或多条跨泳道连线。发送者、当前归属与执行关系的行为边界只定义在交互 SSOT 对应消息段。

Recent Focus 的悬停卡采用清楚的身份与一条任务/消息主信息，项目/Topic、状态与记录来源为次级辅助；头像、字重、留白和图标各有语义，不堆叠表格、重复姓名、聊天气泡外再套相同标题或长段空字段。快速预览保持紧凑，固定阅读保原共同正文完整可读；进入/退出应克制地表达同一对象连续性，不跳动工具带/轨道、不盖控制区，减少动效时保持同样信息与操作。行为与事实边界只定义在交互 SSOT 对应 Recent Focus 检视段。 工作／访问／在线／缺口检视复用此层级：对象与事件为首行，可信时间／时长为第二层，作者／历史项目／Current 资料按需各出现一次。窄窗浮层保持完整可读且不盖时间工具带；浮层定位沿现共享 Portal／FloatingUI，不能用长系统 tooltip 或另一套 Reader 代替。

鼠标平移与＋／－缩放沿交互 SSOT 同节[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)的新增窗口约束；原数字范围两侧加入紧凑的＋／－图标按钮，边界禁用与 tooltip／可访问名称明确。仍共用原一条工具带，正常、窄和短窗口保留日期、Now 与至少一条完整轨道，不增高状态栏或另加缩放工具行。

项目分组与关闭后历史回顾：项目分组的行为与历史保留边界见交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)同名段。用项目图标、短名与折叠控件组成紧凑组头，Branch／Topic 只在区分必要时作为次级路径或 Session 行辅助信息，不强制每组展开四层标题。折叠时展示本窗口内已有片段的聚合轮廓与有事实的 Session 数，明确为项目汇总，不冒单条 Run 或精确执行时长。已关闭工作面的轨道使用克制的中性身份标记，状态和历史缺口可按需读取，不大量常驻“已关闭／Disconnected”文字；沿现有标尺、本节图层预算的单轨、可调高度和独立滚动边界呈现。默认只显示本窗口有事实的项目，不列出所有过去 Session，也不加一块常驻历史墓地。字节与事件双重保留边界只定义在交互 SSOT 同名段；沿既有范围／覆盖说明按需可读，不为该边界增加常驻 banner。

Recent Focus 横向浏览期间，项目与轨道沿交互 SSOT 同节的本次进入顺序稳定呈现；窗口事实显隐不以动画重排已读条目，名称相同仍可用原身份区分。保既有紧凑组头、本节图层预算的轨道、可调名称列和独立滚动，不另加排序工具带、固定空行或历史墓地；行为和活动事实仅引用上述交互合同。

归档输入与已观察 Context 项目的关系只见交互 SSOT 同节的新补充；保留紧凑项目组、本节图层预算的轨道和中性的未知组。用组头 tooltip／按需详情解释「已观察 Context 归属，消息发生时项目未记录」，不为每条消息增加常驻项目徽章或长说明。

同一条约 32px 轨道内，上层 24px 高度的命中带展示离散消息，下层约 4px 展示工作状态并留出间隙，关注访问使用独立细线，在线空心点对齐 Now；头像不压在工作带上。消息作者头像约 16px，水平入口约20px、纵向24px，头像与方向图形均收进该宽度；局部错开时用细短定位线连接到原事件时刻。输入／回复以独立的非色方向图形及可访问名区分，聚合入口保持同级20px水平尺寸且数量可辨，不能为数个头像加宽成卡片再反推聚合。gutter 名称约 11–12px，Current 的字重、弱 surface 与目标图形共同可扫描；工作低饱和状态色不兼作作者或 Current。标尺、工具带、名称列与原独立滚动边界保持，不加第二条工具行。工作带按所选窗口裁剪，缺起止、保留裁切和未知不画虚构长条；在线、访问与消息可键盘到达。窄窗口保留查询两端，刻度文字按实际宽度减少且不相叠。实际碰撞、事实、时长和 Current 资格唯一引用交互 SSOT 同节，不在此重复定义。共享对话轴沿同一紧凑头像／数量入口、局部错开和最终盒预算，不变更 Ruler 范围控件。

用户反馈时间轴大片空白、灰绿线难懂。Now 当前时刻、Working 工作状态、Focused 关注访问与 Running 当前 Run 在线在原 Recent Focus 工具带/标尺同高度内使用短文字和不同形状可辨；当前时刻使用非工作 accent，working 保低饱和带，关注保持中性短片，在线为独立空心点。宽窗可见短图例，窄窗沿同一入口可读可达；图例、tooltip 与可访问名称使用同一含义，当前状态与历史覆盖分别可辨；真实已读来源数和覆盖说明可见可达，不新增常驻 banner 或增高全局状态栏。该图例只解释时间图形，不修改作者/共同正文的“不增加图例”条款；多来源保留与未知边界统一见交互 SSOT 同节时间轴覆盖约束。

当前输入的观察提醒沿原 Input records／覆盖入口与紧凑阅读面可读可达，使用已有服务说明和动作语言，区分「自动更新不可用」与「保留当前阅读窗」；不另占工具带、全局状态栏或常驻横幅，不把服务提醒画成输入标记，行为唯一见交互 SSOT 同节对应约束。

大数量下的滚动与加载沿用这些自然窗口边界，保持原工作面可读与输入命中；性能资格、数据来源及同一工作面交还规则归交互 SSOT 的对应 Focus 章节，不以隐藏内容、额外 loading 屏或另一套列表解释资格结果。长期不活跃泳道后置的依据与稳定次序也归该章节；后置仍使用原紧凑泳道，不增加占行的空闲分区或每项计时标签，不以动画移动打断阅读。

### 卡片、预览与状态

已核执行 Agent（含 Terminal 内已核的 Agent）使用统一两层条目：首行左侧是共享 Tab／Region 或 Executor 身份与可识别任务名，右上角固定呈现共享状态字形，不等 hover 才出现，也不因 Results 组头已显示而省去卡片状态；完整状态通过 hover、父行键盘 focus 的 tooltip 和可访问名称读取。次行是最近已知动作或真实状态说明，必要请求与失败事实不只藏在 tooltip。身份图形只占标题行，正文使用卡片的可用宽度，不被整卡两侧头像或尾部图标永久缩进；卡片不再显示 hover 跳转图标，整卡打开行为仍清楚可发现。Provider 已由身份图标表达，完整绝对路径和内部标识进入 tooltip/详情；缺少任务事实时保留真实可识别身份。行高约 48–60px，组头约 28px；空分组不放大卡片。选中用整行柔和 surface 与字重表达，需处理与错误只在状态标识承载颜色，普通项不反复绘制彩色框。悬停与键盘聚焦保原整面反馈与明确键盘入口，不通过浮动位移表达 hover。

紧凑卡片左上身份沿[共享 Tab 缩略图与 Region 地图](spaces-and-layout.md#topic-topology-tab-缩略图的空间密度)：多 Region 使用真实分格，hover／键盘聚焦查看同一原地图，并在缩略图和地图内强调本卡 Agent 的目标格；单 Region 直接复用现 Executor／内容身份设计。图形、名字和右上状态各有预算，目标格高亮不代替状态或选中，也不新增常驻第三行、独立跳转动作或重复头像。准确位置和未知边界只见交互 SSOT 的[卡片合同](../behavior/focus-context.md#卡片内容预览与-agent-操作)。

Goal 关系入口用共享 Goal 图标安静地放在固定状态左侧，身份仍最左、状态仍最右，标题与两行原正文各保预算；不另加 Goal 泳道、进度或常驻关系行。单 Goal 图标可按需读标题与关系，多 Goal 加已确认关系的去重数量并用原紧凑菜单逐条选择；无关系且无候选不留空槽，已结束在原说明或列表可辨。Goal 与主卡片使用独立兄弟控件和键盘命中，不嵌套按钮；鼠标、键盘的完整名称、关系、返回及原菜单可达。关系、身份和查看语义唯一见[Goal 关联合同](../behavior/focus-context.md#goal-关联与独立查看)。

只有未确认候选时，Goal 图标常驻可辨的关系未知标记，可访问名称和按需说明明确表达「可能的 Goal 引用／Session Host 未确认」，不能只在 hover 中修正普通关系图标的确定含义；此标记不借用最右 Agent 状态。已有确认关系时保原确认数量，候选在同一披露内以 Host 未确认组可读；同 Goal 只列一次，确认与未确认角色／来源分层说明。候选数量如需展示须明确是候选数，不能与确认关系数混读；入口仍保持原紧凑标题行，不增加正文行或服务横幅。

卡片的信息层级须以可读工作内容为中心：名称保持首层字重与对比，摘录使用较名称安静的现有次级正文色，强调、代码和服务说明仍可读，不用与标题相同的整段亮度争抢重点。紧凑 Markdown 沿共同解析语言保强调、代码与结构含义，标题／列表不扩大字号或垂直间距，不露可解析的原始语法标记，不嵌链接控件、图片读取或独立滚动区。活动正文允许在窄列占既有行数，保住工具动词与具体文件/命令，不把全部识别信息藏进 hover。首层名称与短状态各有边界，长名称、中文和未知状态不得互相撑出行框；完整内容仍可按需查看。两层结构不新增常驻第三行、进度装饰、重复的项目/Provider/路径标签，也不挤高全局状态栏。内容来源与请求/结果/失败优先级只在交互 SSOT 的对应 Focus 段定义。

Focus、工作区 Agents 工具与 ProjectActivity 共用同一单 Agent 信息层级，卡片／行各守原尺寸与打开动作。身份、名称、固定状态和两行进展为主层；阅读面默认以原回复和输入为主体，用量、Goal、已知消息关系及详细来源在显式进入的资料层阅读，不把通用资料折叠行置于正文之前。底部资料摘要用既有语义图标配准确的会话累计 token、当前上下文剩余和已确认 Goal 数，缺事实保持未知；消息关系没有现成数量时保独立可读资料入口，不补零或为填满图标新增读取。图标的 hover／键盘说明及可访问名称表达指标含义、范围和原数，不只靠颜色或无名称数字。未知用量不形成正文前的空字段或指标墙，必要服务原因仍紧邻身份可读。资料层区分会话累计、最近响应和上下文占用／剩余，关系保角色及覆盖说明，来源细节按需读，不逐项堆叠 Host 和内部 ID。用量内容复用原输入面详情，不再嵌用量弹层；事实与准确导航只归[共享卡片行为](../behavior/focus-context.md#卡片内容预览与-agent-操作)。

ProjectActivity 保留紧凑状态图标与准确数量，展开面只保一处整体状态汇总，不在菜单标题、说明行和子层重复同范围计数。Zone／Tab 使用低强调的组织标题与必要位置线索，路径和完整 Host 等细节按需可读；同名对象仍可辨。Agent 行沿共享两层内容突出原名、固定状态、最近已知进展与必要服务原因，不重复整段组摘要、项目／Provider／路径。组的准确数量、真实 age 与未知说明可读可达；同一 Agent 的多个位置用轻量位置说明表达，不能让去重数量与重复行看起来互相矛盾。身份图形沿原 Executor／Agent 外观，在菜单内不再形成另一处拓扑 hover 命中；完整位置仍在共享 Reader 按需阅读。

只有一个有成员的组织组时，直接显示 Agent 行及已有的低强调 Tab 标题，不让用户经过没有选择价值的中间层；Zone 与无位置成员并存时仍保各组入口。宽面子级在 hover 时侧向展开；窄面组织行以箭头和 `Select a group to see its Agents` 表达显式进入，点击、Enter 或 Right 直接显示 Agent 列表，不增加 Show Agents 中间控件。窄面用一份可读宽度的列表逐级呈现，顶部显示当前范围与明确返回入口，不把父子两层各压成窄栏，也不因组织行 hover 替换整层。窗口放宽时保留已进入的单列层，返回后再采用宽面级联。各层保有界滚动，返回保持原行与阅读位置；名称、状态、正文和命中区先得到可用预算，长名按需读全，路径和重复统计不挤掉任务辨认信息。单列与级联使用同一行和焦点语言，组织行的进入与 Agent 行的 hover 阅读、明确打开工作面分别可辨。Agent 浮窗沿同一 Reader 的阅读 surface 与层级，不另造菜单专用详情外观；父行、子菜单和阅读面之间保连续、可自然通过的指针路径，键盘焦点清楚可辨。成员、位置、交互与读取边界唯一见[Activity 活跃入口与空间级联](../behavior/focus-context.md#activity-活跃入口与空间级联)。

Focus 卡片 recap、预览与 Agent 菜单沿交互 SSOT 同节合同。身份与工作内容保持两个层级；普通卡片内容区以最多两行带来源的会话摘录承担主体，不再把正文压成一行并常驻工具／Stop／transport副行；无摘录沿原活动摘要，紧急与必要服务说明直接可读，完整活动和原摘录按需。已识别的包装声明与来源安静表达，不挤掉具体正文；解析和事实边界只沿交互合同。缺摘录沿现活动／空态，不增加常驻第三层、重复项目／Provider／路径或进度装饰；中断任务仍为原项目内的可读卡片，使用恢复警告和直接可读的服务说明，不压成仅姓名图标。悬停、选中与键盘聚焦使用层次不同的整面 surface、字重或完整焦点轮廓，不用状态颜色或单侧细条冒充选择；不以位移表达悬停。

完整预览采用不透明的阅读 surface，在窗口内保持可读宽度与有界高度，以一个外层纵向滚动区承载当前正文或资料层，不再把回复单独嵌入短小纵滚区；窄／矮窗口中最后一段仍可到达，减少动效时同样可用。头部主头像以可辨尺寸复用已核 Project 或 Mote 的现有头像与 Executor 组合外观，表达主体／归属和执行者；不以微小 Provider 图形或 Region 分格代替主体头像，也不从名称、路径或第一处位置猜 Project／Mote。归属缺失或无法确认唯一主体时保原 Executor 身份和按需来源，不伪造组合头像。Region 图作为次级位置线索，完整地图与准确目标格沿原检视入口可读。

头部只放一个原名称，长名约两行并保完整可访问名称与按需全文；状态和活动时间使用独立预算。Reader 状态沿同一原事实提供准确字形与可直接读懂的完整名称，覆盖已确认工作、等待、闲置、结束、失败／断连和未知，不只用 Active 图形、裸问号或颜色让用户猜义。必要服务原因直接可读时不重复整段状态说明；普通未观察描述和观察范围注记降为按需资料，缺口不能被写成正常状态。正文、资料摘要与服务说明不放没有独立含义的 Info／叹号装饰，必要警告与未知标记仍保原语义。

原回复以完整正文为主，最近输入以紧凑任务回忆条目补充；常规的 Latest reply、Observed at opening、End of this reading window、Earlier records remain in History 等框架标签不再围住正文或常驻占行，阅读范围与 History 路径在原资料入口按需可读。确有冻结、来源变化、失败或部分覆盖时仍有准确可发现的说明，不能为少字抹掉缺口。按需全文继续沿共同 Markdown 的段落、列表、强调与代码保持层次，长行／表格仅在自身边界横向滚动；完整纯文本长正文仍可选取、换行和读到末尾。原正文、来源与必要说明各表达一次，不叠重复姓名、SID、路径或包装标题。正文只读模式把链接、非图片资源引用、文档锚点和脚注前后跳呈现为可选文字，不留可聚焦的无动作控件，不以 inert 换取只读而破坏选择；普通共同正文的既有控件保持。

同一阅读面可由临时预览进入 Agent 浮动书签，身份、正文及来源保持连续，不另开默认常驻侧栏。单一书签／取消书签按钮放在无需滚动即可到达的标题区，以可辨非色标记和准确可访问名称表达状态；底部不重复固定按钮，不新增一条固定说明行、第二工具带或重复标题，原键盘入口保留。正文、资料和返回入口均可键盘到达，焦点清楚。底部资料摘要、显式进入工作面和关闭组成同一紧凑动作区，已固定时提供独立的 Agent 链接复制及末端缩放命中区；常规单行高度、字号和垂直对齐接近现项目 status bar，不给动作再套厚内边距或重复 Info 图标。窄宽只必要换行，资料摘要与动作清楚成组，不缩小命中区、裁控件或以底栏遮挡末段。资料页有明确返回正文入口，未知与来源变化说明不因简洁而隐藏；主体唯一性、更新、关闭、选区与恢复只归[书签行为](../behavior/focus-context.md#agent-浮动书签)。

已固定窗口的标题旁提供轻量复制标题动作，当前回复的范围／标题处提供复制该回复动作，Agent 链接复制留在底栏；不把三项塞进通用 More 菜单或增加每条用户输入工具栏。沿共享复制语汇提供低强调图标、可见焦点、准确名称与充分命中区，鼠标和键盘路径等价。成功可短暂换为确认图形或沿原反馈说明，不改变布局宽高或重复长 toast；失败沿原错误说明保可重试。回复缺失或仅为摘录时的资格与范围沿书签行为说明，不用装饰性成功或“最新”标签掩盖；复制按钮不占标题拖动区域。

临时预览与书签沿同一内容优先的阅读 surface 移动，不变成另一套 Agent 卡或默认工作台侧栏。有足够可用空间时，临时预览优先在入口侧边呈现，避开入口及打开预览的鼠标位置；窄视口按实际空间采用上下定位，保持标题、固定入口及正文可达。标题保一个原名称、共享身份、当前状态与必要服务事实；两种状态的标题均提供可辨的拖动提示与抓取指针，可拖区与按钮命中区分开，移动时不把姓名当按钮、不以整块正文作拖区。拖动连续跟随手势，不闪回旧位置；纯平移不令正文重新排版、抖动或发生无关滚动，释放后停在最后可见位置。临时预览拖动转 Pin 后沿原固定标记表达，不新加固定说明行；显式撤销本次新 Pin 时，原模态来源仍有效则恢复原可读层级，不能让临时阅读面留在遮罩后而无法阅读或关闭。转换、取消及准确来源条件只归[书签行为](../behavior/focus-context.md#agent-浮动书签)。

已固定窗口的右下缩放把手用清楚的斜角语汇表达尺寸调整，形状、方向与指针一致，不画成含义模糊或被裁切的边框 L。静态可辨、hover／键盘 focus 增强反馈，保原充分命中区且不遮关闭、正文末尾或底栏动作；有焦点时仍可读键盘尺寸提示和重定位动作，不常驻八个大把手或额外布局工具带。固定时沿当前实际尺寸，尺寸保持和主动调整只归上述书签行为，不因切换外观自动撑大窗口。最小尺寸以名称、动作与可滚动正文都可读为依据，窄／矮窗口不能为了守固定像素下界把关闭或末段移出视口。

标题、正文、底栏和输入条目统一收紧非必要纵向留白，减少重复元信息和装饰分隔，让正文保持主要高度；名称、状态和上下文动作各守预算。不能以缩小命中、压低对比、自动收小书签或截断全文换紧凑，必要来源和完整已观察原文仍可读。

多书签的主体仍各自可辨，前景层次用整面、阴影及完整焦点轮廓表达，不借 Agent 状态色或单侧细条作激活态。重复 Pin 只使已有对象前置，不重新铺排其余书签；移动、缩放和来源更新不令其他卡片跳位，保底下工作面可继续操作。恢复的几何以用户保存位置为主，屏幕条件变化只作必要的可达性调整，不把所有书签堆到同一坐标；具体稳定身份、顺序与落盘边界由[书签行为](../behavior/focus-context.md#agent-浮动书签)定义。

最新内容与正在阅读的旧版本须容易分辨：未受保护时沿原层级更新，不闪烁整面；受保护时只给克制、可操作的新内容提示，采用前不换正文或选区。最后观察快照、来源未知、原 Run／来源改变、保存失败各使用准确的短说明，必要原因仍直接可读，详细来源沿原资料入口展开；不以空态、无限 loading 或旧 Working 颜色假装当前状态。临时预览、书签、单条输入全文与资料页共用现有字体、图片及正文语言，不叠重复身份墙或再造消息阅读弹层。

预览中的位置资料每个原 occurrence 只占一条紧凑横行，沿共享小 Tab／Region 图、原位置标签、Region 数与准确高亮表达，不常驻复制大幅 Region 地图或地图内的同一 Agent 标题／状态。同名标题不反复占行，确有区分作用的原 Tab 名仍可读，完整名称按需取得；全部位置保留并在有界预览内滚动。详细地图沿次级位置入口的 hover／键盘检视取得，复用同一几何、身份外观和目标高亮，不挤占 Reader 的主体头像；其数量、精确身份及只读行为只归交互合同。

最近输入作为原回复之外的紧凑任务回忆分区，标题可简为 Recent inputs，可访问名称仍表达最近用户消息。默认最近六条已加载输入，每条采用固定高度的两行正文省略与轻量作者／记录时间，正文字号较原回复小一级、行距紧凑、上下 padding 收紧；不靠增高条目容纳长文，不给列表再叠内层纵滚。单条完整阅读的显式进入方式只归[卡片行为](../behavior/focus-context.md#卡片内容预览与-agent-操作)；所有预览与书签的条目提示统一表达点击或键盘阅读全文，不再提示悬停即展开。条目的悬停与焦点反馈须可辨，并与外层 Agent 卡片的 hover 预览区分，不增每条工具栏。全文 surface 有界、可移入滚动与选择，清楚保留原作者／记录时间，不重复整张 Agent 身份墙或增加每条 Info／复制栏。作者与完整记录日期／时间放在同一紧凑行，确实不足时只必要换行，日期不能被省略成只有时分；来源进入该时间的 title／可访问说明，不再每条另占来源行。正常窗口不绘制冗余说明；缺时和服务／覆盖问题沿交互合同保持可见。

输入采用平面列表与轻分隔，减少嵌套卡盒、标题与重复底色；图片在紧凑条目中使用稳定尺寸的小缩略图，在完整阅读中可读，加载与失败不撑坏定高条目。完整阅读的代码、段落、原图片与末段保持可读，不用图片路径或空白冒加载成功。

输入记录的项目名与有界省略路径作为安静来源注记，完整来源身份在同处按需读取，不与阅读面动作区混成多行 origin／SID 身份墙。共同用户外观沿交互合同，不重复身份墙或常驻工具栏。长中文、长行与代码在窄窗可读、可选取，数量与排序、缺时及服务说明只由同节交互合同定义；不因增加输入阅读区提高常驻卡片行高。

Agent 菜单沿原 ContextMenu、图标与 Portal 语汇，菜单头用单行省略的对象名称确认目标、降低视觉权重，不堆状态与 SID 说明；改名动作在前，准确 Session 地址复制不重复同义分享入口，`Stop Agent` 置于独立分隔的停止动作组；动作目的通过原菜单语汇表达。行内名称输入保持原卡片几何与正文层级，焦点可见；菜单与编辑不冒称卡片已选中。宽窄窗口的完整名称、来源、命中区和键盘入口均可达，不新增常驻动作栏或增高全局状态栏；动作、复制和焦点保全只定义在上述交互合同。

同 Tab 多个 Terminal 内已核的执行 Agent 在原两层条目中使用已有 Region 同名视觉编号和原工作面名区分，项目名不在每格重复，机器地址留在 tooltip/可访问说明，不加第三行或常驻徽章；事实和归属规则见交互 SSOT 对应 Focus 段。

失败或结束的已核执行 Agent 条目次行优先显示可读的退出事实，沿用两层条目与原有错误/中性色；完整说明按需查看，不新增常驻失败栏。当前泳道与历史 Run 的边界、原工作面和恢复事实只定义在交互 SSOT 对应 Focus 段。恢复接续后的选中呈现沿用本节既有选中态与工作面边界，行为只归上述交互合同。

Needs you 与 Error 共用一个紧凑待处理分组。严重性由单项状态图标与可读说明表达，授权/回复采用注意色、真实失败采用错误色，不用两块空状态框维持区别。所有状态分组统一轻量组头；泳道组头的零态和数量沿上文标题带入口约束，原过滤入口仍保名称与计数，不在项目条目下面重复一排零；已确认 Idle、活动 Unknown 与恢复上下文在原中性组内以共享字形、准确可访问名称和完整按需说明区分，组头与计数不得把 Unknown 冒称 Idle。

中性组中的已确认闲置、活动未知与待恢复保持可扫读区别；现共享状态字形、hover/键盘说明及可访问名称表达 Run 存活、活动确定性与就绪，计数说明区分 Unknown 与 Idle，不能用 Idle 总数吞掉未知。仅活动证据不足、过期或不支持报告时，由原右上共享状态图形持续表达，完整原因、观察范围及已有能力在同处 hover／键盘检视和可访问说明可读；已有任务摘录不再叠 Activity not confirmed／Last confirmed 等独立第三行。无摘录时沿原内容区给准确短说明，必要请求、真实失败／断连、恢复及来源问题仍直接可见。保任务摘录与操作入口，不把未知涂成 Working、不新增服务横幅，原注意／真实结果语汇保持。

失败 Agent 的原 Attention 处理面直接显示已有失败事实与可操作的关闭入口，动作名称清楚区分关闭失败 Session、关闭请求面和收起 Focus 投影；沿原紧凑动作组与服务窗，不增加常驻失败横幅或第二套确认面。进行中和未确认结果在原位置可读，健康或未知 Run 不被画成已结束。资格、准确对象与确认后收尾只定义在交互 SSOT 的对应 Focus 失败关闭合同。

Results 条目以真实结果摘要承担次行内容，并有可发现的查看入口；Idle 使用独立、中性的分组和短状态，不与 Working 共用运行中的视觉信号。分组数量与样式来自实际可观察内容；无产出的 Results 空分组只保留可理解的计数入口，不占一整列空白。

结果查看与原上下文交还只归交互 SSOT 的对应 Focus 章节。当前工作面的阅读、输入与几何保持稳定；未展示的保留工作面及其编辑器内容不能绘制到 Focus 泳道、音轨或输入区，也不能占用命中。目标工作面显示后沿用原内容边界与操作控件。

输入框引用沿既有 Space 与文件工作面查看，不增加预览浮窗或第二套导航控件；显式查看和后台准备的行为边界统一见上述交互章节。

### 操作栏与原工作面

窄栏或窄窗无法同时保扫描与正文可读时，打开原工作面以可用全宽展示，并提供明确的返回扫描入口；Header、原 Goal 行、正文和草稿沿正常纵向阅读，不挤成窄竖列，不保打开状态却隐藏原工作内容。返回只交还原扫描布局，行为保全沿[Goal 关联与独立查看](../behavior/focus-context.md#goal-关联与独立查看)及原工作面合同。

顶部使用横跨左右的同一条 32–36px 操作栏，过滤区与当前上下文区沿主工作面比例对齐，使用一条连续背景与底边界。右侧工作面标题与身份区域可唤出同一 Tab 菜单，长名称截断并按需查看全文；必要动作与系统窗口控件始终可操作，不堆叠大标题、副标题和第二条工具栏。Agent／Terminal 的名称、Host 与该格菜单在单格和多格中统一放在原 Region 内，复用同一紧凑角部身份语汇；顶栏不再搬入单格 Header，不增一行或重复 Region 身份。下面直接延续完整的 Region 工作面；调整布局无进入动画、白屏或 loading 闪烁。所有子区保留 min-width/min-height 的溢出边界与可操作 resize handle。同组卡片按行为 owner 的进入顺序稳定呈现，不因新活动动画换位。显式 `Tab actions` 使用可辨的 Tab 图形与短文字或展开标记，与格内 Agent More 区分；菜单沿既有共享语言与命中区，菜单头保准确 Tab 名与 Tab 作用范围，不另画菜单工具条；菜单贴合原触发器，原紧凑标题和菜单内容不为鼠标过渡增加空白带；标题与改名的对象归属、悬停、键盘入口、改名取消与显式继续/关闭后的第一键归属见交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)的操作栏合同，不新增焦点提示条。

`View in Space` 与 `Chat about this tab with Mote` 在右侧同一操作栏直接可发现，沿原紧凑按钮与图标语言；宽窗可显示短文字，窄分栏保留可辨图标、完整 tooltip、可访问名和独立键盘命中，不只藏回 More。长 Tab 名、对应明确 Agent 的 Review、Tab actions、关闭投影及系统窗口控件仍可操作，不增加第二工具行或压住 Region 内容。讨论的准确 Tab 和 Mote 目标、草稿与投递事实只定义在交互 SSOT 的对应操作栏合同。

Chat 采用同一紧凑 split button：原明确 Chat 动作与相邻当前 Mote 名／下拉各有独立命中；宽时短名可扫读，窄时保 Mote 图形、chevron、完整当前目标 tooltip／可访问名与键盘入口，不能挤掉 Tab actions、关闭和原 Region 内容。选择菜单复用现共享 HoverDropdownMenu／RadioItem 和原 Mote 身份图形，选中、归档、未知以可读名称和说明区分，不按颜色猜身份，不新增标题行或第二工具栏。菜单 Escape 回本次仍可用触发器，较晚输入焦点优先；收件与记忆、选择不发送的行为仅定义在交互 SSOT 同段。

Mote 选择菜单的头像固定占 20px 列，名称使用剩余宽度，勾选保留右端 12px 列。默认、face 与图片头像沿同一盒与名称起点排列，不因图标内部包裹层把头像拉伸成文本列。长名称在有界菜单内必要折行，归档与身份问题保留原次级说明，不重复姓名或状态；沿原 Radio、Portal 与键盘交互。

右侧操作栏以当前 Tab 名称为主，Space 与 Chat 为常用动作；Chat 收件 Mote 与原 Region 的执行 Host 分开成组。Host 保安静的资料层级，Region 的 Agent 菜单与顶栏 Tab actions 各有明确作用范围。长收件名称按实际分栏宽度收紧，不挤掉可辨的当前工作面名称、原菜单和独立收起入口；仍使用同一条操作带，不增加控制或资料 owner。

顶栏 Tab actions 与标题右键共用同一菜单内容，仅呈现 Tab 改名和 Focus 显示级别；Agent 的停止、重启和请求处理留在明确 Agent 入口，不与 Tab 操作混排。保留的直接 Review 以原 Agent 名称确认对象，不能让 Tab 标题、Chat 收件 Mote 或独立收起图标冒充请求目标。格内 Agent 菜单沿原确认框展示准确对象名与当前 Run 后果，未知身份说明及取消／失败沿同一可读服务语汇；停止与退休事实边界只定义在同主题交互合同。

同一收起投影动作只留最右侧常驻快捷入口，Tab 菜单不再重复图标和文案；快捷入口仍可见、可命中和可键盘操作。本格 Agent 菜单与 Tab 菜单按已有作用范围区分，Tab 菜单中的 Rename／显示级别和准确 Agent 的原 Review／Stop 入口仍用共享菜单语言，不新增按钮或工具行。行为与焦点资格只定义在同主题交互合同。

Region 角部身份栏与原关闭命中区不压住正文、首行输出、History 或输入，原菜单和模式仍清楚可达；对象与动作范围只见交互合同[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)。

Focus 过滤区沿本段 32–36px 单操作栏与系统窗口让位。宽栏将当前项目、状态和类型表达为紧凑条件片，维度名、原值及独立移除命中可辨；长名称与多值摘要有界，完整值在同一筛选面板可读。按实际可用宽度自动收敛为搜索与单个筛选入口，保生效条件数量和可访问摘要，状态选择与历史正文入口收进同一面板；不让用户管理两套模式，不换行增加第二工具带或另加常驻结果／清除行。条件片、筛选入口和菜单复用中性 surface、已有图形与选择语汇，不用任务状态色冒条件选中。

筛选面板按项目、状态与类型分组，状态选项仅在原组内出现一次，不在底部重复同义快捷入口；支持搜索选项和多选，并用清楚的勾选与准确计数表达条件；“任一匹配”与跨组“同时满足”在同一紧凑层级可理解；面板范围涵盖执行与独立协调候选，不把协调计数写成执行计数。连续选择保本次菜单位置和操作对象，清除与完成动作可发现，鼠标、键盘及触屏均可达。Mote、Topic、Survey、Project 沿原类型图形，组合来源不画成互斥 Radio；类型未知与活动未知可区分，Unknown 和恢复保持原事实用词，中文 Working 使用“工作中”，不以“运行中”混淆进程。已选但来源失效的条件仍显示原名称／身份和暂不可用说明，零计数不隐藏移除入口，不退回 All。逻辑、准确身份、状态及原集合边界只见[搜索行为](../behavior/focus-context.md#搜索上下文对象身份与历史正文)与[来源归属](../behavior/focus-context.md#项目归属任务状态与恢复)。

非阻塞的项目来源目录与泳道信息读取失败合并为原顶部工具带内的紧凑服务状态入口，不在工具带下方或泳道中独占提示行。入口用可辨服务图形与短状态，长原因进入点击后的原服务详情，鼠标和键盘均可读完整原因及准确只读重试；窄宽仍保完整命中与可访问名称，不挤掉搜索、筛选、当前工作面及原动作。复用共同服务披露与服务窗的图形、详情、收起和焦点语汇，不另造浮层或状态账本；收起后仍可辨本次未恢复状态，正常或确认恢复时不留占位。失败、未知、重试及能力保全只见[同主题交互约束](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)。

### 中断恢复与导航

中断与恢复：已保留任务在原项目的 Idle／Recovery 中正常呈现，当前关注、名称与原工作面动作保持可达；不另放离线目录或隐藏计数。真实中断以进程框内明确断开、略错位的轨迹及 Interrupted／Run interrupted 说明表达，不借主动停止的方块、暂停双线或失败叉号。当前活动未确认／不支持报告时用静止、未闭合的观测框，与完整 Idle 进程框区分；未观察到原 Run 仍沿原 presence 未知图形与 Run not observed，不混作活动未知。两种状态在共享语义图标 owner 各有含义，12px 单色下仍需清晰，未知不循环、不冒加载；颜色只是辅助，完整名称与原原因按原入口可读。不得把旧回复盖在必要恢复说明上，也不把 Run 中断画成任务失败或完成。恢复与未知混合时组头明确含 Recovery，准确分类与原因按需可读，沿原四组整数列布局与滚动边界，不改变时间轴用户高度、分栏比例或 Session 生命周期。

不为 Focus 另留一行标题或冗余说明脚注，必要过滤控件使用紧凑内容行。左下角 Focus 导航项吸收原 status bar 的 Agent 摘要，名称后只保留有值的短运行数与待处理数；注意色只用于待处理，详细类别按需读取，不增加箭头组、独立名册或第三层 chrome。Focus 的入口、观测与定位共用一个紧凑命中区；全局状态栏密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)。PMO 提醒沿用现有紧凑入口，更新不重排执行卡片；请求更新与原 Region 定位合同归交互 SSOT 的对应 Focus 与 PMO 焦点段。提醒收起后不留下占位控件；浮窗的焦点交还遵守同一交互段，不增加第二个入口。恢复打开时的键盘返回也复用常驻入口，不新增返回按钮或占位。

### 音轨几何与刻度

Recent Focus 的刻度模式与时区设置沿原紧凑单工具带按需展开，不增加常驻控件行或挤掉轨道；四级整时间刻度以长度与强度可辨，文字按实际时间区域宽度减少且不重叠。查询范围两端仍可读，不为填满窄窗口伪造整时间刻度；重复本地时间的偏移可发现。三模式、十一档窗口、时区与历史事实边界只定义在交互SSOT对应Recent Focus段。

底部音轨参考视频编辑器的水平标尺、细分刻度、固定轨道身份头、低饱和片段与竖向播放头。顶部一条约 28px 工具带提供历史范围、缩放与展开/收起；初始整体约 110px，最小占高包含工具带、分隔条、标尺、项目头与一条完整轨道。高度可从顶边拖拽调整，边界有完整位于布局内的 8px 命中带、横向拖拽柄、悬停反馈与键盘焦点；名称列的分隔线只从工具带下方开始。收起态只留工具带，展开恢复用户高度；音轨至多占主内容的一半，避免挤掉原工作面。单轨高度遵循本节图层预算，轨道数量增加时在该区独立纵向滚动，水平缩放拥有同步标尺与轨道视口；精确时间通过 tooltip 与可访问名称读取。选中片段用柔和填充与清晰边界标示，键盘可定位已有 Context；播放头与选中标识的语义统一归交互 SSOT 对应 Recent Focus 段。不画装饰性波形或虚构时长。无历史时只用短的就地说明。

色彩沿用现有中性 surface 和状态 token；采用清晰的字号、对齐、单一内容边界与 restrained motion。减少重复背景、胶囊、边框和同义标签；项目、任务、动作、状态、历史各自只承担自己的语义。

### 搜索范围与结果

Focus 的筛选无匹配空态以短说明与轻量清除查找／筛选入口帮助恢复；动作在原空态内，不增加常驻工具行或装饰卡片。原因与范围可读，原历史搜索结果和当前阅读对象保持，不把失败或未知覆盖画成空数据。

协调命中以明确的 Mote 协调结果组复用现有上下文卡片，沿原 Mote 身份图形、准确名称、状态与必要来源呈现，与执行项目泳道和计数清楚区分。默认仍为紧凑协调提醒；查找或条件生效后的协调结果可在同一滚动扫描区读到，不加第二套筛选工具栏，清除后回到默认紧凑呈现。长名称、未知来源、无匹配和原位置待确认均保可读说明及鼠标／键盘入口；结果组不冒充执行选中或改造右侧原工作面。候选、计数、显示时机和原导航边界只见[来源归属](../behavior/focus-context.md#项目归属任务状态与恢复)。

历史命中优先呈现准确 Host／Session 当前可得名称和有界正文摘要；当前名与记录时作者区别清楚，原 Session、Host、来源和记录 ID 可完整读取。摘要对当前字面、区分大小写查询作局部强调，不以颜色独占命中含义；长名、原标识和摘要可换行，键盘展开／折回与原记录阅读保持。无当前准确名称时保原 ID，不猜命名或关联。

搜索沿既有顶部工具带；占位提示可辨识文字、ID 和对象链接，宽栏在同一输入旁提供明确的历史正文搜索动作，窄栏在同一筛选面板保持可达。即时 metadata 筛选与显式 history 阅读的范围直接可读；原位置和历史结果说明它们独立于本地执行／协调上下文的项目／状态／类型条件，不只依赖 tooltip 才能辨别。完整链接、较长 ID 与不可用原因均可读，不以截断文案代替身份。空间命中用紧凑条目显示对象种类、原名称与准确位置；多个位置保可辨的 Workspace／Group，资源归属与执行 Host 不混写。历史命中显示原来源和文字摘录，来源目录未确认、部分覆盖、不可用与确认查完沿同一紧凑披露可辨，继续／取消和原准确重试入口清楚可见；无 UI 或部分 Host 来源缺失不表现为全局空结果。窄分栏保输入、关键名称与操作可达，不常驻展开长范围说明或新增空白状态行。公共结果语义只见[统一全局搜索](../behavior/public-control.md#统一全局搜索)，Focus 发起、原工作面与有界阅读行为见[搜索合同](../behavior/focus-context.md#搜索上下文对象身份与历史正文)，呈现不另造匹配、来源或状态事实。

### Focus 设置与实时示例

Map 的轮廓与逐级缩放编辑沿独立[地图设置呈现](collaboration-map.md#轮廓与-lod-设置)，在同一 Focus 设置中导航与保存，不复制绘制或偏好 owner。

Focus 设置使用清楚的项目扫描、Agent 阅读、打开位置三组，字段控件及保存反馈沿原设置语言；默认值和行为只定义在[个性化设置合同](../behavior/focus-context.md#focus-个性化设置)。一块有界的所见即所得示例与控件并列，窄窗自然堆叠；清楚标识 Example，真实卡片、原状态 SVG、回复摘录、输入条目和指标共享生产组件，不另画一套微缩 Focus。切换字段就能看出内容行数、触发节奏、输入数量和链接位置的差异；示例状态不能只表达正常完成，未知和需处理也应可辨。

动效用于解释本次选择和空间关系，保持短促、有界、可重试；不循环播放假活动或强迫观看，不以装饰卡、大段说明或额外渲染框架营造高级。未激活或后台停止动效并废弃迟到意图；reduced-motion 停止装饰与自动演示动效，仍保原悬停计时与明确键盘阅读。键盘试用、当前选择和保存状态清楚。演示与真实界面共用主题、字号与密度，不靠 CSS 缩放导致字和命中区失真。
