## Agent 焦点历史与 PMO 隔离的空间密度

Agents 表面在工具栏下提供一条低高度的“最近执行 Agent”上下文 rail：只显示当前与少量最近 Session 的头像、显示名和状态，允许直接回到对应工作面；没有历史时用一行短空态，不占用卡片首屏。PMO 浮窗不复用这条 rail，也不在执行 Agent 卡片中混入 PMO 身份。PMO 的当前 Session 只在自己的标题和工作面中表达，避免两个焦点在同一条视觉层级竞争。

焦点历史是导航事实，不额外创建卡片、Region 或对话。rail 使用现有 Agent 头像与状态语言，最近项按轻微叠压和紧凑间距排列；完整 Session、Workspace 和恢复状态放入 tooltip/可访问名称。

## Focus 执行台与底部视频编辑器式音轨

用户要求的成熟产品水准、完整使用流程自行体验与竞品比较边界，统一归交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)。本节的密度、可读性与控件命中须在该完整流程的宽窄窗口和鼠标、键盘操作中成立。

Focus 首屏只显示交互 SSOT 同节确认的 Agent 集合；普通 Terminal 不占泳道、筛选、空列或预览行，不使用 Terminal 图标充当 Agent 身份。手动启动且已核的 Agent 使用现有 Provider 身份图形、原上下文名与克制状态；缺少任务信号仍读中性状态，不伪装成 Working／Results。识别未确认的说明留在原 Terminal 的就地服务提示，不添加全局名册、常驻探测条或阻断浮层；原右侧 Terminal 和历史密度保持。识别、控制权和保留边界只定义在交互 SSOT 本次 Terminal Agent 资格段。

Focus 入口的动态预览使用紧凑、非交互的浮层：名称与短状态计数在上，最多三条双层上下文摘要在下；当前关注项清楚标注，紧接需处理和工作事实。Disconnected 只保留短计数，当前关注离线项也不占摘要行；行为边界见交互 SSOT 对应 Focus 章节。长任务名与活动摘要截断，项目归属低对比度显示，不重复绝对路径、Session 标识或完整正文。空态使用简短说明；不为零值类别添加显眼状态色。浮层锚定在入口上方并限制在 viewport 内，沿用窗口级 tooltip 层与 Browser 让位机制，保持原按钮命中区，状态栏密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)。交互与事实来源只定义在交互 SSOT 的对应 Focus 章节。

用户反馈 Focus 不够现代化，卡片信息看不出区别且空间利用率低；用户要求时间音轨参考视频编辑软件并放到最下面。交互、事实与连续性规则归交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)。

Focus 上方为紧凑的项目扫描区与原 Tab 工作面，底部为横跨整个 Focus 的 Recent Focus 音轨，再下面是全局状态栏，其密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)。主工作面保留可调整比例；各泳道按相同状态顺序排列，内容列按本泳道实际非空状态与可读卡宽有界分配空间，只有确实不足才按同序必要换行；不能在统一宽度断点把五状态全部纵排。单非空泳道在常见窄栏仍横排，零态收成紧凑状态带而不各占整行，避免多个泳道各自横向滚动。空状态列采用图标在上、零计数在下的窄轨，完整名称保在可访问标签与 tooltip，不用整宽彩色空行；列头与本泳道实际列宽对应，列宽不同不暗示跨项目位置对齐。有内容列内增加卡片排列，单卡有可读宽度上界，不随宽屏无限拉伸。项目不再占固定列或独立大标题行：紧凑组头用既有项目图标、Project / Branch / Topic 路径、Topic 一句短说明、活跃数和必要恢复标记表达归属。列头保短名字，并以现有状态 token 的克制色和非颜色标识区分，不反复绘制彩色框。已销毁 worktree 的泳道使用中性虚线标记与明确文字，不以错误色代替事实。图标、Topic 说明与状态事实边界见交互 SSOT 对应 Focus 段。

已确认 Topic 的组头使用既有 notebook 语汇，Mote 使用现有 Mote 专属身份图形与实际对象名；首屏不重复 Scratch / Project 父图标、父名称或无意义面包屑。普通项目仍使用原项目图标与必要 Branch 路径；完整 Host / 路径 / 身份进入按需来源，未知分类使用中性提示。既有用户图标选择优先，Focus 专属 Topic 字形不改变 Space / Rail 原自动 monogram 默认，不新增第二份图标账本或读取；身份与精确导航边界见交互 SSOT 本次 Topic / Mote 段。

Focus 固定消息的正文外观引用交互合同《共同对话的用户默认外观与协作来源》；标记与来源说明仍区别真实作者事实，不增加图例或常驻身份栏。

Recent Focus 的紧凑工具栏提供日期时间入口、前后窗口、窗口大小与回到当前时刻的动作；窗口范围始终可扫描，窄宽度下仍为单行，工具组可以横向浏览；滚动反馈不能盖住按钮的可见命中区，也不增高工具带或挤掉轨道。当前时刻使用一条细竖线与标尺上的短标识贯穿时间区域，不占 Context 身份列；选中 Context 仍沿用已有柔和 surface。消息使用轻量、可键盘到达的标记，与 focus 片段在同一条轨道里可区分；正文进入按需预览，避免展开消息撑高每条轨道。窗口、取消高度调整与事实边界只定义在交互 SSOT 对应 Recent Focus 段。消息沿既有身份图形、tooltip 和可访问名区别已核 Agent、明确人类与未知作者；发送者与项目信息在单条查看时出现，执行关联复用原轨道事实，不增高轨道、不增加占行卡片、常驻工具条或多条跨泳道连线。发送者、当前归属与执行关系的行为边界只定义在交互 SSOT 对应消息段。

Recent Focus 的悬停卡采用清楚的身份与一条任务/消息主信息，项目/Topic、状态与记录来源为次级辅助；头像、字重、留白和图标各有语义，不堆叠表格、重复姓名、聊天气泡外再套相同标题或长段空字段。快速预览保持紧凑，固定阅读保原共同正文完整可读；进入/退出应克制地表达同一对象连续性，不跳动工具带/轨道、不盖控制区，减少动效时保持同样信息与操作。行为与事实边界只定义在交互 SSOT 对应 Recent Focus 检视段。

鼠标平移与＋／－缩放沿交互 SSOT 同节[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)的新增窗口约束；原数字范围两侧加入紧凑的＋／－图标按钮，边界禁用与 tooltip／可访问名称明确。仍共用原一条工具带，正常、窄和短窗口保留日期、Now 与至少一条完整轨道，不增高状态栏或另加缩放工具行。

项目分组与关闭后历史回顾：项目分组的行为与历史保留边界见交互 SSOT 同日[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)同名段；用户已授权继续完成。用项目图标、短名与折叠控件组成紧凑组头，Branch／Topic 只在区分必要时作为次级路径或 Session 行辅助信息，不强制每组展开四层标题。折叠时展示本窗口内已有片段的聚合轮廓与有事实的 Session 数，明确为项目汇总，不冒单条 Run 或精确执行时长。已关闭工作面的轨道使用克制的中性身份标记，状态和历史缺口可按需读取，不大量常驻“已关闭／Disconnected”文字；沿现有标尺、约 24px 单轨、可调高度和独立滚动边界呈现。默认只显示本窗口有事实的项目，不列出所有过去 Session，也不加一块常驻历史墓地。字节与事件双重保留边界只定义在交互 SSOT 同名段；沿既有范围／覆盖说明按需可读，不为该边界增加常驻 banner。

Recent Focus 横向浏览期间，项目与轨道沿交互 SSOT 同节的本次进入顺序稳定呈现；窗口事实显隐不以动画重排已读条目，名称相同仍可用原身份区分。保既有紧凑组头、约24px轨道、可调名称列和独立滚动，不另加排序工具带、固定空行或历史墓地；行为和活动事实仅引用上述交互合同。

归档输入与已观察 Context 项目的关系只见交互 SSOT 同节的新补充；保留紧凑项目组、约 24px 轨道和中性的未知组。用组头 tooltip／按需详情解释「已观察 Context 归属，消息发生时项目未记录」，不为每条消息增加常驻项目徽章或长说明。

同一条约 24px 轨道区分低饱和的工作状态带、当前时刻处的在线小标记与细的关注片段；形状、位置与 tooltip/可访问名共同表达含义，不只靠颜色。未知起点不画虚构长条，在线标记与当前时刻竖线保持对齐，访问与消息仍可键盘到达。标尺按轨道可用宽度减少时间标签，窄窗口保留两端，标签不得彼此重叠。新增事实不增加每轨高度、工具带或全局状态栏高度；工作、在线与访问的事实边界只定义在交互 SSOT 对应 Recent Focus 段。

用户反馈时间轴大片空白、灰绿线难懂。Now 当前时刻、已确认 working、focus visits 与 Run 在线在原 Recent Focus 工具带/标尺同高度内使用短文字和不同形状可辨；当前时刻使用非工作 accent，working 保低饱和带，关注保持中性短片，在线为独立空心点。宽窗可见短图例，窄窗沿同一入口可读可达；真实已读来源数和覆盖说明可见可达，不新增常驻 banner 或增高全局状态栏。该图例只解释时间图形，不修改作者/共同正文的“不增加图例”条款；多来源保留与未知边界统一见交互 SSOT 同节本轮时间轴覆盖约束。

当前输入的观察提醒沿原 Input records／覆盖入口与紧凑阅读面可读可达，使用已有服务说明和动作语言，区分「自动更新不可用」与「保留当前阅读窗」；不另占工具带、全局状态栏或常驻横幅，不把服务提醒画成输入标记，行为唯一见交互 SSOT 同节对应约束。


大数量下的滚动与加载沿用这些自然窗口边界，保持原工作面可读与输入命中；性能资格、数据来源及同一工作面交还规则归交互 SSOT 的对应 Focus 章节，不以隐藏内容、额外 loading 屏或另一套列表解释资格结果。长期不活跃泳道后置的依据与稳定次序也归该章节；后置仍使用原紧凑泳道，不增加占行的空闲分区或每项计时标签，不以动画移动打断阅读。

Agent/Terminal 使用统一两层条目：首行是身份图标、可识别任务名与共享状态字形，完整状态通过 hover、父行键盘 focus 的 tooltip 和可访问名称读取；次行是最近已知动作或真实状态说明，必要请求与失败事实不只藏在 tooltip。Provider 已由身份图标表达，完整绝对路径和内部标识进入 tooltip/详情；缺少任务事实时保留真实可识别身份。行高约 48–60px，组头约 28px；空分组不放大卡片。选中用整行柔和 surface 与字重表达，需处理与错误只在状态标识承载颜色，普通项不反复绘制彩色框。悬停与键盘聚焦都可发现动作，不通过浮动位移表达 hover。

卡片的信息层级须以可读工作内容为中心：活动正文使用可读的次级正文对比，允许在窄列占最多两行，保住工具动词与具体文件/命令，不把全部识别信息藏进 hover。首层名称与短状态各有边界，长名称、中文和未知状态不得互相撑出行框；完整内容仍可按需查看。两层结构不新增常驻第三行、进度装饰、重复的项目/Provider/路径标签，也不挤高全局状态栏。内容来源与请求/结果/失败优先级只在交互 SSOT 的对应 Focus 段定义。

本次 Focus 卡片 recap 与复制菜单沿交互 SSOT 同节本次合同。身份与工作内容保持两个层级；普通卡片内容区在最多两行内区分带来源的会话摘录与当前具体动作，紧急说明直接可读，完整内容按需。缺摘录沿现活动／空态，不增加常驻第三层、重复项目／Provider／路径或进度装饰；原 compact 断连条目保 28px，不摊开历史名册。Session 复制子集复用原 ContextMenu 与图标/Portal 语汇，名称/ID清楚可辨、宽窄与键盘可达，不新增常驻动作栏或增高全局状态栏。

同 Tab 多个 Terminal 在原两层条目中使用已有 Region 同名视觉编号和原工作面名区分，项目名不在每格重复，机器地址留在 tooltip/可访问说明，不加第三行或常驻徽章；事实和归属规则见交互 SSOT 对应 Focus 段。

失败或结束终端的次行优先显示可读的退出事实，沿用两层条目与原有错误/中性色；完整说明按需查看，不新增常驻失败栏。当前泳道与历史 Run 的边界、原工作面和恢复事实只定义在交互 SSOT 对应 Focus 段。恢复接续后的选中呈现沿用本节既有选中态与工作面边界，行为只归上述交互合同。

Needs you 与 Error 共用一个紧凑待处理分组。严重性由单项状态图标与可读说明表达，授权/回复采用注意色、真实失败采用错误色，不用两块空状态框维持区别。所有状态分组统一轻量组头，全局数量为零时统一列头与过滤入口保图标和零计数并缩窄，不在项目条目下面重复一排零；Idle 与恢复/未知在中性组内以共享字形和完整按需说明区分。

Results 条目以真实结果摘要承担次行内容，并有可发现的查看入口；Idle 使用独立、中性的分组和短状态，不与 Working 共用运行中的视觉信号。分组数量与样式来自实际可观察内容；无产出的 Results 空分组只保留可理解的计数入口，不占一整列空白。

结果查看与原上下文交还只归交互 SSOT 的对应 Focus 章节。当前工作面的阅读、输入与几何保持稳定；未展示的保留工作面及其编辑器内容不能绘制到 Focus 泳道、音轨或输入区，也不能占用命中。目标工作面显示后沿用原内容边界与操作控件。

输入框引用沿既有 Space 与文件工作面查看，不增加预览浮窗或第二套导航控件；显式查看和后台准备的行为边界统一见上述交互章节。

顶部使用横跨左右的同一条 32–36px 操作栏，过滤区与当前上下文区沿主工作面比例对齐，使用一条连续背景与底边界。右側身份区域可唤出 Focus 菜单，长名称截断并按需查看全文；必要动作与系统窗口控件始终可操作，不堆叠大标题、副标题和第二条工具栏。下面直接延续完整的 Region 工作面；调整布局无进入动画、白屏或 loading 闪烁。所有子区保留 min-width/min-height 的溢出边界与可操作 resize handle。More 沿既有共享菜单的视觉与命中区，不另画菜单工具条；悬停、键盘入口、改名取消与显式继续/关闭后的第一键归属见交互 SSOT[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)的操作栏合同，不新增焦点提示条。

单格预览的身份与既有控制合带按交互合同[《Focus 执行上下文、项目泳道与底部时间音轨》](../behavior/focus-context.md#focus-执行上下文项目泳道与底部时间音轨)执行；不再保留重复身份的空行，原菜单和模式仍清楚可达。多格保各格局部控制与原关闭命中区，合带不以 overlay 压住正文、首行输出、History 或输入。

Focus 过滤区收窄时以可识别的搜索与当前筛选摘要保留层次，完整值按需可读，不把两个筛选都裁成无法区分的 All；沿本段 32–36px 单操作栏与系统窗口让位，不加第二工具行，行为只见交互 SSOT 的操作栏合同。

Disconnected 使用独立、稳定的中性离线图形与计数窄轨；无论数量、当前选中或搜索命中都只占一个紧凑入口，不分配内容列宽，不在本泳道展开列表。摘要在入口旁的既有 tooltip 层按需呈现，最多三条紧凑名称与已有短活动；完整详情复用页尾既有收纳视图的紧凑行。空轨图标与零计数竖排，320 / 640 等窄窗口的入口与键盘命中可用；不为第五列增加每泳道横向滚动。仅断连项目不占主泳道，混合项目保本泳道的独立入口与原身份。事实资格、全离线收纳集合、过滤、精确定位与返回只见交互 SSOT 同名章节。

不为 Focus 另留一行标题或冗余说明脚注，必要过滤控件使用紧凑内容行。左下角 Focus 导航项吸收原 status bar 的 Agent 摘要，名称后只保留有值的短运行数与待处理数；注意色只用于待处理，详细类别按需读取，不增加箭头组、独立名册或第三层 chrome。Focus 的入口、观测与定位共用一个紧凑命中区；全局状态栏密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)。PMO 提醒沿用现有紧凑入口，更新不重排执行卡片；请求更新与原 Region 定位合同归交互 SSOT 的对应 Focus 与 PMO 焦点段。提醒收起后不留下占位控件；浮窗的焦点交还遵守同一交互段，不增加第二个入口。恢复打开时的键盘返回也复用常驻入口，不新增返回按钮或占位。

Recent Focus 的刻度模式与时区设置沿原紧凑单工具带按需展开，不增加常驻控件行或挤掉轨道；四级整时间刻度以长度与强度可辨，文字按实际时间区域宽度减少且不重叠。查询范围两端仍可读，不为填满窄窗口伪造整时间刻度；重复本地时间的偏移可发现。三模式、十一档窗口、时区与历史事实边界只定义在交互SSOT对应Recent Focus段。

底部音轨参考视频编辑器的水平标尺、细分刻度、固定轨道身份头、低饱和片段与竖向播放头。顶部一条约 28px 工具带提供历史范围、缩放与展开/收起；初始整体约 96px，高度可从顶边拖拽调整，边界有可发现的横向拖拽柄与键盘焦点。收起态只留工具带，展开恢复用户高度；音轨至多占主内容的一半，避免挤掉原工作面。单轨约 24px，轨道数量增加时在该区独立纵向滚动，水平缩放拥有同步标尺与轨道视口；精确时间通过 tooltip 与可访问名称读取。选中片段用柔和填充与清晰边界标示，键盘可定位已有 Context；播放头与选中标识的语义统一归交互 SSOT 对应 Recent Focus 段。不画装饰性波形或虚构时长。无历史时只用短的就地说明。
