## Settings 控制工作面

- Keyboard shortcuts 在同一 Settings 分类、Overview 与搜索中呈现实际 registry 的命令、平台和弦与作用域；紧凑命令行配清楚的 `kbd`，长命令、搜索空态和窄窗保持可读。只读与可配置的真实能力区分见交互 SSOT[《Settings 中的 Keyboard shortcuts》](../behavior/settings-and-observation.md#settings-中的-keyboard-shortcuts)，不另加悬浮手册、工具栏或独立和弦清单。

- 材质服务于导航与紧凑功能层：导航／窄窗分类入口与当前分区的原保存区可属于同一克制的材质语言；多个区域不叠玻璃，选中项、搜索与按钮不各自形成另一层。设置正文、资源列表、长文本编辑与只读示意保持稳定实色底与清晰对比。品牌仍用既有石墨、Mint 与薄高光，不把整页透明、循环光效或装饰卡片当产品感；保存范围与真实反馈归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)。这是光学启发的产品材质，不声称精确复现某平台的原生材质。

### 动作按钮

设置动作沿[共享控件语言](shared-rules.md#控件语言)的原四档类名和角色呈现，由同一设置呈现 owner 定义几何与状态，不在各页另拼一套按钮。普通文字动作以 28px 最小高度、12px 正文字号、6px 图文间距和小圆角形成一致节奏；主次按钮共用垂直尺寸，长动作自然换行而不裁切。图标动作沿原 28px 命中区，图标不被挤扁。

主动作保留品牌绿与克制高光；次动作采用清楚、安静的 Surface，危险操作沿原危险档。无改动时的禁用主动作不铺强品牌色，其他禁用状态保持可辨与相同几何；hover、按压和键盘焦点清楚，不靠移动、缩字或换层级表达忙碌。保存状态与错误继续在原动作附近显示，忙碌不改变其原操作档或资格。导航、卡片、分段选择和确认弹窗保持各自原角色，不为整齐而把不同交互拉平成同一种按钮。

### 模块图标身份

设置中的独立功能模块有稳定、具体、容易辨认的图标；图标表达模块目的地，不借用刷新、搜索、编辑等单次动作代指模块，也不以泛化图形掩盖不同功能。相同模块在侧栏、Overview、搜索的模块入口与窄窗菜单沿同一模块贡献呈现，和原工作面相同的目的地复用已有语义身份。默认图形在实际导航尺寸、单色和浅深主题下仍能区分，名称与选中／键盘焦点继续清楚；不靠颜色、动画或多层小角标制造区别，导航图标保持静止。

模块与图标的对应留在原设置模块贡献，语义与默认图形沿[共享图标规范](shared-rules.md#语义图标密度与性能)及[标准接入流程](../../guides/semantic-icons.md)，不另建平行模块表、图标配置或业务身份。外部渠道沿原品牌资产 owner，不能用相同通用对话图形替代所有品牌，也不把品牌复制为可任意改绘的通用语义。用户已明确保存的主题图形仍由原主题 owner 保留；图形不授予权限、不表达运行事实、不改模块名称或动作目标。

### Browser use 与实时模拟

- Browser use 与现有 Settings 组同层可发现，原基础设置先保持熟悉的编辑入口，Agent 操作呈现按鼠标／讨论浮窗、点击反馈与内发光的实际对象组织。开关、颜色、叠加、动画与宽度各有准确标签、当前值和单位；高级参数按需展开，不为每个字段堆一张卡片。配置和控制权不是同一组动作，不能把外观开关画成接管或批准按钮。
- 实时模拟与参数编辑相邻，宽窗保持预览和当前字段同时可见，窄窗沿原阅读顺序纵排并保持有界预览面积。示意页、操作者标签、真实目标样式、波纹与四边内发光可比较，明确区分“模拟”和真实网页；切换效果不移动当前编辑控件或抢焦点。当前草稿、已保存状态与保存动作分别可辨，不用效果已变化暗示已经保存。
- 颜色与叠加在浅／深示意背景中仍保留文字、目标与焦点对比；预览不得以过曝、整页蒙色或长期绕边运动掩盖主内容。动画可通过明确的模拟动作观察，减少动态效果时可读静态结果保持，隐藏后停止自身动态。原 Browser 的持续身份、显式接管、消息入口和实际反馈语义沿[Browser 呈现合同](browser-workface.md#browser-控制权提示)，本页不另造控制状态。

行为、保存、公共配置与原运行保护只见[Browser use 行为合同](../behavior/settings-and-observation.md#browser-use-与-agent-操作呈现)；实际正常／窄窗设置和真实 Browser 消费均须独立看图，模拟通过不代签真实网页。

### Message Tool 分组

Message Tool 与现有设置组采用同一导航层级，五个独立入口的职责沿[设置行为](../behavior/settings-and-observation.md#message-tool-设置分组)。User Input 先展示可编辑初始形态与快捷输入，再以紧凑按键行说明输入动作；A2A 以一个真实来信提醒选择为主，接收 Agent 的现行通知规则为简短次级说明；Automation 按恢复后续行、持续推进默认值、安排与 quiet follow-up 默认值分组，字段邻近展示单位、默认与生效范围，固定恢复正文按需预览。新任务默认值与当前 Agent 任务动作在文案上清楚区分，不铺诊断墙、空分类或重复总开关。Prompts 继续使用原指令库工作台，amux Protocols 独立使用原只读参考，不能合成一页。全局与局部快捷键复用同一行语言，作用条件清楚可读，窄窗换行保留键帽与动作对应，不靠缩字容纳。

### Prompt 库与编辑工作面

- Prompts 采用上下文筛选、可检索纵向指令库与单对象编辑台的主从构图；筛选依据现有适用范围或使用绑定，不画成 Provider→Executor 式的固定父子树。列表以名称与 `/keyword`／Provider 范围的紧凑两行认出对象，未保存与待校验有具名的小型标记；完整正文留在编辑区，状态与回复卡绑定为次级事实，避免列表把所有元信息铺成同等层级；正文编辑为主，名称与到达方式为紧凑次层，只读使用示意与当前草稿同框。资源工作台在可用空间足够时可局部加宽，其他偏好沿原有限正文宽度；正文不足时保持单层列表或编辑、明确返回，不用缩字塞进第三列。复用现标题、正文、元信息与间距刻度，长正文按可读正文档、技术词按等宽，组间留白与轻分隔建立层级。选中用完整 Surface 和非颜色标记，键盘焦点独立清楚；错误、未保存与待删除有文字或图形事实，不能只靠玻璃亮度或颜色。微动态只响应实际操作，已知减少动态、透明度或增强对比偏好下保持静态清楚的实色与边界；未取得系统偏好事实时仍保守可读、原动作可用，不能宣称偏好已经接入。材质面积和动态成本随真正可见功能区域增长，不订阅 Terminal、Run 或输出热路径。具体工作流与草稿／保存事实归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)。

### 分区层级与通用反馈

- Survey 的默认浏览器选项使用原设置分组、紧凑按钮和就地反馈；清楚说明系统中选择的是 AgentMux，网页在 Survey 打开。HTTP(S) 已确认状态、部分匹配、未知与设置请求反馈分别可读，正常与窄窗都保完整命中和刷新入口，不增加常驻提示栏或第二设置面；行为只引用[Settings 合同](../behavior/settings-and-observation.md#分区资源与配置生效)。

- Session continuity 沿现有紧凑偏好工作面，Session recovery 展示恢复时机与同操作复查，Automation 展示恢复后续行；字段邻近显示默认、已保存来源和单位，固定续行正文按需预览，真实副作用说明与预览保持连续。宽窗标签与控件同排，窄窗按原阅读顺序纵排，长正文自然换行，保存区和分类入口始终可达。字段归属、历史正文保留、默认、准入与投递行为只归同主题交互[《会话连续性设置》](../behavior/settings-and-observation.md#会话连续性设置)，不以绿色、摘要或预览授予恢复资格。

- 所有设置分区共享清楚的标题、正文分组、字段 label / hint、原生选择以及 hover / focus / disabled / pending / error 和保存反馈语言；对齐、行距、密度与触达保持连贯，浅深主题、窄窗、长值和真实错误完整可读。专业感来自准确命名、稳定对齐和清楚主次，紧凑来自去除重复层级与无效间距，不靠缩字或减小命中区。导语只说一次，对象身份与作用范围清楚，不靠装饰卡、重复标题或全页动画营造高级。具体产品命名与菜单默认展开沿[设置页的信息架构](../behavior/settings-and-observation.md#设置页的信息架构)，不因视觉精简换成泛化名称或隐藏原入口。
- 各页首屏以当前任务与可操作内容为主体，页头、分类、筛选和工具行保持从属；复杂页的常用选择优先呈现，高级参数、完整状态解释与技术来源按需展开。短说明贴近对应字段，不把多段同权重说明、连续大卡片或空白预览排在主要操作之前；精简文案保留原条件、作用范围与决定权，完整内容仍可查。
- 宽窄窗与短屏都保留足够的正文和编辑空间；固定导航、工具区及保存区不叠成遮挡内容的多层栏。对象切换、原具名返回与保存范围清楚，分组或高级项展开后所有字段与末尾动作仍可达。需要比较的选择保持可扫读；已有预览与当前调节项形成可连续比较的阅读路径，避免为观察一次改动反复跨越整页，同时不让预览遮挡输入或动作。当前值、选中、未保存和就地校验反馈有清楚的文字或形状依据，不只靠颜色与动画。
- 每页保留实际用途：偏好展示可理解的选择和实例，资源页展示对象、范围、配置与状态；Prompt 的 library / editor 不成为所有页的模板。主动作与次级操作可辨，当前草稿、保存事实、权限与来源不被材质或光效混淆，status bar 保持原低条与完整命中区。动态只帮助辨认当前交互，文字、输入与焦点稳定；减少动态、减少透明和高对比时仍清楚可读。成本、隐藏停止与证据边界只定义在交互 SSOT《Settings 全分区完成度与相关消费者成本》；实际完整页面经独立看图，修正后复采，不从样式声明代签。

### 局部材质与连续选择

- 液态玻璃的切换与交互沿[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)的已确认范围。选中反馈应呈现为同一块局部材质在真实目标间连续移动、有限形变后稳定停靠，而不是各行独立亮灭、仅改颜色或整页淡入。材质在既有导航与 Prompt 选择区域内表达当前对象；同一控件只保留一份选中面，文字、图标与正文输入不随材质缩放、扭曲或失去清晰度。选中面仍是既有功能层的一个几何信号，不叠第二层模糊，不另铺整页光学背景；当前选择的非颜色标记与独立键盘焦点始终可辨。
- 反光只对正在交互的局部控件给出受控方向反馈；离开指针、完成切换后收敛，不持续漂移或呼吸。减少动态启用、设置关闭、当前 Pane/选择区域隐藏或应用进入后台时，移动、形变与指针动态停止，原选中事实和可读静态 Surface 保持；偏好变化时立即按当前事实呈现。滚动、筛选与宽窄重排后，选中面仍准确停靠在本次真实目标，窄窗分类入口保持完整可选。动态成本只随可见的相关控件与操作增长，不在每个列表项常驻，也不订阅 Terminal、Run 或输出热路径。减少透明与增强对比沿本节既有实色合同。
- Prompt 的更高完成度来自当前对象、正文与用途示意的主次：编辑台的名称编辑本身清楚表达当前 Prompt 身份，不另加重复的同名标题；正文是主要阅读与编辑对象；关键词、Provider 与状态范围是紧凑次层，跨对象修改与全库保存事实清楚可读。列表选中连续反馈与编辑台共享同一对象归属，原正文、到达方式与使用示意保持稳定对齐，长名称、长正文与窄窗不靠缩字、裁剪动作或装饰卡片维持构图。只读示意保持与编辑区可辨的轻层级，不制造第二套输入或发送按钮。实际正常与窄窗、浅深主题、选择切换关键帧须由独立 Agent 逐图亲看；单张静态图、动画声明或 blur 数值不能证明本次流动与品质目标。

### Overview、品牌与阅读构图

- Overview 入口的选择、额外点击与直接访问约束统一见交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)，图像构图与动效仍须实际页面独立看图。图像必须与既有 AgentMux 身份及设置辅助用途相符，主要入口、搜索、设置正文和关闭动作在宽窄窗口都清楚可用；不能以图像加载成功、通用装饰或工程测试通过代替完整构图的独立看图判断。入口图的装饰层允许有限品牌色与切面构图，控件的绿色仍表达原焦点、状态或主操作；装饰不伪装选中、进度或运行事实，同一入口不叠加多组完整龙头徽章或品牌字锁。动态保留同一静态可读布局，遵守减少动态效果偏好，在页面隐藏／离开时停止；不能闪烁整页、等待动画才允许操作，不能为了装饰订阅 Terminal、Run 或输出热路径。status bar 与完整命中区不受品牌画面覆盖，其密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)；现有设置分区的标题与控件语言仍遵循本节，不自动给每个分区新增宣传层。
- Overview 的品牌、重点直达与完整目录形成清楚的阅读主次。首屏能够认出设置用途及主要入口，品牌构图不把实际导航推成次要长目录；重点直达用明确标题、用途和完整命中区表达任务，不铺同等强度的装饰卡。全目录按同一目录顺序组织连续的分组章节，组名与用途说明、入口网格和准确类别的轻量摘要支持扫读；摘要的事实边界归[设置页的信息架构](../behavior/settings-and-observation.md#设置页的信息架构)。宽窗组名与条目形成清楚的对齐关系，窄窗按同一稳定顺序纵向阅读；文字、摘要和动作不靠缩字或裁剪维持构图，不再固定把各组分配到互不平衡的左右两列。条目网格的具体列数与重点项按当前完整页面评审，资源入口在侧栏和首页都易发现。
- 插画只在能辅助用途辨认且与当前工作面协调时少量使用，沿[共同美术语言](shared-rules.md#ui-现代化的独立评估边界)，不为每组凑齐配图。图形贴近原组标题，搜索和关闭仍清楚可用。组图不成为新导航或状态指示，不重复完整品牌标识，不把组标题撑成第二排宣传卡；具体分区正文、资源行与编辑控件保持原密度，不能顺势给每页加 banner。图片缺席或失效时原文字、动作和保存事实仍完整。
- 用途较新的 Capsule 与 Goals 各保留一处克制的概念介绍，强度低于 [Mote 伙伴故事板](motes-and-coordination.md#伙伴从哪里来用户故事板与教程-banner)。Capsule 用单幅紧凑场景说明实际 Agent 把页面成果保存为可再次打开的小工具，延续 Mote 的切面角色、柔和材质与少量 Mint；Goals 用更轻的关系示意和价值说明表达目标、协作与结果。图示与文案组成一处主次清楚的阅读单元，真实配置、服务状态及保存仍为页面主体；窄面收敛图形占比，保持主要设置可发现。每页不叠三幕故事、轮播或重复口号，图示不冒充真实成员、页面、授权或执行完成；图片缺席仍由文字说明用途，独立看图评审须同时看完整明暗与窄窗页面。
- 设置的编译期模块贡献沿交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)中的同名约束。各模块复用原分区、表单、保存反馈与控件语言，保持原分区的视觉顺序和 Overview 的轻量摘要；模块化不增加注册列表、技术配置页、第二导航层或通用装饰卡片。
- 设置页面参考成熟产品的真实任务层级。导航、页内设置组和资源详情应表达真实层级；减少一级页面不以再叠一条常驻工具栏、空页或不清楚的保存栏为代价。常用控件与按需说明有清楚主次，品牌与原密度仍沿本节既有约束，status bar 的密度引用[《左下角导航与右下角工具组》](spaces-and-layout.md#左下角导航与右下角工具组)；对象、作用范围和原入口保全归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)。
- 侧栏以紧凑、可见的组标题与稳定的原分区入口表达分类，Overview、搜索、当前页与普通入口的主次清楚；分组标题的展开动作和当前展开状态清楚可辨，图标、文字和命中区对齐，组间留白适度，不重复首页摘要、分区导语或数量装饰。导航足够长时仍易扫读、滚动和返回当前选择，不能只留空白分隔让用户猜归属，也不靠缩字换密度。当前选择的材质反馈与独立键盘焦点可辨，分组展开、收起与搜索重排后仍准确停靠真实入口；原分区及对象直达、完整功能和窄窗分类入口保持可达，宽窄呈现变化不增加新的业务导航层。
- 默认展开的侧栏以紧凑行、安静组标题和清晰缩进保持专业密度；Agent 设置沿同一组标题与叶子行语言呈现，不增加无标题孤立行或重复同名层级。完整目录自然滚动，搜索和设置身份保持可达，不用缩小字级或把必要操作隐藏来容纳全部入口。默认与手动展开语义归[设置页的信息架构](../behavior/settings-and-observation.md#设置页的信息架构)。
- Settings 的工具密度以同产品 Space 的分类、搜索与列表节奏校准，按文字职责与对象层级收紧，不统一缩放整页。当前分区标题采用既有区块标题层级，组标题安静，导航、搜索、普通表单和相关字段减少不必要的高度与间距；Prompt 正文、长值、错误和状态继续保持原正文可读性。精致感来自对齐、分组与留白的稳定节奏，不能靠缩小必要文字、隐藏元信息或把所有树行高度硬套到多行编辑取得。
- Agent 配置在明确配置范围后，用横向 Provider 上下文、纵向 Executor 列表与当前对象详情表达真实关系；适配说明属于当前 Provider 的辅助信息，不能与 Executor 编辑竞争成两套互斥导航。Provider、Executor 和全局模板／准确 Host 的语义边界归交互 SSOT；长名称、检索、未知 Provider 与窄窗往返仍能辨认原准确对象，不能把所有 Executor 再横铺一行。常用字段、高级披露及原保存反馈形成连续阅读顺序，沿既有控件、密度与材质，不照搬参考产品的业务字段或状态开关。
- 页面体现已确认的主次：Copied paths 是 General 的可操作设置组，本地数据与诊断为次层；Appearance 按窗口外观、终端字号、终端配色的任务顺序呈现。分组与默认入口只归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)；使用原设置行、真实预览与保存反馈，不增加装饰卡片、第二标题栏或新的配置层，status bar 仍有完整可点击范围。
- 在 320px 窄窗中，status bar 的品牌入口、工作面、状态数量和右侧工具仍必须完整可见且可点。只收紧间距和原紧凑按钮的宽度，不能把可见按钮裁到窗口外，也不能隐藏状态或动作来通过命中检查。
- 设置面的视觉完成度必须在真实窗口里成立：内容与留白有明确构图，标题、当前值、可用动作和次级说明有可扫读的主次。仅有深色主题、共享 Token 或样式规则在场，不能证明达到“现代工作台”的目标。诊断与候选方向不能替代本节的已确认要求；实际品质仍由当前完整页面判断。
- Settings 使用“紧凑导航 + 宽内容”的工作台构图：左侧导航不靠重复描述撑高，当前分区的完整说明只在主区头部出现一次。控件邻近说明只补充具体例子、作用范围和边界，不重复主区的分区导语。正文不另起泛泛的号召或愿景导语；同段中的具体操作方式、触发条件、作用范围和决定权必须完整保留。
- 分区图标在导航承担语义识别，标题不重复装饰；品牌色只表达焦点、状态或唯一主操作。选中导航使用 Surface 填充和顶部高光，不使用左侧竖条或整圈描边。
- 主区头部提供分区层级、说明和 Close/Escape 入口；区块间用抬起的可操作 Surface 与平铺的信息层形成主次，保持现有 Token、圆角和动效刻度。
- 窄窗口时导航提供完整可选的分类入口，设置内容保持独立纵向滚动；搜索和关闭动作仍可键盘访问。
- 搜索的具体目标使用紧凑、可换行的结果行，分区路径作为次级文字，字段、动作与只读说明可辨；在宽窄窗口均可直接点选或用键盘进入。原控件定位后沿既有焦点与 Surface 语言短暂强调，不改布局、不以常驻彩框增加噪声，减弱动效时使用静态强调。无匹配与清除入口留在原搜索区域；导航、恢复与草稿的行为只归[设置页的信息架构](../behavior/settings-and-observation.md#设置页的信息架构)。
- Settings 作为辅助界面保持清楚的品牌身份。品牌来自既有 AgentMux 标识、石墨材质、绿色情境强调、清楚的排版和克制的动态；整屏构图在宽窗口保持平衡，不堆砌装饰卡片、技术标签或大型说明。品牌标识只承担产品身份，设置内容仍是可读的主体。
- 设计判断需要说明参考与本产品任务的对应关系；工程验收通过和参考产品的外观不能单独支撑最高完成度的判断。参考比较须说明适用限制；RSI 与配置抽象问题归[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)，此处不另立运行时要求。
- 主内容是居中的有限宽度设置画布，分区标题、说明与正文共享对齐线；列表与设置组以轻分隔组织，新增表单和真实预览拥有自己的层级。固定操作区属于当前分区，保持独立滚动与窄窗口的文字可读性。status bar 的高度、完整命中区与 PMO 的独立凸起遵守本文既有底栏约束；设置内容不得覆盖它们。行为合同归交互 SSOT「设置页的信息架构」。
- 品牌只保留一次真实标识，删除重复口号；分区标题与一句具体说明组成主层级，数量、检测范围与动作组成第二层。资源摘要紧凑，编辑面有克制的表面差异；常用身份与外观先于按需启动配置。只读身份用文本而非灰掉的输入框，技术值用等宽字体，其余表单用工作台正文。行为与身份约束只归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)。
### 参数效果与窄窗预览

Automation 的跟进条件与 Session recovery 的重试节奏以紧凑、可扫读的草稿示例靠近原字段呈现，分别说明组合条件和每次等待；原操作复查与重新尝试有清楚区别。示例沿原正文、分隔与主题 token，不画运行进度或铺装饰数字卡；未保存与无效输入可辨，实际调度的不确定条件不包装成确定承诺。

Survey 以图像缩略图和具名选图、替换、清除动作承接换图，URL 输入按需展开；内联图片内容不占据正常表单。图片预览入口紧邻图像字段与缩略图，名称说明实际预览范围，不被横向拉长的帮助文字推离当前操作。

Mobile 的扫码与复制在同一连接层级可见，扫码保持方形、对比与静区。

Focus 与 Agent takeover 的窄窗预览提供与当前控件相邻的查看、返回路径，不用持续覆盖字段的大型悬浮预览；比较后仍能继续原输入。返回动作与预览标题同层，有限宽度优先保留可辨认的目标字段或分组，长名称可自然重排或使用准确短名，并保留完整可访问名称；不能只剩泛化的返回词或必须悬停才知道去向。宽窗保持已有并排构图，示例高度随内容收束，空闲与完成状态不保留仅为撑满画布的大块占位；长内容及原阅读位置仍可达。

### 资源、检查与保存状态

原设置保存区在未保存、保存中、成功与失败切换时保持保存动作的位置和视觉宽度；反馈文字可自然换行，失败保完整原因和原草稿。按钮、图标、文字与表面沿既有tokens和焦点语言，不为状态另加卡片或把失败挤出窄窗。

- 添加项目沿现有表单和对象反馈，重复登记呈现已有项目；CLI 登记、命名与工作面保留的行为约束归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)，不在辅助设置界面展示底层请求或脚本来代替清晰的对象与动作。
- Agents 沿现「Check on」和一个全组 Refresh、原位短状态及就地完整原因；CLI 能力不制造第二检查面板或每行按钮。可用、没有可执行文件、检查失败与尚未检查／正在检查必须可辨，已确认非普通文件给类型原因，不能只让用户凭 Not installed 猜安装问题；原因不能只藏在回执。未取得诊断事实用服务提醒语言，不借进程死亡的强错误表达。结论、普通文件事实、输入和实际连接适用性见交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)。
- Agents 的查找与「Check on」／Refresh 依据正文实际可用宽度排列。空间足够时保持紧凑同排；空间不足时搜索拥有完整一行，不能被 Host 名称挤成只露残词的输入。检查范围与刷新作为同一组清楚可达，原命中区、焦点与固定保存栏保持；不复制控件或以缩字换取一行。
- 设置摘要的已保存值用原有轻量文本明确事实类别，与编辑控件及原保存栏同框，不增加常驻徽章或第二状态栏；已保存值与未提交草稿的行为边界归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)。
- 设置的 CLI 能力与命令清晰度约束归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)，界面不展示底层命令语法或配置实现细节来代替可理解的控件。 完整请求／回执与保存结果未确认的行为同归该交互合同；反馈沿现保存栏和就地原因，不另造常驻状态、诊断面板或强错误遮罩。
- General 的日志诊断沿原辅助动作就地反馈，路径与失败原因可完整阅读，隐私说明与动作保持同框；不增日志查看器、复杂诊断面板或底层命令展示。不存在、检查失败与请求已发出的行为与事实边界归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)。General 原动作及只读说明的搜索可发现性归同一章节；结果标注原分区，选择后定位原正文。
- 外观与终端主题卡片保留整个卡片的可点击范围；键盘焦点用现有 focus token 清楚标出，选中标记同时可辨，不能只用颜色区分当前选择与焦点。完整键盘行为归交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)，此处不重复行为规则。
- Appearance 的配色小预览在既有卡片密度内清楚区分静态输出行与输入行；示例文字在浅深主题与窄窗中完整可读，不意外换行或被样片边缘裁切。主题名称与说明保持主次，不能靠增加卡高、缩字、额外模糊或动效弥补示例裁切。静态示例与运行事实、原选择及保存的边界只见交互 SSOT[《设置页的信息架构》](../behavior/settings-and-observation.md#设置页的信息架构)。

### 工作面恢复与原入口

Settings 再打开时，原已访问分区的编辑字段、滚动与未保存／保存失败反馈仍可继续阅读；关闭后的表面不可见且不可聚焦，不以额外遮罩或确认打断正常导航。重新打开或显式分区导航沿原入口与焦点语言，不用成功图标冒充未保存内容已落盘。

重启恢复是工作面的一等状态：恢复期间保留原 Tab、Tab Group 和 Region 的几何位置，不用空白欢迎页替换它们。流程故障以停在旁边的服务窗提示，提示包含失败步骤、当前按什么状态运行以及恢复动作；只有 Core 确认 Session 退休时才收掉对应 Region。冲突提示必须区分“旧 owner 仍存活”和“租约可回收”，不能把一次重启后的 stale lease 画成健康 Session 被其他进程占用。

旧“未认领”Terminal 的启动处理沿现有 Session 目录与恢复状态表达，不增加自动停止或隐藏一类对象的界面；意图、归属和 Run 保留约束统一见交互合同[《Tab、Tab Group 与 Region》](../behavior/spaces-and-layout.md#tabtab-group-与-region)。

Surface、文字与状态 token 的唯一基础规则见[《主题与样式 SSOT 规范》](shared-rules.md#主题与样式-ssot-规范)，Settings 的两层内容与侧栏选中预算见[《密度预算》](shared-rules.md#密度预算)。本页不另定义 S0–S3 用途表。

### Executor 启动配置阅读

可执行文件与参数在当前 Executor 详情中相邻呈现，参数不藏在高级环境与权限折叠中。简短说明区分单一程序路径和参数；只读启动预览使用可换行等宽文字，长路径、带引号与空参数可辨且不撑宽窄窗，不抢占名称和配置主体。未完成参数的预览提示就地保留草稿。行为边界沿[分区、资源与配置生效](../behavior/settings-and-observation.md#分区资源与配置生效)。

- 一键 YOLO 使用单个低噪声的语义按钮，和 Executor 的其他启动设置放在同一层级；当前权限姿态仍以启动参数和 Provider 回执为准。

## Activity 工作线聚合与错误告示
- Activity 的组织标题、准确数量、Agent 内容及位置线索统一见[共享卡片呈现](focus-context.md#卡片预览与状态)；成员、空间身份和选择语义沿[Activity 活跃入口与空间级联](../behavior/focus-context.md#activity-活跃入口与空间级联)。
- transient 错误使用靠近窗口边缘但不覆盖内容的 notice surface（优先顶部或侧边的保留槽），最小 32px 高，带关闭按钮与 `aria-label`；关闭按钮命中区不小于 24px。错误文字允许换行但不得把 Terminal/Activity 内容推离视口，重新查看入口放在状态或诊断面。
- Service Window Notice 使用持久、非模态、可收起和复查的服务窗语汇；收起与事实保留的行为统一见交互合同[《我们的流程坏了，不等于 Agent 坏了》](../behavior/session-recovery.md#我们的流程坏了不等于-agent-坏了)，轻量控件统一见[《服务提醒与结果信息的轻量控件》](#服务提醒与结果信息的轻量控件)。
- 完成与 error 判定可信度、流程诊断的作用域和健康输入边界，唯一行为来源见交互文档[《完成与 error 判定可信度》](../behavior/session-recovery.md#完成与-error-判定可信度)；本节沿用既有服务窗语汇，不另建状态颜色或错误严重度规则。

## CPU/Memory 面板密度

- Performance 以总览、资源、诊断、原件提供清晰主导航，App／Runs／Runtime 作为资源区内的归属筛选。紧凑态优先展示本机与应用负载摘要、准确热点和下一步动作，扩展态为同一 Tool 提供更宽阅读面；资源表、趋势和选中详情共用稳定列，不以大数字卡片挤掉比较空间。窄窗保留完整导航、内部滚动、关闭与导出，切换不重置已取得分析；扩展、收回和键盘焦点沿原 Toolkit 交互。
- Host 的 CPU、物理内存、压力／Swap、卷容量和接口吞吐以紧凑分区呈现，来源、区间与未知可按需阅读。应用／Run 和整机指标分别标明范围，接口上下行对齐且可选择，不画未测量曲线、推测总流量或装饰性健康分数；颜色只辅助真实状态，不用 free memory 自造压力等级。
- Run 行以可识别的 Agent 名称、Project 和遵循设置的路径建立归属，CPU／RSS 保持稳定对齐。原 Session 跳转是明确次级操作，与资源详情展开分开；未知身份保留原引用、读数和原因，不用标题或路径猜可跳转目标。

- 长内容可通过鼠标与键盘在原内部阅读区读到底，头尾操作保持可达。当前窗口诊断以一个明确的短时采集入口承接；模块样本热度、可选调用栈与原回执按需展开，原材料导出是次级操作。函数名过长、空样本、错误、未知与窄面保留完整读取路径；运行时等合成标签完整呈现，最新未知回执与仍可用的原 profile 清楚区分，不用持续动效或多层弹窗代替分析层级。
- 已保存的 CPU profile 通过独立折叠区显式导入，复用同一火焰图与模块视图。历史原件的进程和构建未核验状态直接可见，文件来源及 SHA 按需展开，原件与技术报告导出保持次级操作；导入失败与仍可用的上一份材料清楚区分，窄面可完整阅读与清空。来源、生命周期与采集独立性归行为合同。

- 用户要求「信息多了，界面也应该优化下」。右下角观测面板按应用、Runtime、Agent 分组；默认先看当前负载与保留资源摘要，进程、owner 和回收细节可明确展开。CPU 与内存列对齐，采样时间及不可用原因是次级文字，不堆大数字卡片，不让所有 Agent 的活动正文挤掉性能事实。
- Agent 本体与子进程的数量、用量和 RSS 口径沿同一紧凑行与按需明细呈现，磁盘 Storage 保持独立标签；不因高占用增加常驻告警或第二个观测面板。真实归属、未知与安全处理约束统一见交互合同的「Status Bar CPU/Memory 资源面板」。
- Toolkit Agent 卡片复用标准 Agent 头像与身份语言，工具可声明头像、名称、Provider、状态、工作区及精确身份的显示字段；隐藏字段不留空占位。Performance Runs 使用同一通用卡片，列表主层可辨具体 Agent，具名细节保留原 Run／Host 与进程拆解。全部 Runs 汇总位于列表前，与所选单 Run 的读数明确区分；窄窗仍能读到总量、覆盖范围和身份，更新不跳焦点、展开或滚动。
- CPU 数值并列百分比和逻辑核等效，硬件容量作为次级事实；紧凑的分组行可用键盘展开到进程实例。CPU 与 RSS 各有稳定数列与低干扰热度底色，分组和二级明细明确各自时窗与强度标尺，不用面积、堆叠或颜色制造可加份额。未知、旧读数及遗漏保留可读文字；当前窗口堆与“工作与等待”按需可达，单独说明范围，不挤成默认展开的诊断墙。数据刷新保持展开、焦点、进程实例与滚动位置，窄窗保留数值与动作，沿同一内部滚动区域阅读。
- 面板宽高受窗口可用空间约束，长列表在同一个内部滚动区域阅读；分组标题和指标列保持可辨，错误可见但不占满工作面。沿用 Agents/Activity 的字级、圆角、行高、hover 与键盘焦点语言。指标口径、Runtime 所有权、按需采样与订阅释放约束归交互合同的「Status Bar CPU/Memory 资源面板」。

## Toolkit 的入口、结果与配置

Toolkit 的区域归属、默认增长方向与 Settings 的唯一入口位置，仅见交互 SSOT[《Toolkit 与官方 Performance 工具》](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)。Toolkit 入口保持原右侧低条图标基线、完整命中区与可见焦点；工具名称、图标与 icon / label 显示布局使用共同语言。Settings 沿原功能导航的图标、hover 与独立键盘焦点语言，不因设置打开冒充工作面选中。工具启用或名称变宽时，Settings 与原功能导航的位置保持稳定；工具数量和长名不抬高底栏，不让左右两组重叠，也不挤掉状态提醒、快捷键和 Settings。窄窗不静默把已选 label 改成 icon；更多内容在同一按需浮窗中呈现，不铺常驻仪表盘。

Hover 可预览，点击和键盘能稳定进入同一结果与动作；指针从入口移到浮窗时保持可操作，真实 connected 焦点与窄窗边界完整。浮窗先明确工具，再看最近数据、来源与时效，最后是具名动作。声明展示入口的工具在真正展开时显示求值进度，保留上次数据及时间；本次展示失败与旧操作 unknown 分开说明，数据更新不移动焦点、滚动或详情。触发、共享与默认只读边界仅见[《Toolkit 展示时求值》](../behavior/settings-and-observation.md#toolkit-展示时求值)。长文本、错误与 unknown 就地可读，不靠持续动画或单一颜色冒充成功。

Toolkit 共用浮窗以紧凑标题、正文和按需底部动作条形成连续工具面，标题与正文沿同一阅读起点对齐。工具身份、短状态和关闭优先在标题内组织，来源等次级信息不机械另占常驻一行；减少框架上下叠加留白，不缩小正文或叠加装饰卡片。采用稳定实色底，保留原文字、边界和轻高光；打开时不以整面淡入、缩放或位移留下不可投影的中间帧。Hover 预览与点击／键盘进入的同一面板均须完整位于原生 Browser 之上，关闭后仍可操作原页；原生绘制、实际交叠范围与未交叠输入的行为只见 [Browser 小浮层合同](../behavior/browser-workface.md#browser-任务能力与可复用资产)。

有底部操作条时，含内边距和分隔边界的实际总高不得超过同窗 App StatusBar；尺寸基准与常规命中区沿[底栏呈现合同](spaces-and-layout.md#左下角导航与右下角工具组)，不另维护一套高度事实。常用动作保持共同基线、完整命中区与可见键盘焦点，次级或长名称动作从具名更多入口展开，窄窗仍可读全并操作全部动作；不靠换行撑高底条、缩字或裁掉末项凑密度。正文中的用户结果动作仍可按内容展开，框架限高不裁剪正文、错误或恢复服务窗。动作已在标题内的 TUI 不重复增加底部条；动作、焦点与原能力边界只见[Toolkit 行为合同](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)。

Performance 是首个内置工具，按钮与浮窗统一层级、间距、数值对齐与克制材质；资源分组仍沿本文件[《CPU/Memory 面板密度》](#cpumemory-面板密度)，不重复铺卡或保留第二个入口。Settings 的 Toolkit 配置按工具身份、显示、触发及可审阅动作组织；查看官方脚本、编辑用户工具、手动执行和定时 enable 的主次可辨，未交付能力不显示成可用开关。行为、权限、查询与成本仅见交互 SSOT[《Toolkit 与官方 Performance 工具》](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)，实际完整构图、hover 到动作和长结果按独立看图收敛。

内置与用户工具在同一设置模块里按来源清楚分组，自定义工具的库与编辑工作面承担清楚的导航／内容层次。创建、保存与运行的视觉权重可辨，同屏只突出一处当前创建主动作：宽窗空态由中央创建承接，有工具或窄窗库态由新建入口承接；已预装工具直接进入同一普通编辑对象，保存沿其原反馈。搜索有轻边界，图标与入口样式仍为有界次级控件，名称与图标编辑在 hover／focus 时可发现，保存状态以短文字和有界状态形状识别；不能靠微字号、同重按钮或整页装饰卡补层级。品牌颜色直接引用既有 Mint、焦点、选中背景与边界语义 token，官方锁保持中性，当前选择以整体选中面与 Check／原生 checked 同时识别。脚本正文保持稳定实色，库与编辑不叠玻璃。结果浮窗先看用户工具与最近结果，再到具名动作；来源、时间、运行或冲突就地清楚，长文本按需阅读。多工具和长名不抬高底栏、不挤掉原功能入口，余量外项目沿同一右工具区具名收纳，用户 label 选择仍保留。操作、目标、保存与成本只见交互 SSOT[《Toolkit 与官方 Performance 工具》](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)；原 LiquidSelectionSurface 沿已接受的局部材质与隐藏／后台停动语言，数据更新不驱动持续形变或焦点跳位。

工具图标选择沿名称旁的具名入口展开紧凑分组与搜索，以图形、共享语义名称和已选标记帮助辨认用途；支持按名称、稳定 ID 及中英文用途查找，空结果明确可读，不用无标签的密集图墙替代选择。搜索不隐藏当前工具的已选身份，窄窗内全部候选和名称可达；原生键盘单选与可见焦点保持，Escape 只收起选择面并返回原入口。Picker 与实际底栏图标消费同一主题覆盖，不增加最近使用持久层或另一套图库导航。保存及目录边界只见[Toolkit 行为合同](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)。

inline 与本地包工具共用工作目录字段的呈现：可编辑输入与具名目录选择入口相邻，实际展开的绝对目录以次级文字就地可读，不以 placeholder 代替真实默认值。长目录在窄窗可完整阅读、选择和复制，选择入口与保存动作仍可达。目录格式或保存错误靠近原字段，具体原因可换行且保留输入；home 尚未知时清楚说明预览未确认，不伪造地址或展示为目录错误。默认、解析范围、选择回执与已有执行的保全只见[Toolkit 行为合同](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)，不在 TUI 或本地包面另设一套规则。

用户直说 Performance 界面「一塌糊涂」。新浮窗的首屏须有清楚的工具身份、观察状态与时间、可比较的当前用量及低干扰趋势；主要消耗对象具有稳定的名称和数值列，技术说明与诊断退出主阅读路径，但可明确展开。禁止重复分组标题、满屏微字号说明、连续嵌套折叠和用六七张数字卡替代层级。窄窗仍读得懂名称、指标与操作，不横向裁掉数字或关闭入口。

材质、排版、图标与 Settings 已接受的品牌语言连贯；玻璃与形变用于开合、选中和明确交互，不能给数据更新增加持续光效或整面板重绘。图表有限点数与固定几何，数值更新不引起跳列、滚动位置重置、焦点或详情状态丢失。入口与浮窗的键盘、hover 和暂停语义仅见交互 SSOT[《Toolkit 与官方 Performance 工具》](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)。

趋势点读数在原图表内以轻量标记与有界详情呈现，数值、单位、采样时刻和缺测可辨；悬停不抢输入焦点，明确点选与键盘阅读使用同一内容。详情不抬高整面板、不遮关闭或相邻动作，明暗、窄面、触屏和可见焦点保持；真实样本与淘汰语义仅见[Performance 行为](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)。

预装 Auth / Account usage 与 Performance 等工具采用同一层级的列表行和工具详情，仅按 Custom / 内置来源分组；进入页面就能找到它，不以 Example 按钮、模板预览或采用动作代替真实工具行。其名称、图标、脚本与动作来自本地包文件，启用、显示与运行参数来自当前用户配置，Custom 身份清楚可辨，预装来源不抢主标题或暗示官方只读。预装后直接进入普通工具详情；源码与动作在列明的本地文件中编辑，配置偏好在设置保存，不建立账户专用配置面、模板商店或第二份固定呈现对象。已保存工具的名称、图标、内容与结果沿通用 Custom 身份呈现，不要求用户结果采用账户观测的固定布局；具体账号业务说明沿该用户工具当前内容呈现。账户观测、额度与重置权益的内容完全由包脚本定义，沿通用结果阅读呈现；用户可换成任意本地业务，不为所有 Custom 工具设定账户字段或固定布局。原右侧工具区、窄窗可达和键盘／hover 语言继续复用本节。行为唯一见交互 SSOT[《Toolkit 与官方 Performance 工具》](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)，不在视觉精修中改变用户脚本、参数、目标、动作或执行资格。

### TUI Toolkit 的配置与终端

TUI 与有限结果脚本在同一 Custom 工具库中配置，模式选择使用清楚的名称，不依靠图标区别。TUI 编辑面保留工具身份、固定目录、脚本与参数，脚本标明 shell 命令，参数说明位置参数语义；命令留空时就地说明将使用 Host 默认 shell，不用预填 bash／zsh 冒充用户命令或把合法空值显示成错误。Shell command 的注释、字符串、变量与关键字沿原 Monaco shell 语法和[共享主题](shared-rules.md#主题与样式-ssot-规范)呈现可辨层次，普通命令名沿原语言规则保留正文色。名称旁的图标选择须以可见短标签或编辑标记表达可修改，当前图形与具名选项清楚可辨，键盘焦点及已选标记沿原选择器；不要求用户靠猜测点击装饰图形。创建或启用附近简短说明加载后运行，保存已有内容则明确下次执行生效。TUI 不显示不适用的展示求值和结果动作编辑区。启用、运行与停止的真实边界仅见[《TUI Toolkit》](../behavior/settings-and-observation.md#tui-toolkit)，禁用工具的现有执行与停止入口在设置中仍可找到。

终端配色选择在同一工具编辑面可发现，采用可比较的紧凑配色预览而不是下拉列表，明确区分「跟随全局 Terminal」与某个具名配色项，显示已保存来源和待保存选择。具名预览展示真实终端背景、正文及 ANSI 色，选择同时有明确文字／选中图标和完整键盘焦点；不用色块或单侧细线独自表达状态。选项名称、预览和 ANSI 色来自原[终端主题目录](shared-rules.md#主题与样式-ssot-规范)，不另铺一套色板；全局跟随、Workspace theme 与显式配色的关系不能靠颜色猜测。配色草稿、还原和统一保存入口保持紧凑清晰，不另堆一个竞争的主保存按钮。切换保持原终端内容与阅读位置，保存及生效边界只见[《TUI Toolkit》](../behavior/settings-and-observation.md#tui-toolkit)。

打开 TUI 后以原终端画面为主内容，复用终端字体、颜色、选择、滚动与输入语言；标题和关闭、设置、运行状态及必要动作共用紧凑标题栏。Running 等真实状态紧邻工具身份，不再另占横贯面板的一行；需要引导时，以标题内次级短提示说明进入终端交互，已进入后不持续提示点击，也不常驻重复的类型标题。标题不靠缩字或单一颜色表达状态，窄窗保留名称、状态和关闭，次级操作可紧凑收纳。错误与恢复信息仍沿下文服务窗，不为压缩高度隐藏原因。

浮窗有足够的阅读宽高并受窗口边界约束，终端随实际可用区域适配，不缩成不可读的终端缩略图。TUI 浮窗以靠近工具入口的右下角为稳定锚点，在左上角提供可辨的尺寸调节把手，向左、向上拖动扩大；命中区、方向光标和键盘可访问名称清楚，不能只换把手外观而让另一角随拖动漂移。碰撞调整保窗口内边距及原入口关系，拖拽不抢终端输入、不误触关闭。再次打开时沿该工具已保存尺寸呈现，窄窗的临时夹限不改写偏好；保留标题、关闭及调节入口，不另加尺寸表单或改变其他 Toolkit 的默认几何。尺寸持久语义只见[《TUI Toolkit》](../behavior/settings-and-observation.md#tui-toolkit)，终端尺寸与历史恢复沿[Terminal 呈现](terminal-reading.md)，不因 Toolkit 外壳另造网格或滚动规则。

Hover 展示同一终端且不夺走原输入焦点，明确点击或键盘进入后可操作原 TUI；从入口移到终端时浮窗保持稳定，焦点在终端内时不因指针离开而关闭。关闭按钮与停止程序须易于区别，终端焦点、原生键与关闭返回沿[《TUI Toolkit》](../behavior/settings-and-observation.md#tui-toolkit)及原 Toolkit 焦点合同。

启动、连接原终端、已退出和未确认状态使用短文字就地表达，旧画面仍可读；失败步骤和恢复动作沿终端服务窗呈现，不覆盖正文或用空白面替代保留内容。健康运行时不常驻协议、Run 身份或恢复说明；详情可查看准确执行与目标。退出后的画面明确标为已结束，重新运行动作可达，不能用旧屏幕或动画冒充当前仍在执行。生命周期、unknown 与原能力保留只由行为合同定义。

### 本地 Toolkit 包的呈现

包与普通用户工具沿同一 Toolkit 列表及来源分组呈现，名称和图标来自本地 manifest。详情明确本地包目录、可编辑文件入口和用户配置，不能把固定账号 pattern 或 Example 身份硬编码到 Renderer。脚本/动作显示本地实际源码和文件来源，启用/参数/显示是用户配置；不能用复制源码进配置伪装“安装扩展”。Auth 和 Performance 同层，前者可编辑本地包，后者系统维护。

## 资源面板密度
CPU/Memory 面板复用 Activity 行的紧凑列表语言：一行一个 Agent，首行身份，次行项目与状态，指标靠右；默认折叠，展开后不重复冗余标题。

Performance 首层提供紧凑、可见的“采集现场”动作；采集中的文字说明短时串行采样，原资源读数仍可阅读。结果首层只放完整／部分／未知状态、本机保存事实和导出入口，来源与各阶段详情按需展开。长身份和原因可换行，面板内滚动可达，窄窗不溢出或遮住关闭动作；CPU 火焰图与分配栈复用原分析区，不在首屏铺开原始 JSON。采集、保存与证据边界唯一见[Performance 行为](../behavior/settings-and-observation.md#toolkit-与官方-performance-工具)。

## 全局通知与底部状态入口

- 跨会话 Agent 汇总只在[Focus 入口](focus-context.md#中断恢复与导航)出现；运行数与待处理数沿该处原紧凑预算，类别及明细按需读取，不另设底部三组展开按钮。共享图标居中，hover、键盘焦点和展开态清楚，不能露出浏览器默认按钮的灰底、边框或 padding。聚合、请求顺序与准确 Session 定位归[跨会话注意力 owner](../behavior/settings-and-observation.md#跨会话注意力与系统通知)。
- 全局系统通知使用底栏固定紧凑铃铛入口，徽标只表达未读，不再叠一个表示相同意思的红点；无未读时保持安静的常驻入口。图标、徽标、hover、键盘焦点和展开态沿共享控件，不让数字变化拉高状态栏或挤动工作面，不增加整行常驻警告、滚动错误文本或第二个通知入口。新提醒的浮动提示有界、可关闭，保持原工作面尺寸、焦点和输入；故障、降级、未知与信息用有区别的语义字形和文字表达，颜色只作辅助，未知不使用死亡或终局的视觉语言。
- 通知中心直接锚定实际调用的铃铛，在其上方留小间隙并沿右边缘对齐；仅为视口边界平移及限制阅读高度，不借输入框顶部、其他 Region 或其高度作为虚拟锚点。显式打开的浮层可覆盖底层工作面，不改变原输入框、草稿或布局。标题、Current／Activity 与关闭共用紧凑顶行，分类筛选位于第二工具行；视图中的数量不再复制为列表开头的统计段。选中视图、分类和未读行有明确的文字或形状／整面底色信号，不只使用单侧细线。空视图说明当前范围为空，读取未知具名表达，不用空列表暗示已解决。
- 列表围绕准确对象形成常规两行的紧凑条目：首行承载对象名、必要 Host／来源、同组更多问题及原主动作；次行由问题短标题本身承担原生 Details 展开入口，等级字形与明确文字同排，标读位于对应问题旁，不再为状态、Details 和操作另铺一行，不重复每组分类。每条问题的阅读及动作归属清楚，组内展开后各问题仍有对应入口，顶行动作不呈为作用于整个对象的批量动作。真实时间、重复次数和未读仍可辨；长信息与窄窗允许必要重排，不能为严格维持两行而挤掉问题或动作。面板以更少的单项高度在更小阅读区域内呈现更多可辨认对象，避免仍保留三层条目而仅缩短面板。缺少时间或来源如实表达；组内问题数量与全局未读数量的视觉口径清楚区分。
- 问题预览可单行省略，完整标题、影响、原始原因、准确身份、失败步骤与原回执在同一 Details 中可读可复制；长对象及必要来源保留 tooltip 和可访问原文本，不用长协议错误、完整身份串或重复标题填满首屏。展开字形、hover 和键盘焦点明确表达短标题可展开，标读与原主动作独立可命中，不嵌进详情展开控件。长内容在中心的有界阅读区内滚动，关闭、切换和必要主动作保持可达。整体沿原 Graphite／Mint、字号、细分隔和浅深主题，不套厚重错误卡片或大块红底。窄窗中分类与动作按需要重排，诊断正文自然折行，保留原键盘阅读顺序、字号及不小于26px的控件命中高度，不靠缩小文字和按钮凑密度。复制留在详情中，局部服务提醒共享该语言，原必需恢复入口仍靠近对象。
- 中心的阅读、批量标读与历史清理分别用具名动作表达；仅打开中心不让全部未读视觉立即消失。新项到达时保留当前选择、展开项、焦点及阅读位置，不能自动切换视图或抢到列表顶部。按需展开和局部状态变化使用克制动效，遵从减少动态偏好；关闭后仍能从同一铃铛复查原问题。
- Notifications 设置以 OS 横幅为明确对象，时长、声音、预览与 Off 状态都说明投递范围；窗口通知中心的持续问题与阅读入口不画成随 Off 消失。保持原配置保存控件与回执语言，原生平台实际停留限制具名说明，不用预览暗示系统已经采用该呈现。
- 收起、已读、问题合并、恢复与解决的行为约束唯一见[《全局通知与底部状态入口》](../behavior/settings-and-observation.md#全局通知与底部状态入口)。

## 图标与打断按钮复查

- Executor／Agent Provider 图形用很细的外轮廓描边，不得画背景光晕、模糊发光或状态扩散阴影。
- 外描边必须像珐琅徽章：Provider 与左上固定 Icon 先合成相对实面的轮廓，镂空下方由不透明中性底片承托；底片比图形向外多出 1px，最外沿再加清晰、不透明的 1px tint 描边。图形本身颜色和细节保持原样，tint 不能铺满原图，也不能在镂空内侧重复描边；没有自定义 tint 时不增加彩色轮廓。
- 禁止在这层轮廓、外层容器及连接／恢复页继续叠加 drop-shadow、模糊或半透明发光；working 和 attention 同样不例外，状态只由右上共享标记表达。实际渲染必须能看见实体底片与外沿之间的层次，而非荧光。
- 固定 Icon 选择位于左上；右上只表示状态，右下只表示数量，三者不得重叠。Icon 与 Provider 图标先合并再描边，设置预览与菜单／实际 Agent 入口保持同一位置。
- 打断主按钮唯一见[《Message Tools 主按钮密度》](conversation-input.md#message-tools-主按钮密度)，不在设置专题重复图形或配色。

## 服务提醒与结果信息的轻量控件

用户反馈「"result ready" 这类信息条的视觉设计太糟糕了, 缺乏现代感, 按钮也特别厚重, 我觉得应该好好优化」。Result ready 与同类服务信息采用现代、轻量的状态表达：短文字与有含义的状态字形承担首层，必要动作沿既有紧凑控件、命中区与焦点语言，避免厚重按钮、大块背景、重复标题和多行解释堆成长期占用。细节按需展开且高度有界，窄分屏保持文字可读、入口和关闭动作可达，不以缩小文字或点击范围换取轻量。失败、未知与结果就绪清楚可辨，颜色不独自承担含义；关闭较大呈现后仍保留克制、可发现的状态入口。通知逃生、事实归属和复查行为只见交互合同[《我们的流程坏了，不等于 Agent 坏了》](../behavior/session-recovery.md#我们的流程坏了不等于-agent-坏了)的“通知必须有逃生通道，并按同一交互治理”。

## 设置页现代化密度

Conversation Channels 在 Settings 中作为一级组，以 InApp、Lark、Discord 子项呈现；各页沿原模块目录参与侧栏、Overview、搜索与窄窗分类，不在 Mods 保留等价入口。InApp 首层说明[App 内对话模式](conversation-mode.md)，以紧凑具名入口到达原输入、外观和快捷键工作面，标清共享范围与只读参考；不展示设备列表、连接二维码或无真实消费者的模式开关。Lark 与 Discord 首层分别围绕本平台的准确机器人及其当前任务，导航名不替换真实平台、Host、应用或设备身份。原机器人库、扫码、已存对象与未决任务保持同一工作面；真实适配器与可执行方式可辨，不以静态未来平台列表冒充能力，不新增通用频道看板或重复状态总览。设备密度沿 Remote 的[手机连接与设备活动](#手机连接与设备活动)，外部应用行为唯一见[外部对话应用接入](../behavior/settings-and-observation.md#外部对话应用接入)。

设置布局采用轻盈、清爽的现代工作台表达。任务标题、对象资料与一个主动作沿同一阅读线组织，以字号、留白和轻分隔建立主次，避免厚重卡片嵌套、重复边框与工具式参数平铺；从属服务设置和诊断按需阅读，不与当前任务竞争。轻量不靠缩小字号、命中区或隐藏必要说明取得，浅深主题沿既有语义色与控件语言成立。

channel 设置首屏以本平台的机器人列表或当前准确机器人任务为主。托管 Host 与 Automatic chat sync 在首层以紧凑、从属的环境／服务行直接可达，保留选择 Host、明确 Enable 与变化后的 Save changes，不用大区块、展开的技术身份或长说明占满上半页。当前已保存值与未提交选择可辨，完整 Host／Runtime 身份与服务历史按需查看；未确认与原请求恢复仍就地可见。“在 Agent 标题栏显示”、“自动收发消息”、全部外部机器人的 Automatic chat sync 与单个机器人启用分别标清作用范围，不用 Lark 或 Discord 导航名暗示全局设置只作用于当前群或应用。入口显示只作用于当前 App；自动收发作用于准确托管 Host 的该平台。隐藏入口不暂停消息，暂停消息不自动隐藏入口；全局同步关闭不冒作平台已关闭。两个设置分区呈现，各自明确保存与结果，避免用一枚开关同时代表两个动作。管理与恢复入口保留，未知不画成已关闭；作用、回执与恢复只见[同主题行为](../behavior/settings-and-observation.md#外部对话应用接入)，展示控件不复制服务事实。

关闭后的管理、恢复开关和原结果查询仍在原设置面可发现，未确认保存与完整原因沿原反馈按需阅读；不画空白页、假成功或另一套停用流程。从[Agent 连接菜单](conversation-mode.md#agent-群聊连接入口)进入时直接看到同一控件并保留原 Agent 导航上下文，打开页面不改变选择或自动保存。开关只在准确回执后呈已保存结果，未知、当前读取和原请求不混写；具体生效边界只由同主题行为定义。

channel 页只保留一份以机器人为主体的 Bots 列表，不在前面另铺全部 Mote 的未关联创建卡，再在底部重复 Saved bots。每条机器人以名称为主、平台与可区分的应用身份为辅，初始化、当前接入观察和准确 Mote 用途各有简短层级；同名对象不只靠 hover 区分。已确认的新群默认与私聊用途分别命名，关联读取未完成或失败明确保持未知，不由暂无关联说明机器人失败或不可用。创建／接入操作集中在列表标题旁，原未知任务与恢复入口不被重排隐藏；轻行、间距与分隔建立层次，不用重复绿色 CTA、外框或状态总分代替。

为 Mote 创建或关联身份是可发现的独立用途入口，明确进入后才以紧凑可选行列出全部准确 Mote；不在机器人库默认展开多张未关联 CTA。行内显示原头像、名字与准确默认／私聊关联，未关联、不可用和读取未知分别表达；选中后进入该 Mote 的原身份任务，一处返回即可回到原目录。Mote 既有头像直接预览并用于本次创建，准确读取失败才就地说明与刷新，不增加准备头像步骤。已关联对象以管理为主，解绑与创建另一个身份为明确次级动作，影响说明紧邻确认。通用创建不要求先选 Mote，从具体 Mote 抵达则保原来源和资料，不要求重选；不因列表重排新增弹窗或复制保存流程。

机器人详情继续管理准确原应用，Mote 关联只说明实际用途，不与平台身份混成一份事实或暗示 Mote 仅属 Lark。现有单份新群默认与独立私聊配置如实按各自用途呈现，不能将两个 channel 入口画成已有各自独立保存值；既有多 channel 群关系也不因此被隐藏或改写。本地别名与平台公开名称不混写，完整应用与连接归属按需可辨。从 Mote 进入创建或同步只增加原来源与本次公开资料预览，不复制 Mote 编辑器。资料已写入、待发布、审核中、已拒绝、线上已确认或结果未知由原回执分别表达，主面只呈当前事实与下一步，完整版本和操作凭据按需查看；本次局部失败不覆盖应用原接入与群投递状态。

管理账号确认替换当前机器人详情的任务内容，保留原设置导航与一处返回，不叠加弹窗或竞争列表。扫码、手机确认、正在读取、待确认账号、结果未知和账号已确认以各自的当前结论呈现；读取中的短暂空响应不画成未知结果。账号与企业合成一组紧凑事实，名称缺失时完整显示准确身份，确认用途紧邻主动作。账号已确认后仍直白说明待完成的配置及真实出口，不画整条接入已完成。其他原申请、换账号和诊断按需展开，私密材料不进入历史或详情；主层不并排堆叠含义相近的恢复按钮。

创建结果未知时，先直白说明尚不能确认机器人是否已创建。没有可用确认链接时，就地说明目前无法取得平台确认入口、创建结果仍未确认且原申请保留；主动作只检查这份原申请的结果，不暗示再次创建或保证能继续平台创建。同一申请的查询与恢复只保留一个首层入口，不将含义相近的动作铺成并列选择。检查仍无新进展或本次检查失败时，在动作附近持续显示简短结果及仍缺的确认，不让短暂加载冒作完成；技术错误原文保留在具名详情，不单独落在页面末尾让用户推断创建结论。接入已有机器人以克制但可发现的次级入口保留，并简明说明其面向已有应用，不让它看起来是另一项进度检查；另一独立申请收在明确的展开项内，只用一处简短说明交代可能另建机器人且原申请仍保留，不能包装成刷新或重试。等待平台确认的说明与未知结果的说明分开，准确操作身份、修订、原始阶段与技术原因默认收在具名详情；详情保留安全原文，不再复制一组等价查询按钮。

从创建、扫码到接入结论保持同一连续任务面，不让用户在多个技术页面间搬运凭据或猜测下一步。等待本人确认、等待企业审批与系统正在处理分别用简短动作说明表达；原请求的查看和恢复仍可达。应用名称与真实接入结论构成主层级，原 Agent 菜单的连群下一步从属但可发现，不以庆祝画面或“全部就绪”掩盖群与成员尚未确认。完整原因、准确应用身份和安全的原操作凭据按需展开，密钥与一次性授权材料不进入详情。正常状态不铺协议原因，按群查看投递的入口保持准确范围。保存、接入与原操作恢复的事实边界唯一见[外部对话应用接入](../behavior/settings-and-observation.md#外部对话应用接入)。

在实际 332px 窗口视口及短屏中，扫码、当前说明与动作沿单列自然重排，二维码保留完整静区和可识别尺寸，长原因、应用名与可复制的安全原文能有界阅读；同一内容滚动区内主动作和关闭保持可达，不能横向裁切、缩字或压缩命中区。键盘焦点、触摸、浅深主题、减少动态效果与原字段 IME 沿共同控件语言，扫码结果刷新不重挂正在编辑的字段或跳动滚动位置。

Browser 自动化开关与已记住链接的 Forget 沿既有设置控件和就地反馈，不增加审批平台或常驻授权栏；本地配置管理与原生权限选择的行为边界归交互 SSOT「设置页的信息架构」。

本节的视觉约束统一归上文「Settings 控制工作面」；侧栏保持单行标题，分区说明只在主区出现，避免两处约束互相冲突。保存反馈与草稿保留归交互 SSOT 的「设置页的信息架构」。

## Remote 管理拓扑

本节持有 Remote 的画布、节点、详情与连接编辑的呈现要求；对象、状态、信息来源、操作资格及建议分期只见[Remote 管理 PRD](../behavior/remote-management.md)。参考图中的深色拓扑和右侧详情用于关系阅读，不照搬其网络业务、配色或大屏指标。这里描述目标呈现，不声明新页面已实现或通过图审。

### 总览、画布与选中详情

Remote 分组下以 Hosts 进入同一 Host 工作台；总览、项目、应用与访问、连接配置沿准确对象切换，不把三份独立 Host 库铺进侧栏。应用与访问分别呈现应用账户同步、Agent 配置盘点和来源 Core 信任，三种范围使用具名分区，不混成一个“权限已同步”状态。Remote 沿 Settings 的原页头、关闭、搜索与状态栏边界，主内容以可探索的拓扑和选中对象详情形成连续工作面。正文足够宽时画布为主、详情居侧；不再同时常驻一份宽 Host 库、完整画布和大表单而挤压可读面积。工具行只放真实范围、查找、拓扑／列表切换和一个明确新增入口，不铺欢迎横幅、重复全局计数或无来源的健康总分。

画布去掉点阵与重复背景网格，以现主题 token 构成安静、平整的底面。节点采用厚实的块面、清楚的明暗层次、克制的嵌入边缘与仪器铭牌感，形成复古未来的模拟科技质感；Graphite／Mint、浅色与原复古未来主题分别保持自身配色。不铺噪点、扫描线、发光、流动粒子或常驻脉冲，材质不能降低文字、焦点和状态的可读性。布局让管理入口、Host 路由与其已确认绑定有可循的阅读方向，长地址不挤进连线；线上的短标签只承载真实关系和具名观察，不暗示未知物理跳点。缩放与适配控件停在不遮挡节点和详情的边缘，状态与动作不依赖无限画布水印或默认控件样式。

节点以名字为主扫描线，连接类型与简短地址次之，具名状态和必要工作摘要再次之。节点在准确 Host 旁以紧凑铭牌呈现已配置的 hostname／SSH alias、用户与端口、Runtime 绑定及本次检查与时间；没有网络读取时，未覆盖值仍标为由 SSH 配置决定。选中对象取得的网络摘要沿下节分源展示，不为其他节点铺空指标。内容以端口行与分区块面形成主次，不能堆成等权日志。节点不塞完整密钥或 socket 路径、全部网卡地址、CPU／内存假曲线或全部 Session；准确 ID、长地址、观察来源和时间在详情可完整选择。不同层级有可辨图标或文字，不能只用颜色区分机器、Runtime 与项目。

节点以仪器模块的结构接缝、连接接点与嵌入读数区强化物件感，保留名称的主扫描轨道。当前 Host 的配置连线随选择形成连续可循的强调路径，并配具名选择信号；它表达当前阅读对象，不表达链路健康、实时流量或已确认的物理网络路径。选中、悬停与焦点变化不改变模块尺寸，不为酷感添加重复计数或无动作的装饰控件。

整体以多设备管理控制台组织：可选择的环境模块、紧凑编号的配置中转、按来源排列的接口架各有可辨的形状和密度，形成从环境全貌到所选链路的连续阅读。模块标题、接点和嵌入读数承载准确对象、配置顺序与来源，不让所有内容变成同形卡片；样式变化沿原主题、字号与控件语言，不增加假仪表盘、装饰流量或无业务含义的控制按钮。 材质按安静底面、实体模块、嵌入读数三层收敛，容器不与设备使用等强描边；结构高光和短阴影仅服务模块分层，不反复叠框或堆叠异形圆角。名称与地址保留主扫描轨道，编号、角色与来源用安静的侧轨或次行承接；路径详情以紧凑有序行保全身份和用户／端口，不把同一路径重复铺成等权大卡片。

选中态同时使用稳定边界／表面与焦点或文字信号，沿 Mint 语言，与状态色分开；hover、键盘焦点和 selected 各有区别。平移、缩放和数据刷新不使节点无故跳位、重置选择、抢焦点或推走详情滚动。未知节点有可读文字与克制样式，不呈正常绿色，也不借用死亡或危险删除的强红。

详情首先显示准确对象、当前可确认结论和一项下一步，再按工作、能力、连接与维护披露。项目沿原名字与完整可换行路径，Agent 沿标准身份、语义状态和准确执行归属呈现；不重复做另一套名册卡片。serving、bundled、最后成功与当前失败用明确标签区分，原升级当前阶段和更新时间邻近主动作可见；Native 适配器能力在具名详情中逐项可扫读，原来源与保留时间相邻，不画成 Run 健康或权限矩阵。版本串、协议和 operation ID 收在具名技术详情；缺失读数用“未取得／未提供”等准确说明，不用零、空仪表盘或装饰曲线填空。

### 网络观察与配置路径

选中环境的网络区以一项明确的读取／刷新入口展开，先呈本次可确认结论，再呈配置路径、保活策略与分源地址；读取范围和事实语义只见[所选 Host 的只读网络观察](../behavior/remote-management.md#所选-host-的只读网络观察)。图、列表和详情使用同一观察，当前选择、草稿与详情滚动不因刷新改变。Fleet map / Selected link 范围控件置于拓扑页头，与原 Topology / List 控件保持层级区别；所选 Host 名称邻近范围可见，未取得链路观察时指向原读取入口，不铺虚构中转或空指标。

首层用“Owner 请求耗时”等具名短标签及来源时间表达读数，并说明该耗时可能包含建连、排队与处理；不用笼统 Ping 或延迟仪表盘。保活采用“当前 SSH 配置”的策略行，不画成活跃心跳、连续脉冲或健康绿灯。接口架分为观察服务与目标 Owner 两组，组头带准确来源及读取／采样时间，行内以原接口名、地址族和完整地址分层；IPv6 和 CIDR 可换行、选择与复制。接口架与配置路径分区，不将网卡逐一串成中转；不加没有来源的 VPN、隧道已连通或当前出站徽标。节点只摘取少量有来源的摘要，不把全部地址铺到画布。

Selected link 沿原拓扑画布以被动节点呈现观察服务、按原顺序的配置跳板与目标，名称、用户与端口可读；本地路由不铺 SSH 中转。受管环境模块与配置中转以形状、编号和具名关系区分，配置关系与已核验 Runtime 保持不同图形层级，中转不带 Host 管理按钮。ProxyCommand 只以单个路径不透明节点说明，不补出内部跳点或显示原命令。实际连接端点尚未取得时用简短未知说明，不把 DNS 候选或网卡地址摆成已连接的节点端口。

局部失败邻近相应来源显示原因与刷新动作，保留值带最后确认标记，不遮掉其他结果、Host 管理或原 Agent 工作。完整来源和技术字段按需展开，不回显原命令或标准错误。宽窄窗与浅深主题沿原块面语言重排；窄窗沿原等价列表与单对象详情纵向呈同一配置顺序和分源接口，先保持名称、关键结论和动作可读，不靠缩字或横向裁切保住列数。

### 应用账户同步

应用同步在准确环境的 Apps & access 中形成一条连续任务：选择或配置应用连接器 → 明确来源与目标账户及 scope → 查看差异计划 → 明确执行 → 查看目标验真与原操作结果。行为、材料和资格唯一见[应用账户同步合同](../behavior/remote-application-access.md)。默认显示已保存规则和准确目标；没有配置时给一项清楚的添加入口，不显示虚构应用状态或示例授权。

名称、来源 → 目标、应用账户与范围构成主阅读层；命令与独立 argv、执行账户和连接器协议说明收在配置面。只保存命令和非敏感配置，不提供粘贴 token 的普通字段。差异计划用具名文字说明可复用、需要传递、不可迁移或冲突，并只给当前有效动作；目标已有登录也显示已核实的账户，不能只用绿色 Ready。计划变旧时保留原内容并说明需重新比较。

执行结果区分已发送、目标已确认、目标验真完成和结果未知；不伪造进度比例。未知保留原操作及“检查原操作”入口，不能把查询画成再次同步。简短当前结论和下一步在首层，完整安全身份、范围、阶段和时间可展开。局部失败不遮掉其他应用、来源信任或 Agent 配置。离开、重新进入和窄窗返回均保留原操作可查，不让 spinner 或短暂 toast 承担结果保存。

表单与计划沿原控件和块面语言；双端信息在窄窗自然叠放，长账户、Host ID、scope 与命令可完整读取或选择。刷新结果不重挂编辑字段、不抢输入、不展开整份技术日志；浅深与复古未来主题均保持可读。

### 等价列表与小窗口

列表是同一准确 Host 与详情的另一种阅读方式，保留名字、地址、短检查状态和必要工作摘要。环境可展开连接配置与关联项目，轻缩进表达子菜单；完整选中面与 Check 仅标记当前子页，父项以克制字形提示当前环境，避免两层争夺主层。图与列表的选择、筛选范围和具名状态保持一致，不显示两套冲突结论。

正文宽度不足以让节点、线标签和详情同时可读时，使用列表／单对象详情的明确往返；不靠缩字、横向裁切、极小缩放或隐藏关键动作维持分栏。宽窗的画布与详情、窄窗的列表与编辑各有有界滚动，原保存栏和关闭保持可达；不为了保留草稿提前挂载其他对象的编辑器。键盘可从等价列表准确选中、进入详情和返回，操作命中区、焦点、文字对比、长内容与减少动态效果沿共同控件语言。

### 连接编辑与检查反馈

连接编辑沿用现 disclosure、字段间距与焦点语言，高级用户、端口、密钥路径和服务覆盖按需展开。原始基线、逐位输入、展开意图、保存期间输入及远端准备失败的行为唯一见[连接配置与测试](../behavior/remote-management.md#连接配置与测试)；不为修输入或保留草稿新增设置项、常驻说明或另一份编辑面。

字段、保存栏与就地错误沿 Settings 控件，当前对象名称、完整地址与长原因可读。检测中、就绪、明确不支持与检查未取得事实用简短状态识别；就绪安静，不支持中性，未知检查失败沿提醒语言，不借用进程死亡表达。窄窗完整换行，不把协议／版本长串用作状态装饰。

Host Test 在准确连接编辑内继续采用短状态、就地完整原因与原生 details，不因检查增加第二套重复诊断面板、常驻标签或命令展示。Remote 的选中详情负责跨来源的观察与维护理解，不能把该详情与单次 Test 反馈合并成一项成功或错误。原维护 operation 未确认时，其状态与可核对动作留在准确对象旁；换 Host 或刷新不擦掉原回执，正常对象不铺协议错误。

## 手机连接与设备活动

手机工作面延续 AgentMux 身份和控件语言，以紧凑页头、可扫读的名称与状态列表组织；五入口导航唯一见[手机公共呈现合同](public-control.md#手机版-relay-连接的呈现)。正常连通不常驻连接说明或教程，连接与默认主页配置归菜单；会话对话与终端是选定对象的下钻工作面。列表不以 UUID、绝对目录或实现名称代替产品名称，长名可读且不挤掉操作，压缩留白不缩小触摸命中区，输入保留 iOS 可用字号。一级导航与默认主页行为仅见[《手机版 Relay 连接》](../behavior/public-control.md#手机版-relay-连接)。

手机下钻保持单一紧凑页头、准确返回目标和当前对象；Topic 的分类、讨论、知识各有明确层级，Survey 保原研究列表与当前内容。主要操作与阅读内容优先，元信息及实现诊断按需展开；触摸命中区保持至少 44px，输入满足 iOS 的 16px，正文不被头像或不透明标题栏遮挡。自定义头像、原动画与失败状态纳入实际完整手机图审。一级入口及菜单集合只由[《手机版 Relay 连接》](../behavior/public-control.md#手机版-relay-连接)定义，本页不另列三项导航或将 Desktop 分组映射为手机集合。

手机连接在 Toolkit 的 Built-in 库中紧随 Performance，以手机图标、名称及 Official 身份可辨。右下角沿同一低条入口与 Toolkit 浮窗显示，首层围绕“连接手机”组织：真正展开后取得当前数据，读取中就地说明；确认链接后以可扫描二维码和就近复制完成跨设备接入，完整 URL 按需展开且可完整选择，无须先操作生成按钮才能取得链接。刷新与复制结果就地反馈，扫码区保持清楚的方形几何、对比与留白，不把长链接、脚本或 Run 术语塞进主阅读路径。二维码与复制的结果一致性仅见[《手机版 Relay 连接》](../behavior/public-control.md#手机版-relay-连接)。

连接入口之后呈现最近查询时间、当前连接数量及简洁的设备列表，离线设备不铺在 Toolkit；辨认详情与撤销在设置管理。当前展示与上次显式操作分开：本次数据已确认而旧请求未确认时，扫码／复制及展示刷新保持可达，旧请求用简短任务说明及可用的核对／继续动作形成有界服务窗，原错误和执行身份在具名详情可达；不把“Execution restored”作为连接状态或让未知说明占满浮窗。展示读取失败保留原数据与时间，历史链接在扫码区就近注明未重新核实，不能用成功颜色冒充当前已核实。浮窗保留固定标题、关闭和设置入口，内容在单个有界区域内滚动，正常状态不铺协议错误或内部解释。设置先显示同一局域网的连接主动作及扫码／复制，再给出默认收起的设备记录入口；显示开关与 icon／label 归 Toolkit 配置，隐藏入口不撤销设备授权。

手机设备入口与 Toolkit 沿同一当前链接、扫码或复制的连接层级，原位展示读取及操作反馈与最近核实的连接状态，说明手机打开即可使用；不以系统提示代替结果页，不把证书或配置诊断放在正常接入流程中。设备区清楚区分“当前在线”和“已授权”数量。设置的设备记录整体默认收起，每个设备详情也默认收起；展开后以名称、Connected／Disconnected 或未确认状态辨认当前对象，只呈最近连接与断开时间，不铺业务方法、目标和结果的逐次日志。完整指纹可选择／复制，IP 标明当前或最近接入与时间，原 deviceId 及登记时间可查；浏览器线索有来源可辨，缺省如实显示未记录／未确认，不拿名称或短 ID 填补。长指纹、IPv6 与浏览器文字在窄窗完整换行或可完整选择，不能裁掉辨认信息。刷新不自动展开记录，展开选择沿原设备身份保留；同一设备的撤销入口仍可达。未知或读取失败保留原列表与折叠状态并就地说明。授权、连接事实、计数与来源边界唯一沿[《手机版 Relay 连接》](../behavior/public-control.md#手机版-relay-连接)。

### 手机品牌与紧凑导航

手机启动连接使用龙品牌图，工作面不常驻巨幅品牌。列表压缩外框与行间留白，同时保留可读项目、Agent 名称与真实状态；底栏几何、五入口与 Mote 居中唯一见[手机公共呈现合同](public-control.md#手机版-relay-连接的呈现)。Mote 对话顶部只保留原头像，必要身份与状态按需揭示，不叠重复名字或不透明标题条遮正文；固定输入与按需展开的执行过程保持。

Focus 摘要在三行以内保项目、名称与 recap，正文 13px、元信息 11px、列表约 56px，触控目标仍至少 44px，不用大字留白冒充层级。连接、设备与默认主页配置沿同一行为 owner 的菜单，不在本页重列一级导航。

## 主题编辑器

主题选择样片呈现完整工作台的表面、文字、状态与图标语言，名称、明度和当前选择明确；Graphite / Mint、Light、辐射 4、复古未来在相同真实内容下评估，样片不冒充运行事实。编辑区按颜色、字体/表面和语义图标组织，字段与当前预览一一对应，已保存、未保存预览和内置只读边界可扫读。恢复、取消、保存副本、上传、下载及冲突动作使用原控件层级，不用额外装饰卡、缩字或全页动画撑页面。

语义图标区直接呈现图形、含义和稳定 ID，支持按含义分组、搜索及只看已修改项。选中项清楚显示默认与当前图形、标准尺寸预览、单项还原和有名称的可搜索字形图库；不要求用户先知道 Lucide 名称。默认字形相同的不同语义项仍可辨别、独立编辑。当前选择用面、边界与可访问状态共同表达；目录与详情在窄窗自然重排，长 ID、无结果、校验错误与自定义 paths 都完整可达。沿原设置控件和主题 token 实现，交互动作不另开页面或隐式保存。

标准、窄窗和短屏下所有参数与文件反馈完整可达；键盘 focus、当前选择、hover、disabled、错误、危险和未知有清楚区别。主题自定义图标在标准尺寸、所有控件状态及手机实际槽位中保持辨识与对齐；手机继续使用原触控和输入字号。完整实际页面原图与真实编辑/文件往返路径经独立 Agent review、修正复拍至明确可交付，颜色字符串和截图采集成功不代替美术与交互验收。
