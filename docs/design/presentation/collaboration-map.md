# Focus Map 的呈现与交互

本文定义[Focus Map 行为](../behavior/collaboration-map.md)的绘制、层级、缩放和动态语言。共享卡片、Reader、主题 token、窗口提示层和动效偏好继续沿原 owner；布局与动画不产生业务事实。

## 层级轮廓与关系层次

父区域以包住完整子域和直系节点的外轮廓表达地形，子域具有独立内轮廓、标题与留白；轮廓由真实几何生成，保持清楚包含，不用堆叠矩形、重阴影、随机地形纹理或颜色深浅代替层级。外层填色弱、内层轮廓可辨，名称、Host 与种类分别可读；聚焦一个子域时保留必要祖先方向感，兄弟区域退后。共同父目录导航分组不画成虚构的 Space 地形。

通信邻域是视觉重心，连线从准确可见节点边缘离开，端口分散、双向分道；较强关系可在克制的线宽/强调预算内被扫到，选中或键盘聚焦后突出准确邻接关系，其余路径退后但不消失。区域背景不压过节点身份、箭头与选中路径。

首次组织与增量调整使用一致的通道留白：求解占位同时容纳真实节点和必要的端口出口，卡片尺寸保持原阅读密度，整理、折展与路由使用同一几何边界。

## 连续缩放与有意义的动态

LOD 从点状概览、紧凑身份到共享可读卡片连续过渡，透明度、可见轮廓与端点由同一缩放进度计算，不能在阈值突然换形、跳接箭头或改变世界位置。轻量身份层与原共享卡片在有界过渡带交接，任一时刻只保一份可操作语义；键盘正在阅读的准确对象保住焦点，透明层不抢输入、重复 Tab stop 或挂全世界重卡。屏外保留原几何，缩放不发整图布局或新增无关来源读取。

轻量身份与卡片的名称、头像顺序交接，避免停在中间倍率时出现错位叠印；紧凑名字依据头像实际占位及可用屏幕宽度逐步显露，外壳与圆环沿同一缩放进度连续变化。

显式定位、适配、缩放和区域阅读的短转场帮助人追踪去向，后来的真实手势优先。hover、选择和关系强调使用短而克制的反馈，不弹跳世界坐标、不循环呼吸装饰。自动时间转场消费原有效动效开关，关闭时立即完成，系统默认与显式覆盖语义保持；用户直接缩放仍有连续几何。真实消息的方向移动和双端反馈沿原事件期限，显示切换不重播。渲染、路径与布局可独立取消和复用，慢计算保既有可读画面。

结构变化的有限局部调整沿[相对稳定合同](../behavior/collaboration-map.md#相对稳定与结构调整)，以短转场帮助人看清新旧邻域的关系。相关节点、标题、包含轮廓与连线端点同步过渡，不先跳动成员再补画边界，不让路径短暂指向另一对象；旧邻居可以随变化适当让位，完成后落定，不持续摇摆、弹跳或模拟。原阅读锚点保持屏幕位置，不用自动平移或缩放掩盖位移，无关区域不陪同运动。过渡中仍只有一份准确的可操作对象，后来发生的真实手势可取消或接管尚未完成的转场；关闭动效时直接采用同一最终几何。没有结构变化或最终几何未变时不制造位移动效，也不重播旧活动。

## 轮廓与 LOD 设置

设置遵循[地图呈现偏好](../behavior/collaboration-map.md#地图呈现偏好)，以可用预设开始，逐级调整按需展开。Map 内的设置入口进入原 Focus 设置并显露 Map 项；返回保留原地图阅读位置。边界用两张同成员范围的小示例表达多边形和贝塞尔曲线，不以抽象术语代替实际差异。

LOD 编辑器同时呈现级数、由远及近的级别顺序、形态和信息。每级明确列出身份、状态、摘要中的哪些内容会显示；点状层不提供无法实际呈现的摘要选项。首级标明为固定起点，不展示无意义的过渡字段；后续缩放范围以百分比表达，开始和完成值相邻可读，默认三级沿现有概览、身份、卡片的节奏展开。选择级数会载入对应的可用起点，界面说明可继续逐级修改；恢复默认是明确动作，不暗中覆盖其它 Focus 偏好。

预览使用同一轮廓、LOD、节点内容与可见端点 owner，提供连续缩放以观察中间形态；示例与正式工作事实可辨，不生成演示通信或读取真实 Session。名称和头像顺序交接、屏幕文字预算、命中区及单一语义层在自定义设置下仍成立。窄屏让逐级编辑纵向排列，保留完整字段名称、预览、校验与保存入口，不靠缩字或横向滚动塞入参数。

## 入口、密度与完整阅读合同

协作图沿[Focus 的 List／Map 与同一世界](../behavior/collaboration-map.md)呈现。Focus 主栏以有文字、可键盘操作且当前状态明确的 List／Map 分段切换表达两种视图，没有选中 Agent 也能发现 Map；选择 Map 后直接进入画布。Space 保留准确上下文的“在地图中定位”动作，不再将 Workbench／Map 作为另一组主视图。Agent 的图内定位、在 Focus 中查看与打开原工作面使用可区分的动作表达；准确跳转与阅读保留只见上述导航合同。当前区域或 Agent 通过相机位置与清晰的选中信号呈现，不以“当前／全部”切换制造不同世界。主视觉精致、紧凑、简约，以区域、Agent 与关系内容建立层级；说明直接表达准确对象和可用动作，减少口号、重复元信息和常驻说明，控件密度与命中区沿[共同视觉规则](shared-rules.md)。

地图采用现代、克制的战略地图语言：区域形成可辨的空间轮廓，节点身份与真实活动成为视觉重心，紧凑控件保持清楚的操作反馈。游戏感来自层次、定位感与有限的事件动态，不靠常驻扫描、装饰粒子、虚构流量或不断移动节点营造忙碌。沿原主题与语义 token 工作，明暗主题均保有可辨的区域、节点、关系和选中信号。

Map 在同一条 Focus 主栏中组织视图切换、Agent 查找、关系筛选披露及来源状态，画布不再重复一整排全宽工具或全宽数据脚注。当前定位以画布内轻量上下文标记表达，不占据另一条主导航。查找结果的上下键只移动候选高亮，Enter 才定位，Escape 收起结果并保留查找输入；候选高亮不改变相机或启动来源读取。查询范围与定位目标可辨，不把 List 的正文搜索或隐藏筛选条件带成地图范围。来源数量、读取状态与问题集中在一个明确的 Sources 按钮，正常时保持安静，失败时持续可辨；打开后在同一可收起阅读区切换为来源内容，披露参与者、已读窗口与续页，保留原对象选择并可返回对象详情。来源阅读区只持有一处展开状态，不在多个位置重复同一组计数或维护另一套内嵌来源展开。

Map 使用完整 Focus 内容区，不同时摆放 Space 左侧菜单或 List 泳道；保留共同主栏与可收起详情，不增设另一层导航。

地图布局以区域、真实关联和阅读顺序组织疏密，不把所有 Agent 机械排成同尺寸的双列卡片；没有关系的成员仍有可发现的位置。区域边界由完整成员几何和标题的留白形成清晰而克制的轮廓，浅／深色下均能分辨区域与画布，结合原区域类型、可读名称和成员数量建立层次，不用模糊底色承担唯一的归属信号，也不以等宽矩形容器主导视觉；标题保留方向感，同时让位于节点与关系；零成员区域使用轻量、紧凑的名称标记，在工作区域之外有序安放，不与有成员区域竞争首屏空间；无关联 Agent 的区域仍属于工作内容，不能混同为空区域。活跃 Agent 在可读尺度显示完整共享卡片，闲置 Agent 使用较小的紧凑标记，已确认关闭的 Agent 收为可悬停或键盘聚焦阅读的点。节点大小与视觉深度结合原最近活动表达层次，未知保持可辨，不能把小点、暗色或低对比度作为关闭的唯一信号。变化不突然推开正在阅读的节点或抢动相机。

缩放层次服务于同一地图：远景以可读的区域名称、成员数量和准确 Agent 之间的关系保持方向感，停止显示不可读的卡片小字；缩放本身不把通信端点改成区域标题，点状节点的连线也须接到实际可见标记。进入区域后展开 Agent 标记，再到可读尺度按上述活动层次披露共享卡片。名称与命中目标保持可用尺寸，概览仍能直接进入准确区域，不能靠无限缩小同一套卡片形成总览。有成员的主要区域不能仅退化成无文字小方块；标签按实际可用空间及定位、缩放等控件的真实屏幕边界避让，当前定位、选中及主要工作区域的项目名完整显示，优先分配宽度和合理换行，不以省略号或 hover 代替首层识别；种类与数量保留次级层次。活动标记始终保留稳定位置，出现和消失不挤短名称或改变标签边界。局部阅读时仍能知道所在区域，不能要求先把屏外标题找回来。颜色只辅助分区，不使用随机彩虹替代明确对象。概览标记与阅读节点共用准确身份、语义与动作 owner，不另造一套 Agent 资料；缩小或点状节点保留鼠标、键盘及窄屏的原详情入口。阅读节点直接消费已有 Focus Agent 卡片及已打磨的详情 hover，沿[卡片、预览与状态](focus-context.md#卡片预览与状态)保留共同身份、内容层级与鼠标／键盘阅读语言；详情沿原阅读宿主，不以局部样式或计时复用代替真实接入。屏外保留世界几何，不挂载完整卡片来测量或等待裁剪，缩放、平移与定位不被重内容加载卡住。

区域的 Mote／Topic／项目种类使用既有语义图标与可读类型表达，配合克制但可分辨的标题和轮廓处理；不能只换颜色而保留难以区分的同一种区域。Remote 是原 Host 来源的独立标记，和区域种类分别表达；已知多个 Host 来源时分别保留，来源未知不能画成本地或从名称猜远端。区域与 Agent 已有的头像、图标及身份外观沿原 owner 复用，在实际可辨的尺度披露，缺少素材时使用原语义图标；状态和最近活动另有清楚信号，不把头像替换成状态点，也不为增加细节读取全部卡片正文或建立另一套头像资料。

地图保留紧凑的定位、缩放、适配与布局操作。节点／连线的来源细节在选择后进入可收起的阅读区，未选中时不堆满协议字段，也不让常驻详情挤成狭窄画布。选中 Agent 的关系列表由所选 Agent 建立上下文，每行突出对端、相对方向、关系种类与数量，不反复拼写当前 Agent；对端支持直接在同一地图中定位。选择具体关系后再披露准确两端、原消息与来源，既有 Agent 内容继续使用共享 Reader，侧栏不复制一套 Agent 详情。区域标题支持鼠标与键盘折叠，折叠或展开保住刚操作的可见标题位置与缩放层次；原世界标题在屏外时，以用户实际操作的屏内区域标签为锚点，保留原地展开入口，后续用户平移或定位优先于尚未完成的折叠定位；不同关系沿共同语义色、实／虚线及文字共同区分，连线避开卡片正文和区域标题，同一对端的相反方向与不同种类使用可分辨的路径和箭头；同方向聚合仍能展开准确原关系，数量表示原证据数量；选择 Agent 时突出其相关路径，其他关系退后但不删除，减少跨区域密集连线对阅读的干扰。加载、空结果、未观察与来源失败用局部状态表达，不用整图闪烁、清空或自动适配制造变化。局部路由失败先说明未绘出的关系数量、原记录仍可阅读和准确重试动作；原机器身份与完整诊断进入可展开详情，不能堆满首层，也不能隐藏实际缺线。窄屏让主栏控件有序收敛，将详情改为下方阅读区，保留视图切换、定位、返回、来源与缩放入口，不靠缩字塞入桌面侧栏。

关系种类和方向在画布内可直接理解：紧凑可见图例以文字、线形与箭头共同说明消息、创建与调度，也说明活跃、闲置、关闭、未知节点与近期通信的不同信号，不让相同圆点承担全部含义；悬停或键盘聚焦连线时，完整原关系说明复用窗口级提示层，按原种类、准确端点顺序和证据数量表达；长名称允许换行，提示保持在当前窗口可见范围，不被画布或卡片裁挡，也不跟随消息标记漂移。选中后的准确两端和完整证据由原详情披露，画布保留清楚的选中路径与箭头，不因选中而常驻重复长句。路径保持简洁，避免无必要的绕行、往返折线及同端口堆叠；密集场景退后无关路径，不能靠难辨的色差或在菜单中寻找术语才能理解关系。身份资料未齐的节点表达已知名称、类型和来源缺口，不把 Related Agents 呈现为真实组织或下属群。详情区分原展示绑定、按工作资源关联及区域待确认，披露关联的准确项目／主题与依据；准确身份已知的成员不能仅因没有展示位置而被说成身份未知。

地图的视觉动态开关与画布操作一同保持可见、可键盘操作，以明确的动效名称及开／关状态表达，不使用容易被理解为暂停消息观察的播放语义。系统默认与显式选择沿[地图行为合同](../behavior/collaboration-map.md)，关闭后的静态活动和方向仍可感知；控件不新增全宽工具排或常驻解释面板。紧凑图例与动效状态共同帮助理解当前画面，图例不成为第二组状态或关系事实。

对话与协作关系用克制但可感知的局部动态表达本次发送、回复或进展，准确端点、方向和所指关系可辨，不能只靠运动或颜色传达含义。动态在实际屏幕尺度上具有可辨的方向移动与双端反馈，不能只留下与静态连线难以区分的细微变化；表达仍服从原活动的有限时长，不延长事实。新消息在区域概览与可读尺度均有真实活动反馈；动效的观察不要求为所有成员读取正文或历史，尚未完成路径计算也不能使本次活动完全不可见。消息与事件反馈本身不移动节点或打断阅读，减少动态时保留静态关系、活动提示与来源；隐藏、结束或来源失效时停止旧活动反馈，不循环制造热闹。每次活动独立到期，其他来信、重绘、折叠、缩放或滚动重挂载不能续期或重新播放旧活动；监督变化不冒充一条沿原请求方向发送的回复。活动事实与事件归属只由上述行为合同确认。演示中的合成通信明确标为演示，并提供播放／暂停；演示播放状态与正式产品的实时观察状态分别表达，不用历史重播或循环伪活动冒充正式通信。
