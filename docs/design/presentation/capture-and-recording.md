# 截图与录制的呈现

本文定义系统截图覆盖面、来源选择、编辑窗与贴图的视觉、密度和控件语言。截图行为、原稿归属、输出回执与权限由[同主题交互](../behavior/capture-and-recording.md)持有；共享图片标注的工具与证据呈现沿[Browser 任务工具与证据的紧凑呈现](browser-workface.md#browser-任务工具与证据的紧凑呈现)，本文不另写一份图标或样式规范。

## 系统截图选区

Capture 位于 Message Tool 的紧凑工具行，以 tooltip 发现系统快捷键，不为截图增加常驻输入行。快捷键、直接完成、原位标注、`⌘E` 展开编辑、不激活主窗口及没有输入框时的交付行为见[系统截图快捷键与选区](../behavior/capture-and-recording.md#系统截图快捷键与选区)。

截图覆盖面在冻结底图上用半透明遮罩、清楚的边框与可命中的边角控制点区分待选、拖动和调整。尺寸标签明确 px，坐标需要区分来源时就近标明 pt／屏幕像素；不同缩放下不混用单位。指针放大镜显示像素网格、中心点、准确坐标及 HEX／RGB，随操作贴近指针但避让控制点和工具栏，靠近屏边自动换侧；取色与复制色值有可发现的显式动作，不能仅靠颜色或隐藏手势。浮动工具条在选区静止时出现，拖动和调整期间收起；它贴在选区外侧、右缘对齐选区，放不下时翻到另一侧，仍放不下才内嵌在选区角。取消与快捷标注以图标呈现，具名由可访问名称与带快捷键的 tooltip 提供；完成是唯一带文字的主操作，使用实心主色。`Enter`、`Esc`、拖动与方向键提示在框选前的单行提示和 tooltip 中可发现，选区后不常驻。尺寸以单一 px 标签贴近选区角，pt 只在放大镜中就近标明；放大镜在框选前、调整选区和取色时出现，避让选区、控制点与工具栏，选区静止后收起。工具栏、尺寸和提示在显示器边缘向可见范围内调整，不能跨屏缝落入无显示器区域，也不遮住正在操作的控制点。

截图菜单采用紧凑、现代的浮动工具条，选区调整、编辑工具与完成动作层次清楚。尺寸、辅助提示与快捷键是次级信息，完成与取消易找、可键盘操作；避免重底色的大按钮、重复提示和装饰性容器。正常与窄／短屏幕均保留图像主位、可命中的工具和清晰的选中、hover、禁用与键盘焦点。

选区工具条分三组：常用标注组（框、椭圆、箭头、画笔、马赛克、文字、编号，按键与共享编辑器一致）；直接输出组（贴图、另存 PNG，展开完整编辑的 `⌘E` 在 tooltip 中可发现）；取消与主“完成”。选区、工具条与标注由同一截图覆盖面呈现，直接复用 Browser 的图片编辑组件与[截图标记呈现规则](browser-workface.md#browser-任务工具与证据的紧凑呈现)；点标注工具只改变当前工具，工具条位置与尺寸不变；属性以贴近当前工具的小浮层呈现，不显示头部、属性行、底栏与侧栏，编号备注在编号旁就地输入；放弃未输出标注的确认就地出现在工具条中。共享工具语言、属性、历史、裁剪及遮挡反馈，宿主只说明本次结果会复制、或复制并附到原草稿。

Capture 保留直接区域截图，窗口与整屏选择用同一轻量菜单可达；来源选择按屏幕／窗口清楚分组，以实际名称、缩略图及必要所属信息辅助辨认，失效与未知就地说明。选择来源不另铺常驻工具行。覆盖面在冻结像素就绪后一帧内整屏出现，准备状态可读且可取消，避免露出实时桌面、空白跳闪、重拍造成内容变化和恢复主窗口的动画；展开到独立编辑窗时沿同一图像与裁剪衔接。原生选区、原位编辑面与独立编辑窗的可见文案及 tooltip 使用与 Desktop 相同的界面语言。

## 编辑窗与贴图

滚动采集期间原选区显示透明、可穿透的细边框，保留真实来源内容可见和可操作。侧边紧凑控制条保留进度、缩略预览、停止和取消，不展示整套回看编辑操作。控制条不抢来源焦点，边框不接收输入；停止后释放边框并恢复回看窗。放置次序与输入行为由同主题交互合同持有。

Capture 旁不另设模式下拉箭头。覆盖面使用紧凑的截图／滚动／GIF 模式条和明确选中态，来源与延时放在同一组件的次级入口；不以大号菜单侵占消息输入区。截图后编辑面板的文字提取与敏感信息工具使用共享主题。不可操作按钮仍可发现，通过可聚焦包裹控件展示原因浮窗，不依赖 disabled 按钮自身接收 hover；原因具体到当前图片、能力或动作。敏感信息候选可逐项选择，应用动作明确称为遮盖。

编辑窗的 Copy／Copy & attach、Save PNG、Pin、Copy context 与 Original 用途分别可辨；PNG、贴图和原稿不混用一个含糊“保存”。主交付继续说明是否同时附到原草稿，其余动作使用紧凑次级分组；原稿路径或来源选择在需要时展开，不能以缺少 Workspace 隐藏可用编辑、复制或退出。贴图以图像为主体，轻量浮动控件提供复制、另存与关闭，鼠标／键盘均可发现，非 hover 环境仍有可达入口；缩放保比例，错误和结果靠近本窗，不增加全局截图管理面。行为、临时性与文件保全只引用[截图结果合同](../behavior/capture-and-recording.md#截图结果与悬浮贴图)。

## 连续采集与 GIF 回放

滚动截图与 GIF 使用轻量独立窗，图像占主位，采集控制集中在一行。准确区域、采集状态、帧数及错误就近呈现，开始、停止与完成可辨。滚动采集提示手动滚动及保持重叠，预览可撤回最后一帧。GIF 回放以播放按钮、可键盘操作的时间轴、上一帧／下一帧和当前帧号呈现；关键帧有可见标记，备注在图旁编辑，点击关键帧可返回准确帧。窄窗保持预览与主动作可达，不常驻内部协议字段或文件路径。

采样进行时使用紧凑、置顶的控制窗，优先放在选区外且不越出所在显示器。滚动采集展示最近一帧与帧数，GIF 以简洁计数与停止动作呈现；停止后在原窗口恢复完整回看与标记工具。普通截图及原工作面不因此切换、隐藏或重建。
