# 品牌架构

本页定义 AgentMux 品牌的整体结构：主标志、境、共用工坊与共同美术语言、IP 形象、App 图标的呈现、品牌可以出现的位置，以及哪些标志不归品牌管。具体素材怎样增改与派生，见[品牌素材指南](../../guides/brand-assets.md)。App 图标怎样选择与保存，归行为合同[《外观、App 图标与主题文件》](../behavior/settings-and-observation.md#外观app-图标与主题文件)。

## 一条龙，五个境

品牌的主体是同一条中国龙：长吻、眉骨、分叉角。境（realm）是一种渲染语言，决定龙用什么材质、构法和光来画，不改变龙本身，也不改变 Mote、工作界面或任何运行事实。

每个 App 图标是龙在一个境里的肖像，选图标就是选自己的境：

| 境 | App 图标 | 材质 |
| --- | --- | --- |
| 原境 · ORIGIN | Classic | 发光的翡翠低多边形龙，石墨面板与 Mint 电路线；所有境的祖先 |
| 青篆 · QINGZHUAN（默认） | 青篆 | 象牙底上的森林绿木刻侧像 |
| 回环 · HUIHUAN | 回环 | 墨绿底上盘成玉璧的长龙 |
| 折玉 · ZHEYU | 折玉 | 平面玉片折成的正面龙首 |
| 灵伴 · LINGBAN | 灵伴 | 复古未来陶瓷伙伴头像，石墨面罩与 Mint 双眼 |

用户已保存的 App 图标是唯一的品牌选择，不再另设「境」的设置。品牌调整不会改写用户的保存值。原境是唯一保证画齐所有大图的境。

## 混用规则

角色可以跨境，但同一帧里不混风格。每张画只属于一个境。

- **大图**（启动、Launcher 背景、Settings 概览条）显示用户所在境的画。这个境还没有自己的画时，显示原境的画。原境是其他境的祖先，所以借来的画读作「祖先的画挂在你家里」，是有意的组合，不是不一致。
- **题款**写在启动和 Settings 概览条的画角上，内容只描述这张画属于哪个境（如「原境 · ORIGIN」），不描述用户的选择。所以题款永远为真，包括选择未知时。题款是静态装饰：次级文字色，从不用 Mint，不可交互，不随指针视差移动，窄面隐藏。Launcher 是工作入口，不加题款。
- 保存值本客户端不认识，或首帧拿不到观察结果时，显示原境的画和原境题款，不对用户所在的境下任何结论，也不回写或记住一个选择。
- 首帧就要正确：启动面在配置载入前绘制，境从同步主题快照里读取，首帧之后不换图，也不预载其他境的画。

## 共用工坊

Goals 行动与澄清插画、设置概念场景、Topic 晋升场景和 Mote 起源故事板，描绘的是所有境的 Agent 与 Mote 相遇工作的地方。这一层叫工坊（commons），属于所有境，不随 App 图标切换，也不加题款。工坊插画沿下文[共同美术语言](#共同美术语言)：复古未来的铬金属与青铜造物、石墨底与玉色玻璃。

## 共同美术语言

本节是角色插画、概念场景与产品对象符号共用的美术语言，工坊插画、Mote 头像、Goals CTA 与设置概念介绍都沿用它。界面表面、密度与控件仍归[全局视觉与样式](shared-rules.md)。

角色与动作插画以真实 3D 角色或场景形成体积和表演，采用镜面铬金属的复古未来方向，并探索伪二维的非写实着色。清楚剪影、经过设计的图形五官、受控明暗与随形体转折的反射共同形成质感；角色自信、友好、安静而有个性。造型、表情和材质共同设计，金属高光与暗部仍让神情可读，成人感与精致程度在真实小尺寸和连续表演中成立。方向先核成熟角色作品、模型与 shader 的原来源及适用边界，再选择造型和渲染能力；独立素材与实际整页分别评审。Mote 新头像、可编辑捏脸、Goals CTA 及其他美术素材共享这一角色与材质语言，具体角色和场景随真实用途选择；静态插画可由同一 3D 素材预渲染，动画与可编辑形体由对应真实能力证明。界面表面继续沿 Graphite / Mint，角色与关键动作承担美术重心，密集终端、工具条、列表和编辑区以文字与语义控件为主。深浅主题中材质仍有层次，完整页面保文字、动作和图形的清楚主次；大图细节或 shader 的存在不代称高级感。已保存头像与用户图片沿各对象原外观 owner 保持；插画辅助用途辨认，动作标签、当前值、状态与反馈继续表达真实事实。

Space 与 Focus 使用同族的产品对象符号：Space 以开放工作舱表达容纳与组织，层叠壳体和开放工作面构成主要轮廓；Focus 以聚焦镜表达关注与观察，分离的四角框住当前工作。两者延续 Goals 的复古未来金属造物质感与 Mote 的 Mint，靠形体建立辨识。概念场景、简化轮廓与小尺寸导航图形保持同一对象的连续识别；小图形按实际尺寸提炼，不直接缩小复杂渲染图，也不把 Space 简化成通用文件夹。图形沿现有语义目录与共享 owner 复用，保留 Mote 的伙伴人格及 Goals 的[共识身份](goals-and-demand.md#goal-的共识身份与局部反馈)，不因新符号另造 Agent 身份或状态。设置页概念介绍中的应用强度沿[设置呈现](settings-and-observation.md#overview品牌与阅读构图)。

Space 小图形以横向并排工作面和分隔表达空间组织，保持开放、低宽的整体关系，避免竖向圆拱与独立底座组合产生墓碑联想。Survey 小图形以浏览框与探查镜表达浏览和探索，须与 Recall 书册及单纯 Browser 窗口可辨；小尺寸优先用途辨认，不机械复刻立体造物的切面。大插画仍保持已确认的同族材质与物件设计。Space、Focus、Goals、Survey、Recall 共享画框与笔重，并按实际导航尺寸校准光学中心和视觉面积。

Survey 与 Recall 的对象符号延续 Space／Focus 同族的石墨金属、Mint 透光体与暖金细边。Survey 采用探索棱镜，前后错开的斜切光学面与一体石墨承托构成有方向的开放轮廓；Recall 采用一体折页，两个清楚的 Mint 页面嵌入从封面延续到中央折脊的石墨壳体，形成简洁的展开书形。概念呈现保留既有深色场景、受控暖光与造物质感；正式素材与小图形沿同一结构提炼，不将整体换成浅底、银灰硬件产品照，也不重新引入古典罗盘指针、刻度、扇形叠页或卷曲书签。完成度来自可辨的专属轮廓、协调的比例、完整的部件连接、统一的曲率与边缘，以及各自明确的材质反射；不以通用图标挤出后镀金、全轮廓发光或重复噪纹代替造型设计。概念造型及小尺寸图形须分别判断，设置应用仍遵循原紧凑介绍与真实配置主体。

## IP 形象

- **龙**是品牌主体，出现在 App 图标和大图里。
- **通用 Agent** 用规整圆角的小方脸，与 Mote 共用实心剪影和双眼留白的角色语言；不加嘴线、天线或耳片。对象、工具入口、Space 装饰与对话角色的默认图形及内置主题保持同族，在 12–16px 和深浅主题中清楚可辨；保持静止，不以表情表达状态。Mote 保留自己的非对称轮廓；人的图形、Provider 标志及用户已保存头像和主题自定义继续由原 owner 决定。
- **Mote** 是持久的伙伴人格。它的默认身份图形与装饰徽标归[《Mote 默认身份与装饰徽标》](shared-rules.md#mote-默认身份与装饰徽标)，随主题着色。
- **Mote 主对话角色**的图标提炼参考 Goal 小人的一体流线头壳及上扬与横向延展的双角，保持与原角色的连续识别；眼形以圆润、向右的神态精修，不将参考插画的细眼缝固定为唯一几何。双角的延伸和收尖方向随头部朝向共同改变，眼睛、头壳与双角形成一致的右向姿态。角色图标按脸部主体比较视觉体量，角向外延伸，不以包含角的整体外接框挤小主体；主体不能因为角色区分而比普通 Mote 更小。具体绘图与默认采用沿原语义目录和真实消费者确认，角色标记不授予 Goal 或其他控制资格。
- **Mote 头像系列**是 Mote 自己的多元宇宙：同一个 Mote 的多种美术方向，加上低多边形伙伴（龙、狼、鸮、豹）；随包系列位于 `apps/desktop/resources/avatar-series/`。头像归 Mote 头像的 owner，按[头像行为合同](../behavior/motes-and-coordination.md#mote-头像与主-mote)保存，不并入五境，也不随 App 图标切换。

## 不归品牌管的标志

各家 Agent Provider 与渠道（Lark、Discord 等）的标志属于各自厂商，原样呈现，从不按品牌重绘或换色。项目图标、Space 外观与用户头像归各自的身份 owner，App 图标切换不改变它们。

## 品牌可以出现的位置

| 位置 | 内容 |
| --- | --- |
| Dock、窗口图标、欢迎与设置标识、新 bot 头像、手机接入页 | 所在境的 App 图标；新 bot 头像在创建时定下，之后不随图标变化 |
| 应用启动 | 所在境的启动大图与题款；构图与动效归[《启动与恢复的分量分开》](session-recovery.md#启动与恢复的分量分开) |
| Launcher 背景 | 所在境的宽幅大图，不加题款；密度归[《初始 Launcher 的现代工作台密度》](spaces-and-layout.md#初始-launcher-的现代工作台密度) |
| Settings 概览 | 所在境的宽幅大图与题款；构图归[《Overview、品牌与阅读构图》](settings-and-observation.md#overview品牌与阅读构图) |
| Browser 起始页 | 从龙的上扬尖角与折脊抽象出的光褶，随主题着色，不属于任何一个境 |
| 工作面、终端、列表与编辑区 | 不放品牌主体，以文字与语义控件为主 |

## App 图标的轮廓与选择

- macOS Dock 与包图标由构建层输出带透明留白的圆角轮廓，视觉体量与相邻标准 App 图标协调；界面和 iOS 资源按各自宿主呈现，不复用 Dock 专有的留白。
- Classic 保留原低多边形龙，配克制的复古未来感圆角底板；底板是该款共享品牌资源的组成部分。
- 设置中的各款图标用完整预览、名称与非颜色的选中标记表达，尺寸与留白保持同级，深浅主题及窄面都可辨。

## 色彩角色

界面沿 Graphite／Mint。Mint 只表示焦点、状态和唯一主操作，从不用作境的装饰。境的配色只存在于各自的画里，不改写界面 token、主题或语义图标。

## 新增或替换

- 新增一个境：先有它的 App 图标；它的大图可以晚于图标交付，交付前借原境的画是正当状态。新图标若不带自己的大图母版，优先归入已有的境，不轻易开新境。
- 补一个境的大图：一份母版，按启动 16:9 和宽幅两种裁切交付。龙放在右侧，左侧留给文字。在深浅主题下都要和界面的覆盖渐变协调，并经过独立看图评审。
- 每个文件、境与来源都登记在品牌清单，工作台的「品牌」视图从同一份清单和产品自己的解析函数呈现全部素材，具体步骤见[品牌素材指南](../../guides/brand-assets.md)。
