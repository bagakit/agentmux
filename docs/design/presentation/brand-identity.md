# 品牌架构

本页定义 AgentMux 品牌的整体结构：主标志、境、共用工坊、IP 形象、品牌可以出现的位置，以及哪些标志不归品牌管。具体素材怎样增改与派生，见[品牌素材指南](../../guides/brand-assets.md)。App 图标怎样选择与保存，归行为合同[《主题编辑与文件交换》](../behavior/settings-and-observation.md#主题编辑与文件交换)。

## 一条龙，五个境

品牌的主体是同一条中国龙：长吻、眉骨、分叉角。境（realm）是一种渲染语言，决定龙用什么材质、构法和光来画，不改变龙本身，也不改变 Mote、工作界面或任何运行事实。

每个 App 图标是龙在一个境里的肖像，选图标就是选自己的境：

| 境 | App 图标 | 材质 |
| --- | --- | --- |
| 原境 · ORIGIN | Classic | 发光的翡翠低多边形龙，石墨面板与 Mint 电路线；所有境的祖先 |
| 青篆 · QINGZHUAN（默认） | 青篆 | 象牙底上的森林绿木刻侧像 |
| 回环 · HUIHUAN | 回环 | 墨绿底上盘成玉璧的长龙 |
| 折玉 · ZHEYU | 折玉 | 平面玉片折成的正面龙首 |
| 灵伴 · LINGBAN | 灵伴 | 复古未来陶瓷伙伴头像，石墨面罩与 Mint 双眼 |

用户已保存的 App 图标是唯一的品牌选择，不再另设「境」的设置。品牌调整不会改写用户的保存值。原境是唯一保证画齐所有大图的境。

## 混用规则

角色可以跨境，但同一帧里不混风格。每张画只属于一个境。

- **大图**（启动、Launcher 背景、Settings 概览条）显示用户所在境的画。这个境还没有自己的画时，显示原境的画。原境是其他境的祖先，所以借来的画读作「祖先的画挂在你家里」，是有意的组合，不是不一致。
- **题款**写在启动和 Settings 概览条的画角上，内容只描述这张画属于哪个境（如「原境 · ORIGIN」），不描述用户的选择。所以题款永远为真，包括选择未知时。题款是静态装饰：次级文字色，从不用 Mint，不可交互，不随指针视差移动，窄面隐藏。Launcher 是工作入口，不加题款。
- 保存值本客户端不认识，或首帧拿不到观察结果时，显示原境的画和原境题款，不对用户所在的境下任何结论，也不回写或记住一个选择。
- 首帧就要正确：启动面在配置载入前绘制，境从同步主题快照里读取，首帧之后不换图，也不预载其他境的画。

## 共用工坊

Goals 行动与澄清插画、设置概念场景、Topic 晋升场景和 Mote 起源故事板，描绘的是所有境的 Agent 与 Mote 相遇工作的地方。这一层叫工坊（commons），属于所有境，不随 App 图标切换，也不加题款。工坊插画沿[共同美术语言](shared-rules.md#ui-现代化的独立评估边界)：复古未来的铬金属与青铜造物、石墨底与玉色玻璃。

## IP 形象

- **龙**是品牌主体，出现在 App 图标和大图里。
- **Mote** 是持久的伙伴人格。它的默认身份图形与装饰徽标归[《Mote 默认身份与装饰徽标》](shared-rules.md#mote-默认身份与装饰徽标)，随主题着色。
- **Mote 头像系列**是 Mote 自己的多元宇宙：同一个 Mote 的十二种美术方向，加上低多边形伙伴（龙、狼、鸮、豹）。头像归 Mote 头像的 owner，按[头像行为合同](../behavior/motes-and-coordination.md#mote-头像与主-mote)保存，不并入五境，也不随 App 图标切换。

## 不归品牌管的标志

各家 Agent Provider 与渠道（Lark、Discord 等）的标志属于各自厂商，原样呈现，从不按品牌重绘或换色。项目图标、Space 外观与用户头像归各自的身份 owner，App 图标切换不改变它们。

## 品牌可以出现的位置

| 位置 | 内容 |
| --- | --- |
| Dock、窗口图标、欢迎与设置标识、新 bot 头像、手机接入页 | 所在境的 App 图标；新 bot 头像在创建时定下，之后不随图标变化 |
| 应用启动 | 所在境的启动大图与题款；构图与动效归[《启动与恢复的分量分开》](session-recovery.md#启动与恢复的分量分开) |
| Launcher 背景 | 所在境的宽幅大图，不加题款；密度归[《初始 Launcher 的现代工作台密度》](spaces-and-layout.md#初始-launcher-的现代工作台密度) |
| Settings 概览 | 所在境的宽幅大图与题款；构图归[《Overview、品牌与阅读构图》](settings-and-observation.md#overview品牌与阅读构图) |
| Browser 起始页 | 从龙的上扬尖角与折脊抽象出的光褶，随主题着色，不属于任何一个境 |
| 工作面、终端、列表与编辑区 | 不放品牌主体，以文字与语义控件为主 |

## 色彩角色

界面沿 Graphite／Mint。Mint 只表示焦点、状态和唯一主操作，从不用作境的装饰。境的配色只存在于各自的画里，不改写界面 token、主题或语义图标。

## 新增或替换

- 新增一个境：先有它的 App 图标；它的大图可以晚于图标交付，交付前借原境的画是正当状态。新图标若不带自己的大图母版，优先归入已有的境，不轻易开新境。
- 补一个境的大图：一份母版，按启动 16:9 和宽幅两种裁切交付。龙放在右侧，左侧留给文字。在深浅主题下都要和界面的覆盖渐变协调，并经过独立看图评审。
- 每个文件、境与来源都登记在品牌清单，工作台的「品牌」视图从同一份清单和产品自己的解析函数呈现全部素材，具体步骤见[品牌素材指南](../../guides/brand-assets.md)。
