本页定义手机特有的尺度、布局和呈现适配；共享专题继续持有对象身份、输入、权限、读取与恢复合同。共享专题中的 Desktop 几何与类名不直接套到手机，本页未另作适配的共同要求继续有效；手机呈现不能改变原业务资格或事实 owner。

手机样式由 `apps/mobile/src` 持有。修改 `packages/client-ui` 的共享组件或默认样式会同时影响 Desktop，须核对真实 Desktop 消费者；只为手机调整时，使用手机作用域选择器或具名呈现参数。首屏外壳、连接页、底部面板与新建 Agent 所需样式必须随首屏可用，不能只放在延迟加载的工作面样式中。

## 产品标准

手机是 AgentMux 的第一方 client，目标是达到成熟手机对话与协作应用的完成度：安静、紧凑、即时响应、一眼看懂。判断画面时依次核对：

1. **主次可辨。** 正文、当前对象和主动作先被看到；技术身份与诊断按需展开。
2. **没有无信息元素。** 已确认的正常状态不常驻说明，没有数据不铺空表，同一事实在同一屏只作一处主要说明。
3. **几何干净。** 对齐、留白和字号来自同一刻度；用填充、明度与字重表达层级，避免逐项描边、大卡片和重复容器。
4. **触屏可用。** 点击范围、按压反馈与键盘焦点清楚，不被软键盘、安全区或浮层遮挡。
5. **状态诚实。** 故障与未知持续可发现、可展开、可恢复；不把未知画成成功，不以界面美化拿走健康能力。

“同一屏”指同一时刻可见的画面。底部面板或侧边菜单与其下方可见的工作面各算一屏；不同面板可以各有同一事实的入口，但每屏只有一处主要说明，其余提供跳转。

## 尺度与 token

手机尺度由 `apps/mobile/src/mobile.css` 的根变量持有，按触屏阅读任务与 Desktop [字号阶梯](shared-rules.md#字号阶梯)区分。颜色、表面、高光、阴影与可配置外观沿[共享主题](shared-rules.md#主题与样式-ssot-规范)，保留字体、圆角及语义图标选择，不为手机另造偏色材质或用固定绘制值盖过用户配置。手机动效 token 由手机根样式定义。

| 用途 | 手机尺度 | 变量 |
| --- | --- | --- |
| 页面与对话顶栏标题 | 17px，字重 600 | `--fs-title` |
| 正文、列表名称、按钮 | 13px | `--fs-body` |
| 元信息、次级说明、分组标题 | 11px | `--fs-meta` |
| 底栏标签、角标、计数 | 10px，字号下限 | `--fs-micro` |
| 可编辑字段 | 16px，避免 iOS 聚焦缩放 | 保持编辑尺度 |
| 内容左右留白 | 12px | `--sp-5` |
| 间距 | 2 / 4 / 6 / 8 / 12 / 16 / 24 / 32px | `--sp-1` … `--sp-8` |
| 控件绘制面／最小命中范围 | 32px／44px | `--mobile-control-surface`／触控几何 |
| 图标动作绘制 | 16–18px | 随语义图标槽位 |
| 圆角 | 6 / 9 / 12px | `--radius-sm` / `--radius` / `--radius-lg` |
| 按压、着色 | 120ms | `--dur-fast` |
| 面板、菜单入场 | 200ms / cubic-bezier(.16, 1, .3, 1) | `--dur-enter` / `--ease-enter` |
| 最窄布局验收 | 320px | 不整体缩放 |

新样式引用对应变量，不另写字号档位或字面时长；安全区、命中范围与专用绘制几何可使用字面值。等宽 ID、路径随所在位置取字号并配 `--font-mono`，不另设一档。

视觉尺寸与命中范围分开，完整触摸范围不等于大片实心底板，也不放大头像和图标。紧凑感来自一致比例与克制表面，不靠整体缩放、缩小编辑字或删掉动作。窄、矮视口下，长名称、菜单、未确认请求和软键盘仍保留编辑器与关键操作；安全区、键盘收起底栏和滚动沿既有 viewport owner。

## 控件语言

手机复用 `Button`、`IconButton` 等共同原生控件的具名、焦点、按压及禁用语义，在手机样式边界适配几何，不另造按钮状态或操作资格。档位含义与[共同控件语言](shared-rules.md#控件语言)一致；下表的手机类不替代 Desktop 的落地类。

| 档位 | 手机呈现与入口 | 用途 |
| --- | --- | --- |
| Primary | 实心品牌绿、深色文字、顶部高光；`.mobile-primary` 或共享 `Button variant="primary"` | 一屏唯一的主要决定 |
| Secondary | Surface 填充、软高光、无常驻描边；`.mobile-secondary` 仅用于面板或整行次级确认，行内用共享 `Button` 或现有工具行样式，保持 13px 正文字号 | 次级确认与行内动作 |
| Ghost / Icon | 透明底，按压出现 Surface；`IconButton` + `.mobile-icon-button` | 页头、工具栏、行尾动作 |
| 文字动作 | 品牌绿文字，无底无框；`.mobile-text-button` | 短恢复动作、详情与跳转 |
| Danger | 实心红色变体；共享 `Button variant="danger"` | 删除、撤销等破坏性主操作 |

- 主次由当前任务决定，同一组同类动作使用同一档位；不能把每个动作都画成 Primary。状态色与主动作颜色各自表达语义。
- 描边不作主要层级手段，只用于输入聚焦、键盘焦点及需要强调的危险或未知。不要用父级通配选择器给所有按钮套边框或覆盖共享反馈组件的排版。
- 当前选择用一个几何信号表达，可配字重或语义图标；不叠描边、左侧竖条、多重底色，也不用品牌绿表达“已展开”。
- 页头与工具栏优先用语义图标并保留可访问名称，图标说不清时才用短文字。键盘焦点使用 `--focus-line`；绘制面小于命中范围时，焦点边界贴齐可见面。
- 分组列表和表单用一块 `--surface-1` 或 `--surface-2`、`--radius-lg` 与高光承载，组内以轻分隔组织，组外无描边；导航行在尾部放 `navigation.submenu`。

## 文案

普通界面使用工作用语，技术详情保留准确原文：

| 普通界面避免 | 表达方式 |
| --- | --- |
| 泛用的“原”前缀，如“刷新原研究” | 同类对象唯一时直接写“刷新”“资料”“这个 Agent” |
| Host、Session、Run、PTY、operation、回执、unknown、观测、样本 | Mac、对话、终端、操作、确认、未确认、数据 |
| 英文异常、错误码、`undefined`、CLI 命令 | 一句中文说明发生了什么、仍能做什么；原文放入“技术信息” |
| UUID、hostId、executorId、绝对路径、内部枚举 | 可读产品或对象名称；准确身份在详情中可读、可复制 |
| “原展示位置已确认”等正常状态说明 | 不常驻显示 |

- 同一台电脑统一叫 Mac，同一动作在全应用使用同一说法。返回指明目的地；退出编辑用“完成”或“取消”。需要区分版本时，明确写“这台手机上的草稿／Mac 上的版本”等具体对象。
- 可访问名称、提示和反馈与可见控件用语一致；技术详情中的配置名、身份和诊断全文不因改文案而丢失。字段缺失写“未记录”。
- Goal 状态与检查结果使用同一词表；Agent 自报只写“Agent 报告已达成”，人接受后才写“已验收”。共享控件的手机界面文案使用中文。
- 中文与英文、数字之间留空格，中文句内不插半角空格；完整句子在一处生成，不拼接半句。
- 时间按距离呈现：今天显示时分，今年显示月日，更早带年份，不带秒。缺失、无效或明显不可能的时间不显示具体值。

## 状态、提醒与未知

| 事实 | 默认呈现 |
| --- | --- |
| 已确认正常 | 不常驻说明；必要时只用状态图形 |
| 在途、等待 | 就地短说明或行内忙碌图标 |
| 故障、未知 | 一行摘要、展开和收起入口；详情依次为说明、恢复动作、技术信息 |

- 普通 Agent 列表和 Mote 成员中的「运行状态未确认」默认不常驻文字或状态图形，例如仅缺少当前 Run 观察的条目。原会话、名称、位置与操作继续保留；从既有更多操作或成员详情查看未确认说明、原状态及刷新／恢复入口。错误、实际待答复、权限请求仍就地可见；显示取舍消费原类型化事实，不匹配状态文案，也不把未确认改判为正常或已停止。
- 摘要先说明哪里未确认、仍可使用什么，例如“自动任务未确认暂停 · 你可以继续输入”。完整失败步骤、观察范围、错误及准确恢复路径在同一提醒内可读，不把操作 ID 或命令放进摘要，也不把成功反馈和普通工作状态画成故障。
- 所有 warning 提醒都能收起，并从菜单固定的“提醒与诊断”恢复原说明及恢复动作。收起只改变本设备呈现，不确认结果、不删除原意图或草稿。
- 同一连接或目录观察事实只作一处主要说明，贴近受影响对象；不在标题、正文和输入区重复铺告示。连接中断与消息是否送达是不同事实，分别保留准确状态、原请求与恢复入口，不能合并成一个业务结果。
- 目录读取问题收进当前页头的紧凑、具名状态入口，可带问题数量；默认不另占整行横条或全局底部告示。展开后先显示受影响对象、原因及「刷新」等具体处理，再提供准确身份和技术详情；入口保留完整触控命中范围，不能只靠小图标或 tooltip。仅属于已离开对话的元信息问题不常驻无关目录，原说明仍沿「提醒与诊断」和对应对象可达。
- 输入下方的提醒总量须有界，短屏仍能阅读正文、编辑草稿和触达关键操作；并存的状态、完整原因及恢复动作全部可到达，不通过删状态或改变业务判断来压低输入区。展开详情时先出现解释与动作，不重复铺出编辑器里已有的草稿。
- 没有数据的读数折为一行，有数据才展开表格；未知与数值可辨，不补零、不推算。
- 外观读取失败保留共享的默认身份图形与未确认标记，不显示空白方块或另造同义身份。多个对象的同类失败合成一条摘要；小标记不能成为触屏上读取原因的唯一入口，须有完整触控目标展开原因并重读各原对象。
- 加载占位按将出现的标题、列表画骨架，同时保留 `role="status"` 文本。底部面板已有关闭时，加载占位不再放第二个返回；空状态用语义图标、短说明和至多一个次级动作。

## 动效与按压反馈

动效说明出现、展开、切换或按压，不延后动作，不冒充加载完成，也不是状态的唯一载体。节奏引用手机 token，尊重 `prefers-reduced-motion: reduce`；减弱动态时可直接切换。

- 底部面板打开时从底部上移并淡入，背景同步淡入。关闭立即撤销呈现与输入占用并恢复焦点，不等待装饰动画。
- 位移使用独立的 `translate`，不覆盖定位用的 `transform` 和 `bottom`；受管节点入场动画限定在 `[data-state='open']`。动效是否播放与成本须由[真实渲染证据](../../testing/strategy.md#动态视觉的浏览器成本验证)核对。
- 侧边菜单作为覆盖层从左侧滑入，背景淡入，不整体平移或缩放应用外壳。
- 行、图标按钮、底栏和 Mote 选择按下即时出现 Surface，抬起按 token 褪去；hover 不能是触屏唯一反馈。展开箭头与内容同步，不给大块内容做高度动画。
- 刷新图标只在主动刷新或首次读取时旋转，后台定时读取不持续干扰画面。

## 页头、返回与底栏

- 工作面只有一层紧凑页头：返回或页面名在左，当前对象名称使用中间可伸缩标题槽，沿阅读起始边对齐，图标动作组贴齐内容右缘，控件垂直居中。下钻时标题是当前目标、Topic 或研究，不重复目录名。
- 非顶层工作面在当前上下文直接提供返回，说明目的地或来源，与辅助菜单分开。正文不再放第二个返回；Topics 在树内展开分类只使用展开标记。
- 五个主入口等宽、图标槽位与标签基线一致，Mote 居中作身份锚点，不做浮起的新建按钮。当前入口以轻量完整表面配字重或图标强调，并保留可访问的当前页面事实；不能只给小图标加底色。
- 菜单与主入口分开，辅助能力经菜单揭示；切换与收起不卸载原工作面，不重复创建阅读实例或订阅。

## 对话

- 正文和输入是主面，身份、返回与常用工具只占一层顶栏。内容不足一屏时靠近输入区，超出后保持原连续阅读行为。减少重复品牌、标题、身份与无信息留白，不缩小编辑字、不遮正文或折断工具。
- 顶栏常驻终端切换，明确查看终端或返回对话。Goal 与 History 靠近终端、更多动作，默认无底板、边框或阴影，不新增工具行，正文和输入保持完整宽度。窄屏可收回返回文字，当前名称仍可辨；极窄或原生头部可在既有高度内用两行，完整名称和项目按需可读。
- Commands 在默认紧凑工具栏直接可达，不要求先发现展开开关；附件与工具开关同排可用。输入布局沿 [Composer 密度](conversation-input.md#composer-状态与队列密度)，可发送时发送键用 Primary，空草稿退为低对比填充。
- 消息身份、时间、复制与详情沿[共同阅读密度](conversation-mode.md#共同阅读密度)。普通来源徽标可进消息详情；作者、投递、操作和关联来源未读提示仍在原上下文可见，收起不改变消息关系、投递资格或读取事实。阅读范围只有缺口或未知才单列，普通历史范围与“更早消息”一起呈现。
- 正文、交互请求、投递反馈和输入区形成连续信息流。投递说明只在等待、停止、未接纳、未知或失败时显示紧凑摘要；收起后保留状态及通信记录入口，不把已确认输入常驻成故障卡，也不在共享 `MessageDeliveryFailure` 外再堆第二份原消息折叠。
- 同一答复的状态和查询只保留一处：问题卡在时就地说明，卡退出后仍可查询原操作；重挂不另建答复或覆盖草稿。
- 原生包装的撰写入口在当前对话动作面板中，不另占常驻顶栏。面板有明确关闭，焦点回到触发图标；图标避开安全区、键盘及其他操作。打开与收起不增加历史读页、重复订阅或复制历史实例。

## 目录：Focus、Space、Topics、Survey

- Focus 沿原项目与 Topic／Mote 对象分组及工作优先次序，让待回应、执行中和近期工作先被看到，较早与未确认项低强调但仍可展开；组内按待回应、执行、结果与闲置／待恢复组织，未知清楚可辨。名称是扫描主轨，recap 是次级信息，状态与尾部动作靠右；完成状态有清楚图标与文字，不能只靠弱颜色。长状态保留完整读取入口，不挤掉名称或撑大行高。准确归属、活动排序和阅读保护归[行为 owner](../behavior/public-control.md#手机对象身份与工作面)，不以隐藏旧对象或裁掉身份换取首屏整洁。
- 项目与对象外观、Provider 和状态图形复用共同身份，不另造同义图标、首字母替身或状态词表。Provider 等次要信息用可读产品名称，放入次级行或更多菜单。
- Topics 分类与子项、Space 项目与后代共用连续树行。层级用缩进和明确展开控件，当前行、展开、按压与键盘焦点分别可辨；保留完整可访问名及 `aria-expanded`，无子项不留空箭头槽。名称和详情可完整披露，“更多”不拆成单字换行，不照搬 Desktop 三栏宽度。
- 页头、搜索和尾部动作对齐。搜索用放大镜与轻填充字段，回车搜索；刷新、新建在页头动作组。分组标题用元信息档位并带计数，不用 hostId、UUID 或绝对路径作标题；单机不额外分主机组，文件夹分组写“文件夹”，同名需区分时才按需披露路径。
- Agent、文件、Browser、Launcher 资源沿各层固定左缘排列，尾部动作靠右，不居中正文或以大片左空白分配行宽。单 Region Tab 直接显示内容名与动作，不重复技术占位标题；多 Region 保留分组，有效 Tab 名与内容名不同时可按需保留。
- 标题省略只改变呈现，准确 Tab／Region tuple、来源、导航与创建目标仍完整。Launcher 同行提供具名“创建 Agent”动作，不能以静态不可用说明代替健康能力；Survey、Goal 关联 Agent 与 Focus 使用相同的行结构。无关联内容不另起空标题块。

层级、身份与授权沿[手机对象身份与工作面](../behavior/public-control.md#手机对象身份与工作面)，共同对象语言见[对象树与知识层级](spaces-and-layout.md#对象树与知识层级)。

## Mote、Profile 与 Goals

- Mote 对话是日常工作中心。顶部头像直接打开 Profile，并显示当前 Mote 名称；结果、终端和对话动作在同一上下文就近可达，不靠头像猜对象。
- Mote 以紧凑横向头像与名称条切换，当前项清楚选中；Profile 是直接入口，不嵌进树子行。日常选择 Mote 先进入主对话，Threads 提供原工作查找与原成员入口，未配置主 Agent 时保就近建立／设置入口；横排不另造空间层级，窄屏保留完整名称披露。主 Agent 的真实状态、打开、设置和未知来源沿行为合同，不用呈现代签恢复完成。
- 自定义头像的绘制与动画图层随槽位等比缩放，在 Safari 及支持浏览器不溢出邻行；保留配色、部件、表情、动态与减弱动态偏好，不用裁切或替换掩盖缩放问题。
- Profile 将当前工作、资料与相关对象分层，身份与进展不重复堆入标题。资料行以合作方式、自我设定等可读标签为主，路径和技术身份按需展开；执行器用产品名称，刷新用图标，不常驻资料来源说明。读原文时返回、标题、刷新、编辑共用一行页头。
- Goals 页头显示目标名和紧凑元信息，刷新使用具名图标动作。正文、成功标准、结果、证据、差距与未知清楚可读；工作属性、活动、决策、协作及高级动作按需展开。工作状态与 Agent 报告不代替人验收。
- 主决定按已确认阶段表达：范围待确认时突出“确认当前目标”，结果可接受时突出“接受并结束目标”；其他动作沿共同控件档位。证据用文件行呈现名称、来源与尾部复制，不将说明和按钮挤成一串。
- 对话目标页已有结果时先呈现成果与验收，再呈现持续推进；未开始的持续推进收为一行，展开再填写间隔。

## 底部面板、菜单与表单

- 标题和关闭吸顶，内容在有界区域滚动；面板用填充、阴影与顶部高光分层，不画外圈描边。关闭后焦点回到原控件，打开不重排或重读无关目录。
- Agent 行的更多图标与长按打开同一底部菜单，不挤断名称或把整行变为操作栏。一级面板提供紧凑身份、常用读数和短操作组，不先藏入二级或铺空表、长说明。
- 用量按会话累计、最近回复和上下文分清层级。先显示已有读数与明确读取状态，远端结果只更新对应读数，不延后面板显露或反复移动动作；未知与数值的呈现沿[状态规则](#状态提醒与未知)。
- 动作行使用分组填充面、图标和名称，相同图标不表示不同动作。表单标签、值与选择入口对齐，整行提供原生选择命中区，文本输入沿编辑尺度；字段不同时堆填充和描边，主提交贴近表单末尾。
- 上次 Agent 创建尚未确认时，原操作摘要与核对动作先于新建表单，核对是主动作，继续原创建与另建保留为可辨的次动作；不以主次调整代签回执或禁用另建能力。原位置与操作详情按需展开，窄屏下关键恢复动作仍可完整触达。

## 终端

终端把空间留给原输出，观看与控制方式清楚可辨，模式与长说明归信息入口。阅读比例、复制与刷新共享紧凑动作组，默认使用“只读查看 · 终端大小跟随 Mac”等工作用语。

本地缩放和触摸滚动可发现且不中断历史；本地阅读比例不改变原 Run 网格，与改变 Mac 终端网格的控制明确分开，当前值、焦点、未知说明和恢复动作保持可达。呈现沿[终端阅读](terminal-reading.md#terminal-信息与恢复画面的视觉品质)，连续阅读及成本验收沿[行为 owner](../behavior/terminal-reading.md#terminal-连续向上阅读历史)。

## 连接、设备与网页更新

- 未连接且无保留工作面时，接入页显示龙品牌图、简短说明与连接详情；连通后不常驻品牌和教程，连接及默认主页设置归菜单。
- 已确认新版本时，在当前工作面主动显示轻量可关闭提示和明确更新入口，不遮对话、输入或必要动作。菜单固定“提醒与诊断”紧凑呈现当前网页、Mac 提供与待载入状态；设备、页面、构建和操作详情按需展开。不可达、未上报和旧观察明确可辨，原因与查询路径仍可到达。
- 更新受内容保留约束时，就地说明待载入，并保留返回、收起与继续使用；不强制清空编辑器、附件或未知请求。行为与权限归[手机网页诊断与更新](../behavior/public-control.md#手机网页诊断与更新)，Mac 设置与 Toolkit 呈现见[手机连接与设备活动](settings-and-observation.md#手机连接与设备活动)。
- 有限 Goal 操作在途或结果未知时，“提醒与诊断”显示准确目标、动作与未确认状态，完整 Host、操作和请求可展开、复制。目标已删除或暂不可读，记录仍在；关闭不移除记录、不冒充确认，也不影响其他健康操作。
- 未确认持久的请求可复制完整原请求与已知状态；仅复制成功后，才提供确认已另存并移除本页副本的出口。原记录不可读或身份冲突时明确未知，须核对原确认结果；该选择不写、不删除设备记录，不代表存储恢复、目标改变或原操作完成、重发与确认。
- 请求已写入而收到的确认尚未保存时，说明原记录保留、需恢复设备存储并重试保存；留页期间迟到确认仍须重新显示并保留。

## 验收：采图与看图

1. **实际操作与采图。** 从仓库根运行 `node apps/mobile/scripts/fixtures/mobile-product-redesign/capture-ui.mjs`，通过受控 Chromium 操作真实 `MobileApp`；尺寸、深浅主题、专项参数和模拟边界见 [scenario.md](../../../apps/mobile/scripts/fixtures/mobile-product-redesign/scenario.md)。保留完整 PNG、`receipt.json`、`review.md` 与编译身份。选取实际受影响场景；共享选择器变化须覆盖其真实消费者，场景缺失则补齐，不以一次默认采图代替全部覆盖。
2. **独立看图。** 未参与该实现的 Agent 逐张打开完整截图，并结合切换、面板、输入和错误状态的操作顺序，判断主次、密度、对齐、遮挡与操作可达；结论写明具体位置和未确认范围，方法见[独立看图评审](../../guides/agent-visual-e2e-review.md)。
3. **修正与复拍。** 需要修改时复拍对应场景，直到明确可交付，保留旧图与旧意见。局部画面、CSS 在场或采图成功都不能代替全屏审美结论；动效沿[动态视觉验证](../../testing/strategy.md#动态视觉的浏览器成本验证)取得真实渲染证据。
4. **行为不退化。** 状态、提醒或动作的变更通过真实 `MobileApp` 消费者证明未知仍可见、恢复仍可达、触控与阅读空间保留；用实际加载的变异证明改坏会红。纯文档收敛核对来源、链接与语义，不虚构实现测试通过。

受控 Chromium 不等于真机。iOS／Android 输入法、系统键盘、安全区、前后台与 Safari 绘制需设备证据，交付说明明确已测与未测范围。手机共用原对话、输入与终端语言，连接或观察失败不得清空原身份、工作面、草稿与未知操作；准确能力和恢复判定仍由行为合同持有。
