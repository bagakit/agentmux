## 匿名 Browser 标识

Survey 创建菜单及 Browser More 的新匿名页动作使用原紧凑菜单语言，不增加常驻工具栏。匿名页面用清楚的文字／图标身份和就近简短说明表达临时网站数据，不只靠颜色；正常、窄 Pane 与恢复后的空白页均可辨。重启后原匿名位置明确提示临时数据已结束，地址输入和继续浏览仍可用。普通 Profile 控件不冒充匿名身份；模式、隔离、显式成果留存与生命周期只见[匿名 Browser](../behavior/browser-workface.md#匿名-browser)。

## Browser 空白起始页

- 空白起始页以配置的主标题、副标题与中央地址／搜索输入表达起点，沿原字体和主题 tokens，不固定应用品牌或 Survey 名称。可选图标未设置时不显示且不留空槽；已设置的图标保持克制，不与主标题争夺层级。顶部保留清楚可辨的地址输入框，空白页也能直接输入；中央入口作为更突出的起步动作，两者沿同一控件语言且不另加工具栏。普通已加载网页沿原地址工具栏和真实内容呈现；共享草稿、焦点、启用范围及配置行为只见[《Browser 空白起始页》](../behavior/browser-workface.md#browser-空白起始页)。
- 背景图作为起始页背景使用，文字、输入、历史卡片、焦点与操作仍有清楚对比和完整命中区；图像缺失或加载失败时原主题继续提供可读表面，不因等待图片让整页空白。背景不延伸覆盖已加载网页，不用背景或装饰层截走输入。
- 起始页的默认视觉互动采用具有 AgentMux 品牌辨识度的柔和极光：从品牌的上扬尖角、中央折脊与明暗光面抽象光褶，以少量预绘制光面分层合成，沿当前主题建立安静的空间感，不压过标题、输入和真实历史。指针带动可辨的前后层次与局部亮度反馈，形体和明暗共同建立辨识度；仅有通用光晕、细线或整层平移不等于视觉品质成立。运动平顺、低幅，指针停止后收束为安定画面；静态模式、减少动态效果和触控／键盘使用仍有完整而精致的起始页。背景层不新增教程、状态墙或额外工具栏，也不让文字与卡片随指针漂移；默认装饰沿原设置，仅作用 Browser 起始页，用户自选背景图与关闭效果的偏好优先。视觉效果、品牌辨识与良好渲染性能须同时成立，动态成本沿[共享渲染边界](shared-rules.md#动态视觉的渲染边界)核实，不以增加持续运动或渲染负担换取存在感。动态开关、停止条件与输入边界只见[同主题行为合同](../behavior/browser-workface.md#browser-空白起始页)。
- 自定义入口以小型、可辨的图标与文字安放在起始页边缘，正常、窄及短窗可见可操作，不与搜索提交或历史打开混淆。它定位原起始页设置，不在首页常驻展开一整套表单；主副标题、图像、历史显隐与首屏数量、交互效果沿原 Settings 的控件、草稿预览与保存语言呈现。数量控件清楚表达初始展示条数，历史关闭时仍保留已有数量偏好；预览内容与真实历史区别可辨。
- 启用历史时，中央输入下方用紧凑的相册式卡片呈现最近地址与搜索，与输入焦点时的建议列表层级分开。真实截图可用时作为卡片封面，保留清楚的上次查看标识；没有截图时使用域名／搜索类型、可识别字形与克制的主题色层次构成信息封面，避免整片同色大占位块。真实提交文本、可解析域名与提交时间仍可辨，长地址在层级内省略且完整内容可查看，未知标题或网站图标不补成事实。卡片不冒完整访问历史、收藏或当前打开页面；预览来源、记录与导航行为只引用上述交互合同。
- 起始页利用当前 Pane 的可读宽度与高度组织品牌、输入和历史区，宽窗可看到更多真实记录，不把全部内容锁在大面积空白中的窄小卡片组。卡片随宽度增加列数、窄分割收敛列数，保持清楚的文本层级、完整命中区与键盘焦点；hover／focus 给出一致且克制的打开反馈，动效尊重减少动态效果设置。有更多记录时提供就地继续展开与收起，内容超出时使用有界滚动，不堆成固定大卡墙或挤掉主标题、起步输入及 Browser 必要动作。关闭历史后收回这块面积；真正无记录时用轻量空状态，读取失败显示就地持续说明与紧凑 Retry，输入仍清楚可操作。不铺教程、步骤器或额外工具栏。

## Browser RSI 操作表面

- 地址／搜索建议在原 input 下方紧凑呈现，当前范围、加载／无结果及失败可辨；建议不占常驻页面高度、不遮住输入或把网页换成静态图。展开意图与自动聚焦的区别只引用[交互 SSOT](../behavior/browser-workface.md#browser-地址搜索输入历史与基础编辑)。真实 favicon 沿网页条目／图标 rail 共享同一克制尺寸和回落 glyph；列表开合沿[知识导航的共享动效](spaces-and-layout.md#survey-的-zone-工作面与液体玻璃)，原生页面与浮层按同一遮挡边界保持。
- 地址／搜索输入的历史建议沿原 input 下面的紧凑按需列表，复用 Graphite／Mint、现有字体、选中与焦点语言，不增加常驻历史栏、第二工具栏或成套线框；空白起始页的可选历史卡片唯一见[《Browser 空白起始页》](#browser-空白起始页)。地址／搜索词可辨，单条删除与清空当前范围可达，正常、234.5px 窄 Pane 与短窗不挤掉输入或覆盖 More／Close；列表关闭后原页面与草稿仍可用。复制／粘贴／剪切沿平台原生菜单，不画一组常驻按钮。人工意图、历史范围、隐私、恢复、IME、晚结果与编辑归属只引用交互 SSOT[《Browser 地址／搜索输入历史与基础编辑》](../behavior/browser-workface.md#browser-地址搜索输入历史与基础编辑)。
- Browser 操作状态与详情的控件语言统一见[《Browser 任务工具与证据的紧凑呈现》](#browser-任务工具与证据的紧凑呈现)，本节不另定义常驻状态条。
- 本地书签保存／源码动作沿现 Browser 紧凑工具栏与 hover 提示语言；恢复后的可用与禁用表达、格式、读取和保存边界只引用交互 SSOT[《书签文件（.webloc / .url，）》](../behavior/files-and-git.md#书签文件webloc--url)，不增加重复卡片或警告层。
- Agent 的后台 Browser 活动沿原 Tab／Browser 就地符号可辨，不通过选中 sidebar、切 Tab、闪烁或新增常驻栏索取注意与焦点；行为只见交互 SSOT[《Browser 工作面》](../behavior/browser-workface.md#browser-工作面-1)的 CLI 优先与保用户焦点约束，页面动效沿本节既有约束。
- 操作条上的 Agent 身份取自那个 Session 的真实事实（它自己的名字与 Provider），不得由 Session id 拼出一个名字。解析不到时显示 id 本身并让 Provider 图标缺席：一个显示 id 的操作条会让人去查这是谁，一个显示「Agent 7f3a9c2e」的操作条会让人以为那就是它的名字。
- Agent 接管和交还使用同一条身份语言：驱动时显示头像与“正在操作”，人接管后变成安静的确认态并保留最后一步；不靠颜色或呼吸动画表达唯一事实。
- 当前操作位置保留语义目标标记（ref、role、可访问名或页面内目标框）；有真实位置事实时同时显示轻巧、可辨且区别于人的系统鼠标的虚拟指针，旁边显示真实操作者头像、标题／名称与简短动作。标签避让页面边缘和当前目标，未知身份、头像回落与位置真实性只引用交互合同；不显示猜测坐标或用装饰中心点充数。目标、当前位置与当前动作可读，不靠颜色承担唯一事实。
- Browser 当前控制边界由固定、向内的 1px 清晰细边与原网页内快速衰减的柔光共同表达。内置原生页面的细边沿原宿主输入隔离层绘制，不依赖网页 DOM，不参与背景混合或呼吸／脉冲动画；被动镜像在原 Stage 的实际页面范围呈现同一细边。网页柔光继续保留颜色、叠加、动画与宽度偏好，细边复用同一颜色和透明度；现有 Highlight page edges 关闭时两者均隐藏，chrome 身份、控制状态和显式接管仍可达，不增配置。默认静态、克制，不绘制粗重设备壳、整页蒙色、绕圈跑马灯或额外工具栏。启用时，活动程序内等待、导航和内容替换不丢当前边界，也不将等待画成点击；真实动作可有一次低幅局部强调，不刻意 hold 原动作。正常、窄、短窗口、缩放与嵌入 frame 后，细边对准原生内容或镜像中实际页面范围，保留中央阅读面积；减少动态效果时细边静止，移除柔光动画与指针位移／脉冲，真实目标和文字状态保持。装饰不增加命中区，不替代原输入隔离；控制寿命、失败与健康能力保留只引用[交互合同](../behavior/browser-workface.md#agent-操作可见性与输入隔离)。
- **虚拟指针移动。** 两个真实位置间采用短促、平顺收束的 tween，实际看见中间过程，不能瞬移、只显终点、靠参数存在或为截图 hold 原动作。头像与动作标签随指针协同位移并沿页面边缘避让，不能让箭头还在途中而身份标签先跳到终点；hover 的局部浮动仍只作用于箭头。连续新目标从当时实际呈现位置续接，不回跳起点、不排队追赶、不叠 ghost；不加轨迹线、放大、弹跳或新控件。完成通知不重新播放位移或延长提示。
- **hover 与减少动态效果。** 箭头可小幅慢浮动，标签与语义目标 anchor 保持稳定，文字、页面阅读和输入不受影响；浮动不冒 busy，不增加常驻循环，原提示结束或清除即停止。减少动态效果下，tween 与浮动全部静止，保留真实静态终点。位置真实性、同 document／导航续接、历史失效、owner、人工优先和非阻断只引用交互 SSOT[《Browser 工作面》](../behavior/browser-workface.md#browser-工作面-1)的指针与执行反馈约束。
- **按键与执行器符号。** 非敏感实际命名键的就地键帽／通用按键图标，以及小型脚本执行器符号，沿原 Graphite／Mint 语言，紧凑、轻巧；动效限局部 transform／opacity。执行循环随真实执行结束或人工接管立即停，减少动态效果时符号全静止，状态仍可辨。不增加标签重复、长期背景运动或 toolbar；内容边界只沿上文同一内发光表达。真实性、秘密排除和非阻断只引用交互 SSOT[《Browser 工作面》](../behavior/browser-workface.md#browser-工作面-1)的按键与脚本反馈约束。
- Browser 的 `elementContext` 结果沿既有 Browser/Composer 语汇呈现：结构化字段使用紧凑的可复制文本块，错误靠近当前 Browser 工作面显示并保留下一步动作；不新增常驻 DOM 检查面、不把原始 HTML 直接铺在页面上，也不以颜色单独表达授权或失败。
- Browser timeline 与聊天 timeline 共用 20px 节点槽、时间 ruler、状态 glyph 和折叠规则；连续的低价值 CDP/等待步骤可合并，但脚本、用户接管、权限等待、失败和不确定结果始终可见。
- 回放入口显示“预览 / 单步 / 运行”三档动作和停止按钮。回放脚本的来源、页面身份和人工闸门在入口附近可见，避免把一次重放误认为普通刷新。
- 历史入口与操作条同层可达，不要求先发生新操作。历史列表使用有限高度的独立滚动区，短窗打开轨迹时仍能直接看见所选操作的阶段与当前步骤；旧 completed 记录不能占满首屏，阅读历史不因新步骤到来而被强制滚动。记录不可用时沿用紧凑、持续的服务窗；被隐去的敏感步骤保留行号、原因与确认状态，不能在预览里消失。行为以 interaction 的“人工闸门”及“历史可达，记录失败可见”为准。
- 用户要求「轨迹放到左侧或右侧，用更能表达 trace 的风格」：正常 Pane 的操作轨迹占**页面一侧的竖向 rail**。竖向 rail 里步骤自上而下排成一条**连续的脊线**，节点串在同一根线上；跨过 rail 的边界就是页面，停靠时原生视图按 rail 挤出来的真实展示矩形收窄，轨迹不覆盖原生页面。活动程序期间展开阅读仍须保留原执行 CSS Viewport；当前 Responsive 呈现若不能保持执行尺寸，采用独立阅读浮窗，原程序结束后才允许 dock，不能借看轨迹偷偷使网页重排。轨迹与页面同时可见是这条约束的目的，任一方被另一方完全遮挡都不算满足。最窄分割中，半宽 rail 若使状态拆成多段、步骤名大范围省略，显式打开的详情改为同一 Pane 下方的有限高度阅读区，同样守住执行 Viewport；原页面保持可见正面积与当前控制权允许的输入，工具栏、More 和 Close 的位置与命中区保持。该窄 Pane 例外只改变停靠阅读区的方向，不把正常轨迹移到下方，也不让停靠详情覆盖原生页面。

### 原生网页子窗口导航

原生网页子窗口直接复用正式 BrowserPane 的完整交互呈现。地址／搜索、工具、Agent 身份与动作反馈、控制权、接管／交还、轨迹和场景沟通沿本页同一控件、主题与密度规则；独立窗口只提供承载边界，不保留另一套简化导航壳或专属控制面。对象、能力、原生状态、输入和新窗口语义只见[原生网页子窗口合同](../behavior/browser-workface.md#原生网页子窗口)。

正常、窄及短窗沿正式 Browser 的响应式收拢和 More 入口保留完整能力可达，当前控制权、主要导航、地址编辑及窗口关闭清楚可辨；轨迹与详情按原工作面的阅读规则展开，不覆盖原生页面或挤掉命中区。Agent 在子页面上的真实动作与当前控制归属保持可见，宿主控件、地址草稿与当前控制权允许的网页输入保持可操作；窗口尺寸或宿主变化不成为隐藏反馈、删除入口或另画一套工具栏的理由。原生窗口边框及关闭控件与 BrowserPane 不重叠、不重复表达；不为此增加目的地配置或改变原外部链接目的地。

小窗提供清楚、紧凑的来源入口，能查看准确触发 Tab／Region，并一键切回；可用同一入口与按需详情承载，不要求并列两组按钮或新增常驻工具栏。位置、返回目标和不可用原因可读，窄窗及键盘下同样可达；来源移动、关闭与未知的判断只消费[原触发位置合同](../behavior/browser-workface.md#原生网页子窗口)，显示名称不承担身份或导航授权。

### Browser 任务工具与证据的紧凑呈现

用户要求界面「简洁、聪明、紧凑」，尽量少线框。行为与 Owner 只引用交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)；本节不把 Browser 变成第二个工作流控制台。

- 整页失败或连接恢复面沿原 Browser 内容区呈现：页面标题／域名与目标地址先帮助认页，随后用简短状态说明问题，主 Retry 与次级 Edit address 清楚可辨。地址提供紧凑复制入口，原始错误收在可键盘展开的有界技术详情中，不以大块报错或长地址占满首屏。有真实旧预览时用克制的小图与“上次查看”来源说明表达，不能冒实时可操作网页；没有图时收回其面积，不铺空框、骨架图或猜测封面。正常、窄分屏和短窗保留完整动作与有界滚动，浅／深主题沿原 tokens、字体和按钮语言，不添第二工具栏或层层错误卡片。行为只见[失败恢复面合同](../behavior/browser-workface.md#browser-工作面-1)。正常工作面导航与切回时，原 Agent 控制沿既有安静状态表达，不把正常输入隔离或原生输入展示不迁移画成预览故障、连接异常或要求 Retry／接管的服务窗；真正页面媒体预览失败仍沿现有就地 Retry 显示可辨的动作表面与键盘焦点，不替换健康原页面，也不隐藏实际失败。恢复资格只引用[多位置展示与媒体边界](../behavior/browser-workface.md#多位置呈现局部遮挡与输入交接)。

- 认证等待和能力限制只在当前 Browser 用简短、持续可辨的就地提示；多账户选择沿既有紧凑浮层语言，账户、选中态、取消和键盘操作清楚，不新增常驻认证工具栏或层层线框。单候选不额外弹选择面，等待本人返回沿原紧凑就地状态表达。系统认证对话保持真实可见的交接，原页面不消失；行为与来源边界只引用交互 SSOT[《Browser 通用认证与 passkey 能力》](../behavior/browser-workface.md#browser-通用认证与-passkey-能力)。
- 工具栏随当前 Pane 的真实可用宽度收拢，常用动作保留紧凑入口，次要动作进入 More；More 与 Close split 各有完整且互不交叠的命中区，不靠挤窄地址、画第二条工具栏或隐藏关闭动作解决。工具显示偏好不能关闭窄 Pane 所需的 overflow 入口，具体工具的启用偏好仍保持。行为与工作面保留只引用交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)。
- Viewport 独立入口与 More 中的二级菜单复用同一组选择。常用模式、手机、平板和桌面尺寸清楚分组，设备名、CSS 宽高与已应用状态可辨；Portrait／Landscape 及自定义宽高入口紧凑、可键盘操作，校验和应用失败在尺寸编辑处说明。长菜单在正常、窄及短窗口中保持有界滚动，子菜单不截断或遮掉选项命中区。固定尺寸完整适配 Pane 四边，Responsive 随 Pane 展示，不加常驻设备壳或第二工具栏；行为与原页面保留只引用交互 SSOT[《Browser 视口与尺寸调整》](../behavior/browser-workface.md#browser-视口与尺寸调整)。
- 页面仍是主内容，沿既有一侧 trace 展示步骤，状态融入已有 Browser 控件。普通工具行只显示动作、目标、状态和最相关结果；时间、文件、字段数与预算使用次级文字，失败和不确定结果能一眼定位。脚本、证据、完整结果与恢复经过按需展开，不常驻堆截图、JSON、技术 ID 或空面板。未使用的演示记录与可复用任务默认只留最小可发现入口，按需展开，不以两块空脚手架占据 trace 首屏；同一工具结果不叠同义标题。已有记录、当前执行、失败告示、停止与人工检查点仍按上述层级可达。
- 成果条件的有限值类型保持小型、就地、选中状态可见；文本、数字和勾选这三个选择可用真实指针或标准键盘输入直接完成切换，不依赖另一层系统弹出菜单才看见当前选择。选择完成后再执行条件，声明必须对应用户实际选中的类型。正常、窄、短窗口中标签、选中态与焦点可读，原页面与既有工具保持可用。
- 用户再次反馈「异步脚手架 UI 太多太大」「AI 正在操作用了土工具栏」，要求非常简要的符号或精妙方式。AI 操作不独立占一条工具栏：以融合现有 Browser 控件的符号、操作者头像或克制微动效表达；详情和停止在 hover、focus 或当前操作 popover 可达，不为每种异步阶段叠 banner。running、waiting、human、failed 在正常与窄窗口中仍须可辨，并尊重减少动态效果偏好。原当前操作由 Agent 控制且处于协议 waiting 时，复用共享沙漏的落沙、短停与翻面循环；等待结束、人工接管、终局或当前事实缺失时回到完整静止态。历史记录、Task ready 与等待人工检查点保持静止，不从记录文字或工具名补推实时等待。参考成熟产品的就地状态与渐进披露，独立真实看图判定是否简洁。
- 小浮层沿现有浮层语言就地呈现，不把 Browser 换成静态预览或空白；hover tooltip 与 popover 两种形态均保留页面可见性与可操作区域。原生层级、真实 compositor frame 与相关 Browser 更新范围只归交互 SSOT 的本节；视觉证据注明原 Renderer、原生页面与 OS 整窗各自的捕获边界，不拼图冒充整窗，不另增浮层状态投影或常驻提示。
- 复用现有 Graphite / Mint、字号、间距、状态 glyph 与 icon-button 命中区。分组靠对齐、轻表面差异和少量段距，少用嵌套卡片、每步框线、重复标题和装饰阴影；trace 脊线只表达步骤时序，不兼作选中信号。当前步骤、选中项、hover 与键盘焦点分别可辨，不靠颜色或单侧细线承担唯一状态。
- 参数化资产的主对象是有名字的步骤与参数。录制、预览、编辑、运行、停止和当前待确认动作各有就地可发现入口；版本、来源与验收状态紧邻当前资产，详情再展开。原始演示草稿与导入后的编辑步骤按需切换或展开，不同时铺开两份重复列表；当前检查点沿已有控件就近表达，行为与状态真源引用交互 SSOT 的人工检查点合同。秘密值显示需要重新输入的状态，不能用占位字符暗示已保存可回放。完成和正常运行使用克制的中性或成功语义，不能整块使用等待提醒色；待人工、真实告示、不确定与失败才按对应语义强调，版本、下一步、停止和未知原因照旧可辨，不添线框。
- 外部目标来源与分享状态、演示语义草稿的解释状态、批处理当前项与条件路径、版本可靠性沿现有 Browser 与资产入口紧凑呈现；行为只引用交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)。默认显示当前目标或步骤、必要状态和样本范围，详情再展开，不新增工作流画布、常驻统计面板或成排空工具栏。演示事实与待解释文字、真实成果与未知样本分别可辨，窄分屏和短窗口仍保留可读内容及键盘命中区；异步更新不遮页面、不抢焦点，AI 操作继续用原就地符号。
- 外部标签选中文件的保留与本人显式丢弃仅见交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)；Browser 设置复用原轻量条目与服务窗，按原页面呈现实际数量、空间占用与未知保留状态，不另搭维护面或常驻统计栏。
- 下载/上传用紧凑产物行表达文件名、传输状态和可执行动作；结构化输出优先可读字段，原始 JSON 按需展开。大结果显示准确范围、裁剪和继续读取入口；嵌入文档的观察范围与缺失事实只引用交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)的局部观察合同；恢复结果、证据不可用和成果未确认沿同一服务窗呈现，不新增全局遮罩或重复警报。
- 长字段默认摘要只占一行；完整 JSON 可读或完整值未保存的提示只在当前结果区说明一次。展开时保留原有有界预览的全部内容，摘要不再重复铺同一前缀；展开原 JSON 保持有限高度，分页动作和键盘焦点可达，不让长值或原始内容把字段状态与任务主次撑走。完整值与准确字节范围仍按上述结果入口读取，不以摘要冒充完整结果；零值、false、空字符串、Partial 与每字段错误仍须准确可辨。
- 页面截图标记沿成熟截图工具的紧凑语言呈现：绘图工具、当前工具参数、历史操作及完成／退出清楚分组，当前工具、颜色、线宽或字号、可用与禁用、hover 和键盘焦点各自可辨，不堆成难识别的无差别按钮和彩点。正常、窄分割、短窗口及缩放后保可编辑 Canvas 的主要面积，控件完整可命中且互不覆盖，线宽选择不挤住颜色按钮，取消始终容易找到。具体能力仅由已确认行为决定，本条不自行增加工具；绘图、复制与退出边界只见[《Browser 页面截图与标记》](../behavior/browser-workface.md#browser-页面截图与标记)。实际产品入口采图与独立评审确认可交付，不以 gallery 或静态样式扫描代签。
- 选择与移动以清楚的区域／对象选中态和命中反馈表达；二次尺寸／端点调整用可辨、可命中的局部手柄，已有文字的编辑入口和编辑状态清楚，不以无提示的隐藏手势承担唯一入口。裁剪框、像素化、实色遮盖及编号批注分别可辨，编号与就地备注相互对应；自由备注与现象／期望／要求模板保持轻量，当前正文与定位动作可达，不铺成必填的大表单。相关属性与备注按当前工具或选中对象就地展开，避免全部参数常驻。
- 原尺寸、Fit、当前缩放与平移方式清楚可发现；放大后可找回整图，批注定位后对应区域、选中态与备注仍能相互辨认，不靠持续动画或移动页面焦点解释位置。正常、窄分割及短窗口中画布保持主阅读面积，工具、定位与参数区不互相覆盖。
- Copy PNG、Copy context 与保存／重开可编辑原稿的用途分别可辨；原稿入口简短说明包含原图及可编辑标注，不能用“已脱敏”或处理图缩略图暗示原稿已经清除被遮内容。复制、保存等待、已确认成功、未保存修改、冲突及未知在原动作附近表达；复制成功保留编辑器与另一个复制入口，保存回执不冒后来修改也已落盘。文件名、路径与错误在窄窗可读且不挤掉退出或主要画布，不增加常驻文档管理面。能力、处理后产物、坐标、文件资格与人工交接边界仍只引用上述行为合同。
- 正常与窄分屏、短窗口、长文件名/参数/错误和键盘操作都保持可读内容与完整命中区。展开详情不盖住原生页面或误改 Terminal 尺寸；异步结果不能抢焦点。设计验收看实际挂载的 Browser/对话工具入口，非空真实步骤、失败、待确认和成果均可达；不能只用 gallery 或来源扫描替代真实工作流。

## Browser 控制权提示

- 操作指示融入已有 Browser chrome：头像／名称、当前阶段与步骤就近可读，接管／交还复用原操作条的同一常驻位置，无需 hover 即可发现并可键盘操作。确认人工控制且有关联 Agent 时，`Return to Agent` 一键直达，展开菜单不能成为必需步骤；直接按钮与已有菜单入口消费同一个准确 Browser 的可信交还动作，不自动交还或重放旧程序。明确没有关联 Agent 时，同一位置提供“在右侧创建 Agent”：创建入口融入原 Browser 工具栏，以轻量紧凑的图标或短标签表达；图标沿整体 Agent 图形语言清楚表达创建动作，与交还已有 Agent 可辨，不借用另一类对象的身份图形。图标独立呈现时仍沿原方形工具栏命中、hover 和键盘焦点语言，具体图形和组合须在实际工具栏中独立看图确认。完整动作和右侧位置沿原 tooltip 与可访问名称清楚可得。正常、窄和极窄 Pane 都保持克制，不用宽大常驻按钮抢主导航或挤掉地址、消息、More、Close；不增加第二条工具栏或将 hover、展开菜单作为必经步骤。创建中的忙碌、已创建但交接未确认及真实失败在原入口附近紧凑可读，收紧外观不削弱待确认状态，不用无接收者的交还图标暗示成功。窄 Pane 优先保留操作者、接管／交还或创建和消息入口，完整标题与步骤按需展开。不另外增加配置；可访问名称与状态图形表达真实控制权，不能只靠呼吸灯或颜色。页面保持可读，输入资格、关联与创建语义只引用[交互合同](../behavior/browser-workface.md#agent-操作可见性与输入隔离)及[从 Browser 创建 Agent](../behavior/browser-workface.md#从-browser-创建-agent)。
- 当前动作沿[统一头像旁提示](agent-capabilities-and-messaging.md#头像旁的阶段与动作提示)在原身份／真实目标附近显示紧凑图形与短标签，具体 Browser 方法与当前阶段只消费行为 owner。真实目标、头像标签、脚本或协议调用图形与讨论浮窗相互避让；读取／等待不播放执行脚本反馈，缺当前 thinking 事实不画思考气泡，不另添状态条或装饰中心点。
- 正常结束时改为安静的完成态，停止 Agent 忙碌与执行循环；准确 Browser 仍归 Agent 时，保留原控制身份、静态边界与接管入口，明确“执行已结束”与“Agent 控制”可以同时成立。只有本人显式接管后才显示人工控制并撤去 Agent 控制边界，普通点击或滚动不能使状态跳为人工。接管／交还入口只沿真实控制事实出现，窄窗不被完整阶段标题挤出；当前阶段未知时明确未知，不能借旧步骤或 Provider working 补成执行。行为真源只见[控制权与交接合同](../behavior/browser-workface.md#agent-操作可见性与输入隔离)。
- 操作呈现参数与嵌入模拟沿 [Browser use 设置呈现](settings-and-observation.md#browser-use-与实时模拟)，复用原生页面／Stage 的同一边界材质与效果绘制原语，明确演示活动、等待、导航、完成后仍由 Agent 控制及显式人工接管；等待／导航不留虚构目标指针，完成／接管不保执行光效，完成后的控制边界保留、接管后才撤去。浅／深背景均保持身份文字和焦点对比；控制权、等待人工、失败与未知仍有独立文字／图形，不把用户选的强调色当错误等级。偏好和减少动态效果只改变呈现，不延长动作或控制；配置／草稿／保存和模拟生命周期继续归原 Settings owner。

### Browser 场景消息浮窗

- 消息入口紧邻当前操作者，浮窗为一个轻量输入面：接收者、来源页／步骤摘要、正文和发送动作。上下文以可移除的紧凑 chip 显示，完整 URL、原步骤和附件按需查看；不常驻技术 ID、JSON 或协议预览，不另造完整聊天面板。正文、键盘焦点、IME、已入队／投递未确认和失败状态沿既有 Composer 语言。
- 正常 Pane 浮窗锚在 Browser 内容的空闲角落并可收起，避免遮住当前动作目标与接管入口；窄／短 Pane 沿同一 Browser 的有界阅读区让位，不能挤掉原页面、More 或 Close。不因 Agent 更新移动正在编辑的浮窗、重挂输入框或夺回焦点；开启与关闭复用共享非模态浮层的原生投影和准确命中范围。
- 框选时清楚标明“标注捕获画面”及原步骤／捕获时刻，与仍在执行的 live page 分开；矩形、编号与备注复用原截图工具。缺失帧、已导航或操作者变化以就地来源提示表达，不借旧框伪装当前网页目标。历史轨迹沿原侧边 rail，当前／历史选中态与执行位置分别可辨；阅读不在 live page 铺永久鼠标轨迹线。

## Browser 与身份浮层的空间层级

对话 hover、上下文菜单、子菜单与头像详情浮层保持紧凑尺寸，并拥有跨 Region 的连续阅读与点按层级；相邻 Region 的 Browser 不能盖住浮层文字或命中区。浮层打开时 Browser 让位只覆盖实际需要的短暂 hover/focus 生命周期，关闭后沿原边界恢复；不能用扩大浮层尺寸、重复画一份 Browser 或永久降低 Browser 层级来解决。

模态、所属附件、窗口兄弟顺序及跨客户端语义层级统一消费[《弹层作用域与层级》](shared-rules.md#弹层作用域与层级)，Browser 适配不另定义层级表或材质。内容、遮罩与失败恢复责任只见[交互合同](../behavior/browser-workface.md#浮层让位与输入层级)。

同一窗口存在 Main 已确认可见的原生 Browser 时，共享浮层采用直接入场，避免透明度或缩放过渡造成首帧遮挡与命中漂移；同窗口未交叠的浮层也沿这一入场规则，无原生页面时保留普通动效。仅对最终真实交叠的浮层建立原生投影，关闭、撤去展示或卸载后释放；真正透明或不支持的裁切不伪装成已支持。


Browser 调整窗口或分栏尺寸时优先保持最近一次有效内容，避免“先消失再出现”的视觉断裂。零尺寸、布局尚未提交和 ResizeObserver 的中间读数不画空白占位，也不触发停放动画；有效矩形稳定后平滑更新。加载、错误、主动停放仍使用各自已有状态表面，不与尺寸过渡混在一起。

## Browser 资源列表

- 采用成熟系统监视器与浏览器任务管理器的克制列表语言，服务快速辨认、比较与操作。标题／域名与位置摘要认页，状态和简短保留原因说明当前事实，进程内存使用对齐的数字与明确单位，行尾集中原页动作；完整 URL、Browser／Tab／Region ID、PID、CPU 采样与全部原因留在当前行详情。正常密度以对齐、轻分隔和完整选中底面建立层级，不把一页元数据铺成多段同等小字、重复卡片或诊断墙。浅深主题沿现有 Graphite／Mint 与字体、控件 tokens；列表保持稳定实色底。
- 顶部只保留当前范围、一次清楚的资源摘要和搜索／筛选／刷新。数量与内存的观察范围就近可读，进程共享、缺测和上次观测有文字标记；缺测使用明确的未确认占位，不以零值、绿色、进度条或虚构趋势暗示空闲、可释放或已成功。原释放／恢复结果紧邻对应行，批量只给简短完成摘要与可展开逐项结果，未知原因持续可读，不用全屏告警遮住健康页面。
- 勾选、行详情、排序、单页动作和批量范围各有清楚的控件与可访问名称；选中用完整表面及勾选，键盘焦点独立可辨。批量入口在已有选择时明确数量与动作，不挤掉搜索和原页面身份；自动释放偏好为紧凑独立设置行，未保存反馈沿原保存区，不与手动动作回执混为一项。释放、恢复、关闭与清理网站数据使用不同动作名，不使用含糊的“清理全部”。
- 窄正文沿同一行对象改为紧凑纵排，保留标题、状态、占用与主动作，次级进程列进入详情；长地址与完整原因自然换行，搜索、批量范围及键盘动作可达，不通过缩小字体或横向大表保全所有技术列。刷新、数值变化和逐项回执不跳动正在操作的行，不抢焦点。加载或刷新失败保留旧列表及就地 Retry；隐藏后的相关观察沿原 owner 退出。真实正常／窄窗与非空状态的独立看图负责呈现验收，工程通过不代签审美；事实、保护及动作资格只引用[Browser 工作面](../behavior/browser-workface.md#browser-工作面-1)。

## 破坏性 Browser 确认密度

- Profile 删除确认必须在目标 Profile 行内表达目标名称、不可逆影响和当前打开 Browser 阻断状态；确认按钮只对当前 Profile 生效，不使用全局或模糊的“清理全部”动作。
- 未确认或被打开 Browser 阻断时，列表保留原 Profile 和一行可操作原因，不显示成功态，不把失败转成空白。

## 应用链接与工具回执提示

- Browser 的应用链接提示是工作面级服务窗；外部应用交接请求来自嵌入 frame 时，提示仍挂在当前 Browser，不新开不可追踪的窗口，也不改变地址栏。提示按通用 scheme 与用户选择表达，不出现站点或厂商专用文案。
- Browser 工具反馈采用紧凑、可读的结果与失败呈现，能继续行动的结果与需要重新规划的失败清楚可辨。`cdp` 的返回与异常合同只见[Browser 工作面](../behavior/browser-workface.md#browser-工作面-1)。
