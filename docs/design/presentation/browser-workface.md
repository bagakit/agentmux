## Browser 空白起始页

- 空白起始页以配置的主标题、副标题与中央地址／搜索输入表达起点，沿原字体和主题 tokens，不固定应用品牌或 Survey 名称。可选图标未设置时不显示且不留空槽；已设置的图标保持克制，不与主标题争夺层级。顶部不重复中央输入，普通已加载网页沿原地址工具栏和真实内容呈现；启用范围及配置行为只见[《Browser 空白起始页》](../behavior/browser-workface.md#browser-空白起始页)。
- 背景图作为起始页背景使用，文字、输入、历史卡片、焦点与操作仍有清楚对比和完整命中区；图像缺失或加载失败时原主题继续提供可读表面，不因等待图片让整页空白。背景不延伸覆盖已加载网页，不用背景或装饰层截走输入。
- 启用历史时，中央输入下方用紧凑的相册式卡片呈现最近地址与搜索，与输入焦点时的建议列表层级分开。URL／搜索类型、真实提交文本、可解析域名与提交时间可辨，未知页面信息不补成事实；没有真实截图时使用信息卡片，不绘制虚构缩略图。卡片不冒完整访问历史、收藏或当前打开页面，记录与导航行为只引用上述交互合同。
- 历史卡片随当前 Pane 宽度收敛，正常、窄分割及短窗保主标题、中央输入和 Browser 必要动作可达；内容超出时使用有界滚动，不堆成固定大卡墙或挤掉起步输入。关闭后收回这块面积；真正无记录时用轻量空状态，读取失败显示就地持续说明与紧凑 Retry，输入仍清楚可操作。不铺教程、步骤器或额外工具栏。

## Browser RSI 操作表面

- 地址／搜索输入在人工 focus 时于原 input 下方打开紧凑建议列表，当前范围、加载／无结果及失败可辨；建议不占常驻页面高度、不遮住输入或把网页换成静态图。真实 favicon 沿网页条目／图标 rail 共享同一克制尺寸和回落 glyph，不绘制猜测品牌。列表开合沿[知识导航的共享动效](spaces-and-layout.md#survey-的-zone-工作面与液体玻璃)，原生页面与浮层按同一遮挡边界保持。
- 地址／搜索输入的历史建议沿原 input 下面的紧凑按需列表，复用 Graphite／Mint、现有字体、选中与焦点语言，不增加常驻历史栏、第二工具栏或成套线框；空白起始页的可选历史卡片唯一见[《Browser 空白起始页》](#browser-空白起始页)。地址／搜索词可辨，单条删除与清空当前范围可达，正常、234.5px 窄 Pane 与短窗不挤掉输入或覆盖 More／Close；列表关闭后原页面与草稿仍可用。复制／粘贴／剪切沿平台原生菜单，不画一组常驻按钮。人工聚焦、历史范围、隐私、恢复、IME、晚结果与编辑归属只引用交互 SSOT[《Browser 地址／搜索输入历史与基础编辑》](../behavior/browser-workface.md#browser-地址搜索输入历史与基础编辑)。
- Browser 操作状态与详情的控件语言统一见[《Browser 任务工具与证据的紧凑呈现》](#browser-任务工具与证据的紧凑呈现)，本节不另定义常驻状态条。
- 本地书签保存／源码动作沿现 Browser 紧凑工具栏与 hover 提示语言；恢复后的可用与禁用表达、格式、读取和保存边界只引用交互 SSOT[《书签文件（.webloc / .url，）》](../behavior/files-and-git.md#书签文件webloc--url)，不增加重复卡片或警告层。
- Agent 的后台 Browser 活动沿原 Tab／Browser 就地符号可辨，不通过选中 sidebar、切 Tab、闪烁或新增常驻栏索取注意与焦点；行为只见交互 SSOT[《Browser 工作面》](../behavior/browser-workface.md#browser-工作面-1)的 CLI 优先与保用户焦点约束，页面动效沿本节既有约束。
- 操作条上的 Agent 身份取自那个 Session 的真实事实（它自己的名字与 Provider），不得由 Session id 拼出一个名字。解析不到时显示 id 本身并让 Provider 图标缺席：一个显示 id 的操作条会让人去查这是谁，一个显示「Agent 7f3a9c2e」的操作条会让人以为那就是它的名字。
- Agent 接管和交还使用同一条身份语言：驱动时显示头像与“正在操作”，人接管后变成安静的确认态并保留最后一步；不靠颜色或呼吸动画表达唯一事实。
- 当前操作位置保留语义目标标记（ref、role、可访问名或页面内目标框）；有真实位置事实时同时显示轻巧、可辨且区别于人的系统鼠标的虚拟指针，不显示猜测坐标或用装饰中心点充数。目标、当前位置与当前动作可读，不靠颜色承担唯一事实。
- 用户要求覆盖 Browser 画面的操作光效：使用克制、低遮挡的页面范围光感与就地动作反馈，页面仍是主内容，不另加状态工具栏、整页框线、遮罩或截图替身。文字、控件和人工点按继续清楚可用，光效本身没有交互命中区；正常、窄、短窗口、滚动、缩放和嵌入 frame 中保持正确对位，普通单次点击或 hover 也能看见真实反馈；动作或 operation 正常完成后的短暂一次完成提示与正在执行可辨，不延续执行光效，不靠循环动作或刻意 hold 掩盖不可感知。减少动态效果时移除位移、扫光、脉冲和循环，保留真实静态指针、目标与状态；等待和人工状态沿原就地符号，不继续播放操作光效。行为、归属、失败与原页面／健康 Run 保留只引用交互 SSOT 的虚拟指针与光效约束。
- **虚拟指针移动。** 两个真实位置间采用短促、平顺收束的 tween，实际看见中间过程，不能瞬移、只显终点、靠参数存在或为截图 hold 原动作。连续新目标从当时实际呈现位置续接，不回跳起点、不排队追赶、不叠 ghost；不加轨迹线、放大、弹跳或新控件。完成通知不重新播放位移或延长提示。
- **hover 与减少动态效果。** 箭头可小幅慢浮动，标签与语义目标 anchor 保持稳定，文字、页面阅读和输入不受影响；浮动不冒 busy，不增加常驻循环，原提示结束或清除即停止。减少动态效果下，tween 与浮动全部静止，保留真实静态终点。位置真实性、同 document／导航续接、历史失效、owner、人工优先和非阻断只引用交互 SSOT[《Browser 工作面》](../behavior/browser-workface.md#browser-工作面-1)的指针与执行反馈约束。
- **按键与执行器符号。** 非敏感实际命名键的就地键帽／通用按键图标，以及小型脚本执行器符号，沿原 Graphite／Mint 语言，紧凑、轻巧；动效限局部 transform／opacity。执行循环随真实执行结束或人工接管立即停，减少动态效果时符号全静止，状态仍可辨。不增加标签重复、长期背景运动、toolbar 或整页框线。真实性、秘密排除和非阻断只引用交互 SSOT[《Browser 工作面》](../behavior/browser-workface.md#browser-工作面-1)的按键与脚本反馈约束。
- Browser 的 `elementContext` 结果沿既有 Browser/Composer 语汇呈现：结构化字段使用紧凑的可复制文本块，错误靠近当前 Browser 工作面显示并保留下一步动作；不新增常驻 DOM 检查面、不把原始 HTML 直接铺在页面上，也不以颜色单独表达授权或失败。
- Browser timeline 与聊天 timeline 共用 20px 节点槽、时间 ruler、状态 glyph 和折叠规则；连续的低价值 CDP/等待步骤可合并，但脚本、用户接管、权限等待、失败和不确定结果始终可见。
- 回放入口显示“预览 / 单步 / 运行”三档动作和停止按钮。回放脚本的来源、页面身份和人工闸门在入口附近可见，避免把一次重放误认为普通刷新。
- 历史入口与操作条同层可达，不要求先发生新操作。记录不可用时沿用紧凑、持续的服务窗；被隐去的敏感步骤保留行号、原因与确认状态，不能在预览里消失。行为以 interaction 的“人工闸门”及“历史可达，记录失败可见”为准。
- 用户要求「轨迹放到左侧或右侧，用更能表达 trace 的风格」：正常 Pane 的操作轨迹占**页面一侧的竖向 rail**。竖向 rail 里步骤自上而下排成一条**连续的脊线**，节点串在同一根线上；跨过 rail 的边界就是页面，原生视图按 rail 挤出来的真实矩形收窄，不是被盖住。轨迹与页面同时可见是这条约束的目的，任一方被另一方遮挡都不算满足。最窄分割中，半宽 rail 若使状态拆成多段、步骤名大范围省略，显式打开的详情改为同一 Pane 下方的有限高度阅读区；原页面保持可见正面积与真实输入，工具栏、More 和 Close 的位置与命中区保持。该窄 Pane 例外不把正常轨迹移到下方，也不让详情覆盖原生页面。

### Browser 任务工具与证据的紧凑呈现

用户要求界面「简洁、聪明、紧凑」，尽量少线框。行为与 Owner 只引用交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)；本节不把 Browser 变成第二个工作流控制台。

- 页面预览失败后的就地 Retry 沿现有紧凑按钮语言显示可辨的动作表面与键盘焦点；正常和窄分屏中不退成孤立裸文字，不被详情浮层遮住，重复的保页说明收敛为一次。媒体失败与恢复资格只引用[多位置展示与媒体边界](../behavior/spaces-and-layout.md#zonetabsregions-的实体与展示绑定)。

- 认证等待和能力限制只在当前 Browser 用简短、持续可辨的就地提示；多账户选择沿既有紧凑浮层语言，账户、选中态、取消和键盘操作清楚，不新增常驻认证工具栏或层层线框。单候选不额外弹选择面，等待本人返回沿原紧凑就地状态表达。系统认证对话保持真实可见的交接，原页面不消失；行为与来源边界只引用交互 SSOT[《Browser 通用认证与 passkey 能力》](../behavior/browser-workface.md#browser-通用认证与-passkey-能力)。
- 工具栏随当前 Pane 的真实可用宽度收拢，常用动作保留紧凑入口，次要动作进入 More；More 与 Close split 各有完整且互不交叠的命中区，不靠挤窄地址、画第二条工具栏或隐藏关闭动作解决。工具显示偏好不能关闭窄 Pane 所需的 overflow 入口，具体工具的启用偏好仍保持。行为与工作面保留只引用交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)。
- 页面仍是主内容，沿既有一侧 trace 展示步骤，状态融入已有 Browser 控件。普通工具行只显示动作、目标、状态和最相关结果；时间、文件、字段数与预算使用次级文字，失败和不确定结果能一眼定位。脚本、证据、完整结果与恢复经过按需展开，不常驻堆截图、JSON、技术 ID 或空面板。未使用的演示记录与可复用任务默认只留最小可发现入口，按需展开，不以两块空脚手架占据 trace 首屏；同一工具结果不叠同义标题。已有记录、当前执行、失败告示、停止与人工检查点仍按上述层级可达。
- 成果条件的有限值类型保持小型、就地、选中状态可见；文本、数字和勾选这三个选择可用真实指针或标准键盘输入直接完成切换，不依赖另一层系统弹出菜单才看见当前选择。选择完成后再执行条件，声明必须对应用户实际选中的类型。正常、窄、短窗口中标签、选中态与焦点可读，原页面与既有工具保持可用。
- 用户再次反馈「异步脚手架 UI 太多太大」「AI 正在操作用了土工具栏」，要求非常简要的符号或精妙方式。AI 操作不独立占一条工具栏：以融合现有 Browser 控件的符号、操作者头像或克制微动效表达；详情和停止在 hover、focus 或当前操作 popover 可达，不为每种异步阶段叠 banner。running、waiting、human、failed 在正常与窄窗口中仍须可辨，并尊重减少动态效果偏好。参考成熟产品的就地状态与渐进披露，独立真实看图判定是否简洁。
- 小浮层沿现有浮层语言就地呈现，不把 Browser 换成静态预览或空白；hover tooltip 与 popover 两种形态均保留页面可见性与可操作区域。原生层级、真实 compositor frame 与相关 Browser 更新范围只归交互 SSOT 的本节；视觉证据注明原 Renderer、原生页面与 OS 整窗各自的捕获边界，不拼图冒充整窗，不另增浮层状态投影或常驻提示。
- 复用现有 Graphite / Mint、字号、间距、状态 glyph 与 icon-button 命中区。分组靠对齐、轻表面差异和少量段距，少用嵌套卡片、每步框线、重复标题和装饰阴影；trace 脊线只表达步骤时序，不兼作选中信号。当前步骤、选中项、hover 与键盘焦点分别可辨，不靠颜色或单侧细线承担唯一状态。
- 参数化资产的主对象是有名字的步骤与参数。录制、预览、编辑、运行、停止和当前待确认动作各有就地可发现入口；版本、来源与验收状态紧邻当前资产，详情再展开。原始演示草稿与导入后的编辑步骤按需切换或展开，不同时铺开两份重复列表；当前检查点沿已有控件就近表达，行为与状态真源引用交互 SSOT 的人工检查点合同。秘密值显示需要重新输入的状态，不能用占位字符暗示已保存可回放。完成和正常运行使用克制的中性或成功语义，不能整块使用等待提醒色；待人工、真实告示、不确定与失败才按对应语义强调，版本、下一步、停止和未知原因照旧可辨，不添线框。
- 外部目标来源与分享状态、演示语义草稿的解释状态、批处理当前项与条件路径、版本可靠性沿现有 Browser 与资产入口紧凑呈现；行为只引用交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)。默认显示当前目标或步骤、必要状态和样本范围，详情再展开，不新增工作流画布、常驻统计面板或成排空工具栏。演示事实与待解释文字、真实成果与未知样本分别可辨，窄分屏和短窗口仍保留可读内容及键盘命中区；异步更新不遮页面、不抢焦点，AI 操作继续用原就地符号。
- 外部标签选中文件的保留与本人显式丢弃仅见交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)；Browser 设置复用原轻量条目与服务窗，按原页面呈现实际数量、空间占用与未知保留状态，不另搭维护面或常驻统计栏。
- 下载/上传用紧凑产物行表达文件名、传输状态和可执行动作；结构化输出优先可读字段，原始 JSON 按需展开。大结果显示准确范围、裁剪和继续读取入口；嵌入文档的观察范围与缺失事实只引用交互 SSOT[《Browser 任务能力与可复用资产》](../behavior/browser-workface.md#browser-任务能力与可复用资产)的局部观察合同；恢复结果、证据不可用和成果未确认沿同一服务窗呈现，不新增全局遮罩或重复警报。
- 长字段默认摘要只占一行；完整 JSON 可读或完整值未保存的提示只在当前结果区说明一次。展开时保留原有有界预览的全部内容，摘要不再重复铺同一前缀；展开原 JSON 保持有限高度，分页动作和键盘焦点可达，不让长值或原始内容把字段状态与任务主次撑走。完整值与准确字节范围仍按上述结果入口读取，不以摘要冒充完整结果；零值、false、空字符串、Partial 与每字段错误仍须准确可辨。
- 正常与窄分屏、短窗口、长文件名/参数/错误和键盘操作都保持可读内容与完整命中区。截图编辑控件在窄分割或正常缩放后仍须各自可辨、可点击且互不覆盖，不能让线宽选择挤住颜色按钮；控件区不遮住可编辑的 Canvas，取消、复制与原页面边界保持。展开详情不盖住原生页面或误改 Terminal 尺寸；异步结果不能抢焦点。设计验收看实际挂载的 Browser/对话工具入口，非空真实步骤、失败、待确认和成果均可达；不能只用 gallery 或来源扫描替代真实工作流。

## Browser 控制权提示

- 操作指示的视觉合同统一见[《Browser 任务工具与证据的紧凑呈现》](#browser-任务工具与证据的紧凑呈现)；可访问名称与状态图形表达真实控制权，不能只靠呼吸灯或颜色。页面内容保持可读且可操作。
- 交还用户时改为安静的确认态，不继续显示 Agent 忙碌；尊重减少动态效果偏好，窄窗保持在视口内。行为真源见 interaction「Browser 通用交接闭环」。

## Browser 与身份浮层的空间层级

头像详情浮层保持紧凑尺寸，但拥有跨 Region 的连续阅读层级；相邻 Region 的 Browser 不能在浮层后面继续绘制并截断文字。浮层打开时 Browser 让位只覆盖实际需要的短暂 hover/focus 生命周期，关闭后沿原边界恢复；不能用扩大浮层尺寸、重复画一份 Browser 或永久降低 Browser 层级来解决。

Browser 调整窗口或分栏尺寸时优先保持最近一次有效内容，避免“先消失再出现”的视觉断裂。零尺寸、布局尚未提交和 ResizeObserver 的中间读数不画空白占位，也不触发停放动画；有效矩形稳定后平滑更新。加载、错误、主动停放仍使用各自已有状态表面，不与尺寸过渡混在一起。

## 破坏性 Browser 确认密度

- Profile 删除确认必须在目标 Profile 行内表达目标名称、不可逆影响和当前打开 Browser 阻断状态；确认按钮只对当前 Profile 生效，不使用全局或模糊的“清理全部”动作。
- 未确认或被打开 Browser 阻断时，列表保留原 Profile 和一行可操作原因，不显示成功态，不把失败转成空白。
