# Focus Map：空间地形与协作关系

本文是 Focus Map 的行为需求 owner。它定义地图的用途、实体、层级、关系、阅读和交互边界；视觉语言见[地图呈现](../presentation/collaboration-map.md)，空间身份见[统一概念与空间寻址](spaces-and-layout.md#统一概念与空间寻址)，消息事实见[A2A 协作](a2a-collaboration.md)。需求描述目标，不代签当前实现或安装资格。

## 用途与第一性原理

Map 帮助人建立协作的空间心智模型：辨认工作上下文及其包含关系，沿真实通信找到协作邻域，看到值得关注的变化，并进入准确 Agent 或原工作面。List 适合依状态扫描和处理，Map 适合看结构、关系与局部动态；两者消费同一事实，不能成为两套名册。

- 区域表达归属与包含；距离表达关系邻近；箭头表达种类与方向；有限动态表达一次真实变化。这四种语义各有职责。
- 空间身份、执行身份和展示 occurrence 分开。相近不证明同一任务，嵌套不证明 Agent 上下属，点小或无活动不证明已结束。
- 阅读稳定是信息可用性的基础。首次组织和显式理线可以改变整体组织，结构变化允许有限局部修正，普通消息与渐进读取不破坏人的位置记忆。
- 地图是原事实的可重建投影。计算与观测失败保留原身份、已有工作面、可用能力与恢复入口。

## 层级地形与通信邻域

真实父子区域以嵌套轮廓表达：外层包含完整子区域、直系成员及标题，内层仍有准确身份与独立阅读入口，形成类似等高线的层级地形。Folder 项目包含复用同 Host 的真实目录祖先规则；相同路径前缀、共同父目录分组和跨设备关联项目组不冒充物理包含，worktree 仍沿其原 Project/Zone 归属。Topic Category 与 Topic 的包含消费原 Core 空间绑定，不凭内容目录重建分类关系。没有直系 Agent 但有子区域的父区域不算空区域。多处合法绑定仍完整保留，地图的展示树不反写原空间图或铸造唯一归属。

初次组织及显式理线同时优化真实包含、强关系邻近、节点/标题可读与短而少交叉的路径。通信强度只来自已观察、按原来源去重的消息证据，以饱和方式参与几何，不能让一组多年积累压垮其余关系；创建、调度与消息保持各自原义，同一消息的多条事件不重复增加强度，未读/未知来源不当零通信。无直接关系和历史成员仍在原区域可发现，以紧凑位置为关系邻域保留阅读空间。来源渐进到达时，现有世界立即可用；当前已观察关系参与首次组织、结构性局部调整或下一次明确理线，不以全量预读或等待未知来源作为地图可用门槛。

折叠一个父区域时，其后代只在本次投影中收起，外部关系接到该准确可见祖先，内部关系仍可展开原证据；展开恢复原对象和子树阅读位置。准确 Agent 定位展开其必要祖先并显露原 occurrence。父子轮廓、成员统计和关系汇总避免重复计算同一 Host/Session；各层直系成员与包含范围可辨。

父区域的阅读目的地包含真实子树。父区过大而无法在可读尺度适配时，定位其内部已存在的准确成员；所有成员所在子区均已收起时，定位真实可见的子区汇总框，保留原折叠选择。空父区与没有直系成员的父区分别处理，折叠后仍保留子空间提示和原地展开入口。

连线以准确端点为先，在真实障碍之外选择简洁通道；同端多线根据对端方位分配有序端口，相反方向与不同种类仍可辨。路由同时考虑路径长度、绕行和拥塞，不靠隐藏关系、连错端点或将多条关系误画为新业务实体来取得整齐。单边失败沿原局部服务窗与准确重试披露。

## 相对稳定与结构调整

已有位置是下一次布局的起点与位移偏好，不是节点生成后永久固定的坐标。地图保留可辨认的邻域、相对方向与阅读上下文；真实结构变化时，允许相关旧节点一同调整，不以“没有碰撞”拒绝改善明显分散的邻域，也不要求每次变化都移动已经合理的布局。

成员增删、节点实际尺寸变化、区域折展、真实父子或成员归属变化触发有限的局部调整。新增成员可让已有相关邻居适当让位，移除或缩小成员后可回收不必要的空洞与绕行；调整同时保持完整成员、真实递归包含、节点与标题可读及通道留白。范围从变化所在区域与直接受影响的邻域开始，只为准确包含或实际几何冲突扩及必要的子域、祖先与相邻区域，不沿通信关系无限传播。无关区域的位置与内部组织保留，祖先轮廓的必要重包不成为移动其余子树的理由。

节点移出区域但原通信仍保留时，原邻域仍可回收空位；远端弱关系不能仅因几何跨度很大而压过有限位移与局部紧凑的要求，真实关系、方向和强度继续保留。

最近在图中阅读、选择或定位的准确展示 occurrence 及相机优先保留；同一 Session 的其他展示不能替代这个锚点。折展沿用户实际操作的可见标题保留屏幕位置与缩放层次。相关的其他旧位置作为减少位移的偏好，可为邻域组织、空洞回收或必要避让调整，不任意翻转、旋转或重排原邻域；后来发生的真实阅读与导航手势优先于尚未完成的计算。首次布局与显式重新整理仍可组织整个世界，保留原身份、完整成员、来源和阅读入口。

局部调整有界完成并停止，不运行持续物理模拟。相同结构、实际尺寸与已落定几何再次协调时结果幂等，不随重绘、重复请求或无关更新漂移。仅有消息、关系边或强度证据、名称、读取进度和活动状态变化，成员、实际尺寸与区域结构未变时，复用已有位置，按原事实更新路径与反馈，不自动重新布局整个世界；后续结构性调整可以消费届时已观察的关系。布局与路径计算不以同步整图工作阻塞主线程，不依赖挂载全部共享卡片或预读所有来源；几何仍是可重建的 client 呈现，不产生持久空间归属或第二份 Agent 事实。

## 地图呈现偏好

用户可在 Focus 的 Map 设置中选择区域轮廓、LOD 级数，以及各级的形态、信息与缩放过渡范围；地图提供直接可发现的设置入口。轮廓支持多边形和贝塞尔曲线，两者消费同一完整成员几何与留白，不改变真实包含或 Agent 位置。

LOD 以同一份有序级别定义为准，支持 2 至 4 级，级数由级别集合派生。默认三级为概览点、紧凑身份和可读卡片；二级、四级提供完整可用的起点，选择新的级数后可逐级调整。每级可选择点、紧凑标记或卡片，以及形态可承载的累计信息：身份、另加状态、再加最近内容摘要；信息选项明确其实际显示范围。由远及近的形态与累计信息容量不得下降，放大不退回较小形态或撤去已展开的普通信息。第一层是覆盖最远视图的固定基线，不提供过渡范围字段；后续级别定义在有效缩放范围内从哪个比例开始、在哪个比例完成过渡，开始值小于完成值，各过渡有序且不重叠，末级持续到最放大视图。界面在保存前明确指出无效范围并保留原草稿。

形态表达该尺度的最大信息容量，继续保护屏幕可读性、准确状态与共享阅读入口；缩小不显示不可读正文，未知、失败和需处理提示不受信息预算关闭。闲置、关闭和未知主体保留各自真实状态及紧凑阅读，偏好不伪造活跃或结束。各档之间连续交接，而非突然切换；任一时刻仍只有一份可操作主体，正在阅读的原焦点、Reader、相机和消息来源不因改设置被替换。来源读取跟随实际可见、可读的信息需求与原精确 Reader，后续显式定位沿当前偏好选择可读目的地；即使全部级别选择点状，准确主体仍有可发现的阅读入口。只改变轮廓、LOD 或信息披露不移动相机、不重新排布世界，不预读所有 Agent 的正文。

设置沿原 Focus 偏好、ConfigOwner 与冲突检测保存，提供实时示例预览和恢复默认。预览不提前改写正式地图；无效草稿暂停保存，示例明确显示最后有效草稿；保存失败保留草稿与已确认设置，成功后实际地图消费同一值，重启保留选择。复用原公共 `settings.inspect` / `settings.set` 的声明式设置发现、校验、持久写入和回执，覆盖轮廓、级数和当前各级字段；不新增地图业务状态、Core 图事实或独立配置 Store。

## 同一世界、阅读与事实边界

协作图是一张按 Mote／Topic／项目等准确工作区域组织的地图，呈现用户有权观察的 Agent 及区域内外的通信与协作关系。地图由 Focus 持有，与 List 组成同一 Agent 工作视图的两种表达；Map 占据完整 Focus 内容区，与 Space 左侧菜单和 List 泳道互斥，不作为泳道旁的附加面板；Focus 提供直接可见的 List／Map 切换，没有选中 Agent 时也能进入地图。Space 的上下文动作将准确区域或 Agent 带到这张 Focus 地图，不再持有另一套地图视图，也不新增与 Space／Focus／Goals 平级的目的地。区域身份、成员范围与 Session 展示绑定沿[空间模型](spaces-and-layout.md#空间模型与实体绑定)。地图不从名称或当前打开面猜展示绑定，也不新增一层空间实体；有依据的只读工作资源关联与原展示绑定分别表达。

**世界范围、当前聚焦与读取范围分别表达。** Focus 的 Map 以及从其他上下文发起的定位进入同一张地图，准确区域与 Host／Session 只决定首次定位和高亮，不把世界裁成当前区域或直接关系，也不要求先切换到“全部区域”才能发现其他区域。世界结构沿原空间索引建立，所有获准观察的成员都保留，包括尚无已记录关系、闲置及已关闭的 Agent；不能因没有边、未读事件或显示层次收缩而从地图身份集合中删除。List 的项目、状态与正文搜索条件保留为列表阅读状态，不暗中缩小 Map 的世界。地图查找用于发现并定位准确 Agent，关系类型筛选只改变原关系的显示，不删成员、来源或重置读取窗口。

Focus 首次进入使用 List，此后保留上次显式选择的 List／Map；准确的“在地图中定位”动作可显式进入 Map。切换 List／Map 只改变 Focus 的呈现，不把一次视图切换当作 Agent 定位、执行焦点转移或重新打开工作面。返回已访问地图时保留相机、选中关系、展开来源、原续页窗口与正在阅读的内容；返回 List 时保留其筛选、阅读位置及原工作面。隐藏视图停止新增读取与旧动效，不以卸载原草稿、替换 Session／Run 或重新建图恢复界面。具体读取仍沿原有窗口与生命周期 owner，不新增 Focus 地图事实 Store。

入口保留打开时的准确目标。图内“定位当前 Agent”只将相机移到该 Host／Session 的合法图中位置并突出显示；共享 Session 的多处参与仍是同一身份，不能凭名称选另一个 Agent。原入口后续选择变化不暗中重置已打开地图的相机、选中关系或正在阅读的内容。位置或原身份未核时明确说明缺失，保留地图、原目标与恢复路径，不猜另一处作为成功定位。定位、节点选择与打开原工作面是不同动作，均不移动 Agent、改写归属或发起协作。

地图导航同时由 GUI 与原公共 `app.focus`／CLI `app focus` 消费同一 client 呈现 owner；List／Map 属于 Focus 的视图选择，不新增顶层 Surface 或图事实 API。原 `app.inspect` 和导航回执分别给出所选 Focus 视图、实际呈现及输入事实，不能以命令受理或 Focus 已选中代签地图已显示；准确区域仍沿原空间寻址，保输入、失败与恢复沿[公共展示导航](public-control.md#agent-操作桌面主画面与保留对话输入)。Core 传递 client 呈现合同，不持有地图 UI 状态或 Agent 关系的第二份真值。

消息、创建、Dispatch 与任务分别沿[对象与事实归属](a2a-collaboration.md#对象与事实归属)，图只作可重建投影，不另造可独立改写的关系事实。来源、关系阶段、覆盖范围与查询权限沿[双向事件](a2a-collaboration.md#双向事件与可还原的交互)；消息往来不能推定接单或扩大授权，任务责任沿[交接与委派边界](a2a-collaboration.md#交出去与派出去)。共享 Session 可以在多个区域中出现，各处引用同一准确 Host／Session，查询、Agent 统计与原关系按原身份去重。折叠区域汇总当前可见的原关系，内部关系仍能按来源查看，不因折叠丢掉事实或推断新的协作。

**发现引用后继续识别准确对象。** 消息或创建记录中的关系端点是已知引用，不等于已取得完整资料，也不因当前展示目录未命中就成为识别终点。地图按相关端点及原 owner 有界补查现有 Session／保留历史、名称、创建来源与空间事实，充分使用已有元数据；名称、状态和区域归属分别沿原 owner 确认。独立 Session、Provider 原生子任务与外部 Runtime 引用保持各自身份，不能将外部身份套成本地 SID，或把“有关联／未归区”表达为下属。原生子任务只有 Provider 的结构化身份及父子依据才可识别，不能从正文、名称或 ID 形状猜测。无法补齐时保留准确引用及原证据，说明缺少或不可用的来源，允许同源重查；观察与地图阅读不因此取得控制、正文或额外授权。

**没有当前展示位置，不等于没有工作区域。** 历史与关系引用成员优先沿准确 Host／Session 的持久空间绑定、原协作者记录组织，不要求当前存在 Run 或 live 展示快照。没有已确认展示归属时，可以利用原 Host 下已确认的执行 Workspace、登记项目／worktree 及无歧义 Topic 目录关系作可解释的地图关联；工作资源关联注明依据，不创建、移动或改写 Space／Zone／Region 绑定，不推定任务责任、正文读取或控制资格。已确认的多区域展示保留，不能被执行目录覆盖；不从 A2A 对端、创建者当前区域、名称、ID 形状或跨 Host 同名路径继承归属。仍缺来源或候选有歧义时保留准确引用及缺失原因，区域待确认与身份未识别分开表达。

**渐进读取不改变已经建立的阅读位置。** 活动状态、名称补全、来源续页、关系新增和输入观察不重新排列全部已放置成员；由此确认的真实成员、归属或尺寸变化沿[相对稳定与结构调整](#相对稳定与结构调整)有限修正，保住准确阅读对象、相机与无关区域。

地图以可平移、缩放的连续画布承载整个世界；布局体现真实区域及关联，节点不以统一双列网格作为固定产品合同。首次组织与显式重新整理让当前已知的同区直接关系参与区域内部组织，跨区关系参与区域间相对组织，形成便于沿关系阅读的邻域；不能只在彼此无关的节点排布上补画长连线。关系邻近不取代准确成员范围，也不要求牺牲完整成员、卡片可读性或既有稳定阅读来使每条边最短；缺少或不可用的关系来源不阻断已有地图。准确区域与节点几何不依赖共享卡片是否挂载。首次进入优先以可读尺度定位准确入口目标；没有入口目标时，根据已知成员与活动事实选择主要工作区域建立阅读起点，不为容纳所有空区域将内容压成不可读缩略图。没有活动事实时仍给已知成员或区域明确入口，不猜工作状态。显式“查看全图”显示完整世界；全图、区域与 Agent 是同一地图的阅读尺度，不是不同数据范围。之后只由显式定位、缩放与适配动作改变相机；结构调整与路径同步沿上述相对稳定合同，不借移动相机掩盖节点变化。

节点的活跃、闲置、关闭与最近活动分别消费原 Session／Runtime 及活动观察事实，呈现层级沿[协作图呈现](../presentation/agent-capabilities-and-messaging.md#agent-协作图)。观察缺失、断联或暂不可用不推导关闭，也不因节点缩小而移除原关系或改变操作资格；查看缩小节点仍绑定准确 Host／Session，沿同一阅读入口披露原详情。运行快照暂缺时，原历史目录中已知的准确成员仍保留，状态未知与已确认退出分别表达，不补造当前 Run 或控制资格。目录沿原生命周期变化失效与刷新，普通状态更新不重复扫描；隐藏停止新读，恢复后补齐未观察变化，读取失败保留上次事实与同源重试。

**世界可见不等于全量读取。** 观察工作集按当前视口、缩放层次、用户选择和明确披露的来源有界推进；先读相关主体有界的最近事件与原创建元数据，呈现已观察参与者、已加载窗口、续页与各来源问题。平移、扩大视野或定位可继续观察；观察工作集收窄只停止相关新读取，不因离屏清掉本次地图已读的元数据窗口、原历史续页边界或正在阅读的证据，回到原处继续原读取。保留沿原读取器的有界窗口与生命周期管理，不另建持久关系 Store；不能因图是全局范围就预读全部消息、任务历史或所有 Agent 卡片。卡片内容只为可见阅读节点、明确选择及其必要原来源构造，屏外节点不挂载共享卡片或预构造重内容；原目录的无关更新、读取进度或一封来信不能触发全部 Session 的内容重算。

事件读取沿原 journal incarnation 与冻结边界分别继续历史页或前向更新，不能混用游标、把通知再次算作通信或混合不同原来源的同名消息。监督关系来自原事件，准确请求／回复详情和原信正文只在用户披露时读取；已有 Goal 关联继续由原卡片与 Reader 展示，不为绘图读取所有任务历史。节点阅读与操作绑定准确 Host／Session，复用[共享 Agent 卡片的内容与动作 owner](focus-context.md#卡片内容预览与-agent-操作)，不从标签、动画或当前位置猜目标。

对话与协作的动态变化依据原消息、监督或任务事件，动效不能制造正在通信、已接单或仍在工作的事实。活动有自身的准确端点、来源与结束边界，不因其他活动或视口重挂载续期、重播；活动反馈不改变节点几何或打断原阅读。外观、缩放层次与动态语言归[协作图呈现](../presentation/agent-capabilities-and-messaging.md#agent-协作图)。

地图提供直接可见的视觉动态开关。未显式选择时遵循系统减少动态偏好，用户明确开启或关闭后沿原 Focus 呈现设置保存并执行，普通 List／Map 切换保留该选择；原 Focus 设置可恢复跟随系统。开关只控制地图动效，不停止原事件观察、改变已知状态、确认消费、发送消息或调整布局；关闭时仍保留静态活动、原方向及完整来源，重新开启不重播或延长已观察活动。该选择由原 client 呈现设置 owner 持有，和演示消息生成的播放／暂停分开，复用原设置读取、写入及发现，不建立新的业务命令或第二份实时观察状态。

Focus 的 List／Map 普通切换保留各自的阅读位置、选择与正在阅读的内容，以及原工作面、草稿与 Session／Run。单击地图节点选择该 Agent 及其关系；图内定位只定位同一地图中的准确对象。地图节点明确的“在 Focus 中查看”动作进入 Focus 中对应的准确 Agent，上下文必须显露并被选中，不能将这次跳转改成打开 Space 工作面。目标受查找、项目或状态筛选遮挡时，只临时显露这一准确目标，保留原查找与筛选值，并让用户辨认例外及结束方式；下一次明确定位可替换该例外。请求完成不立即收回目标，原列表负责挂载准确卡片并滚动显露，不能只切换视图而把目标继续藏在原筛选或屏外。普通视图切换不因此重置原查找、筛选或阅读，也不重放旧定位；新的明确导航优先于尚未完成的旧定位。公共入口及真实显露回执沿[桌面主画面导航](public-control.md#agent-操作桌面主画面与保留对话输入)。

跨视图定位沿准确 Host／Session 及原展示位置核对；需要选择工作面时同时核对原 Region，多位置提供选择，位置未核不能退成只凭 SID 打开另一 Host。“打开原工作面”仍是与图内定位、进入 Focus 分开的显式动作。Focus 的执行选择与阅读沿[原 Focus 上下文](focus-context.md#focus-执行上下文项目泳道与底部时间音轨)，未知、已关闭或仅有历史来源的节点保留原身份与可读来源，按原上下文或历史阅读入口处理，不制造执行 Session、可用 Run 或已恢复事实；Mote 协调 Agent 继续由原协调上下文承载，不写入执行 Agent 的选择或历史。关系详情中的对端可沿准确 Host／Session 定位回同一地图，不由重复的显示名称猜目标。

来源或观察失败只影响本次读取，保留已知事实并提供原来源重试；关闭或隐藏停止新读与旧动效，临时隐藏保留正在读的内容。展开地图、观察通知与定位不自动读取、消费或确认原信正文，不授予新的操作权限。
