# AMUX 协议与内置 Prompt

AMUX 为 Agent 和用户呈现本次任务、原资料及其读取入口。从设置里的 Prompts 或窗口工具栏进入同一个 Documentation → amux Protocols，查看当前构建提供的模板和可读示例。精确字节格式归[可读协议](../../specs/amux-protocol.md)，模板交付机制归[协议管理架构](../../architecture/amux-protocols.md)。

## 同一模板供发送与阅读

每种协议和 AgentMux 提供的内置 prompt 都有独立的 `.amux.prompt.md` 文本来源。AgentMux 的发送端从协议模块取得纯文本或按本次已确认参数生成文本。协议参考从同一模块获得名称、用途、模板和示例，随当前构建的定义更新。线格式展示原文和消息卡片，内置任务展示实际 prompt。按需展开原模板。示例使用虚构身份或固定样本。

语言与平台适配沿同一协议和模板入口演进。可编辑说明的变化保留协议身份、原业务参数和已交付历史的可读性。未知格式保留原文，已保存的正文与回执沿原 owner 读取和恢复。

## 发给 Agent 的内容

本次任务说明所需结果。需要回读的资料提供原对象身份和已有 CLI 发现入口。模块 `--skill` 持有操作路线，叶子 `--help` 持有当前版本参数与续页用法。用户的自定义指令作为独立正文交付。必须同时交付的原信、观察和答复各保留其原始数据边界。

派生和接手任务以原 Session、Provider 来源或原 owner 的有界历史为依据。CLI 和 Desktop 沿同一原业务约束确认来源与执行位置。交接遇到读取缺口时说明原来源及覆盖范围，已取得的原历史可继续使用。

协议阅读、模板文本和对象引用均沿原业务 owner 查询。身份、权限、投递、采用和完成由原结构化事实与回执确认。已冻结输入在重试、续接和对账时使用原字节。
