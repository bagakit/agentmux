## 执行 Agent 焦点历史与 PMO 上下文隔离

Space、Focus、Goals 的共同导航及其与 Survey、Recall、左下 Mote 面板的选择边界只见[Work、Survey、Recall 与 Mote 的导航上下文](spaces-and-layout.md#worksurveyrecall-与-mote-的导航上下文)。本节的执行与协调焦点是 Session 语义范围，不代替 Work 的通用空间选择。执行 Agent 与 PMO Teams Agent 保持各自身份与历史；打开或切换 PMO Teams 不得改写执行 Agent，也不得把 PMO Session 放进执行 Agent 的历史。

执行 Agent 的语义焦点由同一 execution focus 入口承载：当前 Session 和真实聚焦事件共用同一份有界持久化记录。最近上下文入口按最近使用顺序从该记录派生，同一个 Session 只出现一次；时间音轨保留记录中的真实重访位置，不以最新位置覆盖旧事件，也不回填从前未保留的事件。真实执行 Agent 在任一合法呈现中的明确打开、选中或跨表面定位，继续通过这一入口记录真实语义聚焦，包括 Survey 中的合法呈现；语义记录本身不导航或覆盖 Work、Survey、Mote 面板的空间选择。单纯切换表面只读取原记录，不另猜一个“最近变化的 Session”，无 Agent 内容或协调 Session 的空间选择不冒充执行聚焦事件。历史可以被 Agents 界面作为可操作的最近上下文入口，也作为只读上下文提供给 PMO Teams；PMO 只能观察这份执行上下文，不能把自己的交互写回去。

PMO Teams 有独立的协调 Session/Tab 焦点，由原 PMO 交互 owner 使用；其语义归属不合并 Mote 面板与 Work 的导航选择。PMO 打开、恢复、提交消息和切换 PMO Tab 都更新 PMO 焦点；从 Focus 的待处理提醒进入时，须激活该请求所在的原 Region，不能因同 Tab 的其他格正在激活而选错 Session。关闭 PMO 只收起其呈现，仍保留的背景继续所属导航上下文的当前选择，不覆盖用户后来已选的目标。执行 Agent 历史和 PMO 历史不合并，两个身份在 UI、持久化和提供给 Agent 的上下文中都必须可区分。从 Focus 提醒打开后，原提醒经 Core 确认收起时，关闭浮窗应把键盘焦点交给当前仍可见的 Focus 检索控件；原入口仍可用时优先归还给它。用户已主动聚焦其他可见控件，或主工作面已切走时，不得把焦点拉回之前的 Focus。从持久状态恢复为打开的 PMO 浮窗，关闭时没有可证明的原入口，就把键盘焦点交给仍可用的常驻 Mote 入口；只交还 DOM 焦点，不改执行 Agent 选择、历史或 Run，仍遵守该段既有的较晚主动焦点优先级。入口不存在或处于明确隐藏、禁用的范围时不强行聚焦；已关闭的浮窗收到关闭请求不触发焦点交还。

Focus 的 Mote 待处理入口在窄栏仍能辨认当前 Mote、真实待处理数量和打开意图。鼠标与键盘沿同一入口进入该请求准确的原 Topic、Tab 与 Region；执行上下文、原草稿及较晚主动焦点继续遵守本节既有边界。空间不足不隐藏必要数量或打开动作，名称与数量沿原身份和待处理事实 owner，不因呈现另建状态、读取或投递。

冷启动先恢复原焦点与工作面，Mote 目录身份可随后完成观察。健康 Session 的工作区或 Topic 归属尚未确认时，保留原协调／执行焦点引用，不能把未知归属判成执行 Agent 并清掉 PMO；已有确认的普通项目、Topic／Mote 分类和 Core 明确终局事实仍沿原规则处理。目录观察不要求启动、停止或向健康 Run 输入，也不阻原工作面恢复。

## Focus 执行上下文、项目泳道与底部时间音轨

用户进一步要求 Focus「达成熟产品水准，交互与性能远超竞品，所有功能自己测试满意」。质量以现有 Focus 的完整使用流程成立为准：从入口预览、辨认和筛选上下文，到处理请求、查看结果、在原工作面继续工作、查询时间音轨并返回，再到布局调整、跨表面切换与重启恢复；各功能既能单独使用，也能连贯完成真实任务。鼠标与键盘、宽窄窗口、空态及恢复状态都须可理解、可到达，阅读和输入不能被操作栏、浮层或滚动边界阻碍。自行体验验收须记录实际操作、可见结果、响应成本与保留的原身份，不能以组件测试通过或安装成功代替；发现的缺陷与未验证边界如实保留。成熟度与竞品优越性是用户目标，只有绑定对比版本、同等数据和任务条件的证据才可形成比较结论，不能将目标写成已完成事实。事实来源、性能、连续阅读及身份保留继续沿用本节与[《Terminal 连续向上阅读历史》](terminal-reading.md#terminal-连续向上阅读历史)的既有约束。

用户补充：「focus 按钮的 hover 感觉信息可以包含一些动态信息，更丰富一些」。Focus 入口的悬停与键盘聚焦预览呈现当前执行事实：Working、Attention、Results 与 Idle / Recovery 数量，以及当前关注和少量优先需要处理、正在工作或已有结果的上下文。每项用任务名、项目归属与最近已知活动回答“谁在做什么”。归类、名称、摘要复用 Focus 的同一事实来源，PMO 协调上下文保持既有职责边界；中断、尚未 resume 或 Run 未观察到的保留任务仍参与原四组计数；当前关注项仍可预览，状态与已知活动如实表达。未知与空态如实呈现，不把存活或旧输出推断为正在工作或新结果。

预览随真实状态更新；关闭后不保留详细预览订阅，不因无关 PTY 字节重绘或新增后台查询、轮询。悬停只阅读，不切换表面、不更改执行焦点、不发送输入；点击 Focus 仍进入既有工作面。Escape、失焦与指针离开正常收起，键盘可读同样的信息。具体视觉约束见密度 SSOT 的对应 Focus 章节。

用户确认「按你说的改一版」，并要求「时间音轨参考一些视频编辑软件的样式，且放在最下面」。Focus 保留项目泳道、Recent Focus 与右侧完整原工作面；时间音轨位于整个 Focus 内容底部、全局状态栏上方，项目扫描与继续工作占据上方主区。PMO Teams 不混入执行上下文或其历史。

用户持续反馈 Focus「滚动有问题」「右边的加载也有问题」，并将 Renderer 性能作为 P0。大数量资格验证须绑定实际数据来源、版本与窗口条件；真实观测集合和扩展压力样本分别声明，不能把合成样本或自然窗口之外的局部测试称为真实使用通过。左侧泳道与底部音轨保持各自连续阅读，右侧加载与 Focus/原工作面交还保持同一 Tab、Region、Session 和健康 Run。成本沿真正相关的消费者和变化事实核对，不因无关项目、保留的断连上下文或其他历史数量反复推导整份工作面。同一次上下文派生的最新记录、结果判断与摘要复用同一份 Core 已读记录投影，不为多个展示字段重复构建相同对话时间线及版本；只变化状态、名称或归属时，原调用者复用来源与版本未变的正文派生事实，不额外保存完整记录树或旧 Store。真实正文、版本或来源变化仍沿原 Core 语义更新，状态与时间观察不被正文复用冻结。常驻导航的工作与待处理计数只消费原会话状态和执行归属，不为几个数字生成正文、摘要或对话版本；归类、PMO 隔离与原观察刷新仍复用 Focus 的同一 owner。通用终端成本与连续阅读要求引用[《Terminal 连续向上阅读历史》](terminal-reading.md#terminal-连续向上阅读历史)，不在 Focus 另立协议或历史账本。

摘要继续复用 Core 的同一内容、作者与来源适配，只生成当前摘要消费的事件记录，不额外构造完整阅读所需的原记录与输入实体集合。完整阅读和窗口仍保留这些原始关系；不能以省略摘要不用的数据为由丢弃正文、作者、来源或恢复事实。

### 搜索上下文、对象身份与历史正文

本地筛选提供项目、状态和类型三个维度；每个维度可多选，同维任一匹配，不同维度与文字查询同时满足，未选择值的维度不限制集合。类型提供 Mote、Topic、Survey、Project，含义沿下文原对象与来源边界，不把它们当互斥身份。筛选菜单可搜索选项，选项搜索只收敛菜单中的可见候选，不改当前条件或触发历史读取；连续选择即时生效且不自动关闭菜单。状态只在同一多选组提供一次，不在面板底部重复提供同义快捷状态；调整状态保项目、类型和文字查询。

条件可分别编辑和移除，也可明确清除全部本地查找词、项目、状态与类型条件。当前列表无匹配时仍有相同清除入口，恢复列表并将键盘焦点交回原查找入口；清除不重新读取历史、不丢弃已读取结果或展开原记录，不改变来源覆盖与未知／失败事实。没有上下文与当前筛选无匹配保持区分。已选项目或其他条件的来源暂不可用、从候选目录消失或当前计数为零时，保原准确身份、最后确认名称与当前未知说明，仍可显式移除；不能显示为 All、静默清除或改选同名对象。项目值按原 Host／Project 身份区分，同名和跨 Host 不合并。

Focus 的同一搜索入口消费[Core 统一全局搜索](public-control.md#统一全局搜索)的 metadata／history 模式及原对象、Host、ID／link、来源覆盖与续读合同。Focus 的 local adapter 只投影原已加载事实和有界阅读意图，不持另一套匹配、关联推断或跨来源历史调度。名称、活动、已加载摘录、状态、Provider、路径、项目／分支／Topic 和全部已支持身份仍可即时筛选；普通文字输入只更新 metadata，不读取全部会话正文。项目、状态与类型条件分别约束原执行候选与独立协调候选，命中结果保持各自集合和身份，不扩大执行 Agent 资格；原位置与保留历史结果分别说明实际范围，不默默套用本地上下文条件，也不把过滤后的卡片集合冒整个全局候选集。查看、检索及条件变化保原工作面、选择、正文、选区、草稿与健康 Run，不因无关输出重推整份来源或新增读取。

状态筛选消费原任务状态、活动观察及恢复事实，保原四组筛选，并可单独缩小到活动未知或已确认需要恢复的上下文，不改原四组泳道归类；中性组的整体筛选不表示其中每项均已确认闲置。Working 表示当前任务工作中，不能仅因 Run 存活命中；恢复条件只匹配已确认需要恢复的事实，观察缺失或活动未知不自动变成待恢复、失败或 Idle。Results 仍需原当前成果的已确认事实，不能仅凭 done 或完成文案命中。状态名称、条件摘要和计数复用同一原事实，不能以显示文字的匹配授予状态或控制能力。

相同 Session 的多个原位置分别可选；Mote 及只有文件、浏览器等资源的对象仍可找到其准确位置，不把它们伪装成普通执行卡片。已有访问归属和 recap 可沿准确原对象作为呈现补充，不证明当前空间绑定、任务活动或控制资格。缺少已确认位置时保留准确身份与未知说明，搜索、查看和复制不启动、恢复、停止或发送输入；明确选择才沿原导航进入准确位置，历史无原位置时仅只读查看，不以命中自动恢复 Run。

历史正文查询通过 Enter／明确搜索动作发起，针对所选原来源的 Read conversation 与继续查询也为明确动作；结果沿现有 Focus 阅读窗的记录和字节预算保留完整原记录。显式继续保当前唯一展开的正文、选区与原资源读取身份，旧结果移出窗口时明确说明，不删除原历史、不另持正文 Store。覆盖说明直接消费公共回执，已知来源查完、来源目录尚未确认、尚有 continuation 与全部已声明范围确认无匹配保持可辨。修改查询、隐藏、取消或卸载只结束本次 reader，迟到结果不覆盖新查询、焦点、草稿及原工作面；读取失败保已读正文与健康能力，重试仍针对原准确来源。

### Goal 关联与独立查看

Focus 的 Agent 条目提供已确认 Goal 关系的次级入口；公开名称与原 Demand 身份、负责人、Supervisor、相关会话、历史参与及当前执行的含义沿[Goal 关系 owner](goals-and-demand.md#负责人相关会话与当前推进)。已确认关系绑定准确原 Host／Session，缺执行或身份依据时不从裸 SID、名称、目录或焦点猜关联。当前执行观察未知与 Agent Host 归属未知分别表达：前者保已确认关系，后者不能产生任何 Host 的确认关系。已结束 Goal 保原关系和状态，不冒当前推进；普通关联、参与或用户所说的关注不自动获得监督或执行含义。

原角色只保裸 SID 而 Host 未确认时，可保留按原 canonical SID 对应的「可能的 Goal 引用」，保原 Goal ID、角色和来源，并持续说明 Host 归属未确认；这仅提供原目标的查看入口，不确认该卡片所属 Host 的关系、当前执行或控制资格。当前目录只有一个候选也不补全 Host；同一 SID 在多个 Host 出现时，各自仍只得到未确认引用，不能借其中一处已知参与或执行推认全部裸角色。

单个已知 Goal 或单个明确标为未确认的候选可打开原目标详情；多个 Goal 由用户逐条选择，不默认第一项。已确认关系按原 Goal ID 去重计数，候选不混入确认数量；同 Goal 的准确关系与未确认角色合并为一个目标条目，保完整角色及来源并分别说明确认范围。无已知关系且无候选不占空入口；来源未确认或失败不冒已确认无关系，已读引用与说明仍可读。查看 Goal 沿[目标独立查看](goals-and-demand.md#goalsfocus-与执行工作面)与原准确导航 owner，仅显式进入 Agent 工作面才改变空间选择；hover／键盘检视不导航，打开 Goal 不发送、启动、恢复、停止 Run 或改写执行焦点历史。返回 Focus 保查询、筛选、滚动、原选中 Context、正文阅读与草稿，并尊重用户后来主动选择。关系投影复用原业务事实和相关增量，不逐卡扫描全部 Goal、拉历史或另建关系 Store，不改变当前执行投影的事实范围。

### Focus 个性化设置

Map 的区域轮廓、LOD 与逐级信息偏好沿独立[地图呈现设置](collaboration-map.md#地图呈现偏好)，复用本节的预览、保存与原阅读保护。

Focus 设置按项目扫描、Agent 阅读与链接目的地组织。沿原配置保存与冲突保护，提供回复摘录 1／2／3 行（默认 2）、自动预览快速／审慎／仅键盘（默认快速）及最近输入 3／6／10 条（默认 6）；原近期活动窗口与链接目的地保持。摘录行数只约束常驻卡片的回复摘录，不裁掉必要请求、失败、恢复或未知说明。预览选择适用于共享 Agent 卡片入口；仅键盘不因指针悬停或仅获焦自动开窗，仍沿原明确阅读键进入，普通点击与 Enter 保原导航。预览意图切换会撤销迟到计时，不关闭或替换固定书签。

输入条数在每次新开阅读时作为目标采用，读取沿下文[卡片输入阅读](#卡片内容预览与-agent-操作)的统一有限预算，完整原文、来源及固定阅读保护保持；偏好更新不裁掉已打开窗口的条目或选区。时间轴标尺、时区、高度、名称列宽以及书签位置尺寸继续由各自已存在的呈现 owner 保存，设置页复用原入口，不复制这些事实。状态与恢复判定、必需的服务提示、准确身份、排序防跳及资源读取边界不可配置。

设置中的示例随草稿即时更新并可试用，保存前不改变真实 Focus 或运行中 Agent。示例复用真实呈现组件、SVG、样式与预览意图策略，以本地明确示例事实驱动，不挂真实 Session／历史／图片读取、书签、运行或导航；设置页隐藏时停止演示意图与动效，保留草稿。公共配置发现、设置与回执继续沿现有 settings 能力，不新增 Focus 控制协议。

### 卡片内容、预览与 Agent 操作

用户进一步指出「每一个砖块上的信息，什么都看不出来，而且利用率很低」。条目首屏必须能区分同一项目、同一模型的多个 Agent：名称遵循既有显示名优先级，最近动作来自已有可观察事件；项目归属在泳道头表达，完整路径和完整身份按需查看，不在每块重复消耗首屏。事实不足时如实说明，不编造任务、进度或正在执行的动作。

屏外卡片的占位控件先显示身份与当前状态，并在可访问名称保留原服务说明。保留且已确认属于 idle/service 的上下文可延后其 recap；未展开不表示没有历史。卡片进入可见范围或经键盘聚焦、检视时，同步取得该原 Session 的完整摘录、来源与可访问说明，并随原事实更新。其余上下文的结果判定、全量分组、名称、活动时间和排序不缩减；非空文字筛选仍覆盖全部原已加载内容。导航预览、Space 目录与 Reader 继续保持各自完整事实范围。

卡片身份复用[原 Tab／Region 身份与检视能力](spaces-and-layout.md#topic-工作面拓扑与在场状态)：已确认多 Region 时展示该准确 Tab 的原分格，并强调本卡 Agent 对应的已确认 Region；单格沿现 Executor 身份。多个合法展示位置不合并成唯一父 Tab，未知不借当前工作面或第一地址补图。身份检视与整卡打开原 Context 的语义分开；hover、键盘聚焦和图形高亮不导航、不改变选择或 Session 能力。卡片状态继续只消费原分类与活动事实，不从摘录文案或空间图生成完成、进度或控制状态；原摘录、来源、按需阅读及准确导航保持。

完整卡片预览以原回复／输入阅读为主，名称与同一当前状态只表达一次；请求、错误、连接／恢复和未知原因保直接可读，有原回复时普通活动作为按需补充，不用旧回复遮掉必要服务事实。位置示意保全部已确认的展示 occurrence 和准确目标格，详细地图仍沿原身份检视按需取得，不能因紧凑呈现猜首位置或隐去原 Host／Session 边界。去冗余只改变资料层级，不删改原消息、来源、输入窗口、reader 身份／预算或健康能力，不新增读取、控制动作或事实 Store。

Focus、工作区 Agents 工具与 ProjectActivity 的单 Agent 展示共用身份、状态、当前进展及按需阅读面；主层保原名、固定状态与原摘录，阅读面先呈现完整已观察回复与输入。用量、Goal、已知消息关系及详细来源由用户显式进入资料层，必要请求、错误和未知服务原因仍直接可读；资料读取继续守原来源与有界按需合同，打开预览不等于查询全部资料。各入口仍保自己的分组、排序、空间选择及动作，不把 Focus 导航变成共享卡片策略；主卡与关系动作保持兄弟控件。Topic 的多 Tab／Region 检视仍表达准确空间 occurrence，不替换成单 Agent 详情。共享展示只消费原业务事实，不另建卡片、用量或关系事实 Store。

临时阅读面保留本次打开时已观察原文，后续新回复不自动替换它；本次既有 reader 尚未完成的准确同来源首批输入仍可沿原预算呈现，不把打开瞬间的空态冒已读完整。原 Host／Session／Run 及来源仍确认相同时，状态与用量可按原事实更新，但与所保留正文的记录范围分别表达；阅读快照不是当前执行、完成事实或新的历史账本。Pin 后的动态更新与持久恢复由[Agent 浮动书签](#agent-浮动书签)定义。

用户显式 Pin 将同一阅读面保留为 Agent 浮动书签，初次固定不重挂当前正文、单条输入或资料页；临时预览与已有书签分别成立，其他 Agent 仍可临时检视或另建书签。阅读面非模态，其他卡片、工作面和输入保持可用；固定、移动或缩放不自动选择 Agent、启动或恢复 Run，不默认扣减、重排或调整原工作面的尺寸。书签的更新、阅读保护及几何操作统一沿[下文合同](#agent-浮动书签)，原卡片打开动作不受影响。

每次正文阅读仍限定准确 Host／Session／Run 与原来源。来源有新记录、替换或覆盖变化时明确说明，不静默替换用户正在读的正文；缺失或未知不冒已确认变化。原 Run 或来源失效时停止该次 reader 和迟到更新，保已读内容及其原身份可读；书签能否跟随新 Run／来源由[准确更新边界](#agent-浮动书签)决定，不借同名或裸 SID 接到另一对象。原触发行或卡片及所属表面隐藏、被过滤或卸载，不结束窗口中仍可见的书签。窗口或阅读面本身隐藏时暂停其观察与计时，窗口阅读 owner 卸载时释放 reader 资源并沿书签合同恢复持久呈现意图；没有可见阅读面时不维持后台读取需求，迟到结果不重开阅读面。原健康 Agent 与其他消费者继续可用。

用量沿[原生报告口径](settings-and-observation.md#状态栏)与[当前上下文判定](conversation-input.md#当前-agent-的上下文余量与输入焦点)区分原生会话累计、最近响应和当前上下文占用／剩余，保原采样范围与未知，不将最新响应或已加载历史相加冒会话累计，也不从累计用量反推上下文剩余。共同用量详情在 Agent 预览与原输入面保持同义，不因入口不同生成第二份统计。Goal 关系沿本节既有合同；消息关系只来自已核验作者／收件者和原监督派发记录，说明准确 Host、来源及已加载／部分覆盖，未确认对端不借裸 SID 或正文声明绑定。已记录、已投递、已回复及业务接受分别表达，监督派发不冒全部普通收发关系；查看复用原有界只读入口，不消费投递、轮询或逐卡扫描历史。

Focus 的活动摘要与 Topic、既有活动视图复用同一事实解释：首屏回答任务是谁、最近做了什么、现在为何需要人处理。具体授权标题或问题、明确失败／连接说明优先于旧工具活动，当前可查看的结果保留结果内容。普通后续消息不能无故盖掉仍适用的最近工具动作；仅有消息事实时明确它是请求或回复，不能将聊天文本当作已执行动作。缺少活动事实仍诚实表达；不为卡片拉取全会话历史、新增轮询或另立状态／活动账本。已消费的状态说明变化必须可见，同状态心跳与无关会话字节不触发内容重算。

卡片以已保留记录的原回复／请求摘录为主体，来源清楚；紧凑摘录复用共同 Markdown 解析能力，呈现强调、代码和段落／列表的阅读含义，不把语法标记直接当普通文字铺出，也不新增可点击链接、资源读取或内层交互。摘录仍受原行数与已加载记录预算约束，完整原文和来源沿原阅读入口保持；不将 Topic 短说明冒作 recap，也不把旧摘录推成当前完成、任务进度、人类作者或新活跃时间。有摘录时普通工具动作或 transport 过程留在按需详情，无摘录才沿现活动摘要。仅当前活动证据不足、过期或不支持报告时，保原共享未知状态及准确说明；已有摘录不再叠独立的活动未确认／最近确认行，原因、观察范围和已有能力通过同处状态的 hover／键盘检视与可访问说明可读。无摘录时可显示准确短说明，不能以未知冒空闲、失败、完成或无任务。待处理请求、失败／断连、恢复、来源失效和其他必要服务说明仍直接可读且优先，原服务窗不被遮掉或静默取消。已完整识别的包装沿共同唯一解析能力把正文置前，声明不认证作者；未识别、不完整及代码／引用中的同形文字保原文，首屏投影不改原摘录、来源及完整阅读。常驻卡片仅消费相关上下文已加载的有界记录，不逐卡追加历史／全文扫描或另一份摘要事实；输入阅读沿下文边界，右键原准确 Agent 动作沿本节菜单合同。

卡片悬停意图与键盘聚焦按需呈现完整的当前已知任务、活动、正文及来源，并在独立的 Recent user messages 分区以紧凑输入条目帮助回忆任务；默认以最近六条为目标，输入仍来自原已接受的有界窗口。每条定高、长文仅视觉省略；所有 Agent 临时预览与固定书签统一由点击、Enter／Space 等显式操作展开单条完整原文。条目悬停或仅获焦不展开、换条或导航，指针离开或悬停其他条目不自动收回已显式展开的原文；迟到的悬停意图同样不能更换或关闭当前原文。Pin 前后保持已经打开的原文层，不收回或重挂。完整原文可移入阅读、滚动与选择，收起返回原条目，不改消息或原 reader 身份。悬停展示与正文阅读只读，不导航、改变选择或夺输入；只有窗口内实际展开且可见的 Agent 阅读面挂载同一准确 Host／Session／Run 的既有用户消息读取器，复用原生与已捕获输入公共投影，不另建 Reader、cache、观察注册表或轮询。读取的暂停、停止与释放沿上文窗口阅读面合同，不随原卡片是否仍在列表变化；常驻卡片本身不挂载 reader，其他现有消费者与健康 Agent 继续可用。原回复及来源保持，不把输入当作回复、已执行活动或新的完成事实。短卡摘录仍有界，原回复与输入的按需全文须保留当前窗口已完整观察到的正文，末段可沿各自阅读面滚动到达，不能先按紧凑条目字符预算删去再称完整阅读。展示条数只决定本次输入目标，不突破下段统一有限读取预算或增加资源读取；来源本身只提供部分内容时如实说明，不能补造未读文本。预览正文复用共同 Markdown 阅读能力，保段落、代码及引用，不将已压平摘要误作原正文；超出安全解析预算的已观察长正文可按完整纯文本呈现，不删文、不补写闭合语法。已完整识别的包装沿唯一 Core 解析器把正文置前，声明只作为声明，未知、不完整或代码／引用中的同形文字保原文；单条输入的原文及来源仍通过只读可选文字或 title 可达，不另加折叠、复制、刷新或导航动作，书签标题／回复／链接的显式复制只归下文书签合同。

Recent inputs 的首次可见阅读沿同一公共 Reader，在配置输入数量不足且仍有原较早游标时有限补读；当前自动预算最多三批来源页，包含首读，同一帧的 wire 分片只用于完整组装，不另算一批。每个合法完整帧的输入逐步可读，达到输入目标、来源起点、批数或原窗口边界即停止；真实来源失败停止本次自动需求并说明原因，不因重绘、普通实时追加或无关 Session 重新补读。自动扩窗请求[共同 Reader 的不驱逐策略](conversation-mode.md#共同对话与原生记录)，不能为找较早输入丢掉原已接受贡献或把实时窗悄悄变成历史窗。首窗无输入但仍有较早覆盖、预算边界或首次补读未结束时不能冒称完整空历史；部分范围与显式继续动作就地可达，已知窗口边界不说成 Agent 或来源失败。用户显式继续可沿原 Reader 进入普通较早历史阅读，保原游标、正文、选区与锚点；受保护的输入原文及版本先沿原明确采用／返回动作处理，不被后台补读挤掉。Pin 不能冻结尚未结束的初始空框；已经接受的输入、单条全文及有效 Range 仍守原阅读保护，不用补读覆盖选中原文。

全部输入时间已知时按记录时间稳定排序，选当前展示上限内最近的条目后按旧到新呈现；时间相同保原投影顺序。任一输入缺记录时间时，保公共投影的原来源顺序取当前展示上限内末尾条目，显示 Current reading window · Order unavailable，缺时条目标明 Time unknown；已知记录时刻呈现能区分日期的本地日期与时间，仍是记录时间而非包装声明的发送时间，不猜全历史最近或跨来源先后。有限读取仍不足展示上限时只显示现有记录，保准确范围与显式继续入口；不同原生／已捕获记录不按正文去重，各保记录身份及来源。 正常有序且没有读取／覆盖问题时，不另占常驻窗口说明行；有界窗口含义、原生／已捕获来源及包装原文仍通过同条记录时间的只读 title／可访问说明按需可达，不能因此冒全历史最近或隐藏缺时、读取／观察失败、来源改变、暂停和不完整事实。单条输入的项目与路径可在来源注记紧凑表达，完整路径、准确 origin 与 SID 保在同处按需说明；单条输入不增加 Info、复制、折叠或导航动作。输入正文的作者外观沿[共同阅读合同](terminal-reading.md#terminal-连续向上阅读历史)中的《共同对话的用户默认外观与协作来源》，unknown 显示 You 但不改写原作者事实，明确 Agent 作者仍按真实身份表达，不以收件者资料代填。读取或观察失败、窗口冻结或不完整沿原事实给简短服务说明，保已读内容、原工作面与健康输入，不增刷新按钮或后台资源发现。

卡片及单条输入的图片沿共同对话图片能力读取和呈现。明确注入图片读取能力后，只读文字仍不产生链接、文件、文档或其他执行动作；受控粘贴图片走原受限目录读取，原生图片走准确 Host／canonical Session／原生来源／record／part 的既有资源接口，不从展示文本或相邻记录猜资源身份。只对当前可见阅读需求加载，隐藏、来源失效与关闭停止新读及迟到附着；未知或读取失败保原引用和可读原因，其他正文及健康 Agent 继续可用。不另建图片索引、缓存、轮询或任意路径读取；单条完整阅读的 Escape 先收回该条，再沿原资料／正文／窗口层级处理，不抢用户后来焦点。

指针可自然移入预览阅读、滚动和选择文字；预览内部滚动不关闭自身。单条输入的显式阅读不改变外层 Agent 预览既有的悬停、关闭和焦点边界；外层临时预览依原 owner 关闭时仍释放其单条阅读，不因显式展开自动变成持久书签。未固定的临时预览在外部泳道滚动、打开本次阅读路径之外的菜单或改名时收起并废弃迟到计时；固定阅读不因指针离开或操作其他卡片关闭，窗口／阅读面可见性、owner 卸载及来源变化仍守上述边界。键盘可进入正文、资料及固定动作，关闭当前资料层先回同一正文，Escape 从正文关闭阅读面；退出时只向仍可用的原触发点交还焦点，用户后来主动聚焦或导航优先。原主卡片的普通左键与 Enter／Space 仍执行原 Focus 导航；书签不被临时预览替换，也不拦截主卡导航或其他 Agent 的临时预览。

卡片右键、Shift+F10 与 ContextMenu 键打开同一准确 Agent 菜单，不改变当前选中；菜单头仅用单行名称确认本次对象，长名称省略且按需可读完整名称，不重复状态或 SID 说明。菜单保留 `Rename Agent` 与唯一 `Copy Agent Link`，并在独立停止动作组提供 `Stop Agent`；打开沿原卡片左键与 Enter／Space，不重复为菜单动作；改名只调用该 SID 的既有命名 owner；复制仅选择原 `copy-session` action、唯一 formatter、clipboard 与错误出口，得到准确 `amux://agent/<SID>`，不发送消息。各入口只保留一个 Agent Link，复用同一 formatter 与 clipboard；空间对象按[统一对象链接](public-control.md#对象地址分享与方向)提供独立链接。多位置或无确认 Region 时不猜空间地址，不继承 Region 关闭、重排或其他 Runtime 控制；复制失败仍沿原错误告知。行内改名的 Escape 取消、空值回既有派生、Enter／失焦提交保护输入法组合过程；退出编辑或菜单不得夺走用户后来选择的焦点。查看和复制保原输入、草稿与生命周期，显式改名仅改变命名事实。

Focus 卡片与格内的 Agent 菜单对明确选中的语义 Agent 共用 `Stop Agent` 动作和原确认框；停止本次准确 Host／SID／Run，不是当前 Tab、Region、Chat 收件 Mote 或后来替换的 Run。Session 的明确停止资格不依赖是否存在已确认的 Tab／Region 展示位置；位置未知、无投影或多位置不能隐藏准确 Agent 的停止入口，也不要求先打开、恢复或新建工作面才能停止。确认前沿原 owner 重新核对身份，缺失或改变只拒绝这次停止并给原 subject 服务说明；活动 unknown 不自行拿走已确认控制身份的显式停止能力。pending 防双点，确认取消与关闭保原键盘返回和较晚主动焦点优先。调用沿公共停止接口，未确认、失败或等待超时保原工作面与草稿并明确未知，不乐观删投影、不冒称已停止、不自动重试或停止其他 Session。Core 确认准确 Run 终局后，沿原退休／run-removed owner 移除已停止投影，保原 Session、native conversation 与历史退休资料供原显式恢复；不承诺成功后旧 Tab 仍在，也不因查询或重启恢复退休 Run。旁边健康工作面、草稿和 Run 不受影响。Focus 收起仍只改变呈现，不与停止混名。

Attention 中的失败 Agent 沿原处理面提供可发现的查看与关闭动作。只有公开 Core 已确认该准确 Session 的进程结束或终局事实时，显式关闭失败 Session 才沿原 Session 生命周期能力收尾；已确认结束的 Run 不要求再次取得停止运行进程的回执，无确认展示位置也不阻断准确 Session 的收尾。关闭请求面和关闭 Focus 投影仍只改变呈现，不能冒成 Session 已关闭。关闭的返回、排队或超时不代替 Core 确认：未确认及失败保留原对象、工作面和可读恢复原因，迟到旧 Run 的回执不能关闭同一 SID 的新 Run。一次关闭未完成后，原准确目标的服务说明与可执行继续动作保持可达，不能因原位置缺席或上一请求未收口让后续点击静默无效；等待边界、租约释放与局部关闭保全沿[《Session、Run 与 View》](session-recovery.md#sessionrun-与-view)。错误状态、握手或观察失败不自行证明进程已结束；健康或未知 Run 保原可用能力及既有显式停止边界，不凭错误文字猜终局。准备失败尚未产生 Session 时，保原 Launcher 与完整草稿供重试，不伪造可关闭的执行对象。Agent Region 的展示关闭与生命周期后果仍归[《Agent Region 关闭与身份入口》](spaces-and-layout.md#agent-region-关闭与身份入口)。

#### Activity 活跃入口与空间级联

ProjectActivity 从状态指标进入活动菜单，展开后先回答有哪些 Agent、当前情况和最近已知进展。状态入口的标识与准确计数保持可辨，展开面只保一处整体状态汇总；Zone／Tab 只承担组织与准确定位，路径与完整位置资料按需查看，不遮住 Agent 和必要服务说明。活动来源、原成员集合和既有分类保持，不因空间级联新增状态筛选或时间阈值；未知状态、缺少活动或时间仍如实表达，不能把旧摘录冒当前活跃。此入口不变成脱离活动语境的通用空间目录。

菜单按 Core 原空间目录、绑定与位置事实组织 Zone／Tab，空间身份沿[统一概念与空间寻址](spaces-and-layout.md#统一概念与空间寻址)。只有一个有成员的组织组（Zone 或无确认位置组）时，首层直接显示其 Agent 与已有 Tab 组织；Zone 与无位置成员并存时仍保各组选择。多个组织组时先显示组织行，宽面 hover 直接级联展开对应子级与原 Agent 行。可用空间不足以同时辨认父子列表时，沿同一内容切换为单列；点击组织行、Enter 或 ArrowRight 直接进入本组 Agent 列表，不再经过 Show Agents 中间步骤。窄面组织行 hover 不替换列表，以保持指针下的操作对象稳定；Agent 行仍沿共享 hover 阅读。返回保原列表位置及本次对象，不导航或重建工作面。空间组织行只展开本组，不按状态、排序或首个 Session 代用户选择 Agent。执行目录和分支名称不替代空间实体；同一 Agent 的多个合法 Tab／Region occurrence 分别保留，并明确表达为同一 Agent 的不同展示位置，准确 Host／canonical Session 与展示位置分开。计数按原准确 Agent 身份去重，不把多个位置算成多个 Agent；无位置、位置未知或空间观察暂不可用仍保原 Agent 与可读说明，不因单组简化被隐藏，原集合中的 Mote 协调 Agent 不因复用 Focus 的执行泳道筛选被排除。

Agent 行复用本节的共享内容与同一阅读面，菜单外壳持有分组、选择与级联；不整壳搬入 Focus 卡片的导航、筛选、改名或停止策略。菜单行的身份图形不另开拓扑 hover 检视，整行预览同一 Agent；Reader 仍持原完整身份、全部已确认位置和准确位置检视，不能为简化菜单丢掉多位置事实。菜单的上下键漫游、左右进入／返回、明确选择和 Escape 逐层返回保持，进入 Reader 的键盘入口不得占用菜单漫游手势；窄面仍提供可发现的显式返回入口。父菜单、子菜单与其唤起的阅读面构成本次连续阅读路径，指针可自然经过并移入阅读、滚动、选择、固定与返回，不能因 Portal 分离或菜单打开／关闭协议误关该阅读面。其他菜单、阅读面自身隐藏及关闭仍沿原边界处理；Pin 后沿[同一书签合同](#agent-浮动书签)保留，不复制 Reader 或书签。

hover 只预览／展开，不导航、不更改空间或执行焦点，不夺取原编辑器或终端的输入焦点，不启动、恢复、停止或向 Agent 输入。Agent 行明确区分预览与打开工作面的动作：点击或键盘明确选择沿原导航 owner 进入本次准确位置；位置尚未确认时保原引用和工作面并说明，不猜首位置，也不移除原 Agent 的可读入口。无确认位置的 Agent 选择仅在原导航 owner 返回成功后收起菜单；调用失败时保留原列表及可重试入口，不把发起调用冒成打开成功。用户后来主动焦点优先，关闭只向仍可用的原入口交还焦点。该菜单消费现有公共 Session、空间发现和导航能力，不新增 Core 实体、RPC／CLI、权限、状态 Store 或历史读取机制；Reader 继续沿本节既有按需预算，详细观察和计时只随窗口中可见、展开且相关的消费者增长，不为菜单扫描全部历史或订阅无关 Session。

#### Agent 浮动书签

Agent 浮动书签是由共享 Agent 阅读入口保留的客户端呈现对象：Pin 后可移动、缩放，多 Agent 可以同时打开，位置与尺寸在应用重启后恢复，内容随原 Agent 的已确认观察更新。本节定义目标行为；不据此声明当前实现、保存或恢复已经通过验收。

同一 Desktop 客户端内，以原控制 Host 与 canonical AgentSession ID 确认同一书签；控制 Host 来自原 Session 控制引用，不借资源／展示 Host、presentation ID、名称、Tab、Region 或当前 Run 代替。同一 Agent 的多个入口和合法 Document 再次 Pin 时，前置已有书签，保其正文树、阅读位置与有效选区，不叠副本或重新取首位置；不同 Host 的同 SID 仍是不同对象。书签只在其明确显示的 Document 呈现，跨 Document 引用不据此复制主体或推导执行位置。

已固定阅读提供三项明确复制：本窗完整标题、当前所读原回复正文、准确原 Agent 链接。回复复制与本窗正在阅读的记录及范围一致，保段落和代码，不混入 UI 标签、活动说明或输入；阅读保护下的新回复尚未采用时，仍复制当前所读版本。只有已观察摘录或部分正文时明确复制范围，不能冒完整或最新回复；没有回复不以任务摘要或活动文案替代。链接从本书签已确认的原控制引用取得 canonical Session，复用统一 Agent 地址 formatter；当前观察 unavailable 不取消已保存原身份的复制能力，不能借 presentation ID、当前 Region 或同名对象拼地址。

复制复用原剪贴板和错误出口，成功反馈只在真实写入成功后出现，失败保正文及可重试动作并准确说明。鼠标与键盘复制不启动标题拖拽、不导航或修改书签，不丢原有效选区、阅读位置或用户后来主动焦点；迟到回执不把另一个对象标成已复制。三项动作只使用本窗已有文本与原身份，不补读历史／图片、不新建复制或消息事实 Store。

书签跟随 Agent，正文阅读另有准确的 Run／原生来源代次。没有阅读保护时，名称、状态、进展、正文及资料从相关原观察自动更新，不要求原卡片仍挂载。用户处于正文中段、有效文字选区、单条输入全文或资料页时，当前正文和其来源保持，新增内容由就地入口说明并由用户显式采用；不能只保旧 scrollTop、强制滚到最新或把选中原文换成另一条记录。采用新内容是阅读动作，不是发送、导航、恢复或任务接受；当前状态／用量与所读正文的观察范围仍清楚区分。

同一已确认 Host／canonical Session 的 Run 或原生来源改变，先释放旧代次的详细观察与迟到结果，再沿原 owner 确认新代次；新的图片／历史回执不能附到旧正文，旧 Run 的回执也不能写入新正文。无阅读保护时可以跟随准确新代次并说明范围变化；受保护时保原只读正文和变化说明，用户明确采用后再进入新来源。身份、Run、来源或覆盖尚未确认时保留书签与最后已读内容，明确未知／已冻结及原可用查看路径，不猜新对象、宣称完成、自动启动或恢复 Agent。

书签持久化只保存可校验的原身份引用、显示归属、位置／尺寸／顺序和有限的最后观察显示快照；不保存 DOM、回调、授权或独立的 Session／历史／资源事实。快照清楚标为最后观察或摘录，不能冒当前运行、完整历史或资源已重新授权；正文预算只约束该显示快照，不裁掉合法书签集合。重启先恢复原书签与可辨的保留内容，再按可见需求确认原 Agent 和来源，不等待全部 CLI／历史恢复，也不以重启新 Run 代替呈现恢复。正常恢复不更改原工作面、草稿或健康 Run。

读取或保存书签失败时，当前书签和正常工作保持可用，就地持续说明保存／恢复的具体失败与准确重试。未读、未知、单项无效或超出显示快照预算不被当作用户已清空全部书签；原不可读保存资料在成功解决前保留，不用写入空集合覆盖。只有用户明确关闭／取消书签才移除该呈现意图，不删除 Session、历史或工作面；临时离开、过滤、切表面、隐藏、崩溃与正常退出不冒关闭。

标题区可拖动，明确角部把手可缩放；正文选择、滚动、按钮与输入不启动几何手势。未固定的临时阅读面也可直接拖标题：明确拖动意图后，同一窗口转为 Pin 并沿原抓取点移动，不要求先够到底部固定按钮；轻点或没有实际拖动不产生书签。拖动开始后不再被临时悬停关闭或锚点重新定位打断，显式 Pin 按钮及键盘等价入口仍保留。高频拖动按显示帧合并更新，纯移动不反复测量、重排或滚动正文；面板连续跟随指针，释放后稳定停在最后位置。旧定位、旧几何或迟到更新不能把当前手势及已提交末帧盖回；结束或取消释放在途帧，不能随后闪回或继续保存已取消位置。取消本次手势时恢复开始前的临时／书签状态与几何，不留下新书签或取消原已有书签；完成手势后才保存稳定结果。显式撤销本次拖动新建的 Pin 时，可将同一阅读树复原到转 Pin 前捕获的准确模态 slot，但仅限该 slot 仍连接、与阅读面同属原 Document，且原入口仍属于该准确 scope；这是本次撤销的复原，不适用于普通显式取消书签。原模态已关闭、scope 改变或 Document 已变化时，不猜后来挂载目标、不复活原模态；其他已脱离阅读保持脱离，不能暗中重新挂回或重挂正文。

初次 Pin 保留切换前阅读面实际渲染的宽高，不跳到默认书签尺寸；重复 Pin 保已有几何。只有用户主动缩放、重置或视口可达性适配才改变尺寸，正文更新、进入资料或展开单条原文不自动撑大或收小窗口；紧凑排版也不改写保存尺寸。几何变化保持同一正文树、当前可见文字锚点和仍有效选区，单条全文与资料返回同样成立，较晚主动焦点／选区优先。视口缩小或屏幕条件改变时，标题、关闭、重定位及正文始终可达。移动、缩放、前置和重定位均有键盘等价入口；Escape 先取消当前几何操作，再沿单条全文、资料和书签的层级退出，只关闭实际处理的书签，不广播关闭其他 Agent，也不抢用户后来工作焦点。

多个书签复用原 Agent 事实和有界读取，工作量随真正可见且相关的书签增长；无关 Session 字节、后台心跳或源卡片重绘不引发全集合正文重算、磁盘写入或历史扫描。隐藏窗口暂停其详细读取和计时，重新可见只恢复各自准确来源需求。书签集合、几何与复制反馈归 Desktop 呈现 owner，Session／Run、消息、图片、Goal 和导航仍由原业务 owner 提供；这些呈现动作不新增 Core 身份、公共 RPC／CLI 或 Runtime 控制。

### 项目归属、任务状态与恢复

用户新增要求「项目已有图标应显示」「Topic 一句话总结」「working 等改图标加 tooltip」「泳道各列固定、空列收窄」「宽屏多排列卡片，不要无限拉伸」，并问「status unknown 为什么进入 Results」。Focus 复用项目既有图标和 Topic 已有短说明；主题说明与 Context 最近活动各守原义，不把文档首段宣传成自动执行总结。卡片状态图形、按需说明与可访问名称共用既有状态事实，必要请求和失败内容仍可直接读。活动未知留在中性组并明确标为 Unknown，不能冒称已确认 Idle，也不能仅因保留旧完成回复进入当前 Results；最近已知 Response 仍明确可读，不改 Core 状态或丢消息。用户随后明确「每个泳道各列宽度可以不同」：各泳道保持相同状态次序和含义，列宽按本泳道实际条目有界分配；没有条目的状态只保标题带内的低强调入口，不占身体列宽，原状态含义仍可读；数量的可见密度沿[同主题呈现约束](../presentation/focus-context.md#focus-执行台与底部视频编辑器式音轨)，完整状态名、准确计数及 Unknown 说明仍由原 tooltip／可访问名称表达。仅改变数量与图标的呈现不改变分类、筛选或控制资格；列头跟随本泳道，不能用错位的全局位置式列头暗示跨项目对齐。窄面按同顺序分组，宽屏增加可扫描条目而非无限拉伸单卡。原关注、层级与工作面保持，不新增图标、摘要或状态账本；既有泳道的字节、心跳、内容或状态更新不重复查询图标或重拉活动历史。纯断连与混合项目之间的实际归组变化只允许新出现的泳道消费者沿既有项目缓存读取一次，不按卡片或无关会话放大查询。

用户继续指出仍在执行的 Agent 被归到 Idle。进程存活、就绪可输入与当前语义活动是不同事实，沿 Core 唯一观察 owner 判定；裸 running、缺少状态、来源不可用及过期 Working 都不证明空闲，也不证明仍在工作，须明确未知或来源不支持。只有准确当前状态才归 Working，已确认完成/闲置与待输入保原义。未知可收在原中性组，但条目与数量说明不得冒称已确认 Idle，不阻断健康输入、原工作面或 Run；不能只延长 TTL 或按最近工具/eventName/输出/agent_id 猜主主体来修正。Provider 主/子主体疑点须用该协议真实原字段证伪，未核清时保未知，不改原隔离与授权边界。

用户进一步要求：「不是 Agent 的 Terminal 等不应该出现在 Focus 泳道；用户手动在 Terminal 启动 Agent 并聚焦后，应能被识别」。Focus 泳道、项目／状态筛选、入口预览和状态计数只包含 Core 已确认的执行 Agent 或当前原 Run 内已确认的 Agent 观察身份；普通 shell、任务命令、失败或断连的非 Agent Terminal 均不因存活、有窗口或被聚焦取得 Agent 资格。PMO／Mote 的协调 Session 沿既有独立语义边界；Mote 实体的空间选择仍沿前述导航上下文合同。排除列表项不关闭或清空右侧原 Terminal、Tab、Region、布局、草稿、输入、输出、Run 或已记录的时间历史，也不夺走当前焦点。

手动启动 Agent 后，聚焦等与该 Terminal 真正相关的事件触发按需、有界的身份观察；进程与 PTY 关联事实由 Runtime 持有，Provider 语义与已核身份由公开 Core 给出。原 shell、子进程与 Provider 入口的关联必须可验证，不能从输出、标题、命令文本、View 或目录相邻关系猜厂商，也不能把 installed／available 当成该 Agent 正在这个 Run 中执行。识别只读取当前事实，不为了发现而新建、替换、重启、接管或停止原 Run；原工作面仍使用原 Terminal control，观察身份不自动获得受管 Agent 的凭证、恢复、输入计划或生命周期控制。明确 Agent、明确非 Agent、无法确认与不支持分别如实表达；暂时观察失败不撤销受管 Agent 的既有确认身份、不清原 Session／草稿，不阻断健康终端输入。普通 Terminal 的前台观察失败时，最后一次确认及其时间仍可读，但当前身份明确为无法确认，不能把旧 Agent 冒成仍在执行；已核执行实体替换或明确非 Agent 时按事实更新当前集合，历史不改。已确认前台 Agent 结束或换成其他程序时更新当前观察身份，既有历史不被回填或改写。隐藏／无关 Session 不发生探测工作；迟到结果必须仍属于原 Host／Run／进程世代与当前观察意图，不能覆盖新身份、抢回后来选择或刷新任务活跃时间。 Runtime 的公开单次接口 observeForeground({runId}) 只选择原 Run；observed、unknown、unsupported 分开，已观察身份须保同一次连接的 RuntimeIdentity、原根进程／SID／PTY 作用域、采样区间及 opaque incarnation／exec 世代。完整物理执行事实归 Runtime，Provider 身份只沿 Core 的唯一贡献解释；不完整、超额或迟到明确未知，读取资源保持到实际工作退出，不因观察超时或不支持阻断原健康输入。单次采样不冒连续前台通知。

Focus 的归属表达须回答 Context 属于哪个对象、可以回到哪里。已确认 Topic / Mote 使用该对象的名称、原短说明与明确类型，Topic 保留区分所需的真实 Category，Mote 保留实际对象与必要工作上下文；不重复无意义的 Scratch 或 Project 父名。普通 Project / Branch 与 worktree 保原资源归属。Topic / Mote 分类复用现有 rawFS / SOUL 与 Core 的已确认内容身份，Category 和工作上下文只沿原空间绑定；未知不猜类型或父级，同名与多处合法绑定不合并成唯一父树，完整来源和准确位置仍按需可读。

Survey 是独立导航上下文，其已保存探索引用不是新的资源类型。已确认位于 Survey 探索 Zone 的执行 Context 沿原项目泳道集中扫描，不按探索另增泳道或全局来源分段；Survey 来源明确，原探索／Zone 名称按需可读，并保留准确 Tab、Region 与执行身份。不能从当前表面、Browser 存在、Scratch 或 cwd 猜 Survey 来源，也不能因集中呈现把同一 Context 复制成多个 Session。Topic／Mote 与 Survey 的合法展示关系分别保留，呈现简化不改内容归属、执行 cwd、选择或原导航目标。来源投影只消费已加载的原对象、空间绑定与 Survey 引用，不新增目录读取、注册表或轮询。

类型筛选沿同一来源投影组合已确认的内容对象与展示关系：Topic／Mote 沿原内容身份，Project 沿普通项目／Branch／worktree 的已确认资源归属，Survey 沿准确 Zone 与已保存探索引用。Project 与 Survey、Topic／Mote 与 Survey 可以分别匹配同一 Context；不存在唯一父级或仅取首个位置的隐含优先级，不能把组合来源压成互斥类型。类型依据未确认时可单独筛出来源未知，不从名称、近似路径、当前表面或默认分支补成 Project／Survey；位置未知不撤销已确认的内容类型，也不补造 Survey 关系。未限制该维度时仍保原可用上下文。

已确认的 Mote 协调上下文作为独立候选参与同一项目、状态、类型与文字条件及选项计数。协调命中不进入执行集合、项目泳道、执行最近上下文或 Recent Focus。无查找词且无生效条件时保留紧凑协调提醒；查找词或任一条件生效时，匹配的协调结果独立可见，不只限于待处理项。仅查看筛选面板可取得协调元数据以表达准确候选与计数，不改变条件或展开协调结果。协调候选与卡片只消费原元数据，不为筛选或摘要补全扫描会话正文，也不新增目录、历史读取或状态缓存。执行与协调均无匹配时如实表达本地无匹配，原位置和历史仍沿各自准确范围可查。

Mote 的协调 Session 继续沿既有独立协调焦点；从协调结果或紧凑提醒明确选择时，复用原 Mote 导航进入该 Session 的准确 Topic、Tab 与 Region，不写执行焦点和历史。原位置不唯一或尚未确认时保留原执行工作面、Mote 身份与可用能力，要求明确准确位置，不选择首候选或因搜索命中创建、恢复 Session。在 Space 中选择 Mote 实体的准确位置仍不据此改写面板目标或重新分类 Session。图标选择与手动优先权沿[《Space、Folder 与 Topic》](spaces-and-layout.md#spacefolder-与-topic)，类型与背景密度见[同主题呈现约束](../presentation/focus-context.md#项目扫描与泳道)；显示简化不改原精确导航目标、完整按需来源或最近活动事实。

用户此前反馈「泳道里有很多显示 failed 的 terminal，感觉逻辑不太闭环」，随后明确普通 Terminal 不属于 Focus Agent 泳道。普通 Terminal 的失败、中断、结束、退出说明与退出码仍在原工作面及既有 Runtime 历史中可读、可恢复，不占 Agent 的 Attention、Working、Results、Idle／Recovery 数量。已确认 Agent 的进程、任务和连接三轴保持原义：已记录主动停止、异常退出、原因未知分别诚实表达，不能把非零码或终止信号推断成具体原因，也不能用旧任务活动盖住退出事实。归类沿同一 Core 事实，不新增轮询、终端历史注册表或生命周期操作。

原工作面恢复终端并得到已确认的新终端身份后，当前仍关注被恢复终端时，Focus 接续该身份；原 Tab、Region、Group、分割布局与用户当前激活 Region 保持。等待期间用户已选择其他上下文、同 Tab 的其他 Region 或关闭关注时，迟到结果只更新原工作面引用，不抢回关注或激活位置。普通进程重启后仍恢复接续后的关注与原工作面，邻近健康 Run 不受影响；新终端按实际新 Run 表达，不称原 PTY 连续。

项目是纵向分组，宽度与内容密度允许时按固定状态次序横向比较。用户要求减少泳道卡片的最高堆叠：在固定状态次序和可读卡宽内，按本泳道各状态的真实条目数分配整数子列，减少整个项目的卡片堆叠与不必要高度；零态图标收在同一紧凑项目标题带，不再为没有卡片的状态保身体列宽，非空状态仍保各自列头和准确数量。释放后的真实可用宽度交给同一整数分配机制，不降低可读下界、另造 allocator 或按状态猜宽度。等高且仍合法的布局保持稳定，不因字节、摘录或无关会话更新反复改变。宽度调整与必要状态移组仍表达真实事实，正在操作的卡片不得变成另一 Session 的命中目标；原选择、菜单、选区、草稿与工作面保持。泳道是否需要重排取决于本泳道实际有内容的状态数量与可读卡宽，不能因为同一宽度断点把四组状态全部铺成纵向大列表；只有一个有内容的状态时，常见窄栏仍保横向扫描。内容组按实际宽度与内容密度沿同一次序必要分行，零态不各占整行；所有 Context 与状态仍可到达。用户指出「项目的名字还是完整地占满了一整行（或一列）」：项目名与层级归属以紧凑组头表达，不独占项目轴。泳道按已有 Project、Branch/worktree、Topic 事实展开到实际层级，Scratch 的 Topic 不能合并成一个看不出主题的大组。已销毁的 worktree 仍保留独立的历史泳道与明确状态；Disconnected 不等于 worktree 已销毁，缺少事实时表达未知。需要用户处理的事项优先可见；空分组不占大块空态。Working 只接收权威状态确认为运行/工作中的上下文，disconnected、stopped、idle、未知或待恢复状态保持原义，不伪装成 Working、完成结果或进程失败。项目计数区分活跃 Run 与全部上下文。

状态组的行归属与行内整数子列数由同一局部分配结果决定，按每行的真实预算共同降低整个项目的无谓堆叠；不能先给所有组各一列，再任由换行把末行多卡组留成单列长表。同一实际行在可读上下界内均分子列宽度，组宽与真正子列数对应；不沿用其他行的宽度份额或制造空子列。内容不变、原布局仍合法时，增宽不能只因跨过单排容量边界反而增加布局预算下的堆叠；同等合法布局保稳定，不以反复分行造成跳动。分行只调整原稳定状态组的几何，不重挂卡片或把正在操作的入口换成另一 Session；所有 Context、必要说明与原工作面仍可到达。

泳道按真实近期活动组织：需要处理的事项与权威 Working 保持前列，并在各自等级内按最近真实活动新到旧排列；其余项目按用户所选近期活动窗口区分近期、较早和时间未知，近期项目按最近真实活动新到旧排列，较早与未知项目各保稳定顺位。窗口变更只调整哪些已知活动进入近期精排，不改变活动事实或项目保留保证。项目标题显示同一已确认 Host / Project 中任一执行 Agent Session 的最近真实活动，取已有可信活动时间的最新值，不因状态筛选、搜索或收起只统计当前可见卡片；同项目的 Branch / worktree 仍保各自泳道，在项目组内连续相邻，以已确认分支区分。仓库根未登记 Workspace 时，已确认的相同 Host／仓库根关系仍属于同一项目；项目名未确认则使用完整仓库根路径，不借分支名称猜项目名。Topic／Mote 对象与集中呈现的 Survey 也只汇总其已确认 Context，不借邻近目录或展示标签串入其他对象。活动只取已有任务事件与权威活动事实，后台探测、同状态心跳、终端字节、打开视图与 focusedAt 不能刷新活动时间或排序依据；缺活动明确未知，历史访问仍独立表达。聚合复用相关 Session 已持有的事实，不为项目标题拉取完整历史或新增轮询。

真实活动时间及时更新，重排以有界的合并更新生效，避免多个活跃 Session 交替产出时项目来回跳动，也不能因持续活动无限延后。同值与未知保持稳定次序；卡片菜单、改名、键盘聚焦与文字选择期间保原操作对象和命中目标，重排不夺取焦点、草稿、原工作面或健康 Run。该排序只作用于上方项目扫描区，不改变 Recent Focus 本次进入后保持稳定的项目／轨道顺序；现有活动门槛仍为可调整默认。

近期活跃过的项目仍保留，没有活跃 Session 时仅轻量收起；当前项目不因仅剩离线 Context 消失，无当前 Context 的项目也可沿既有有界执行焦点历史中可信 Agent／Host／Project 观察保留只读入口。超过默认活动门槛或时间未知只后置、收起，保可发现的项目数量与展开入口，不删除已保留历史。历史标题明确表达已观察项目与 Last focused／历史访问，focusedAt 不是任务活动；已知 Branch／Topic 只表达原记录，不推断当前归属或未记录的分类、名称、时间与控制权。收起、展开和按原日期窗口回顾只改变呈现，不制造 FocusContext、Session 状态或恢复能力，不刷新任务活跃时间，不建立第二项目／空间名册、状态账本或新的消息读取；原搜索、项目与状态条件继续真实作用，历史未知不冒成 Idle 或 Disconnected。

冷启动和当前 Session 观察未到达期间，历史项目直接以正式卡片的共同呈现骨架显示原 execution focus history 已观察的任务身份，使保存的工作可以辨认，并在当前事实到达时连续补齐。每个项目内按准确 Host／Session 保留最近一次有效访问的任务名、分支／Topic 与访问时刻；缺名称或时间如实保留身份与未知，不从当前目录或显示位置补猜。保存观察的卡片仍只是原事件的阅读投影，不为复用外观伪造当前 Context、Run 状态、输入或恢复资格，不等待历史来源目录、不拉取全部消息；原历史回顾动作保持只读，当前卡片的业务事实与可操作能力仍由原 Session owner 生成。当前 Session 分批到达时只替代准确同对象的保存观察，不因同项目已有另一张当前卡片移除其余保留任务。

启动卡片区分正在读取、读取失败和当前事实未知。只有准确对象的原读取确实待回执时显示对应步骤的加载指示；来源目录读取、当前 Session 观察和 Runtime 接回各守原范围，不能相互冒充。失败保原已知内容与服务窗，未知如实静止，均不能延续无依据的加载或据此判定 Agent 失效；读取指示不替换原未知状态图标或授予输入资格。未观察到的摘要、状态、进度、用量与位置不补默认值；不影响辨认和操作的缺字段直接省略，必要的未知、失败与恢复原因仍沿原 owner 可读。

相同准确 Host／Session 的启动与当前卡片采用稳定身份 key，不以加载阶段、更新时间、数组序号或随机值换身份；同一展示位置补齐事实不额外重建卡片或丢失用户焦点、阅读位置与选择，真实分组和位置改变仍沿原规则。加载反馈只更新原请求对应的可见呈现，不增加驱动整份卡片列表的计时器，不为动画重派生历史、摘要或全部项目；原相对时间刷新也不能因新增加载反馈扩大到无关卡片正文。隐藏、失去可见消费者或请求结束后停止对应动态和额外更新，不能以轮询、读取全部历史或跨 Session 扫描维持加载效果。

当前所在泳道只沿共同主空间已确认的 Region 和原泳道归属派生，独立于项目筛选。Agent/已确认 Agent Terminal 沿对应 Context 的执行归属；非 Session Region 仅按已确认资源 Workspace 与 Tab Topic 唯一匹配已有泳道，候选须有现 Context 已确认的相同 Workspace、资源 Host 与 Topic，不把借用展示 Workspace 的未知归属当资源确认。未知、多候选或没有原泳道时不借执行 MRU、当前 display Workspace 或第一地址高亮，至多标出一个当前泳道。相同项目的不同 worktree、不同 Host 及不同 Topic 仍分别表达，Mote 浮窗保独立焦点。左侧泳道各状态组内按进入当前组的时间新到旧排列，同值和未确认时间保原顺序；每个 Context 初次呈现只采用已有可信状态进入时间，不以最近消息冒组进入。卡片真正换状态组或执行项目／Host／Topic 归属时重记本次进入；同组新消息、心跳、改名、搜索、筛选与收起展开不重排。顺序仅为当前呈现，复用原投影的局部状态，不改变状态、原项目排序、底部时间轴顺序或任务活动时间事实。

### 关注、任务状态与 Run 中断

Focus 表达用户正在关注的工作以及实际任务状态，不以当前 Run 是否连接或已 resume 判断关注关系。断电、机器重启、Run 中断、停止或退出，以及尚未 resume，都不证明用户已取消关注；原 Session 仍保留时，任务留在原项目与当前关注中。关闭 Tab／Region 并保留 Session 也不移除关注；Session 的明确退休或成员移除只沿原 Core owner，不由界面猜测。

任务只沿 Attention、Working、Results、Idle／Recovery 四组呈现。明确待处理请求或错误优先 Attention；其余已确认中断及尚未观察到原 Run 的任务留在 Recovery，不能因旧 starting／working／done、旧回复或曾经活跃而冒称当前执行、结果或空闲。真实中断显示 Interrupted 与直接可读的原服务说明；原因未确认就明确未知，不从 daemon restart 等记录猜断电或用户停止。Run 未观察到显示 Run not observed；当前 Run 健康但活动未知则显示 Activity unknown。恢复与未知混合时组头保留 Recovery，准确数量与各项状态按原事实可读。

主泳道、Focus 入口预览、Space Agents 与 Mobile 公共派生呈现共用同一任务分类，不再按 Run 状态另收进 Disconnected 目录或隐藏当前关注项。保原身份、工作面、草稿、焦点与历史；阅读或打开 Focus 不自动 resume、启动、停止或向 Run 输入，不增加关注实体、状态账本或轮询。

当前轮已确认请求失败、中断或仍在原生重试时，不因旧完成回答、普通 Stop／done、进程仍 running 或终端 readiness ready 进入 Results。沿 Core 已确认的当前失败事实进入原优先待处理组，显示可读原因、错误标识和准确原工作面入口；明确当前工作中的重试保 Working 及失败说明，归属／轮状态未知保持未知。错误分类、主体和成功收敛只由[《模型请求失败与工作结果》](agent-capabilities-and-messaging.md#模型请求失败与工作结果)持有，Focus 不解析厂商文案、聊天或工具文本，不另建完成／错误账本。旧来源、旧轮或子任务失败不能覆盖后来已确认的主轮结果；正常收敛后采用同一 Core 当前事实，历史失败仍可查看。

文件仍在读取时，用户后来选择的 Space、Tab 或 Region 继续拥有当前画面；读取完成不能抢回旧结果，即使两个 Tab 属于同一 Space、都没有 Agent Session。成功读取的文件与 Diff 仍保留在原目标工作面，不丢产出，也不把后来选择的文件记成旧结果。

连续显式打开多个文件时，最后一次打开拥有显示目标，不能按磁盘读取完成的先后决定画面；共享同一次读取也不共享激活权。后来的选择失败或用户离开又返回，都不让更早请求自动抢回画面。等待期间在其他 Space 的实际导航同样受保护，包括从浮窗发起的结果查看。

点击 Agent 输入框里的文件、技能或组件引用时，打开引用中的真实文件路径，按本次输入引用的准确来源展示位置（display Workspace／Group／Tab／Region 及已知 Space／Zone）确定打开落点；同一 AgentSession 的多个合法位置不能被收敛成唯一“所属 Space”。当前主面选择、资源 Workspace 与执行 cwd 都不替代该来源。引用的显示名、Space 身份与文件路径各自保持原义，文件打开仍遵循上述最新选择与等待期间不抢导航的约束。

引用点击是显式查看动作：准确来源位置已确认时进入该已有工作面，文件读取成功后在该工作面可见，不能只在后台放好文件让用户再找一次。多个候选或来源未确认时保原引用、Session 和草稿，提供准确选择／重新读取入口，不按列表首项或资源目录猜位置。读取期间用户后来去往别处或打开其他文件，仍拥有最新画面；失败沿既有错误面说明并保留原 Session 与草稿。低层文件与 Browser 准备本身继续保持当前主工作面，不承担此入口的显式导航。

用户追加指出「PMO context is isolated 这种冗余，顶部的标题栏也是冗余，白白浪费一行空间」，并希望「status bar 活跃 Agent 的观测和左下角 Focus 选项合并」。Focus 不重复显示已由导航表达的工作面标题、隔离说明、总量脚注或独立项目标题行；搜索、项目过滤和必要动作贴近内容。整窗 Agent 观测归左下角 Focus 入口：运行数与待处理数可扫描，待授权、需回复和错误的明细及直达原 Session 的动作仍可到达；不在状态栏另复制一套计数和展开入口。待处理须可发现，PMO 与执行上下文仍保留其身份边界，不能为了合并视觉而隐去有效请求。PMO 提醒随其原请求新增、变化与确认及时更新；即使执行上下文没有其他变化，也不能漏显或滞留提醒。资源观测沿用独立按需入口。

Focus 入口与只读悬停／键盘预览消费同一执行 Context 集合和原任务分类；待处理优先，其次 Working、Results 与中性恢复组，至多展示三条真实摘要。执行 MRU 不能标成当前所在或挤到待处理前；原工作面的 Current 资格仍沿上述准确 Region 合同。摘要优先显示待答、错误、观察缺口和恢复原因，再显示已有回复或活动及真实 Project／Topic／Executor 归属；只读查看不选择 Agent、回答请求、Pin、恢复 Run 或新增历史／资源读取。主按钮继续原 Focus 导航，完整处理沿原 Focus 和 Agent 阅读入口。共享状态事实唯一见[Agent 全局状态](agent-capabilities-and-messaging.md#agent-全局状态唯一事实与投影)，此处只持有 Focus 范围与排序。

Focus 顶部用同一条操作栏分别承载左侧过滤与右侧当前工作面，不再叠加标题行。右侧默认呈现完整原 Tab 时，标题复用该 Tab 的显示名，标题右键、显式 `Tab actions` 与键盘菜单中的 `Rename Tab` 只修改本次准确投影的 Tab ID；不能因所选 Context 是 Agent 而改成 Agent 名或修改其 Session 名。Tab 与 Agent 名的独立身份及默认派生沿[《显示名与身份》](spaces-and-layout.md#显示名与身份)，Agent 命名及其动作留在明确的 Agent 身份入口。回到原 Space、查看待处理请求与关闭观察投影仍复用原导航及请求 owner，不因此管理被观察 Agent 的生命周期。显式只查看 Region 时保留原表示身份与控制边界，不由裁剪范围另建命名合同；只有一格的 Tab 仍保留 Tab 身份。 同一观察投影的收起仅保留操作栏常驻快捷入口，`Tab actions` 与标题右键菜单不重复该动作；快捷入口仍只收起投影。标题右键与显式入口复用同一 Tab 菜单内容，以准确 Tab 名和作用范围确认对象，仅提供原 Tab 改名与 Focus 显示级别；Agent 的停止、重启及请求处理不混入 Tab 菜单，仍在其明确 Agent 入口操作。保留的直接 Review 入口明确对应原 Agent，并沿原请求 owner 查看；本格分屏、地址与历史仍由原 Region 菜单持有，不能因表面相邻而合并或删掉。选择菜单动作后由其原目标承接焦点，Escape 返回本次仍可用入口，较晚主动焦点优先；收起后的第一键沿本节原检索控件合同。

右侧操作栏直接提供 `View in Space` 和 `Chat about this tab with Mote` 两个常用入口。查看 Space 沿本次已确认的完整 Tab 与展示位置定位，保原 Group、Region 与输入策略；不能借当前普通工作面的活动 Tab、同名 Tab 或同一 Session 的第一个位置替代正在显示的对象。无法确认位置时保留原工作面并解释真实缺口，不能导航到猜测的目标。

与 Mote 讨论引用点击时正在显示的准确 Tab 身份，完整 Tab 多格或同一 Session 多位置也不改成 Agent 名称寻址；显式只查看 Region 时仍引用其所在的准确 Tab，不新增 Region 命名合同。讨论复用已有真实 Mote 的讨论、输入与公开 Core 能力，以及既有 Tab 寻址与检视表示；不另造发送系统、影子 Mote 或按名称猜收件人。源 Tab 和原 Mote 的未发送草稿保持独立，已创建的讨论沿其原输入 owner 保留请求；准备、配置或投递未确认时如实给出原目标与保留的请求，不冒称已发送或已回复。只有显式操作可以建立讨论或提交请求，悬停不发送；后来的选择、关闭与主动焦点优先，迟到结果不改投目标、不重开已关闭的浮层，也不抢回原主工作面。 用户要求 Chat 下拉选择任一 Mote 并记住选择。Focus Chat 收件偏好只保存明确选择的准确 Mote 身份，沿现 Mote UI 持久 owner，与浮窗当前目标独立；未明确选择时保现有浮窗目标解析，选择后跨执行上下文、页面与普通重启仍用同一身份。下拉查看与选择只改 UI 偏好，不打开／改投浮窗、创建讨论、发送请求或控制 Run；点击 Chat 才固定本次收件 Mote 和正在展示的准确 Tab，沿原讨论 producer。选择变化／浮窗换目标不改已开始请求的收件人，重复 pending 点击仍受原锁保护，迟到结果不抢后来焦点或重开面。选项来自同一 Scratch 文件快照的真实 Mote，归档对象明确标识仍可明确选择；普通 Topic 不混入，已存目标缺失、读取失败或身份未确认时保原身份并明确该次未发送，不静默借默认／同名／其他 Mote，也不重建目录或 Session。其他已确认对象与原健康工作面仍可用。偏好保存失败保本窗口选择与原能力，沿同 owner 给可读非阻塞说明，重选同一准确身份也可重试保存，不冒重启后已记住。

Focus 中单格、多格、混合格、只读或原归属待确认时，Agent／Terminal 名称、执行 Host 和该格菜单统一留在原 Region 内，由同一 SessionPane/Header 呈现；不因 Region 数量把身份或动作移到顶部工具栏。顶部保原准确 Tab 身份及 Tab 操作，Tab 与 Agent 命名边界仍按本节既有合同。悬停菜单与原触发器保持可自然移入的连续指针路径，不要求用户快速越过空档；移出两区、Escape 与外部点击沿原关闭边界，键盘及触屏入口保持，悬停不夺输入。History、观察刷新和精确格动作沿原 owner，原正文、选区、草稿、读取和较晚主动焦点保持。关闭 Focus 只收起观察投影，单格不增加关 Tab、X 或生命周期动作；多格原关闭入口与未保存确认保持可达并绑定原精确 Region，不以名称或当前焦点猜目标。

Focus 的搜索与筛选共用原单操作栏。宽栏直接表达当前项目、状态与类型条件及编辑／移除动作；可用宽度不足时自动收敛为搜索和同一个筛选入口，完整条件、选项搜索、状态多选、清除及历史正文入口在同一面板可达，不增加第二行工具栏或另存一份条件。打开、连续多选、搜索选项、完成和 Escape 均有键盘等价；缩窄、隐藏条件片和悬停不夺当前输入、改变条件或关掉原工作面。显式操作后的焦点交还本次仍可见的入口，后来主动焦点优先；宽窄变化导致原入口不可见时交还同一筛选入口，不聚焦隐藏控件或无条件聚焦终端。

项目来源目录或泳道归属资料读取失败时，Focus 沿原顶部工具带提供持续可发现的非阻塞服务入口；正常不显示，点击后可读准确失败步骤、当前未知范围、仍保留的能力与完整原因，并可对原失败来源执行明确的只读重试。重试复用原读取 owner，不导航、恢复或控制 Session／Run，不新增轮询、目录或服务事实 Store；重试中仍保原失败与未知说明，只有原来源确认恢复后才移除入口。查看、收起或已读只改变呈现，不冒称故障已恢复；来源再次变化沿同一入口表达。读取失败不删除 Context、近期项目、原位置、草稿或已读内容，不撤销健康输入及 Run 能力，也不把观察缺口改成已关闭或已空闲。必要的 Agent 待处理请求、真实运行失败与恢复服务说明继续在原准确工作面可达，不因收紧这类来源提示而被隐藏。

Focus 的 `Tab actions` 菜单沿共享下拉菜单的悬停、点击与键盘入口；悬停查看及自然离开不改变当前输入位置，也不继承上次显式打开菜单的焦点目标。自然关闭后，再从身份区用键盘打开时，第一键能直接操作菜单。显式点击或键盘打开菜单后，Escape 将焦点交还本次打开的控件；从身份区打开的右键或键盘菜单回到当前身份按钮。行内改名按 Escape 取消后回到同一身份按钮，名称保持未提交。选择改名时输入框获得焦点；查看 Space、关闭 Focus 工作区或查看请求后，由所选动作的目标承接焦点，不能被菜单关闭时的焦点恢复拉回，也不无条件聚焦终端。外部点击或改名失焦提交时，焦点继续跟随用户实际选择的新目标。

显式选择 `View in Space` 后，第一键进入实际激活的原 Region；用户不必再点一次终端。显式关闭 Focus 工作区后，第一键进入仍可见的 Search contexts，不能落在页面空处或送给隐藏终端。仅这些明确动作交还输入焦点，后台更新、指针选择与其他工作面切换不自动抢焦点。

### 时间轴的事实、窗口与历史

Recent Focus 只读取同一份持久化 execution focus history 与 Core 已持有的消息事实，点击片段回到对应已有 Session；当前焦点和最近历史可扫描，完整轨道可以展开与收起，轨道内容独立滚动。Current 只表示原共同主空间标定中已核完整展示位置对应的 Agent／Terminal Context 与当前项目轨道；执行 MRU 仍独立用于原阅读默认与生命周期，不代替当前 Region。仅收起工作面不清主标定；File、Browser、合法父级、未知位置或没有本窗事实的 Context 不借旧 MRU、高亮其它历史项目或增造轨道。Locate 与 Current 使用同一资格，只展开／滚动原轨道，不改查询窗口、Reader 或输入。当前 Agent 显示名沿同一 Session 的既有命名 owner，Agent 改名后时间轴的当前身份同步更新；历史片段保留发生时已观察的名称、身份与时间，不将当前改名反写成历史事实。用户要求「下面的时间轴，高度要支持可调」：顶部边界提供完整位于时间轴布局内、易命中的拖拽条，也可用键盘调整，记住用户高度；收起后再打开恢复此前高度。拖动被取消时恢复此前保存的高度并结束本次调整；后续普通指针移动或释放不能继续改变高度或保存已取消的调整。窗口收窄或变矮时仍保留主工作面的有效操作空间。窄窗口工具栏换行后，空间足够时仍须保留标尺和至少一条完整轨道；布局临时需要更多高度时不改写用户保存的高度，变回宽屏后恢复该高度。时间位置取自真实 focusedAt 事件；片段终点只使用已知的下一次聚焦事件，未知终点明确保持开放，不补造未来十五分钟或精确运行时长。

用户反馈「时间轴现在不准，Agent 明明在跑，在时间轴上却没有对应的条」。时间轴须区分当前 Run 在线、已确认的工作状态区间与用户关注记录：即使没有关注事件或已保留消息，仍活着的 Run 在窗口包含当前时刻时也可见；缺少 Run 开始时刻时明确未知，不以 Session 创建时间冒充当前 Run 寿命。工作状态区间消费 Core 在接受准确 Session／Run 的权威语义转移时沿既有持久时间轴保留的结构化观察；已结束、停止、退役或关闭工作面的 Session 仍按所选范围显示真实保留的过去 working 区间。当前开放区间须有已知起点和仍有效的当前 working 观察；有界历史的裁剪或覆盖不足只说明历史可见范围，不能覆盖或否决同一准确 Session／Run 已核、仍有效且起点已知的当前 Working；当前事实与保留历史分别表达，缺少真实起点或观察失效仍不补造连续区间。失联、时钟倒退、Run 更换或观察缺口不补成连续执行，也不延伸到未来。缺起止、未记录、来源不支持与保留裁切分别明确，消息、工具、关注、Session 创建或进程在线不补造 working；区间表达观察到的语义工作状态，不冒 CPU 执行或任务成功。状态接受与历史持久化由原 Core／Store 唯一 owner 负责，同状态心跳不移动起点或重复添历史；普通重启后，可见准确 Context 缺时间轴投影时，沿原只读入口恢复已持久的区间，不依赖前一页面内留存或要求先打开消息来源。已有投影与隐藏 Context 不因此新增读取；失败保留原工作面并说明尚未读回，不能将空白当成没有工作。持久化失败说明覆盖缺口但不拿走健康 Input／Run。访问片段保持原 focusedAt 与已知下一次关注事件语义；历史查询和未来窗口不因当前在线而补造过去或未来的运行事实。所有事实沿既有 Core/Store 来源，窗口、预览与返回不控制 Run，不新增生命周期或历史注册表。

用户进一步要求「Recent Focus 可以支持查询任意时间」，默认「过去三小时到未来一小时共四小时的窗口」，并支持「快速切换窗口大小」。用户可选择任意日期与时间、前后移动同样大小的窗口，并一键回到当前窗口；默认窗口随当前时间缓慢前移，历史查询窗口保持所选位置。窗口选择不改变执行焦点或原工作面。像剪辑软件那样的竖线贯穿标尺与各 Context 轨道，表达真实当前时刻；当前 Context 的选中标识与时间位置分别可辨认。未来部分保持为空，窗口里没有已保留记录时如实说明；任意时间可查询不等于捏造完整无限历史，记录保留边界与未知区间须可发现。

用户要求时间刻度按整时间显示，与查询窗口大小分开：默认按所选时区的每日0点显示6小时主刻度、3小时短刻度、1.5小时更短刻度与45分钟细刻度；可改为均匀间隔加偏移（默认从日界前一小时起、间隔2小时），或保留原自由窗口刻度。均匀模式沿同一时区钟表格线，平移和跨日不重新定基准；夏令时不存在的本地刻度不造记录，重复时刻以不同偏移可辨。窗口档为30分钟、1／2／4／6／8／12／18／24小时、1.5天和2天；默认过去3小时到未来1小时仍保持。所选时区用于标尺、日期查询、范围与消息时间说明，记录与位置始终保原绝对时刻，不改历史身份；模糊或无效本地时间可辨并保此前有效窗口。模式、时区、缩放与名称宽度不改变正文读取来源、原工作面、选区、滚动或健康输入；更大范围不暗示完整历史，不扩大原有界页批次和显式继续更早记录。

用户新增要求「像剪辑软件一样用鼠标左右浏览历史，窗口大小除了数字选择也要有＋／－」。横向滚轮与 Shift＋滚轮连续平移同一时间视口，普通纵向滚轮继续浏览轨道；消息、片段、身份列和日期／选择／正文控件保留原点击与输入。同一时间画布的空白区也持续接受横向滚轮与 Shift＋滚轮；窗口内没有已读记录或暂未读到事实不构成日期导航边界。身份栏（含没有节点的空白名称区）与正文／输入控件不接管时间平移，普通纵向滚动保原行为。＋放大到更小的时间范围，－缩小到更大的范围，与原窗口选择和 Now 共用同一查询位置；历史查询不因缩放跳回当前时刻。高频平移和缩放只改变视口，不改执行焦点、原工作面或健康输入。

同一来源的已读正文与时间视口分开：改变窗口位置或大小只筛选同一份有界已读记录，不能每次清空正文并重新读页。首次明确进入另一阅读模式可沿既有有界批次读取；继续更早记录和刷新仍为明确动作。旧窗口的迟到结果不得覆盖新的呈现、焦点或选中消息；Context、Host、Run、Source 或阅读模式改变、隐藏和收起继续沿原世代边界停止新增页并废弃失效结果。查询覆盖尚不完整时如实表达，不用反复重读、第二缓存、后台扫描或轮询制造完整历史。

用户要求「时间轴拖拽时项目和 Agent 位置不要大变化，大顺序进入页面算好，不能随滑动跳」。本次进入 Focus 时，项目按已有最近任务活动事实组织，Agent 按可读名称与稳定身份排列；活动不足明确未知，不能把关注时间、后台字节、心跳或未读资料当成任务活动。左右浏览、缩放、Now 更新和后来活动不反复重排本次已知项目与 Context；同名对象不合并，窗口暂时没有事实而隐藏后重新出现仍沿原顺位。新增对象不夺已有阅读位置，下次真正进入再按新资料组织。顺序只管呈现，不改变项目历史归属、Session／Run、焦点、工作面或读取来源；原只显示窗口内事实与有界已读记录保持，不能为固定绝对位置保留空历史墓地。固定正文、选区、滚动和后来意图不因重排丢失。

项目分组与关闭后历史回顾：时间轴按项目组织所选范围内的真实已保留事实；当前窗口包含 Now 时，可另外呈现已核的当前在线观察。Session 是否仍有打开的 Tab／Region 不应决定历史事实是否可见；关闭工作面、停止 Run 与 Session retired／unknown 是不同事实，不能混成同一个“关闭”状态。查阅历史只读，不因轨道存在、查询或展开分组而恢复 Session、创建 Run 或改动原工作面；可恢复时的继续工作须为另一个明确动作。项目／Branch／Topic 的历史归属仅凭已有可信记录表达；只有当前归属时明确标成当前资料，缺历史身份、归属、时间或记录覆盖时保留缺口说明，不按路径、当前分支或时间邻近猜测。已销毁 worktree 不使仍保留的历史消失；范围外或没有可定位事实的旧 Session 不为完整性占轨，无时间消息沿既有记录入口可读。关注片段、消息和已核工作／在线观察各保原语义，不能把关注时长或当前 working 外推为历史执行。

历史展示沿唯一 execution focus history 呈现身份，保留发生时实际观察到的只读归属，不持有第二份运行状态或消息账本；已有记录缺资料仍明确未知，不迁移或补猜。紧凑呈现见[同主题视觉合同](../presentation/focus-context.md#时间轴与历史回顾)。

唯一 execution focus history 同时受最多 2000 个事件与 JSON 序列化最多 512 KiB UTF-16（JSON.length × 2）约束；超限裁掉最旧的完整事件，不截断已观察名字或改写历史归属。该限额只保证 Focus 新增历史材料有界，不能代签整个工作面存储配额；查询须沿既有保留范围说明呈现覆盖边界。

完成或关闭条目的项目表达须区分发生时已观察的归属、只知道当前或保存工作区的资料，以及确实未记录。若同一 Host／Session 的保留身份只有一个非冲突项目，可以按「已观察 Context 归属」组织已读输入，但明确消息发生时的项目未记录；缺资料、有冲突或 Host 不匹配则保持未知，不从正文、路径、当前分支或邻近时间补猜。同一 Context 的关注片段与输入如采用不同归组口径，原因在按需说明中清楚，不能让已知的观察被无说明吞掉。

未被关注过但仍由 Core 保留的 Agent 消息来源也应可发现并按需读取；发现来源不代表记录已经覆盖所选时间，尚未读取的来源须明确可继续查看，不能以空轨道代称完整历史。来源发现与正文读取分别有初始批次边界，窗口、展开或无关输出不能触发所有归档来源的全文扫描。

用户反馈「时间轴怎么感觉缺了很多」。时间窗回顾不能因改选输入来源而抹掉其它已读、有效且位于窗口内的真实事实；同一有界阅读窗保留多来源事实，达到共同容量时裁完整记录并说明被裁范围，当前固定正文与选区保留。已读、尚未读取、时间未知、当时未记录、来源不支持/不可用与保留容量不足分别可发现，并有原就地阅读/继续动作；空白不能冒称没有发生。查询不进行全来源后台扫描、不新增 Runtime/历史账本或第二读取 owner；当前工作状态不能外推为未记录的历史工作区间。

Focus 当前输入来源的自动观察不可用或阅读窗已冻结时，原输入记录／覆盖入口必须持续说明哪一步不可用、已知记录仍保留，以及显式刷新或读取最新的动作；它只说明服务状态，不新增消息、时间条或后台读取，不阻健康输入、不清原正文与选区，隐藏及来源身份改变继续遵循本节既有有界阅读规则。原 reader 已明确报告窗口不完整时，也沿此入口说明已知缺口与原显式读取动作，不把已知裁剪或重校验断档仅说成尚未读取更早记录，也不自动补读。


#### 退役历史的保全与维护

退役历史的保全与维护边界：只读历史描述沿唯一 AgentSession Store 保存，累计退役身份与恢复上下文按[Durable Runtime 健康](session-recovery.md#durable-runtime-健康)完整保留，不能按固定条数或共享文档字节淘汰。单条字段与真实存储失败仍沿原边界表达，来源缺失如实 unknown，不能把未覆盖说成没有发生；原生文件不删除。文件维护失败须留下可核对的告警与重试动作，不能让已成功落账的 create/resume/retire 失败或回滚健康 Run，也不能阻只读历史返回。累计事实保全不代签 Provider 原生来源完整性，也不允许加第二份历史账本。

#### 输入、回复与作者来源

时间轴展示同一次有界已读对话事实中的输入与 Agent 回复：输入归准确收件 Context，回复归原发言 Context；使用共同纯记录投影与原正文／资源／来源，不从终端字节或关注事件猜消息。已读记录在真实当前时刻内及时可见，不等待缓慢 UI Now tick；真正未来和无时间记录仍沿原窗口及无时间入口表达。作者区分明确人类、已核 Agent 与未知；输入与回复的事件方向独立于作者，不将原生 user 角色或投递回执冒成作者／回复／成功。原生 user 角色、条目种类和 source=user 提交入口不证明人类；已核 Agent 输入不冒称 Human，未记录发送者的提交仍以「Prompt · Sender not recorded」可读。消息标记能查看时间、原 Context 和正文，并可回到同一已有 Session 的原工作面；按需查看不修改焦点，不复制持久化对话，不创建第二份 Runtime 事实。已核发送者为 Mote 时，消息身份复用该 Mote 已有头像 owner；仅有名字、正文或未知归属不能猜成 Mote，不改变原记录作者、身份或时间。单条 Agent 消息的按需说明可显示已核发送者及其当前 Project／Branch／Topic，并通过明确动作跳到已有发送者 Context；查看说明本身不导航、不写 focus history、不创建或恢复 Session。当前资料与发送时事实分开，缺作者、归属或资料如实未知，不能按名字或正文包装猜发送者。原记录 ID、时间、同正文重复输入和原 Context 身份保持；全来源与无时间可读见[用户输入来源](conversation-mode.md#用户消息从-provider-原生会话取得)，本面读取预算见[共同消息的有界阅读](#共同消息的有界阅读)。 消息标记优先保留原作者头像。近邻头像可在原时刻附近局部错开并用定位线表达准确原时刻，最多移动半个入口宽；同刻两条周围有空间时仍逐条展示，不能只因加大的透明命中框相交就合成数字。只有局部有限空间内无法让最终可见图形与点击入口互不相叠时才形成临时数量入口；分组后重新按最终入口盒判断邻居，不按固定时间差、聚合卡宽度或相邻记录传递链吞并本可独立显示的消息。缩放、平移、窗口变宽后能放下即恢复逐条入口；边缘约束只调整展示位置，不改原时刻。数量组不冒新作者／时刻，成员沿原来源次序可逐条点击、键盘选择及阅读，保原ID／index、未知时间和全部记录。此规则同时约束 Focus 消费的共享对话轴；不改变共享 speaker 判定、Ruler 阅读范围或 Provider。

消息预览复用共享浮层的优先级与打开、关闭协议；窗口或音轨尺寸变化后仍贴近本次查看的入口且保持在可见窗口内，原正文选区与关闭还焦不因呈现位置改变而丢失。观察和尺寸变化不改变 Region 焦点或原工作面；显式 Context 返回继续沿原导航动作。固定消息阅读期间，音轨标题带上的时间导航与缩放控件仍能直接命中，预览不能盖住它们；平移使原标记离开窗口后，已打开正文与选区仍可读，不能用关闭阅读面换取操作空间。

消息标记、预览与显式返回消费[共同记录引用](conversation-mode.md#共同对话与原生记录)。返回先由原空间 owner 选择已有 Session／occurrence，再由其原对话阅读组件定位准确 source／record；同正文不同来源和不同记录分别可定位，缺时间不影响引用且仍保持 unknown。单一短命 client 阅读意图冻结原 itemRef 与 occurrence，完成、取消或后续选择后释放；来源变化、目标不可呈现或未知时保留原引用、诊断、已读正文和当前阅读位置，不跳到相似记录、不全目录或无关 Session 扫描。读取仍走原公共 history 能力，有界加入既有在途读取；隐藏只取消本次观察，不能发送、恢复或创建 Session／Run。定位原输入沿[Mailbox 原入口合同](conversation-input.md#邮箱记录一键定位对话)，Focus 对原回复的查看不扩大 Mailbox 的用户输入语义。

用户反馈「hover 时间线上的头像面板太缺乏设计，信息不清晰、不现代，出场交互简单」。时间轴的轨道身份检视首先回答对应 Context 当前或已保留观察是什么；消息标记检视首先回答真实作者、接收 Context、记录时间和消息内容。快速悬停只提供轻量可读预览，显式点击或键盘操作才固定完整阅读与动作；身份、时间和来源各表达一次，不以重复姓名、空字段表格或当前资料冒充历史事实。当前项目、Topic 一句摘要、真实最近活动按同一现有事实展示，历史资料不完整和发送 Run 未记录用紧凑且可展开的明确说明。悬停意图、可自然移入阅读、键盘与触屏显式入口、较晚主动焦点优先及 reduced-motion 都必须成立；原固定正文、资源、选区和控件命中、未知身份及有界阅读预算保持，不能用重挂、自动导航、查询轮询或关闭阅读面换取视觉简洁。 Zone/Tab/Region/Session沿原实体身份引用，检视和显式返回仅改变对应呈现绑定，不能将当前表面或项目标签作为唯一实体归属，也不建立第二份读取或注册表。 内容只含资源时仍提供诚实的资源提示，悬停不下载或加载资源；固定后复用原共同正文。已固定阅读不被其它标记的悬停替换，关闭、来源或Context改变、隐藏及卸载废弃迟到计时，不能复活旧检视或关闭后来固定的阅读。 工作、访问、在线及观察缺口沿同一轻量检视协议读取对象、事件、可信起止／时长和来源，替代长原生 title。工作起止沿 Core 原 Run／观察；访问结束仅已知下一次 focus；开放、unknown 与 observation-gap 不补成 Now 或连续执行。裁窗不改原起止，0时刻仍有效；可信时长或明确 Observed for 下界复用共同 duration 格式。历史项目只用该片 identity；当前项目／任务／活动显式标为 Current，缺失诚实说明。浮层的迟到意图同时受本次对象、Run、语义及来源约束，不用 Reader MRU 代替被检视轨道；查看不新增读页／资源读取。

用户进一步希望「如果那个 Agent 自己还执行了的话，在 timeline 上也可以去关联起来」。消息与发送者执行的关联只消费公开 Core 已核的原 message/source、Session 与发送 Run 引用；Run 改变或引用缺席时不把旧消息关联到新执行。可展示同一 Run 的真实在线／working 观察，不用正文、近邻时间或关注事件猜因果，不把投递回执当执行、回复或完成。只有作者身份时仍可查看发送者当前 Context，但不能把当前工作说成本条消息的执行结果。不创建第二份历史或关系注册表。

Focus、Space、Goals 的共享导航只引用[Work 导航上下文](spaces-and-layout.md#worksurveyrecall-与-mote-的导航上下文)。切换表面、选择泳道条目、调整比例、收起音轨时，原 Tab、Region、Session、Run 与健康工作面保持；Focus 与 Space 之间不能因 portal 目的地变化重挂载已存在的终端、Browser 或编辑器。分割树与原组地址仍归 durable Workbench，Focus 只改变投影。同一准确呈现位置在 Terminal／对话模式交接的可见帧中只显示一份原分割树，不能将保留的新旧工作面叠成额外格。明确关闭一格后，原准确 Tab／Group 中仍确认存在的 Region 继续呈现；同一准确展示地址仍存在时，原 Space／Zone 归属不再匹配只产生持续、非阻塞的服务说明，不把健康工作面替换成整面位置错误。原空间选择保持，沿原导航 owner 显式确认当前位置后才更新归属；准确地址本身缺失时仍保原引用并给出位置选择，不能从其它 Group／Session 或首候选猜落点。目标暂未出现或恢复事实未就绪时保留原内容与可见说明，自动尝试接管，不以空白或删除身份代替恢复；每条正常分割分组及其非选中 Tab 都必须保持可恢复。

执行 Agent 在任一合法呈现中的显式语义聚焦，包括在 Space、Survey 中点击或键盘进入 Region、从 Focus/Goals/Quick Switcher/Topic 定位时，复用本节同一 execution focus 写入入口；该语义记录不覆盖各导航上下文的空间选择，一般空间选择继续由前述导航 owner 负责。最近上下文入口对同一 Session 只显示一个最近位置；同一 Session 内切 Activity/Terminal 不重复记录切换、不创建第二份历史。重启先恢复历史、当前 Session 和原 Tab/Region，再尝试续接。

主区、音轨与工作面各自拥有明确滚动边界；增长的历史不能挤掉主区，空 registry 壳不能截走点击、滚轮或输入。右侧减少重复标题，恢复/未知/真实失败显示既有服务窗语义并保留输入能力。涉及这些热路径时，正常活跃终端连续向上阅读与工作量边界同时按[《Terminal 连续向上阅读历史》](terminal-reading.md#terminal-连续向上阅读历史)验收。视觉尺寸、密度与控件语言只定义在 surface-density 的同名章节。

### 共同消息的有界阅读

Focus 查询旧时间窗口时，不能把尚未读取的原生记录写成「没有消息」。时间轴保持一个按需阅读 Context；当前 Context 的最新输入沿共享事实取得，用户也可明确选择别的 Context 查看输入而不改变执行焦点。原生记录没有时间时仍能从 Focus 的输入入口查看原正文与来源，不补造横向时间位置。旧窗每批最多读取三页、每页最多三十条原生 record，正文窗口至多保留九十条原生 record；继续读取沿真实不透明游标推进并有界轮换，当前预览正文与其选区保持可读。未到读取快照边界明确说明覆盖不完整，不能凭某条消息时间较早推定已读完；来源发生变化时保留旧内容，由用户明确刷新。隐藏、收起或换阅读范围后停止新增页、废弃迟到结果并释放无消费者正文；已经发出的单页读取按公开能力处理，不能为取消界面读取而停止健康 Run。
