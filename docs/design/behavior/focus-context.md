## 执行 Agent 焦点历史与 PMO 上下文隔离

执行 Agent 与 PMO Teams Agent 属于两套不同的上下文。用户在 Space、Focus、Goals 之间切换时，只沿用当前执行 Agent 的身份、Workspace、Tab、Region 和焦点；打开或切换 PMO Teams 不得改写执行 Agent，也不得把 PMO Session 放进执行 Agent 的历史。

执行 Agent 焦点由一个明确的全局导航上下文承载：当前 Session 和真实聚焦事件共用同一份有界持久化记录。最近上下文入口按最近使用顺序从该记录派生，同一个 Session 只出现一次；时间音轨保留记录中的真实重访位置，不以最新位置覆盖旧事件，也不回填从前未保留的事件。任何执行 Agent 的打开、选中或跨表面跳转都通过这一上下文记录；切换主表面只读取它，不另猜一个“最近变化的 Session”。历史可以被 Agents 界面作为可操作的最近上下文入口，也作为只读上下文提供给 PMO Teams；PMO 只能观察这份执行上下文，不能把自己的交互写回去。

PMO Teams 有独立的当前 Session/Tab 焦点，只由 PMO 浮窗和 PMO Topic 导航使用。PMO 打开、恢复、提交消息和切换 PMO Tab 都更新 PMO 焦点；从 Focus 的待处理提醒进入时，须激活该请求所在的原 Region，不能因同 Tab 的其他格正在激活而选错 Session。关闭 PMO 后回到之前的执行 Agent 上下文。执行 Agent 历史和 PMO 历史不合并，两个身份在 UI、持久化和提供给 Agent 的上下文中都必须可区分。从 Focus 提醒打开后，原提醒经 Core 确认收起时，关闭浮窗应把键盘焦点交给当前仍可见的 Focus 检索控件；原入口仍可用时优先归还给它。用户已主动聚焦其他可见控件，或主工作面已切走时，不得把焦点拉回之前的 Focus。从持久状态恢复为打开的 PMO 浮窗，关闭时没有可证明的原入口，就把键盘焦点交给仍可用的常驻 Mote 入口；只交还 DOM 焦点，不改执行 Agent 选择、历史或 Run，仍遵守该段既有的较晚主动焦点优先级。入口不存在或处于明确隐藏、禁用的范围时不强行聚焦；已关闭的浮窗收到关闭请求不触发焦点交还。

Focus 的 Mote 待处理入口在窄栏仍能辨认当前 Mote、真实待处理数量和打开意图。鼠标与键盘沿同一入口进入该请求准确的原 Topic、Tab 与 Region；执行上下文、原草稿及较晚主动焦点继续遵守本节既有边界。空间不足不隐藏必要数量或打开动作，名称与数量沿原身份和待处理事实 owner，不因呈现另建状态、读取或投递。

## Focus 执行上下文、项目泳道与底部时间音轨

用户进一步要求 Focus「达成熟产品水准，交互与性能远超竞品，所有功能自己测试满意」。质量以现有 Focus 的完整使用流程成立为准：从入口预览、辨认和筛选上下文，到处理请求、查看结果、在原工作面继续工作、查询时间音轨并返回，再到布局调整、跨表面切换与重启恢复；各功能既能单独使用，也能连贯完成真实任务。鼠标与键盘、宽窄窗口、空态及恢复状态都须可理解、可到达，阅读和输入不能被操作栏、浮层或滚动边界阻碍。自行体验验收须记录实际操作、可见结果、响应成本与保留的原身份，不能以组件测试通过或安装成功代替；发现的缺陷与未验证边界如实保留。成熟度与竞品优越性是用户目标，只有绑定对比版本、同等数据和任务条件的证据才可形成比较结论，不能将目标写成已完成事实。事实来源、性能、连续阅读及身份保留继续沿用本节与[《Terminal 连续向上阅读历史》](terminal-reading.md#terminal-连续向上阅读历史)的既有约束。

用户补充：「focus 按钮的 hover 感觉信息可以包含一些动态信息，更丰富一些」。Focus 入口的悬停与键盘聚焦预览呈现当前执行事实：Working、Attention、Results 与 Idle / Recovery 数量，以及当前关注和少量优先需要处理、正在工作或已有结果的上下文。每项用任务名、项目归属与最近已知活动回答“谁在做什么”。归类、名称、摘要复用 Focus 的同一事实来源，PMO 协调上下文保持既有职责边界；Disconnected 以紧凑数量表达，不扩成历史名册，即使它是当前关注项也不展示详情；原关注选择与 Session 身份仍保留。未知与空态如实呈现，不把存活或旧输出推断为正在工作或新结果。

预览随真实状态更新；关闭后不保留详细预览订阅，不因无关 PTY 字节重绘或新增后台查询、轮询。悬停只阅读，不切换表面、不更改执行焦点、不发送输入；点击 Focus 仍进入既有工作面。Escape、失焦与指针离开正常收起，键盘可读同样的信息。具体视觉约束见密度 SSOT 的对应 Focus 章节。

用户确认「按你说的改一版」，并要求「时间音轨参考一些视频编辑软件的样式，且放在最下面」。Focus 保留项目泳道、Recent Focus 与右侧完整原工作面；时间音轨位于整个 Focus 内容底部、全局状态栏上方，项目扫描与继续工作占据上方主区。PMO Teams 不混入执行上下文或其历史。

用户持续反馈 Focus「滚动有问题」「右边的加载也有问题」，并将 Renderer 性能作为 P0。大数量资格验证须绑定实际数据来源、版本与窗口条件；真实观测集合和扩展压力样本分别声明，不能把合成样本或自然窗口之外的局部测试称为真实使用通过。左侧泳道与底部音轨保持各自连续阅读，右侧加载与 Focus/原工作面交还保持同一 Tab、Region、Session 和健康 Run。成本沿真正相关的消费者和变化事实核对，不因无关项目、保留的断连上下文或其他历史数量反复推导整份工作面；通用终端成本与连续阅读要求引用[《Terminal 连续向上阅读历史》](terminal-reading.md#terminal-连续向上阅读历史)，不在 Focus 另立协议或历史账本。

### 卡片内容、预览与 Agent 操作

用户进一步指出「每一个砖块上的信息，什么都看不出来，而且利用率很低」。条目首屏必须能区分同一项目、同一模型的多个 Agent：名称遵循既有显示名优先级，最近动作来自已有可观察事件；项目归属在泳道头表达，完整路径和完整身份按需查看，不在每块重复消耗首屏。事实不足时如实说明，不编造任务、进度或正在执行的动作。

用户要求「彻查当前卡片的信息设计」，指出「有用信息很少，Topic 上最近在干什么的现成能力居然也没用上」，并要求「先调研，找参考；有的抄就照抄」。Focus 的活动摘要与 Topic、既有活动视图复用同一事实解释：首屏回答任务是谁、最近做了什么、现在为何需要人处理。具体授权标题或问题、明确失败/连接说明优先于旧工具活动；当前可查看的结果保留结果内容。普通后续消息不能无故盖掉仍适用的最近工具动作；仅有消息事实时明确它是请求或回复，不能将聊天文本当作已执行动作。缺少活动事实仍诚实表达；不为了卡片展示对所有会话拉取完整历史、新增轮询或另立状态/活动账本。已消费的状态说明变化必须可见，同状态心跳与无关会话字节不触发卡片内容重算。

用户新增要求「Focus 卡片显示现成 recap，右键复制 Agent 信息等，复用 Region 右键菜单的一部分」。卡片复用已保留记录的已观察回复／请求摘录，来源清楚可读；它不是自动任务总结，不将 Topic 文档短说明冒作 Agent recap，也不把旧摘录推成当前完成、任务进度、人类作者或新的活跃时间。普通执行条目以已有回复／请求摘录为主体；有摘录时，普通工具动作或 transport 过程不另占常驻正文行，仍在原按需详情可读。无摘录时复用现有活动摘要；具体待处理请求、失败／连接事实与必要未知服务说明直接可读且优先，原服务窗不被遮掉或静默取消。已完整识别的消息包装只在首屏把正文置前，复用共同消息的唯一解析能力；声明不认证作者，未识别、不完整及代码／引用中的相同文字保原文，原摘录、来源和按需阅读不因首屏投影改写。常驻卡片仅消费相关上下文已加载的有界记录，不为每卡追加历史／全文扫描、轮询或另一份摘要事实；展开后的输入预览沿下文按需读取边界。

卡片悬停意图与键盘聚焦按需呈现完整的当前已知任务、活动、摘录及来源，并在独立的 Recent user messages 阅读区显示当前有界窗口内最多三条输入。预览只读，不导航、改变选择或夺输入；只有已展开的 Agent 卡片预览挂载同一准确 Host／Session／Run 的既有用户消息读取器，复用原生与已捕获输入公共投影，不另建 Reader、cache、观察注册表或轮询。常驻卡片、隐藏及关闭的预览不新增读取需求；关闭或身份失效释放本预览的 reader，其他现有消费者与健康 Agent 继续可用。原回复摘录和来源保持，不把输入当作回复、已执行活动或新的完成事实。 预览正文复用共同 Markdown 阅读能力，保段落、代码及引用，不将已压平摘要误作原正文；唯一摘录 owner 可提供有界阅读投影，原摘录与首屏投影及来源不改写。回复／输入分别保持原 800／360 字符预算，预算内完整正文正常呈现 Markdown；超预算明确呈现有界纯文本摘录，不补写闭合语法、不扩大解析或历史读取窗口。已完整识别的包装沿唯一 Core 解析器把正文置前，声明只作为声明，未知、不完整或代码／引用中的同形文字保原文；原文及来源仍通过只读可选文字或 title 可达，不新增折叠、复制、刷新或导航动作。

卡片悬停与键盘聚焦使用同一状态说明；只有同一 Host／Session／当前 Run 的可信状态进入时刻完整可确认时，才显示已持续工作的、静止的或待输入的时间。状态与起点沿原 Core 事实及其唯一可信时间判据；focusedAt、observedAt、lastActivityAt、最近消息、旧 Run、过期 Working 与观察缺口不能冒作当前起点。缺起点只说明最近已知任务活动多久前，活动时间也未知就明确说明，不猜工作、闲置、完成或死亡。时间只消费原状态与已加载有界事件，由已打开的预览叶节点承担本地计时；关闭、隐藏与身份变化清理本次计时，不新增查询、轮询或后台时钟。

全部输入时间已知时按记录时间稳定排序，选最近三条后按旧到新呈现；时间相同保原投影顺序。任一输入缺记录时间时，保公共投影的原来源顺序取末三条，显示 Current reading window · Order unavailable，缺时条目标明 Time unknown；已知记录时刻呈现能区分日期的本地日期与时间，仍是记录时间而非包装声明的发送时间，不猜全历史最近或跨来源先后。少于三条只显示现有记录，不为凑数加载更早页；不同原生／已捕获记录不按正文去重，各保记录身份及来源。 正常有序且没有读取／覆盖问题时，不另占常驻窗口说明行；有界窗口含义、原生／已捕获来源及包装原文仍通过同条记录时间的只读 title／可访问说明按需可达，不能因此冒全历史最近或隐藏缺时、读取／观察失败、来源改变、暂停和不完整事实。项目与路径可在原 footer 紧凑表达，完整路径、准确 origin 与 SID 保在同处按需说明；不增加 Info、复制、折叠或导航动作。输入正文的作者外观沿[共同阅读合同](terminal-reading.md#terminal-连续向上阅读历史)中的《共同对话的用户默认外观与协作来源》，unknown 显示 You 但不改写原作者事实，明确 Agent 作者仍按真实身份表达，不以收件者资料代填。读取或观察失败、窗口冻结或不完整沿原事实给简短服务说明，保已读内容、原工作面与健康输入，不增刷新按钮或悬停资源加载。

指针可自然移入预览阅读、滚动和选择文字；预览内部滚动不关闭自身。Escape、外部泳道滚动、打开菜单或改名、原来源失效、隐藏及卸载废弃本次查看和迟到计时，不能复活旧对象。普通左键与 Enter／Space 仍执行原 Focus 导航。

卡片右键、Shift+F10 与 ContextMenu 键打开同一准确 Agent 菜单，不改变当前选中；菜单头仅用单行名称确认本次对象，长名称省略且按需可读完整名称，不重复状态或 SID 说明。菜单保留 `Rename Agent` 与唯一 `Copy Session Address`，并在独立停止动作组提供 `Stop Agent`；打开沿原卡片左键与 Enter／Space，不重复为菜单动作；改名只调用该 SID 的既有命名 owner；复制仅选择原 `copy-session` action、唯一 formatter、clipboard 与错误出口，得到含发送与查看模板的准确 Session 地址名片，不发送消息。只有 SID 时现有 Message 入口与 Session 入口复制内容相同，Focus 不重复展示两项；不改公共 AgentRoster action 源或其他菜单。多位置或无确认 Region 时不猜空间地址，不继承 Region 关闭、重排或其他 Runtime 控制；复制失败仍沿原错误告知。行内改名的 Escape 取消、空值回既有派生、Enter／失焦提交保护输入法组合过程；退出编辑或菜单不得夺走用户后来选择的焦点。查看和复制保原输入、草稿与生命周期，显式改名仅改变命名事实。

Focus 卡片 Agent 菜单与操作栏对明确选中的语义 Agent 共用 `Stop Agent` 动作和原确认框；停止本次准确 Host／SID／Run，不是当前 Tab、Region、Chat 收件 Mote 或后来替换的 Run。确认前沿原 owner 重新核对身份，缺失或改变只拒绝这次停止并给原 subject 服务说明；活动 unknown 不自行拿走已确认控制身份的显式停止能力。pending 防双点，确认取消与关闭保原键盘返回和较晚主动焦点优先。调用沿公共停止接口，未确认、失败或等待超时保原工作面与草稿并明确未知，不乐观删投影、不冒称已停止、不自动重试或停止其他 Session。Core 确认准确 Run 终局后，沿原退休／run-removed owner 移除已停止投影，保原 Session、native conversation 与历史退休资料供原显式恢复；不承诺成功后旧 Tab 仍在，也不因查询或重启恢复退休 Run。旁边健康工作面、草稿和 Run 不受影响。Focus 收起仍只改变呈现，不与停止混名。

Attention 中的失败 Agent 沿原处理面提供可发现的查看与关闭动作。只有公开 Core 已确认该准确 Session 的进程结束或终局事实时，显式关闭失败 Session 才沿原 Session 生命周期能力收尾；关闭请求面和关闭 Focus 投影仍只改变呈现，不能冒成 Session 已关闭。关闭的返回、排队或超时不代替 Core 确认：未确认及失败保留原对象、工作面和可读恢复原因，迟到旧 Run 的回执不能关闭同一 SID 的新 Run。错误状态、握手或观察失败不自行证明进程已结束；健康或未知 Run 保原可用能力及既有显式停止边界，不凭错误文字猜终局。准备失败尚未产生 Session 时，保原 Launcher 与完整草稿供重试，不伪造可关闭的执行对象。Agent Region 的展示关闭与生命周期后果仍归[《Agent Region 关闭与身份入口》](spaces-and-layout.md#agent-region-关闭与身份入口)。

### 项目归属、状态与离线目录

Focus 顶部用同一条操作栏分别承载左侧过滤与右侧当前工作面，不再叠加标题行。 原工作面的顶部对话标尺遵循[共同参与者轨的阅读连续性](terminal-reading.md#agent-composer-与-terminal)。右侧默认呈现完整原 Tab 时，标题复用该 Tab 的显示名，顶部右键、More 与键盘菜单中的 `Rename Tab` 只修改本次准确投影的 Tab ID；不能因所选 Context 是 Agent 而改成 Agent 名或修改其 Session 名。Tab 与 Agent 名的独立身份及默认派生沿[《显示名与身份》](spaces-and-layout.md#显示名与身份)，Agent 命名及其动作留在明确的 Agent 身份入口。回到原 Space、查看待处理请求与关闭观察投影仍复用原导航及请求 owner，不因此管理被观察 Agent 的生命周期。显式只查看 Region 时保留原表示身份与控制边界，不由裁剪范围另建命名合同；只有一格的 Tab 仍保留 Tab 身份。 同一观察投影的收起仅保留操作栏常驻快捷入口，Focus More 与身份右键菜单不重复该动作；快捷入口仍只收起投影。菜单中的原 Tab 改名、显示级别、查看请求与明确 Agent 的 `Stop Agent` 保各自准确对象及键盘行为；本格分屏、地址与历史仍由原 Region 菜单持有，不能因表面相邻而合并或删掉。选择菜单动作后由其原目标承接焦点，Escape 返回本次仍可用入口，较晚主动焦点优先；收起后的第一键沿本节原检索控件合同。

右侧操作栏直接提供 `View in Space` 和 `Chat about this tab with Mote` 两个常用入口。查看 Space 沿本次已确认的完整 Tab 与展示位置定位，保原 Group、Region 与输入策略；不能借当前普通工作面的活动 Tab、同名 Tab 或同一 Session 的第一个位置替代正在显示的对象。无法确认位置时保留原工作面并解释真实缺口，不能导航到猜测的目标。

与 Mote 讨论引用点击时正在显示的准确 Tab 身份，完整 Tab 多格或同一 Session 多位置也不改成 Agent 名称寻址；显式只查看 Region 时仍引用其所在的准确 Tab，不新增 Region 命名合同。讨论复用已有真实 Mote 的讨论、输入与公开 Core 能力，以及既有 Tab 寻址与检视表示；不另造发送系统、影子 Mote 或按名称猜收件人。源 Tab 和原 Mote 的未发送草稿保持独立，已创建的讨论沿其原输入 owner 保留请求；准备、配置或投递未确认时如实给出原目标与保留的请求，不冒称已发送或已回复。只有显式操作可以建立讨论或提交请求，悬停不发送；后来的选择、关闭与主动焦点优先，迟到结果不改投目标、不重开已关闭的浮层，也不抢回原主工作面。 用户要求 Chat 下拉选择任一 Mote 并记住选择。Focus Chat 收件偏好只保存明确选择的准确 Mote 身份，沿现 Mote UI 持久 owner，与浮窗当前目标独立；未明确选择时保现有浮窗目标解析，选择后跨执行上下文、页面与普通重启仍用同一身份。下拉查看与选择只改 UI 偏好，不打开／改投浮窗、创建讨论、发送请求或控制 Run；点击 Chat 才固定本次收件 Mote 和正在展示的准确 Tab，沿原讨论 producer。选择变化／浮窗换目标不改已开始请求的收件人，重复 pending 点击仍受原锁保护，迟到结果不抢后来焦点或重开面。选项来自同一 Scratch 文件快照的真实 Mote，归档对象明确标识仍可明确选择；普通 Topic 不混入，已存目标缺失、读取失败或身份未确认时保原身份并明确该次未发送，不静默借默认／同名／其他 Mote，也不重建目录或 Session。其他已确认对象与原健康工作面仍可用。偏好保存失败保本窗口选择与原能力，沿同 owner 给可读非阻塞说明，重选同一准确身份也可重试保存，不冒重启后已记住。

Focus 预览只有一个 durable Agent Region、原 Tab/Group owner 与 Session 归属明确且非只读时，当前身份与原格控制合在同一顶部操作带，不再重复一行身份。History、观察刷新和精确格动作仍由原 owner 执行；多格、Agent 与 File/Browser 混合格、归属未知和只读观察保留原 Header。关闭 Focus 仍只收起观察投影，单格不增加关 Tab、X 或生命周期动作；多格原关闭入口与未保存确认保持可达并绑定原精确 Region，不以名称或当前焦点猜目标。

Focus 窄分栏中的搜索与筛选入口须可辨认，当前项目、状态及完整值可按需读取且原可选集合保持；缩窄和悬停不夺取当前输入，显式筛选后的焦点沿同一控件交还并让后来主动焦点优先，不另持一份筛选条件。

Focus 的 More 菜单沿共享下拉菜单的悬停、点击与键盘入口；悬停查看及自然离开不改变当前输入位置，也不继承上次显式打开菜单的焦点目标。自然关闭后，再从身份区用键盘打开时，第一键能直接操作菜单。显式点击或键盘打开菜单后，Escape 将焦点交还本次打开的控件；从身份区打开的右键或键盘菜单回到当前身份按钮。行内改名按 Escape 取消后回到同一身份按钮，名称保持未提交。选择改名时输入框获得焦点；查看 Space、关闭 Focus 工作区或查看请求后，由所选动作的目标承接焦点，不能被菜单关闭时的焦点恢复拉回，也不无条件聚焦终端。外部点击或改名失焦提交时，焦点继续跟随用户实际选择的新目标。

显式选择 `View in Space` 后，第一键进入实际激活的原 Region；用户不必再点一次终端。显式关闭 Focus 工作区后，第一键进入仍可见的 Search contexts，不能落在页面空处或送给隐藏终端。仅这些明确动作交还输入焦点，后台更新、指针选择与其他工作面切换不自动抢焦点。

### 时间轴的事实、窗口与历史

Recent Focus 只读取同一份持久化 execution focus history 与 Core 已持有的消息事实，点击片段回到对应已有 Session；当前焦点和最近历史可扫描，完整轨道可以展开与收起，轨道内容独立滚动。当前 Agent 显示名沿同一 Session 的既有命名 owner，Agent 改名后时间轴的当前身份同步更新；历史片段保留发生时已观察的名称、身份与时间，不将当前改名反写成历史事实。用户要求「下面的时间轴，高度要支持可调」：顶部边界可拖拽，也可用键盘调整，记住用户高度；收起后再打开恢复此前高度。拖动被取消时恢复此前保存的高度并结束本次调整；后续普通指针移动或释放不能继续改变高度或保存已取消的调整。窗口收窄或变矮时仍保留主工作面的有效操作空间。窄窗口工具栏换行后，空间足够时仍须保留标尺和至少一条完整轨道；布局临时需要更多高度时不改写用户保存的高度，变回宽屏后恢复该高度。时间位置取自真实 focusedAt 事件；片段终点只使用已知的下一次聚焦事件，未知终点明确保持开放，不补造未来十五分钟或精确运行时长。

用户反馈「时间轴现在不准，Agent 明明在跑，在时间轴上却没有对应的条」。时间轴须区分当前 Run 在线、已确认的工作状态区间与用户关注记录：即使没有关注事件或已保留消息，仍活着的 Run 在窗口包含当前时刻时也可见；缺少 Run 开始时刻时明确未知，不以 Session 创建时间冒充当前 Run 寿命。工作状态区间消费 Core 在接受准确 Session／Run 的权威语义转移时沿既有持久时间轴保留的结构化观察；已结束、停止、退役或关闭工作面的 Session 仍按所选范围显示真实保留的过去 working 区间。当前开放区间须有已知起点和仍有效的当前 working 观察；有界历史的裁剪或覆盖不足只说明历史可见范围，不能覆盖或否决同一准确 Session／Run 已核、仍有效且起点已知的当前 Working；当前事实与保留历史分别表达，缺少真实起点或观察失效仍不补造连续区间。失联、时钟倒退、Run 更换或观察缺口不补成连续执行，也不延伸到未来。缺起止、未记录、来源不支持与保留裁切分别明确，消息、工具、关注、Session 创建或进程在线不补造 working；区间表达观察到的语义工作状态，不冒 CPU 执行或任务成功。状态接受与历史持久化由原 Core／Store 唯一 owner 负责，同状态心跳不移动起点或重复添历史；持久化失败说明覆盖缺口但不拿走健康 Input／Run。访问片段保持原 focusedAt 与已知下一次关注事件语义；历史查询和未来窗口不因当前在线而补造过去或未来的运行事实。所有事实沿既有 Core/Store 来源，窗口、预览与返回不控制 Run，不新增生命周期或历史注册表。

用户进一步要求「Recent Focus 可以支持查询任意时间」，默认「过去三小时到未来一小时共四小时的窗口」，并支持「快速切换窗口大小」。用户可选择任意日期与时间、前后移动同样大小的窗口，并一键回到当前窗口；默认窗口随当前时间缓慢前移，历史查询窗口保持所选位置。窗口选择不改变执行焦点或原工作面。像剪辑软件那样的竖线贯穿标尺与各 Context 轨道，表达真实当前时刻；当前 Context 的选中标识与时间位置分别可辨认。未来部分保持为空，窗口里没有已保留记录时如实说明；任意时间可查询不等于捏造完整无限历史，记录保留边界与未知区间须可发现。

用户要求时间刻度按整时间显示，与查询窗口大小分开：默认按所选时区的每日0点显示6小时主刻度、3小时短刻度、1.5小时更短刻度与45分钟细刻度；可改为均匀间隔加偏移（默认从日界前一小时起、间隔2小时），或保留原自由窗口刻度。均匀模式沿同一时区钟表格线，平移和跨日不重新定基准；夏令时不存在的本地刻度不造记录，重复时刻以不同偏移可辨。窗口档为30分钟、1／2／4／6／8／12／18／24小时、1.5天和2天；默认过去3小时到未来1小时仍保持。所选时区用于标尺、日期查询、范围与消息时间说明，记录与位置始终保原绝对时刻，不改历史身份；模糊或无效本地时间可辨并保此前有效窗口。模式、时区、缩放与名称宽度不改变正文读取来源、原工作面、选区、滚动或健康输入；更大范围不暗示完整历史，不扩大原有界页批次和显式继续更早记录。

用户新增要求「像剪辑软件一样用鼠标左右浏览历史，窗口大小除了数字选择也要有＋／－」。横向滚轮与 Shift＋滚轮连续平移同一时间视口，普通纵向滚轮继续浏览轨道；消息、片段、身份列和日期／选择／正文控件保留原点击与输入。同一时间画布的空白区也持续接受横向滚轮与 Shift＋滚轮；窗口内没有已读记录或暂未读到事实不构成日期导航边界。身份栏（含没有节点的空白名称区）与正文／输入控件不接管时间平移，普通纵向滚动保原行为。＋放大到更小的时间范围，－缩小到更大的范围，与原窗口选择和 Now 共用同一查询位置；历史查询不因缩放跳回当前时刻。高频平移和缩放只改变视口，不改执行焦点、原工作面或健康输入。

同一来源的已读正文与时间视口分开：改变窗口位置或大小只筛选同一份有界已读记录，不能每次清空正文并重新读页。首次明确进入另一阅读模式可沿既有有界批次读取；继续更早记录和刷新仍为明确动作。旧窗口的迟到结果不得覆盖新的呈现、焦点或选中消息；Context、Host、Run、Source 或阅读模式改变、隐藏和收起继续沿原世代边界停止新增页并废弃失效结果。查询覆盖尚不完整时如实表达，不用反复重读、第二缓存、后台扫描或轮询制造完整历史。

用户要求「时间轴拖拽时项目和 Agent 位置不要大变化，大顺序进入页面算好，不能随滑动跳」。本次进入 Focus 时，项目按已有最近任务活动事实组织，Agent 按可读名称与稳定身份排列；活动不足明确未知，不能把关注时间、后台字节、心跳或未读资料当成任务活动。左右浏览、缩放、Now 更新和后来活动不反复重排本次已知项目与 Context；同名对象不合并，窗口暂时没有事实而隐藏后重新出现仍沿原顺位。新增对象不夺已有阅读位置，下次真正进入再按新资料组织。顺序只管呈现，不改变项目历史归属、Session／Run、焦点、工作面或读取来源；原只显示窗口内事实与有界已读记录保持，不能为固定绝对位置保留空历史墓地。固定正文、选区、滚动和后来意图不因重排丢失。

项目分组与关闭后历史回顾：时间轴按项目组织所选范围内的真实已保留事实；当前窗口包含 Now 时，可另外呈现已核的当前在线观察。Session 是否仍有打开的 Tab／Region 不应决定历史事实是否可见；关闭工作面、停止 Run 与 Session retired／unknown 是不同事实，不能混成同一个“关闭”状态。查阅历史只读，不因轨道存在、查询或展开分组而恢复 Session、创建 Run 或改动原工作面；可恢复时的继续工作须为另一个明确动作。项目／Branch／Topic 的历史归属仅凭已有可信记录表达；只有当前归属时明确标成当前资料，缺历史身份、归属、时间或记录覆盖时保留缺口说明，不按路径、当前分支或时间邻近猜测。已销毁 worktree 不使仍保留的历史消失；范围外或没有可定位事实的旧 Session 不为完整性占轨，无时间消息沿既有记录入口可读。关注片段、消息和已核工作／在线观察各保原语义，不能把关注时长或当前 working 外推为历史执行。

历史展示沿唯一 execution focus history 呈现身份，保留发生时实际观察到的只读归属，不持有第二份运行状态或消息账本；已有记录缺资料仍明确未知，不迁移或补猜。紧凑呈现见[同主题视觉合同](../presentation/focus-context.md#时间轴与历史回顾)。

唯一 execution focus history 同时受最多 2000 个事件与 JSON 序列化最多 512 KiB UTF-16（JSON.length × 2）约束；超限裁掉最旧的完整事件，不截断已观察名字或改写历史归属。该限额只保证 Focus 新增历史材料有界，不能代签整个工作面存储配额；查询须沿既有保留范围说明呈现覆盖边界。

完成或关闭条目的项目表达须区分发生时已观察的归属、只知道当前或保存工作区的资料，以及确实未记录。若同一 Host／Session 的保留身份只有一个非冲突项目，可以按「已观察 Context 归属」组织已读发言，但明确消息发生时的项目未记录；缺资料、有冲突或 Host 不匹配则保持未知，不从正文、路径、当前分支或邻近时间补猜。同一 Context 的关注片段与发言如采用不同归组口径，原因在按需说明中清楚，不能让已知的观察被无说明吞掉。

未被关注过但仍由 Core 保留的 Agent 消息来源也应可发现并按需读取；发现来源不代表记录已经覆盖所选时间，尚未读取的来源须明确可继续查看，不能以空轨道代称完整历史。来源发现与正文读取分别有初始批次边界，窗口、展开或无关输出不能触发所有归档来源的全文扫描。

用户反馈「时间轴怎么感觉缺了很多」。时间窗回顾不能因改选发言来源而抹掉其它已读、有效且位于窗口内的真实事实；同一有界阅读窗保留多来源事实，达到共同容量时裁完整记录并说明被裁范围，当前固定正文与选区保留。已读、尚未读取、时间未知、当时未记录、来源不支持/不可用与保留容量不足分别可发现，并有原就地阅读/继续动作；空白不能冒称没有发生。查询不进行全来源后台扫描、不新增 Runtime/历史账本或第二读取 owner；当前工作状态不能外推为未记录的历史工作区间。

Focus 当前发言来源的自动观察不可用或阅读窗已冻结时，原消息记录／覆盖入口必须持续说明哪一步不可用、已知记录仍保留，以及显式刷新或读取最新的动作；它只说明服务状态，不新增消息、时间条或后台读取，不阻健康输入、不清原正文与选区，隐藏及来源身份改变继续遵循本节既有有界阅读规则。原 reader 已明确报告窗口不完整时，也沿此入口说明已知缺口与原显式读取动作，不把已知裁剪或重校验断档仅说成尚未读取更早记录，也不自动补读。


退役历史的容量与维护边界：只读历史描述沿唯一 AgentSession Store 保存；在既有最多256条退役记录与1 MiB durable 文档边界内保留，容量不足时先淘汰最旧完整历史描述，不能改当前 Session、生命周期 reservation 或退役 Run 事实。淘汰后的来源如实 unknown，不能把未覆盖说成没有发生；其 captured sidecar 同步尝试释放，原生文件不删除。文件维护失败须留下可核对的告警与重试动作，不能让已成功落账的 create/resume/retire 失败或回滚健康 Run；维护也不能阻只读历史返回。该约束不保证无限历史保留，也不允许加第二份历史账本。

用户希望把发言发生的时间与 Context 展示在时间轴上，并区分其他 Agent 发来的输入与用户输入；随后要求用户和 Agent 发言都可读，并复用已经正常的对话模式。时间轴在同一有界已读窗口内呈现原生和已捕获的用户输入与 Agent 回复，沿共同对话记录投影与原正文；只用真实记录时间定位到原 Context，区分明确人类、已核 Agent 输入、未知输入与该 Session 的 Agent 回复，不从终端字节、焦点或邻近时间猜发言。原生 user 角色、条目种类和 source=user 提交入口不证明人类；已核 Agent 输入不冒称 Human，未记录发送者的提交仍以「Prompt · Sender not recorded」可读。消息标记能查看时间、原 Context 和正文，并可回到同一已有 Session 的原工作面；按需查看不修改焦点，不复制持久化对话，不创建第二份 Runtime 事实。已核发送者为 Mote 时，消息身份复用该 Mote 已有头像 owner；仅有名字、正文或未知归属不能猜成 Mote，不改变原记录作者、身份或时间。单条 Agent 消息的按需说明可显示已核发送者及其当前 Project／Branch／Topic，并通过明确动作跳到已有发送者 Context；查看说明本身不导航、不写 focus history、不创建或恢复 Session。当前资料与发送时事实分开，缺作者、归属或资料如实未知，不能按名字或正文包装猜发送者。原记录 ID、时间、同正文重复输入和原 Context 身份保持；同一记录时刻的多条发言不可相互遮住并冒成一条，用户可从原锚点查看各条已读原记录，保持准确来源、作者与原序，查看不新增读取；输入归因、全来源、无时间可读及读取预算沿本页《用户消息从 Provider 原生会话取得》与时间轴覆盖约束；回复保准确原记录、Source 和 Session，不伪装成提交输入。缺时间的发言在原记录入口可读，不猜 Now；未读、范围外与保留裁切不能冒没有发生。复用现有共同 reader 的原页和已读投影，不追加另一份读取、正文缓存、注册表或后台扫描。

消息预览复用共享浮层的优先级与打开、关闭协议；窗口或音轨尺寸变化后仍贴近本次查看的入口且保持在可见窗口内，原正文选区与关闭还焦不因呈现位置改变而丢失。观察和尺寸变化不改变 Region 焦点或原工作面；显式 Context 返回继续沿原导航动作。 固定消息阅读期间，音轨标题带上的时间导航与缩放控件仍能直接命中，预览不能盖住它们；平移使原标记离开窗口后，已打开正文与选区仍可读，不能用关闭阅读面换取操作空间。

用户反馈「hover 时间线上的头像面板太缺乏设计，信息不清晰、不现代，出场交互简单」。时间轴的轨道身份检视首先回答对应 Context 当前或已保留观察是什么；消息标记检视首先回答真实作者、接收 Context、记录时间和消息内容。快速悬停只提供轻量可读预览，显式点击或键盘操作才固定完整阅读与动作；身份、时间和来源各表达一次，不以重复姓名、空字段表格或当前资料冒充历史事实。当前项目、Topic 一句摘要、真实最近活动按同一现有事实展示，历史资料不完整和发送 Run 未记录用紧凑且可展开的明确说明。悬停意图、可自然移入阅读、键盘与触屏显式入口、较晚主动焦点优先及 reduced-motion 都必须成立；原固定正文、资源、选区和控件命中、未知身份及有界阅读预算保持，不能用重挂、自动导航、查询轮询或关闭阅读面换取视觉简洁。 Zone/Tab/Region/Session沿原实体身份引用，检视和显式返回仅改变对应呈现绑定，不能将当前表面或项目标签作为唯一实体归属，也不建立第二份读取或注册表。 内容只含资源时仍提供诚实的资源提示，悬停不下载或加载资源；固定后复用原共同正文。已固定阅读不被其它标记的悬停替换，关闭、来源或Context改变、隐藏及卸载废弃迟到计时，不能复活旧检视或关闭后来固定的阅读。

用户进一步希望「如果那个 Agent 自己还执行了的话，在 timeline 上也可以去关联起来」。消息与发送者执行的关联只消费公开 Core 已核的原 message/source、Session 与发送 Run 引用；Run 改变或引用缺席时不把旧消息关联到新执行。可展示同一 Run 的真实在线／working 观察，不用正文、近邻时间或关注事件猜因果，不把投递回执当执行、回复或完成。只有作者身份时仍可查看发送者当前 Context，但不能把当前工作说成本条消息的执行结果。不创建第二份历史或关系注册表。

Focus、Space、Goals 共享同一执行上下文。切换表面、选择泳道条目、调整比例、收起音轨时，原 Tab、Region、Session、Run 与健康工作面保持；Focus 与 Space 之间不能因 portal 目的地变化重挂载已存在的终端、Browser 或编辑器。分割树与原组地址仍归 durable Workbench，Focus 只改变投影。目标暂未出现或恢复事实未就绪时保留原内容与可见说明，自动尝试接管，不以空白或删除身份代替恢复；每条正常分割分组及其非选中 Tab 都必须保持可恢复。

执行 Agent 在 Space 中点击或键盘进入 Region、从 Focus/Goals/Quick Switcher/Topic 定位时，复用同一 execution focus 写入入口。最近上下文入口对同一 Session 只显示一个最近位置；同一 Session 内切 Activity/Terminal 不重复记录切换、不创建第二份历史。重启先恢复历史、当前 Session 和原 Tab/Region，再尝试续接。

主区、音轨与工作面各自拥有明确滚动边界；增长的历史不能挤掉主区，空 registry 壳不能截走点击、滚轮或输入。右侧减少重复标题，恢复/未知/真实失败显示既有服务窗语义并保留输入能力。涉及这些热路径时，正常活跃终端连续向上阅读与工作量边界同时按[《Terminal 连续向上阅读历史》](terminal-reading.md#terminal-连续向上阅读历史)验收。视觉尺寸、密度与控件语言只定义在 surface-density 的同名章节。
