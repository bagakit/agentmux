# Browser 工作面

本文定义 Browser 的操作控制、认证、记录与回放，以及多位置呈现和输入交接。Desktop Main 持有 Browser 与 operation 事实，Renderer 投影；Session／Run 与空间身份仍归各自 owner。本文描述已确认要求，不代签实现或安装验收。

## Browser 工作面

- **网页标识取真实页面事实。** 网页 favicon 由原 Browser Main owner 观察，并连同准确 Browser／当前导航身份向已打开条目的呈现提供；缺失、损坏、不可用或无法确认时回落统一网页图标，不从域名猜标识或另发无关页面请求。后来导航优先，前一页迟到图标不覆盖新页；图标不是权限、加载成功或 Agent 活跃状态。
- Browser 是 AgentMux 内的一等工作面，不是外链跳板：它可导航、可标记、可被 Agent 安全消费，且生命周期与权限事实**只由 Desktop Main 持有**。Renderer 既不拥有 WebContents，也不持有第二份导航或权限状态。
- **Browser 是 Agent 自我改进的观察—行动—复盘闭环。** Agent 读取结构化页面事实，执行语义动作，得到页面变化与失败结局，再把这一轮沉淀成可检查的操作记录和可复用脚本。`browser.run` 的 CLI 是这个闭环的公共入口；每一步都必须有可读结果，不能只有“脚本退出 0”。
- 用户要求「browser被使用不要抢占用户焦点，agent应该尽量用agentmux cli能力操作browser而不是操作界面」。Agent 发起的 Browser 打开、导航、页面操作及其进度、结果或失败投影，保留人当前的系统窗口、主面选择、Tab、Region 和键盘输入位置，不自动激活 sidebar、切工作面、抢原输入或移动系统鼠标；放置和驱动页面不是焦点转移授权。人主动点击 New Browser／目的地菜单或明确发起的 focus 仍按其导航意图执行，不与后台 Browser 工具混在一起。Agent 优先用 AgentMux 官方 CLI 发现准确目标、读取页面、按真实 ref 行动和消费结果；能力或 owner 未确认时就近如实说明，不能猜 ID、通过界面重开／聚焦来绕过失败，不能因此阻断健康 Run 或移除原 Browser／工作面。焦点与输入事实沿原 owner，页面反馈只引用本节既有虚拟指针与动效约束。
- **先分析本任务的原页面。** 用户说“看看 browser”或类似未指定页面的请求时，先结合原任务与[准确空间位置](spaces-and-layout.md#agent-的自身位置与邻居发现)，分析是否指自身同 Tab 的邻居 Browser，并只读核对该 Tab 的真实 Region／Browser 绑定；不能直接把泛指当成新建页面的要求，也不能按标题、最近使用或全局焦点挑选无关页面。已给准确 Browser／地址／位置或指定工具时沿原目标；同 Tab 仍有多候选、关系未知或内容不能确认时，保留候选与原工作面，仅对影响本次操作的实质歧义问清。发现邻居不扩大授权，不把可见关系当成页面已授控制权。
- **Agent 的网页就近可见。** Agent 打开或操作网页时优先使用 AgentMux 自带 Browser 与公开 CLI，优先复用本任务已确认的准确 Browser；同一任务通常留在同一 Tab。需要新页面时，先读取自己的实际 Zone／Tab／Region 及全 Tab 可见布局，默认在同一 Tab 新建可读的方向 Region，使 Agent 与网页同时可读。用户未指定其他位置、双方可读时，优先原 Agent 所在 Tab 的右侧分屏，并适当缩小 Browser；实际方向与尺寸由 Agent 读取布局后结合几何与内容显式指定。Focus 中另开的新 Tab 可能不会出现在当前阅读面，也更难找到；创建成功不等于人已看见，不能为“让人看页面”默认另开隐藏工作面或抢焦点。用户已明确新 Tab、同 Tab、方向与尺寸偏好时优先兑现；完整原型或截图评审本身不构成改开新 Tab 的理由，不能让采图便利变成人的反复切换。布局真实拥挤、阅读确需完整工作面、能力确实不适用或用户指定其他 Browser 时，可以选择相关新 Tab 或指定工具，并简要说明原因和实际位置。Browser skill、使用指引与运行时指导应同时表达同 Tab 新 Region 的默认及合理例外，操作后核对返回的真实 Browser、Tab、Region 和导航回执。创建同 Tab Region 不授权覆盖旧内容、切焦点、夺取人工控制或绕过拒绝；原页面、用户输入及未知操作回执保持。
- **Agent 操作是 Browser 的一等活动。** 一轮操作有稳定的 operation identity、发起 Agent、目标 Browser、脚本/步骤摘要、当前阶段、结果和时间；Desktop Main 是事实 Owner，Renderer 只投影。驱动开始、动作派发、页面观察、权限等待、用户接管和结束都进入同一条有序记录，不能另建一份只供 UI 使用的“操作状态”。
- **交接必须先让人看懂，再让人接手。** Browser chrome、Tab 标记和页面内提示同时表达“哪个 Agent 正在操作哪一页、当前做到哪一步、下一步会触发什么”。普通点击、滚动、按键及程序派发的原生输入不自动接管、不改变控制权，也不因此中断 Agent；Agent 控制期间的人工网页输入按下文[输入隔离](#agent-操作可见性与输入隔离)处理，不能因没有接管而仍让输入改变网页。本人明确选择“接管”时，通过原 Browser 与仍活动的原操作身份停止后续派发，再将网页输入交给人；有活动程序时返回 `stopped`，没有活动程序仍可接管。单独停止程序只结束执行，不隐含接管；若入口同时停止并接管，必须明确表达这两个作用。已发生的动作保留，仍在途的动作结果按实际确认程度表达，后续动作不得派发。接管／交还入口依据实际控制权与准确 Agent 关联出现，单次操作结束不抹掉已确认的关联；明确没有关联 Agent 时，沿[从 Browser 创建 Agent](#从-browser-创建-agent)提供创建入口，不显示无接收者的交还。交还必须由人明确发起，将准确 Browser 控制交回已关联的 Agent，不自动续跑或重放旧程序；Agent 从当前页面事实重新决定下一次操作，不能靠重试夺权。用户主动把控制权交给 Agent 时，要看到目标、脚本摘要和可停止出口。
- **操作记录可以变成脚本，但不是坐标录制。** 回放资产由语义步骤（观察、ref、导航身份、动作、等待、结果）组成，保留页面身份检查、权限/外部应用交接和不可逆动作的人工闸门；不录入密码、Cookie、原始敏感输入或屏幕坐标。回放默认先预览，执行中可逐步暂停，页面身份不符或结果不确定时停在服务窗。
- **人工闸门是操作记录的一部分，不能靠跳过它让回放变绿。** 敏感输入、带私密参数的导航、未审查代码与协议调用在计划中保留原来的步骤位置和阻断原因；隐去原始值后需要重新确认，不能删除步骤或把地址改成另一个地址后继续执行。失败、不确定和记录裁剪造成的缺口同样必须可见。
- **Agent 身份和操作位置必须同时可见。** Tab/Browser chrome 显示 Agent avatar、名称和驱动状态；页面内用不遮挡内容的语义目标标记表达当前 ref/动作位置，脚本生成或等待时显示对应阶段。颜色只作辅助，头像、名称、动作名和目标语义必须能独立说明是谁在做什么。
- 用户要求 Agent 操作 Browser 时「显示虚拟鼠标位置，且有覆盖 Browser 画面的操作光效」。虚拟指针只表达当前真实操作的可验证位置，不移动或替代人的系统鼠标；语义目标标记继续说明正在操作什么。位置与光效归实际 Browser、operation、frame 和当前导航，坐标未知时不猜中心、不用上一页的位置补空；滚动、缩放、分割和 frame 投影后仍指向真实位置，失效即清除。
- 执行光效只表示当前真实执行，不把只读观察、脚本生成、等待人工、人工接管、历史步骤或恢复状态冒成 Agent 正在操作；下文持续的控制权边界提示另表达输入归属，不冒执行。普通单次动作的指针与反馈须实际可感知，不能为显示而延迟原动作；瞬时动作或 operation 正常完成后可保留固定短暂、有界的一次完成反馈（指针运动的窄例外见下一条），明确表示已完成与真实位置，不延长或继续呈现 busy、执行光效或循环。等待、人工接管、停止、失败、页面变化或隐藏时优先立即清除；新 operation 覆盖旧完成提示，旧 timer 或 clear 不得改掉新一轮。同一 operation 内的普通只读观察须重核原目标与 viewport 几何；仍有效时保留原完成提示，不提前清除、不重建，也不续期。普通重启后不复活旧指针或动效。当前控制权允许的网页输入、交还和停止保持可用；装饰提示不持有输入隔离，不遮住阅读、抢焦点、改变控制权或阻断已完成动作，显示失败沿当前 Browser 就近如实说明，原页面、工作面与健康 Run 保留。相关更新仅作用于实际目标 Browser，不扫描或重绘无关页面。控件与减少动态效果的视觉约束只见密度 SSOT[《Browser RSI 操作表面》](../presentation/browser-workface.md#browser-rsi-操作表面)。
- **指针连续移动。** 用户要求两个位置间有“足够快，但最好有过程可以看”的 tween，hover 时有轻微浮动。同一实际 target document 与导航下，同 operation 或跨 operation 的两个已验证显示位置之间，应有短促、可看清过程的连续移动。上一位置只是一条已实际显示的坐标与 document／导航／viewport 事实，不携旧提示、权限或 DOM 目标，不重称旧 ref／目标仍有效。
- **完成提示与下一起点。** 正常完成 cue 到期只移除可见提示，历史仍可供下一真实 owner 作为动画起点；新 target 前重核历史与当前实际终点，不成立时保持静态。旧 expiry timer 不擦新 owner 或新历史，不能通过续期旧 cue 留 ghost。新 operation 清除旧提示与归属后，由当前真实 owner 承接仍有效的历史起点；不同 document／frame／nav 或无有效历史时，不猜跨 frame offset、旧页位置或页面中心，首点保持真实静态位置。
- **失效与人工优先。** 人工输入与控制权变化、等待、停止、失败、隐藏、导航、frame／view 失效及真实 anchor／viewport 几何变化，优先清除动效并使历史作废。人工归属沿原宿主输入来源与显式接管事实确认，不能仅凭 DOM `isTrusted` 把合法 Agent 原生输入归为人工而清除反馈；没有宿主输入归属能力的外部共享页保持未知，不冒称已观察到本人输入或即时接管。旧 callback／timer／clear 不能复活旧提示或改新 owner；非人工的迟到 scroll／resize 在滚动后已验证几何没有变化时，不擦新提示，真实几何失效仍立即清除。
- **动画预算与 hover。** 动画不等待、延迟或延长原动作、CDP 或 operation。正常完成立即结束 busy 与执行光效，至多让已启动位移在原短预算内一次到达终点，不重启动画或延长完成提示。hover 浮动仅是当前可信提示的指针装饰：真实目标 anchor、命中、系统鼠标与控制权不变，标签稳定，不冒仍在执行。历史只属于既有反馈状态，不持久恢复、不建立第二状态 owner／全 frame 缓存，不扫描或唤醒无关 Browser。视觉与减少动态效果规则见[《Browser RSI 操作表面》](../presentation/browser-workface.md#browser-rsi-操作表面)。
- **按键与脚本反馈。** 拟人反馈只消费实际派发的非敏感命名键／已证明的 modifier 语义，以及实际 opaque js／cdp 执行阶段。秘密、非快捷键或无法证明组合语义时使用通用图标，不猜按键，不展示输入值、参数或脚本文本，也不默扩输入协议。snapshot／read／generate／wait 不冒网页执行；结束或人工接管立即停止执行循环，实际很快时仅沿原有界完成反馈。反馈不等待或延长动作，不增加轮询、JS RAF、全页面重绘或无关 Browser 工作，不另建 owner、配置或工具栏。
- **Browser timeline 与聊天 Activity 共用时间语义。** Browser 面提供可展开的操作时间线，能按轮查看脚本、观察、动作、结果、接管和失败；它复用同一条时间轴和状态词，链接回页面快照、脚本行和可重放入口。时间线缺口、页面导航和人接管不能被折叠成“完成”。
- **历史可达，记录失败可见。** Browser 重建或应用重启后，历史操作仍可从 Browser 的历史入口找到；恢复的记录明确表示中断或不确定，不伪装成正在执行。记录加载、保存或投影失败只降低记录能力，不阻断健康页面或 Agent；对应 Browser 持续显示失败步骤、当前仍可用的能力与恢复动作，不能静默变成“没有历史”。
- **失败恢复面先认页，再行动。** 页面错误与原生连接恢复分别消费原 owner 的准确状态和重试入口，保留 Browser、Region、地址草稿及其他工作面。恢复面用原页面标题、目标地址与简短状态帮助辨认；保留的标题或画面须说明原来源，不冒当前文档已就绪或最后成功记录。原页面 Retry 与连接 Retry 不互换，不从错误文案推断控制权或自动重放。用户可显式编辑原地址而不覆盖或提交草稿、复制准确目标地址，并按需查看原技术原因；辅助展示或复制失败不拿走恢复入口。已有旧预览时明确其非实时、不可操作及所属页面，没有真实缓存时不补造缩略图。
- **上次查看的外观归原 Browser。** Desktop Main 为准确 Browser／Profile 保留一份有界的历史标题、小图及原页面来源，普通页面可跨应用重启读取，匿名页面只在原临时会话内保留。外观采集只沿相关原页面可用、真实可见的边界异步进行，不等待、唤醒或保活页面，不读取操作证据充当装饰；错误、换页、来源更替或采图失败不以空图覆盖原预览。读取旧外观不创建或恢复网页，图像不进入 Core 空间事实或每次 Browser 状态广播。历史 URL／导航无需等于后来的失败目标，展示必须区分两者，Retry 仍指向原失败目标。显式关闭 Browser 或确认删除 Profile 时，收口准确范围的预览并阻止迟到写入复活；普通原生资源释放不等于删除外观。缓存缺失、不可读、图片损坏或存储未确认只影响这一辅助提示，原地址、恢复入口、控制权及健康 Agent 保持可用。
- **退出应用或恢复失败不能把 Browser Region 当作用户关闭。** 正常退出只释放原生页面资源，保留原 Browser 身份、Tab、Region、焦点与分割布局；重复恢复同一身份返回原页面的真实状态，不重新导航、不更换 Profile。恢复握手、页面创建失败或原生 owner 意外消失时，同一 Region 保留地址与可执行的 Retry，并在服务窗说明失败步骤；Retry 重新取得同一页面 owner。只有明确的关闭事实才移除该页面投影，资源释放、重复握手与未知恢复结果都不是关闭授权。普通进程重启必须验证原工作面仍在且页面可恢复，其他健康工作面不受影响。
- **冷启动先还原描述，页面按真实消费恢复。** 原 Browser 的 durable 身份、URL、Profile、模式和已保存的 Viewport 随原 Tab／Region 与布局先恢复；仅挂载隐藏工作面或查询目录不创建原生页面。首次真实可见展示或已获授权的公开页面操作，沿同一 Main owner 恢复同一 Browser；并发消费不重复创建，已存在的页面优先复用，不重新导航、释放未提交表单或抢焦点。冷描述仍可公开发现，未实例化与真实 ready 可辨，公开操作不能因延迟创建变成无入口的 Unknown Browser。恢复失败保留原描述、地址草稿和同身份 Retry；旧记录未保存的 Viewport 或网页 DOM 状态保持未知，不冒充已恢复；本次冷恢复不额外释放仍活着的页面。
- **闲置回收覆盖全部导航位置。** 没有实际消费者、保护中的使用或恢复缺口的后台 Browser，沿同一资源 owner 按闲置时间与最近使用预算释放原生页面；离开项目或 Topic 不成为永久保留理由，返回但仍未显示也不重新开始闲置计时。真实可见展示、正在执行的操作、下载、媒体、未提交输入和有效镜像等保护事实须按准确来源核对，未知不当作可释放。Browser 的预算不改变 Terminal 的 replay 保温、Monaco 或共享导航事实；只读目录及资源查询不唤醒页面或延长其使用时间。
- **自动释放开关只控制 Browser 自动预算。** 默认开启安全闲置释放；关闭后停止新的自动 Browser 释放请求，不影响手动安全释放、原身份恢复或 Terminal、Monaco 的既有资源规则，也不主动唤醒已释放页面。
- **预算请求不冒充已释放。** Main 在不可逆动作前复核原 Browser、当前文档与使用保护，原生关闭确认后才提交释放事实；保留、关闭未确认、失败与来源换代分别返回，不提前撤走仍健康的页面或把未知当作关闭。Renderer、自动策略、人工与公开工具消费同一判定和回执；迟到结果不覆盖后来的原生 owner 或新的消费。释放保留 Browser／Tab／Region、地址草稿、Profile 与 Viewport；再次使用沿同一身份恢复，网页重载不冒充完整恢复任意 JavaScript、DOM 或表单状态。
- **关闭未确认的原生资源仍有 owner。** Profile 切换或显式关闭不能先丢掉仍活着的原 view；原生关闭抛错、被阻止或尚未确认时，Main 保留准确 Browser／Profile／Workspace 与原生实例的清理归属，直到权威销毁事实到达。资源目录、进程归属和 Profile 使用保护包含这些待清理者；迟到事件不改变后来的新页面，旧资源清理问题也不阻断独立健康页面。未知关闭不自动重放，明确 Close 沿准确原 owner 恢复清理。
- **统一管理所有 Browser 资源。** 设置中的 Browser 资源目录复用 Core 的原位置绑定、Main 的页面存续与保留原因、原公共进程指标，区分未实例化、运行中、已释放与未知；同页多处展示不重复记实体或进程占用。共享进程和未知归属如实表达，不按页面数均分 RSS，不从标题、地址或旧记录猜创建者与当前使用者。原准确目标的安全释放、恢复及每项批量结果经同一公共能力供人和 Agent 使用，失败保留原目录、页面与可执行恢复路径；查看目录本身不创建页面或建立第二生命周期账本。目录明确本次查询的完整或部分覆盖；部分查询或读取失败不证明未返回的页面已删除，保留其上次观测并标明旧范围，当前可用数量只计本次实际观察到的页面。隐藏的设置页不持续订阅或查询目录。释放内存、显式关闭页面及清理网站数据分别表达，清理登录存储仍沿原 Profile／站点数据批准合同。
- **资源管理先认页、再比较占用和动作。** 默认列表能直接认出页面、当前资源状态、进程占用与可执行动作；完整地址、技术身份、全部位置、原始保护原因及进程明细按需展开。页面存续、释放保护、本次目录覆盖和进程采样各自表达，缺测不填零，上次观测不冒充当前；共享进程不显示为单页独占内存，也不承诺释放某页即可收回所列进程占用。排序与刷新保留原对象选择和键盘焦点，不因数值更新切换操作目标。
- **单页和批量管理都有明确范围。** 批量动作冻结用户明确选择的准确 Browser／文档集合，不把较晚筛选结果或新出现页面补入原批次；各项仍由 Main 在动作前复核原保护事实。结果按原对象分别表达已释放、保留与未确认，局部失败保留其他结果及原页面。安全释放复用原请求，不额外层叠通用批准流程；保护中的页面说明原因，仍可定位、读取详情并沿原恢复入口继续使用。自动释放偏好沿原设置保存，手动资源动作及其回执立即生效，两种范围清楚可辨。
- **公开恢复回执只说明本次原生取得。** 准确目标的公开恢复复用原页面 owner，完整回执仅确认本次已取得的当前原生页面及文档身份，不表示页面内容加载完成，也不提供原 Browser 程序日志之外的恢复历史。未取得完整回执时保留原业务请求身份和未知结果，不自动重发；后续当前页面观察不追认旧恢复已完成。
- **公开释放复用同一安全判定。** 工具按准确 Browser 与当前文档身份请求原 Main owner 释放，不为释放创建页面或扫描全部目录；可见、使用中或风险未知的页面仍按同一保护事实保留。每项回执分别说明已释放、保留或未知及其原因，不关闭 Region、清理网站数据或停止健康 Agent。未获完整回执保留原业务请求身份，不自动重发；当前目录观察不追认旧释放完成。
- **已用操作身份只指向原记录。** 原日志仍保留同一 Browser 程序的 `operationId` 记录时，重复提交不得覆盖原记录、创建页面来重跑程序或把未知结果改称成功。公开入口明确返回操作身份已存在，调用方沿原操作查询、历史与订阅读取当前事实；并发重复提交也由唯一日志 owner 裁决。新操作和原 Browser 的其他健康能力保持可用。
- 原生 Browser 的多位置媒体预览、失败与重试边界只见本页[《多位置呈现、局部遮挡与输入交接》](#多位置呈现局部遮挡与输入交接)。
- **呈现资格依据准确文档，不能依据资源是否加载完。** 受信 App 的当前文档可以在无关资源仍加载时登记和使用原 Browser 呈现；加载进度不证明请求者失去资格。异步准备前确认的原文档请求不能在导航后转由新文档受理，旧文档的租约、采集与输入授权随真实文档更替失效，同文档导航继续保留。失败说明准确的呈现步骤与原因，不把内部登记拒绝说成网站或健康 Agent 失效；原页面和同身份恢复入口保持可用。
- Browser 驱动脚本的 `cdp(method, params)` 是明确的逃生口：Main 必须把 CDP 的成功结果原样交回脚本，并把协议异常作为失败浮现；不能把它变成静默 `undefined`。它是 Agent 自行补齐尚未封装浏览器能力的正式通路，正向结果和异常结果都必须有行为守卫。
- **New Browser 必须有可见结果**。在聚焦的 Universal Pane（包括当前不是 launcher 的非启动器
  Region）点击 `New Browser` 后，必须创建并显示一个 Browser Tab/Region；如果 Main-owned
  Browser 创建失败，必须在同一工作面给出确定性、可执行的错误。按钮不得在状态、Tab、Region
  和错误提示都不变化的情况下静默 no-op；renderer regression 要覆盖聚焦非 launcher pane 的
  Tab/Region/browser 状态变化或错误投影。
- 页面**元素选择**产出结构化上下文——tagName、role、可访问名、selector、文本、邻近文本、白名单属性与净化后的 HTML——并以文本形式进入 Composer 草稿，与其他附件同一条通路。净化在 Main 侧完成，Renderer 不把原始 DOM 当证据传递。当前**不采集 computed CSS**，截图**不自动并入 prompt**；图像复制及显式保存可编辑原稿沿[《Browser 页面截图与标记》](#browser-页面截图与标记)，不以"看起来完整"的措辞掩盖这些边界。
- Agent 发起的元素上下文通过 Browser drive 的显式 `elementContext(ref)` 入口提供：目标必须来自当前 Browser snapshot 的授权 ref，经 Main-owned CDP 句柄解析；入口只能读取结构化字段（tagName、role、可访问名、selector、文本、邻近文本、白名单属性、净化 HTML），不能返回原始 DOM 或执行事件。入口与人工选择是两条有意分开的能力：人工选择继续由真实 `event.isTrusted` 门禁保护，Agent 入口不得删除或绕过该门禁。
- `elementContext` 失败必须保持可区分：ref 不在当前快照、ref 解析后不是 Element、页面导航/句柄失效和提取/净化错误分别给出可行动诊断；不能静默返回空对象或把失败伪装成 Agent 没有权限。读取结果沿 Browser drive 的 typed receipt/Composer 通路交付，不能在 Renderer 另建一份 DOM 事实。
- 截屏与标记编辑属于 Browser 自己的工具，观察、绘图、复制与退出沿[《Browser 页面截图与标记》](#browser-页面截图与标记)的同一生命周期；系统截图入口仍由 Message Tools 原合同持有。
- 链接打开使用统一的**目的地菜单**（当前 Region / 分屏 / 新 Tab），与 Terminal 链接共享同一套目的地语汇，不让浏览器另发明一套打开语义。
- **Agent 正在驱动某个 Browser 时，不切过去也要知道是哪一格。** 页面内角标只在人看着那一页时成立，
  而人恰恰是"在别处干活、想知道那边跑到哪了"。所以标签上的 Browser 标记在被驱动期间要与闲着的
  Browser **画得不一样**，且这条差别是标记去重的一部分——两个 Browser Region 一个在被驱动一个没有，
  标签上必须画两个，折成一个就是把"哪一格在被驱动"这条信息折没了。驱动是**瞬时事实**，随运行开始
  和结束，绝不进持久化：重启后复活一个"正在被驱动"的死标记，比不画更糟。
- Browser Profile 从当前 Browser 的管理入口导入，不强制跳到 Survey；入口归属引用[《Survey、临时 Zone 工作面与知识入口》](knowledge-workflows.md#survey临时-zone-工作面与知识入口)，凭据与 Cookie 归 Main；导入路径落在 Workspace/Profile 约束内，逃出约束一律 typed 失败关闭，不静默降级到默认 Profile。
- **应用链接（非 `http(s)` 的 URL scheme，例如自定义应用 scheme 与 `mailto:`）要像一般浏览器那样交给对应应用，不能当成非法地址挡掉。** 用户原话：「对齐一般浏览器，假定用户会自己把本应用当做浏览器」。这类链接不能被静默吞掉，也不能因为某个站点的按钮形态而增加站点专用分支。约束：
  - **页内导航与新窗口请求都要正确交接。** 页内导航、`window.open` 与 `target="_blank"` 分别覆盖同一应用链接语义；应用链接不留在原生页面中加载，也不生成应用管不着的空窗口。原页面与 Browser 工作面保持，普通网页弹窗仍沿既有语义处理。
  - **默认不静默移交，也不静默丢弃。** 每个 scheme 首次出现时问一次，允许记住选择；拒绝或失败在同一工作面说明，并给出下一步。一个被访问的页面可以任意构造 `scheme://…`，不能无条件拿页面给定的参数启动本机应用。
  - 本应用的 `amux://` 对象链接同样经过上述网页来源询问与已记住的选择，获准后沿[统一对象打开边界](public-control.md#对象地址分享与方向)在内部打开；其他应用链接仍由系统移交。页内、重定向、frame、新窗口及 Browser 弹窗中的地址输入均保留准确原 URI、来源请求与同一授权结果，不因改走内部入口重新询问、绕过拒绝或加载空白网页。
  - 当前分类与交接入口见 [browser-app-link.ts](../../../apps/desktop/src/main/browser-app-link.ts) 的 `classifyBrowserTarget`、`appLinkOutcome`、`browserWindowOpenOutcome`；原 [BrowserViewManager](../../../apps/desktop/src/main/browser-view-manager.ts) 将页内导航与 `setWindowOpenHandler` 的结果投影回同一工作面。
  - `mailto:` 属于同一类，不单开一条通路。
  - **公共机制必须使用协议事实而不是站点身份。** 生产代码、公共测试、设计文档和帮助文字不得预设具体站点、产品名、厂商协议、按钮文案或登录流程；测试交接时使用合成 scheme 和通用触发形态，至少覆盖两个不同形态。真实站点只能作为黑盒输入，发现问题时修复它背后的 URL、frame、系统交接或用户确认机制。

- **「把一个链接存成文件」和「打开一个存着链接的文件」是一般浏览器的既有能力，走标准格式，不自造。** 本机实测确认三种格式都被系统认得：`.webloc`（macOS，plist，键为 `URL`；`kMDItemContentType = com.apple.web-internet-location`，XML 与二进制 plist 两种皆可）、`.url`（`[InternetShortcut]` + `URL=`，CRLF；macOS 报 `com.microsoft.internet-shortcut`）、以及 Netscape bookmark HTML（`<!DOCTYPE NETSCAPE-Bookmark-file-1>`，每家浏览器导入导出都用它）。约束：单条链接的存取用前两者（`.webloc` 在本平台是首选，`.url` 只读即可），整批导入导出用第三者。存下来的文件必须能被本机 Finder 与其他浏览器直接打开——自造一份 JSON 就把这条能力关在了应用内部，那还不如不做。

收藏保存沿原 Workspace 标准文件写入通路。保存期间只有同一保存动作等待，地址提交、前后退、刷新、Viewport 及其它健康页面能力继续可用；动作附近表达保存中、已确认产物、失败或结果未知。结果归本次原页面与导航，迟到回执不冒后来页面已保存；未知写入保留准确候选文件与检查入口，不自动再次写入，另存副本必须明确表达新的保存意图。

- 内置浏览器只能打开本机可达的地址。**没有 SSH 转发或隧道**，因此"看远端主机的 dev server"当前不成立。远端 Agent 的 Runtime 管理沿[联邦 Runtime 与远端恢复边界](session-recovery.md#联邦-runtime-与远端恢复边界)；这项能力不提供 Browser 的端口转发，也不为 Browser 单开私有通路。

### Agent 操作可见性与输入隔离

用户要求操作时能看见虚拟鼠标、旁边的头像与标题，以及颜色可配置的 Browser 边框内发光；显式接管前不能干涉网页，但仍可查看轨迹和与操作者沟通。本节补充这些已确认要求，不证明当前源码或安装版已经满足。

- **控制权与动作进度分别表达。** 持续的身份与边界提示消费准确 Browser 的当前控制事实，瞬时指针与执行反馈只消费真实动作。Agent 已取得 Browser 控制后，等待、导航、页面重绘、单次程序完成或两次程序间隙均不自动转成人工控制；普通人工输入同样不接管。Browser 控制权独立于当前活动程序，转成人工控制须本人显式接管，不能由 Agent Session working、最后操作者、旧 operation 或页面文案推断。原生页面与被动镜像表达同一控制事实，镜像不取得输入权。显示偏好已启用且准确 Browser 已确认由 Agent 控制时，原生页面或镜像中的实际页面范围首次可见即应显示控制边界，不要求先切换工作面、重新选中或再次执行动作来激活；尚未取得页面画面或控制事实时保持其真实未确认状态，不补造边界事实。单次程序结束立即停止 busy 与执行循环，控制身份、边界和输入隔离仍沿原 owner 保留；等待、导航及结束后没有真实目标位置时不保留旧指针，也不编造坐标。已有 chrome 分别说明真实执行阶段与当前控制权，接管／交还入口始终沿原控制事实可达；交还不重放旧程序。边框显示偏好仍由本人选择，隐藏光效不隐藏身份／控制状态或接管入口，也不改变权限；装饰失败与输入隔离分别处理。只读目录与历史查询不取得控制权。
- **就近表达真实动作。** 原 Main 的 Browser／operation／step／navigation 事实沿[通用当前阶段与动作合同](agent-capabilities-and-messaging.md#agent-当前阶段与动作的可见表达)投影到同一操作者旁：snapshot／read 是观察，实际 js 是脚本，raw CDP 是协议／工具调用，click／type／scroll／navigation 分别表达，不从 opaque 调用名或页面文案猜更细动作。Browser 等待不代替 Agent 的思考证明，当前 Provider 只确认 working 时仍只说正在处理；原目标、非阻断、结束和失效继续沿本页既有合同。
- **虚拟鼠标携带真实身份。** 真实目标位置旁显示操作者头像、标题／名称和当前动作；身份沿原 AgentSession／Host 来源，未知不拼造名称，不把任务名当作者。页面内头像复用同一 Session 的既有头像外观，使用宿主核验的有限静态资源，不向网页提供外部资源地址或由网页另取身份资源。头像资源不可用时保留可辨的身份回落，不能阻断页面动作；迟到资源只修饰仍有效的原提示，不重建已消退、隐藏或导航失效的提示，不延长完成反馈。操作呈现偏好与实时模拟由 [Browser use 设置](settings-and-observation.md#browser-use-与-agent-操作呈现)持有，沿原 Settings owner 及同一公开配置能力发现、读取和修改；偏好变化不改变权限、输入资格或任务结果。具体材质、布局与动态效果只见[呈现合同](../presentation/browser-workface.md#browser-控制权提示)。
- **点击反馈取真实派发。** 目标处的一次局部波纹只消费原动作在准确目标上的实际派发确认，不由动作计划、显示指针或 hover 触发，也不把派发确认升级为网页业务结果或整项任务成功。波纹遵守同一提示的 owner、失效和有界预算，不等待动画结束后才交回原动作结果。
- **隔离守在原网页输入入口。** 准确 Browser 确认处于 Agent 控制期间，包括单次程序结束后的空闲阶段，普通人工指针事件（包括 hover）、点击、滚轮、触摸、键盘／IME、粘贴、拖放及网页菜单不能进入网页而改变页面；地址提交、前后退、刷新和修改执行 Viewport 同样不能绕过显式接管。地址草稿、复制链接和宿主自己的阅读、轨迹、消息、框选、切换工作面及接管／停止继续可用。隔离只约束本页，不关闭健康 Agent、不阻断其他 Browser 或工作面，不借透明 DOM 遮罩、页面自述或装饰光效认证输入归属。
- **接管不穿透。** 本人明确接管先在原 Browser／operation 上撤去后续动作派发资格，再交接网页输入；触发接管的那次手势不会同时点击网页。已派发动作与停止回执分别对账，未知副作用不自动重放；不能因为控制权已交人就把仍在途的动作说成已撤销。交还后从当前页重新观察，不续播旧动作。等待本人认证或检查点只开放原请求所需的人工通路，不以普通消息或任意网页点击代替批准。
- **输入隔离与呈现失败分开。** 头像、光效、轨迹或消息投影失败不改变已经确认的控制权；就近持续说明失败步骤和恢复动作，并保留显式接管。观测 unknown 不凭旧记录新建永久隔离，也不称已取得人工控制；沿原 owner 核对原操作与交接事实。当前隔离服务提示沿准确原生恢复或显式人工接管事实消退，不让旧操作的失败记录冒充当前故障；仍未确认的隔离和其他未解决提示继续可见，原操作回执与历史保留曾经失败的事实。外部共享标签若没有宿主输入隔离能力，明确其能力边界，不能把 AgentMux 内的装饰边框冒充对外部浏览器全部人工输入的隔离。
- **看轨迹不操作原页。** 阅读历史步骤、滚动轨迹或查看旧证据不导航、滚动、重放或点击当前网页。历史步骤明确来源 operation、导航与步骤身份，历史预览与 live page 可辨；没有保留的坐标或页面证据就明确缺失，不根据步骤标题编造鼠标路径。展开阅读面不能偷偷改变 Agent 的执行 Viewport；宿主布局与实际几何变化仍沿原 Browser／Viewport owner 处理，不另建页面身份。

### 从 Browser 创建 Agent

- 人工控制的 Browser 明确没有关联 Agent 时，原交还位置提供“在右侧创建 Agent”。点击后在该 Browser 展示所在的同一 Tab 中、相邻右侧新建 Region 并创建一个 Agent；保留原 Browser、页面、地址、输入及其他 Region，不另开 Tab 或覆盖已有内容。空间身份、布局持久化与 Agent 生命周期沿原 Core 公共能力，创建后的原 Browser 与新 Agent 在真实重启后仍可见并按原身份恢复。
- 新 Agent 的初始指令携带本次准确 Browser 及其展示位置、当前页面的必要上下文，明确先查 Browser 和空间相关 skill，再复用该 Browser 工作，不重新创建或猜测目标。页面 URL、标题与页面内容仍是来源数据，不能升级为平台指令或新的操作授权。
- 用户这次点击同时明确授权把该 Browser 交给本次新建的 Agent；创建和准确关联确认后，通过原可信 Browser 控制链自动交接，无需再点一次交还。Agent 从当前页面重新观察，原程序、历史步骤与未知副作用不自动重放，原接管和停止继续可用。创建已发生、位置已保存、初始指令已投递与控制已交接分别按实际回执表达；未确认时保留原身份、页面和仍可用能力，并说明失败步骤及恢复动作，不盲目再创建 Agent。
- 入口选择消费准确 Browser 的控制和关联事实，不以“当前没有运行中的程序”、历史操作条是否可见或 Session 展示列表缺席推断无人关联；未知明确为未知。已有准确关联时沿原交还入口继续工作，不借本入口替换原 Agent 或恢复身份。

### Browser 场景消息与框选沟通

- 当前 Browser 提供快捷向操作者发消息的非模态浮窗。正文由用户编写并明确发送，作者保持用户；平台附带 Browser 场景，不包装成操作者给自己发的 A2A，不借 `agent send` 或终端注入改写作者。输入与实际投递沿[场景化用户输入](conversation-input.md#场景化用户输入)，准确格式与捕获来源边界由[amux 协议](../../specs/amux-protocol.md#场景捕获来源与原输入)持有；协议确认不代签浮窗、框选或安装交付。
- 新草稿按准确 Browser 当前可信 Agent 关联中的 Host／AgentSession，结合该 Session 的实际 `AgentSessionControl`，确认并固定接收者；没有当前或历史 operation 不影响已确认关联的沟通。operation 的 operator、历史步骤、显示名称与 Provider 图标只作场景上下文，不授予投递身份，也不把旧操作者当作当前接收者。关联或实际 SessionControl 未确认时，明确本次接收目标未知及原关联／Session 的查验恢复动作，保留草稿、原页面、健康 Agent 与既有输入能力，不猜另一 Host、Agent 或 Run。
- 旧草稿保留打开时确认的原接收 Host／AgentSession、Run 条件、消息身份与来源 Browser；页面 URL、导航、operation 和步骤带明确的捕获时刻。Agent 继续执行、Run 或关联改变、导航及历史步骤变化都不覆盖草稿、不暗改原目标／Run、不自动重发；捕获来源与后来发送时的已观察状态分别表达，缺失事实保持未知。本人显式建立新意见或处理原未准入输入，继续沿[场景化用户输入](conversation-input.md#场景化用户输入)及原队列的目标、条件与回执合同，不另造 Browser 投递通路。
- 用户可以就当前步骤、某条历史步骤、页面元素或框选区域写消息。框选属于宿主观察工具，不把鼠标拖动／选择事件送进 Agent 正在操作的网页。选区绑定实际捕获帧、原 Browser／navigation、viewport 与坐标空间；页面继续运行时仍标明这是那一帧的意见，不将旧像素当新 DOM ref。实时元素上下文继续沿 Main 净化 owner，截图、裁剪与编号批注复用[既有截图工具](#browser-页面截图与标记)；像素选区不推断 selector 或元素身份。
- 捕获、发送前都能查看并移除附带上下文；只发送本人选择的必要信息。网页 title、URL、文本与截图属于页面来源数据，不升级为平台指令或授权；敏感内容沿原输入与截图边界处理。截图不是默认附件，框选或附图由本人明确选择；无法取得图像时仍可仅发文字，不关闭健康 Browser 或消息能力。
- 打开、关闭浮窗、打字、读轨迹、框选与发送均不自动接管、停止 Browser 程序或批准权限。忙碌时沿已有 Provider／Core 能力决定排队或显式即时输入，不能承诺一发即改变当前动作；需要立即阻止网页副作用时使用明确接管／停止入口。已入队、实际提交、投递确认和 Agent 是否采用意见分别呈现，未知保留原输入身份，不自动重发。

### 匿名 Browser

- Browser 在创建时明确采用 `normal` 或 `private` 模式，Main 持有准确模式与网站数据上下文；创建后不在两种模式间切换。普通 Profile 继续沿原持久 owner 使用和切换，不被匿名创建、更名、清空或替换；匿名 Browser 不使用普通 Profile。失败或未知不回退普通 Profile，也不删除原页面、草稿或健康 Run。
- 每个匿名 Browser 有独立的一次性网站 session，不与普通或其他匿名 Browser 共享 Cookie、网站存储及缓存；其原生子窗口继承所属 Browser 的匿名 session。网站数据不持久化；模式不授予新的自动化、认证、应用交接或文件权限，不承诺隐藏 IP、网络身份或网站指纹。
- 隐藏或只释放原生页面资源不结束匿名 session；重复恢复仍指向原 Browser 和同次 session。本人明确关闭该 Browser 才结束其 session，之后新建不继承旧状态。关闭清理只作用准确匿名 owner 及其子窗口，不能扩大到普通 Profile 或其他匿名页；清理结果未知须如实说明，不复用可能遗留数据的 session。
- 匿名导航与人工地址／搜索输入不持久记录，不读取普通 Profile 的历史建议。普通重启保留原 Tab、Region、混合内容及分割布局，匿名位置恢复为新的匿名空白页并明确临时数据已结束；不保存或恢复匿名访问 URL、标题、favicon、网页历史或临时 session 身份。正常页面的原 URL／Profile 恢复保持。
- Survey 创建菜单和 Browser 更多菜单提供明确的新匿名页动作，沿原准确资源和放置链创建独立 Browser，不改变当前页的模式或 Profile，不要求先关闭原页。公开 `browser.open` 使用同一模式合同，CLI 的 `--private` 明确创建匿名页；返回与目标发现表达必要的非敏感模式，不暴露 partition、Cookie 或本机凭据路径。未指定仍按正常模式创建，不增加默认匿名偏好。
- 用户明确保存的文件、书签、下载及 Agent 操作回执按其原合同保留，匿名不等于磁盘零痕迹；入口说明实际网站数据生命周期和这些留存边界，不自动抹除成果或权威操作身份。网站临时数据结束与工作面身份保全分别验证，不以清空 Profile、删除 Region 或空截图代签隔离。

### Browser 页面截图与标记

- 标记后的图像仍是原 Browser 同一次页面观察的产物，不重建第二份截图生命周期。页面截图只取原页面，不以系统屏幕选区或音频采集授权作为前置，也不暗中切换成系统选区截图；系统截图入口的副本身份、授权、取消与失败边界只引用[《Message Tools 失败反馈与 Browser Region 选中态》](conversation-input.md#message-tools-失败反馈与-browser-region-选中态)。普通图像交付由本人显式复制，可编辑原稿由本人显式保存；两者均不自动并入 prompt。
- 图片标注组件编辑宿主明确提供的同一张图像及其原图尺寸，自身不持有 Browser、Agent 或文件身份，不自行捕获、读取宿主资源、写剪贴板或发送消息。宿主持有准确来源、捕获／读写资格、原生页让位与恢复、外围焦点交接及动作回执；组件边界不产生第二份页面、文件或编辑文档事实。已有 Browser 入口继续消费同一编辑实现，组件独立不等于系统截图或附件已接入编辑。
- 页面标记保留画笔、高亮、箭头、矩形、圆与文本，可明确选择、移动、删除或擦除已有标注；擦除只作用于标注，不破坏截图底图。已有区域形状可再次调整大小，箭头可改端点，已有文字可再次编辑；一次手势或文字提交形成一次可撤销编辑。裁剪限定本次导出的区域，像素化与实色遮盖均实际合成到预览和最终产物，不只覆盖一层可移走的 UI。标注、属性编辑与裁剪共用本次编辑的 Undo／Redo。
- Fit、原尺寸查看、放大缩小与平移只改变观察视口，不改原图坐标或导出内容；缩放和平移后选择、绘制、二次调整和文字输入仍命中实际图中目标。预览、裁剪后的图像和输出范围使用一致的坐标变换。选择一条编号批注能够将对应图像区域带回可见范围，定位不改其几何、显示编号或备注，也不导航原 Browser。
- 编号批注把图中准确区域与用户备注关联，形状身份与显示编号分别保留；编号、范围和备注随同一实际标注列表生成。现象／期望／要求提供可选的轻量正文模板，允许自由文字与空项，不成为保存、复制或继续绘图的必填门槛；正文只表达用户提供的信息，不授予权限，也不冒充网页 DOM、认证来源或操作完成事实。
- Copy PNG 与 Copy context 分别复制处理后的图像与可供 Agent 阅读的结构上下文，本人明确选择，不自动发送给 Agent。任一复制成功后保留原编辑器及标注，用户可继续编辑或分别、重复复制图像与上下文，再明确 Cancel 退出；临时隐藏或切到其他 Tab 保留本次图像标注和备注，隐藏的编辑器不接管其他工作面的按键或持续绘图。成功确认只对应本次实际复制回执，不表示后来修改也已复制。上下文说明同次捕获的页面来源 URL／title／viewport、原图尺寸、裁剪和导出坐标关系，以及编号＋范围＋备注；来源或坐标未知明确缺失，不借较晚页面、不从图像猜 DOM／selector 或认证页面自述。像素化与实色遮盖区域均不附备注或被遮内容上下文，裁剪外与未处理底图、编辑历史不进入本次处理后输出；不以像素化承诺秘密绝对不可推断。图像处理或任一复制失败分别如实反馈，不冒另一项成功。
- 显式保存的可编辑文档保留继续编辑所需的图像、原图尺寸、标注身份与几何、正文、裁剪及已知捕获来源；重开后能够继续修改并导出，不能只存处理后 PNG 冒充可编辑。原稿可含被遮原图与可修改的遮盖，保存入口须明确其与脱敏交付的区别，不默认随处理图／context 附送。文件内容不得触发脚本、网络抓取或任意本机资源读取；重开使用文档原有来源，未知仍未知，不以当前页面补造或重放旧操作。
- 保存和重开复用准确 Host／Workspace／路径上的原用户文件能力，修订、冲突、unknown、外部变更与保留新草稿沿[《Revision-aware 保存与外部冲突》](files-and-git.md#revision-aware-保存与外部冲突)。未确认写入不显示已保存，较晚回执不清除后来修改；读取、格式版本、图像解码或标注校验失败保留当前编辑，不以半解析数据替换。超出实际文件或图像预算时只说明本次保存／重开不能完成，保留可用绘图、处理后复制与退出；不静默截短原稿或增加后台截图库。
- 人工连续绘图、工具选择和取消保持可操作，不能因截图预览、标记绘制或原生投影重绘而吞掉真实输入、截断笔画或让退出等待流程完成。绘制与输入更新仅作用于本次编辑器和相关事实，不让无关 Browser、Session 或工作面承担持续绘图成本；正常与窄分割、长笔画及缩放后用实际 Native Renderer 验证响应与最终产物，不以静态画面或模拟 Canvas 代签流畅。
- Cancel 退出本次标记并回到原 Browser 页面，原 Browser 身份、Profile、地址、工作面与健康 Run 保留；退出不要求重新创建或导航原页，不以编码或复制 busy 禁用取消。较晚的图像处理、绘制或复制结果不得重新打开已取消的编辑器，也不覆盖后来的截图。取消尚未提交的复制不写剪贴板；已经交给原剪贴板 owner 的写入按实际回执表达，结果未知不称未发生、不自动重试或伪造撤销。编码或复制失败就地说明，仍保留当前可用绘图与退出路径。

### Browser 空白起始页

- **起始页通过通用配置接入。** Browser 空白页的主标题、副标题、可选图标、背景图与历史展示开关由宿主提供的起始页配置表达，不从 Survey 名称、展示归属或控制面开合推导外观。图标未设置即不显示，不暗中补默认品牌；背景图未设置时沿原主题。配置只决定空白起点的呈现，不改变 Browser／Tab／Region 身份、Profile、资源 Workspace、控制权、执行或恢复；Survey 的场景标题只见[《Survey、临时 Zone 工作面与知识入口》](knowledge-workflows.md#survey临时-zone-工作面与知识入口)。
- **中央输入沿原导航能力。** 启用起始页且原 Browser 为空白页时，地址／搜索输入在页面中央，顶部不重复同一输入；离开空白页后起始页让位于真实网页，顶部地址／搜索框继续可达。两处输入共享下述[地址／搜索输入历史与基础编辑](#browser-地址搜索输入历史与基础编辑)的提交、焦点、草稿、IME 与失败合同，不为换位置新建 Browser、导航 owner 或输入历史。
- **配置沿原 Browser 设置 owner。** 主副标题、图标／背景资源与历史开关从同一设置事实读取和更改；GUI 与公开 Settings 查询、检查和设置入口同源，发现与真实消费遵守[公共能力贡献约定](../../guides/public-capability-contributions.md)。配置变化仅影响相关宿主的起始页，不导航、创建、关闭或重建已打开页面，也不改原草稿与选择。
- **历史相册是原提交记录的可选视图。** 开关开启时展示当前实际 Workspace／Profile 的最近地址与搜索；范围、隐私、去重、持久化和失败沿原 Main 输入历史 owner，不称全量网页访问历史，不将 Agent／CLI 导航或未提交草稿补成记录。关闭时不读取该视图所需历史，也不删除存量记录；输入建议仍沿原入口按需可用。仅展示卡片不导航、启动或恢复页面；本人明确选择后沿原 Browser 导航处理准确提交文本，不另建图库、历史存储或截图生命周期。
- **辅助内容失败保留起步能力。** 图标、背景或历史读取未确认，只影响对应呈现；历史空集合与读取失败可辨，失败在起始页就近持续说明并提供重试，不能冒称没有历史。中央输入、正常导航、原工作面与健康 Run 保持可用；晚到结果不得覆盖后来的配置、Profile、页面、草稿或焦点。读取与呈现只随当前相关消费者增长，不扫描或唤醒无关 Session／Browser。

视觉、卡片密度与背景可读性唯一见[《Browser 空白起始页》](../presentation/browser-workface.md#browser-空白起始页)。

### Browser 地址／搜索输入历史与基础编辑

- 地址／搜索框按提交内容打开：完整网址、可识别的裸域名与本地开发地址沿原导航；其余普通文字（包括单词、中文和数字）直接用当前默认搜索引擎搜索，保留原查询含义并正确编码。空输入、本地文件和明确协议继续沿原边界处理，不用网络探测猜输入，也不把明确协议的失败改成搜索。Main 与同一输入的 Preview 消费共同判定；输入历史仍记录人的原文，搜索不改变焦点、Profile 或原 Browser 身份。

- **建议由人工意图展开。** 打开、恢复 Survey 或程序自动聚焦地址／搜索框时，只准备输入，不自动读取或展开历史。人工点击、编辑文本或按上下方向键时，在当前输入附近展开真实范围的有界建议；空输入及未编辑地址可显示最近提交，人工编辑后按原查询过滤。建议复用下述 Main 历史 owner，不创建导航、启动 Agent、读剪贴板或另造记录。Enter 明确采用、Escape 关闭与指针选择可达，IME 合成不提交；关闭或目标／Profile 改变后旧结果不重开浮层、不覆盖新稿。历史读取失败保原输入和正常导航，沿原服务窗说明。
- 人工点击地址／搜索框必须能聚焦、编辑、移动光标与选择文字；原生内容区域、历史列表及其他浮层不得截走不属于自己的指针或键盘输入，也不能因历史或观察流程失败而封闭仍可用的输入。原页面、工作面和健康 Run 保留，草稿与编辑归属沿以下约束。
- 用户要求“Browser 输入框应记录历史，支持复制／粘贴／剪切”。顶部地址／搜索框及 Survey／Launcher 的同一人工入口共享输入行为；只记录人显式提交的非空地址与搜索词，不采集未提交草稿、网页密码／表单或 Agent／CLI／脚本导航，不主动读取剪贴板作为历史来源；人粘贴后显式提交的地址／搜索按同一输入处理。历史按实际 Workspace 与 Profile 隔离，有界、去重、最近优先，保留搜索词与 URL query／fragment 的原意；带 URL userinfo 的输入不持久化，不猜任意文本是否秘密。用户能删除单条或清空当前范围，普通进程重启后仍可召回；历史与网页 back／forward 和 Agent 操作记录分开，未知归属不借默认 Profile 混库。读取／保存失败就近持续说明该能力降级，原输入、页面、正常导航与健康 Run 继续可用。
- 输入建议中的历史按需从原输入框就地展开；键盘上下选择、明确提交、Escape 收回与鼠标选择可用，IME 组合输入不误提交。未选定历史时保留当前草稿与选区；新的编辑、Workspace／Profile 或请求归属变化后，晚到历史与导航投影不能覆盖草稿或夺回焦点。列表不改变原 Browser／Tab／Region／分割生命周期，不因浮层隐藏整页；紧凑呈现只见密度 SSOT[《Browser RSI 操作表面》](../presentation/browser-workface.md#browser-rsi-操作表面)。
- 地址／搜索框和网页基础文本编辑支持平台原生复制、粘贴、剪切及原选择语义；快捷键与按需菜单复用成熟编辑能力，不建立另一份剪贴板或全局快捷键通道。可编辑、只读、空选区、disabled、密码与 contenteditable 沿真实平台能力区分，正常密码编辑不额外受限，不读取或保存秘密／选区／剪贴板内容到历史或日志。人工菜单只编辑原 window／WebContents／frame 与原局部输入目标；导航、销毁、换页或人切到另一个输入后，旧菜单不作用新目标，也不夺回焦点。普通 input、textarea、contenteditable 与嵌入 frame 的基础编辑保持，现 Region 菜单不能截走输入的原生编辑入口；不以脚本赋值或合成 ClipboardEvent 冒原生成功。

### 原生网页子窗口

- **同一 Browser owner 与公共目标。** 网页通过 `window.open`、链接或表单目标打开的子页面，进入与普通页面相同的 Browser 页面、控制与生命周期机制；各子页面具有准确的 Browser／navigation 身份，原 Workspace、Profile／匿名会话及来源关系按实际事实保留，不能借父页面 ID 冒充子页面。公共 `browser.targets` 可发现准确子页面，`browser.run`、历史、停止及其他标准公开能力直接消费同一 owner、授权与操作回执，不要求 Agent 另用窗口探测、标题匹配、同源脚本或 raw CDP 绕过正常目标寻址。能力、身份或观察未确认时如实表达，保留原页面、已有可用能力与恢复入口。
- **同一完整交互。** 子窗口复用正式 BrowserPane 与同一 Browser 的导航、工具、Agent 关联、动作反馈、输入隔离、接管／交还、操作轨迹及场景消息能力；具体资格与行为沿本页各 owning 章节，不因窗口宿主不同形成专属能力、控制状态、导航或轨迹副本。地址编辑、草稿、IME、输入历史与原生剪贴语义沿[原地址输入合同](#browser-地址搜索输入历史与基础编辑)，呈现沿[子窗口的统一 Browser 工作面](../presentation/browser-workface.md#原生网页子窗口导航)。
- **保留原网页对象与创建语义。** 同一 Browser owner 承接原 WebContents，导航、地址、历史栈、加载及可用动作始终消费该原生页面的准确事实；保留原网站 Session、Profile／匿名会话、`opener`／`noopener`、命名窗口复用、表单目标、POST／referrer 策略和 `window.close()`。不能以重建 WebContents、重开 Browser 或重放 URL 替代原创建／导航请求；原页面、未提交输入与其他工作面保持。
- Command／Control 点击、中键点击与网页自身的新窗口请求均保持可用，不因有无原 guest 或创建方式不同导致应用退出、漏接公共目标或留下未导航的空页。原请求的发起 frame、请求体、安全边界及原请求／回执身份随该次导航保留；来源未确认或导航效果未知时就近说明，不自动补发 URL、重复创建窗口或影响原页面、工作面与健康 Run。
- **原触发位置可查、可返回。** 子窗口保留原触发 Browser 与当时已确认的 Tab／Region、展示绑定引用，并提供查看准确来源和一键切回该位置的入口。位置与导航沿 Core 的[空间身份及全部展示绑定](spaces-and-layout.md#统一概念与空间寻址)查询；原对象移动后按原身份解析其当前位置，不用标题、当前焦点、Agent 的执行 cwd 或新出现页面猜来源。原位置已关闭、暂不可用或存在未解的多个展示候选时如实说明，保留原引用与子页面，不自动重建来源或选择首项；只有准确目标确认后才导航，切回不重新打开或重放原页面、不改变控制权，也不丢原输入与草稿。
- 原生独立窗口可以承载同一完整 Browser 工作面；窗口尺寸、原生关闭及展示位置由宿主处理，不另立简化导航或控制合同。本要求不强制改为右侧 Region，不新增目的地或默认偏好。其他 App 的系统 HTTP(S) 入口仍沿[系统网页进入原 Survey](knowledge-workflows.md#survey临时-zone-工作面与知识入口)及原 Settings 的系统默认选择合同，是否设为默认由本人决定。

### Browser 通用认证与 passkey 能力

用户反馈 passkey 页面报告支持不完整并一直等待浏览器交互；实际使用 Touch ID／系统钥匙串或密码管理器，要求对照成熟浏览器接入机制，并要求「抄一下吧，注意基于最新的 main」。Browser 必须区分网页等待、宿主能力尚未接入、系统／提供方不可用与用户尚未授权，不能用页面文案猜测认证结局，也不能把尚未证实的宿主或签名缺口当成某次失败的确定原因。

- 页面暴露 WebAuthn 不等于宿主凭据来源可用；来源尚未接入时须在当前 Browser 就近如实说明可用范围与下一步，不能只让用户无限等待，也不能把 Source 合入 main 当成运行中应用已生效。
- 认证归实际发起请求的 Browser、profile、frame、页面来源和本次请求；不能从当前焦点或另一个工作面猜归属。只有可信来源和相应系统能力可进入授权，导航、关闭或请求失效后不留下无法结束的选择等待，也不能把旧请求的选择交给新页面。暂时失焦、隐藏或最小化只影响账户选择的展示，不使仍有效的原请求失效；需要人选时就近说明等待本人返回，原 Browser 可见且原窗口获得焦点后才能展示，不主动激活窗口、切 Tab 或抢焦点。超时和真实失效仍结束一次。同 Browser 新请求结束旧请求，同窗口另一 Browser 的新请求不能覆盖已展示选择，可局部取消新请求并说明。发起 frame、祖先跨文档导航或 frame 被拆除后，原请求即失效并收尾。
- 设备接入按通用安全来源和 FIDO 协议裁决：仅 HTTPS 或可信 HTTP loopback 来源进入受限 HID 检查，实际设备必须具有 FIDO usage page；非 FIDO、非可信来源以及仅借 loopback 主机名伪装的其他 scheme 保持拒绝。多个可用设备由本人选择，不按列表首项猜设备；受限设备接线不代表系统 Touch ID 或既有钥匙串凭据已可用。
- 用户自己的设备绑定平台 key 与既有系统／密码管理器 key 是不同来源；可用性、实际创建或使用结果分别说明。页面能力探测、账户面出现、本地平台认证成功都不能冒充同步、跨设备或其他应用的既有 key 已可用；未知保持未知。
- 任意页面的平台凭据能力须由实际系统宿主和合法签名／授权条件证明；声明权限、应用自己的平台 key 或仅覆盖个别来源的关联条件不能冒通用浏览器能力。宿主可实现性或外部授权尚未确认就保持未接入／未验收范围，不能对用户承诺已可用。
- 系统认证和多账户选择必须由用户本人明确完成；选择、取消、明确拒绝与能力不可用各自有结果。原认证器仅返回一个合法候选账户时继续同一原请求，不额外制造一次账户批准；这不替代认证器或系统的用户验证与授权。AI 不在多个账户间代选或代替系统授权，不向 Agent／CLI 提供账户选择 API，不自动重试凭据拒绝，不把认证秘密、PIN、生物特征或凭据私密材料写入 trace、录制或可复用资产。
- 能力未配置、签名身份不匹配、当前来源不支持或认证失败只影响这次认证，沿当前 Browser 的服务窗说明未完成的步骤、实际可用范围和用户下一步。原页面、控制权、工作面与健康 Agent 保留可用，不因握手／探测失败关闭 Browser 或阻断 Agent。
- 普通重启后仍恢复原 Browser、profile 与工作面；认证能力和未完成请求各自按当前事实处理，不能从旧选择推定新授权或伪造认证成功。公共机制依据通用协议、来源、frame 与用户选择，实际站点仅作黑盒输入。

### Browser 任务能力与可复用资产

用户要求把调研中值得借鉴的能力融入 AgentMux，连同有价值的优化细节一起做；采用已验证的通用交互能力，保持现有 Browser、Agent 与 Terminal 工作面。视觉约束只归密度 SSOT[《Browser 任务工具与证据的紧凑呈现》](../presentation/browser-workface.md#browser-任务工具与证据的紧凑呈现)，本节定义必须成立的行为。

- Browser 异步状态须可辨，运行、等待人工、人工接管与失败不得互相冒充；动作按需出现且键盘可达。失败与未知沿既有服务窗说明事实和恢复动作，保留原页面、工作面与健康 Run。 重启恢复阶段尚无终局事实的 Unknown 或未附着状态不能被呈现为 Browser 完全损坏；保留正在恢复的原 Browser 与工作面，按服务窗说明未完成的阶段、当前能力与恢复动作。
- Tooltip 与小浮层出现时不能让整个 Browser 消失；原生层级只处理实际交叠范围，页面像素与未交叠区域的输入保持可用，不能以静态截图冒充可操作页面。正常 UI 缩放后，浮层与原页面仍须正确对位且可操作。用户缩放或浮层绘制失败，不能留下没有画出来却占用输入的浮层；保留原 Browser，释放失败浮层，并以局部服务窗说明失败及恢复动作。原生页面与 Chrome 浮层的绘制事实须由真正可用的 compositor frame 证明，不能以 DOM、CSS 或图像加载完成代替；依赖须包含已确认的维护方正式修复，不长期保留同一上游缺陷的本地可见性补丁。无关 Browser 不随全局 overlay 变化隐藏或反复重建；普通重启后仍保留原工作面。
- 重启恢复、字体或窗口壳布局变化只改变工作面位置而未改变尺寸时，原生 Browser 也须跟随实际位置；不靠隐藏再显示或强制聚焦纠正对位。
- 当前控制权允许人工网页输入时，用户对真实 Browser 页面的点按必须先或同时到达原页面且只触发一次页面输入，并按普通原生外部点击语义关闭点外的菜单或 popover；Agent 操作中的普通点按沿[输入隔离](#agent-操作可见性与输入隔离)，不自动接管或穿透网页。不能抢回工具焦点、执行隐藏 UI 动作或冒充真实权限确认，零浮层时不产生相关扫描、捕获或 IPC，已打开的 HTML popover 只处理该目标。终端或其他工作面的无关滚动，不能触发原生浮层扫描、捕获或 IPC；浮层自身、相关滚动容器与真实锚点移动仍须及时更新对位。
- 点击原生 Chrome 投影时，同一活跃 App 窗口内的焦点交接不关闭正在选择的菜单。原 Renderer 文档失焦不等于原 App 窗口离开；宿主依据原窗口的原生活跃状态及当前可见、已挂接投影的归属区分两者，不从瞬时 WebContents 读数推断焦点目的地。投影等待绘制不改变这一窗口归属；输入是否就绪仍按原投影的真实几何与输入资格单独判定。只呈现像素的投影不持有新的操作语义，元素失焦、真实窗口离开、页面外点与 Escape 仍沿原事件处理。
- 每个真实窄 Browser Pane 的必要动作与 More 都必须在自己的可见命中区可达，不能侵入或被 Region 的 Close split 命中区覆盖；收拢工具不改变关闭分割、原 Browser 身份、页面、焦点或健康 Run，不能改验收顺序避开窄分割。
- **操作证据回答具体哪一步出了什么问题。** 一次 Browser 操作的步骤、目标、页面/导航身份、结果来源、失败位置与可执行下一步能相互对应。观察、动作完成、脚本结束与业务成果是不同事实；已经执行过的动作不会因为后续失败、结果过大或证据保存失败而被说成没有执行。自动保存的证据只含有界、去敏后的事实；完整敏感页面、输入与凭据不因调试被默认留存。
- **局部观察和大结果都可继续读。** Agent 可以请求当前视口、指定 ref 周边或子树的有界观察，返回范围、实际采集范围、数量预算、缺失 frame 与裁剪事实明确。CSS 范围默认属于主 document，ref 范围属于它的真实 frame；未纳入的 frame 与读取失败的 frame 分开表达，不能把局部结果说成全页完整。同源或同进程的嵌入文档也必须按真实文档身份明确观察，或者告知缺失；不能因为它与主页面共用 CDP session 而没读到却报告完整成功。局部结果保留真实 ref 的身份与有效性，同一次 run 不复用已失效 ref，页面变化不会把旧 ref 静默重编号成另一个目标。超过一次回执容量的观察或结果提供归属于原 Browser/operation 的可读取产物引用与边界，不用杀掉健康 Agent、丢掉已做动作或返回空值解决；引用失效、读取失败或记录不可用有明确状态。小返回值不代表底层采集成本已经减小，实际工作量和相关消费者必须可以核对。
- **文件传输有完整闭环。** 浏览器下载从触发、接收、完成到可读取文件的事实连贯，下载失败、取消、尚未完成与成功可区分；先等待事件再触发动作时不会漏掉即时下载。上传只把明确选择的 Workspace 文件交给当前 Browser 的已授权目标，文件缺失、路径越界、导航失效或文件对话框取消不会退成上传了别的文件。传输产物关联来源页面、operation 和目标文件，经过现有 Workspace 路径与权限边界，可在原工具入口查看。
- **结构化输出与有限成果验收各自诚实。** 页面提取按明确的有限 schema 给出可验证的字段或缺失/不确定结果，来源仍是当前页面事实，不以模型自述补齐未观察数据。业务完成只根据当前这次执行登记的文件、结构化产物或明确人工检查点等有限证据判定；历史产物、另一次执行、外观相似页面与脚本退出成功不能代替当前成果。未满足与验收不可用分开表达；下载终局尚未确认、回执保存失败或事实读取失败时，不能把未知当成条件未达成。验收错误不改变健康 Run、Session 或 Browser 的权威状态。对 Agent 公开的成果 `completion` 与脚本结束 `outcome` 分开，保留原 Browser/operation/navigation/workspace 身份、实际资产 Run/版本、有限条件与失败或未知原因；Core 只解析高层 Client 的有界投影，不重新评页面、文件或人工确认，不持有第二份成果事实，也不依赖 Desktop。单项成果投影无效时说明其未知并保留原 operation/history 与健康工作面，不把缺失投影当成成果通过。成果检查的保存回执尚未返回时，该 checked 事实不能进入补发或实时订阅；回执之后，告示仍对应原来的这次检查。同一 operation 的订阅按发生顺序且只收到一次，补发与实时事件不重叠；等待一项成果保存不得延迟其他 operation 的真实进度。
- **人演示一遍，留下可编辑的语义资产。** 显式开始录制后，当前 Browser 的真实人工操作形成可检查的语义步骤，用户可以删改步骤、命名非秘密参数并预览。删除的步骤不能从原始录制自动复活；无法可靠定位的步骤、敏感输入与不可逆动作保留需要人处理的原因。资产有持久身份与明确版本，运行、编辑和验收分别绑定实际版本；重启后仍能找到草稿、已保存版本与已有产物，不能把旧运行验收套到新编辑上。 累计资产、不可变版本、运行和批次事实完整保留，历史条数或共享文档字节不能占用新操作的准入资格；单次任务和批处理的步骤、输入、动作及时长预算继续限定这次执行。任务还在准备时也必须能停；停止后不得因准备或记录迟到而启动后续动作，其他 Browser 的健康 Run 与原工作面保持。人工重新定位只接受这次真实人选目标，页面自述的同名状态不能替代该目标。
- **人工检查点处于真实流程中。** 需要人作决定时，说明当前步骤、目标、已完成动作和待确认结果；当前任务等待人工须在原 Browser 入口就近可辨并关联实际流程与版本，不能用上一步 completed 冒成整项完成，也不能以历史等待覆盖新的健康 Agent 活动；用户处理后从明确检查点继续，不从头重做，也不以 Agent 点击冒充人工批准。现有控制权交还、应用链接选择与敏感动作闸门仍沿[《Browser 工作面》](#browser-工作面-1)的同一事实，不建立第二份批准或控制权状态。
- **恢复只处理有理由恢复的局部失败。** 恢复保留原 Browser、原 operation 与已经完成的动作，记录失败分类、恢复目标、预算、尝试和结果证据。页面定位或导航失败与用户代码主动拒绝、凭据/权限拒绝、用户接管分开处理；副作用未知时先观察或交还人，不盲目重放整个程序。超过恢复预算或恢复能力不可用时，原页面和健康 Agent 仍可正常工作，服务窗说明当前状态与下一步。
- **外部标签只接本人明确分享的那个目标。** 用户要求受控接入已有外部浏览器标签并保留它的登录态。接入、观察和执行始终绑定本人明确分享的真实连接与标签身份；连接凭据可用不等于已授权任意标签，不能默认选第一个页面或接管其他页，也不导入外部 profile、cookie store、系统钥匙串或其他浏览器凭据；分享页内容可观察不等于页面秘密绝对隔离。外部目标和原生内嵌页面来源可辨，接入不代表内嵌认证已修复。撤回、目标关闭、断线和重连分别保留实际状态，身份未确认时不改指向另一页，不重放副作用；原页面、用户焦点、工作面与健康 Run 保留。
- **停止与撤回按实际来源表达。** 显式 `browser.stop` 终止该外部操作并结束该原 Tab 分享，后续操作须本人重新授予；reader cancel 仅停止结果订阅，不等同于 stop 或撤回分享。外部页面 DOM 的 `isTrusted` 不能证明本人接管，不据此归因是谁停止或撤回。
- **已选文件跟随原页面，不跟随连接。** 当原浏览器文档可独立于 Client 继续存在时，已赋给 FileList 的原 Workspace 文件快照必须在 Client 重启、撤回分享或断线后仍可读取；撤权不等于文档结束，不能为了清理继续观察已撤回页面或凭超时猜结束。未知文档保留快照并占原有有界预算，确证的原文档导航或关闭才释放相关快照，不影响其他页面；本人可在 Browser 设置明确丢弃其选中文件，但须先提示“原页面后续上传将不可读，先完成或取消上传”并确认，Agent 公开 CLI 不提供这一不可逆清理能力。
- **演示中的语义草稿及时可读，解释不覆盖人。** 用户要求演示时实时显示语义草稿并异步解释；沿上文人工演示的同一真实输入与秘密边界，已经观察到的动作、语义标题与非秘密参数预览可及时查看和纠错。观察事实、正在解释与尚不能确定分开表达，解释失败不挡继续演示；迟到解释不能改写用户已编辑或删除的步骤、打乱顺序或把未观察目标补成事实。停止和重新录制后仍保留原草稿，旧解释不混入新录制。
- **批处理只跑明确且有限的输入。** 用户要求有界批处理；每项绑定同一明确资产版本、输入身份和实际执行位置，项数、动作、时间与结果容量都有可检查的边界。逐项结果、已完成位置、失败、停止和待人工可辨，空输入不是业务成功；从检查点继续不重复已确认动作，副作用未知先观察或交还人，秘密不因批处理被保存。批处理不放大无关 Browser、会话或页面的工作。
- **条件分支依据本次有限事实。** 用户要求明确条件分支；条件、来源、已选路径与未执行路径可检查，真、假和未知不能混为一谈，观察或验收不可用不能落入假值或默认成功路径。执行位置包含实际分支与检查点，重启后不凭不完整状态重放；执行必须有界，不能以任意代码或自然语言判断偷换明确条件。人工批准仍属于原控制权与检查点事实。
- **可靠性按不可变流程版本和真实成果统计。** 用户要求按不可变流程版本统计真实可靠性；来源是该版本的实际执行、步骤与成果事实，不另持一份成功状态。分子、分母、样本范围与缺失事实可读，样本为零不显示成功率；脚本 completed、重试次数与历史结果不能冒充本次成果通过。未满足、验收不可用、停止、未知和人工介入分别说明，重复回执不重复计数，不把旧版本成绩套给新编辑。当前运行沿真实选择，不以最后创建的历史运行替代；统计只处理所选资产版本的相关事实。
- **能力归属与交付成本不变。** ctxmux 继续独占 Run/PTY/ordered bytes 与权威进程事实；Core/Provider 只持有其既有 Agent 和公开适配能力，Browser 原生事实、文件与证据由 Desktop Main 持有，流程资产、成果验收和恢复策略是消费公开 API 的高层 Client 能力，不另起 Agent 或 Browser Runtime。新增能力按通用协议、页面和文件事实泛化；真实重启后原 Tab/Group/Region/焦点/布局和健康 Run 保留，新增持久资产与结果引用可恢复或明确说出恢复限制。热路径工作只随被操作的 Browser、相关消费者和实际事实增长，不能扫描、广播或唤醒无关会话来呈现一个工具步骤。单步日志保存只处理该原 operation 的元数据、当前步骤与新增事件，不能因累计历史重复规范化或重写整库；重启后保留完整原步骤与回放屏障，未确认副作用仍为未知。

## Browser 通用交接闭环

- 用户要求「彻底完成」：外部应用交接以系统调用的完成或失败为准；失败在当前 Browser 说明失败步骤与重试动作，网页保持可用。记住选择失败不能阻断用户这一次明确同意的交接，也不能假装保存成功。
- 顶层、子 frame、重定向及新窗口中的应用链接复用同一机制；普通网页导航和原生窗口语义保持可用。异步结果不能覆盖后来的请求或已经离开的页面；一次用户回答只执行一次交接。
- 用户要求「Agent 在操作的指示要高级，最好也参考交接设计」：操作中、交还用户和结束必须可区分；接管与停止只消费本节的显式交接事实，不从普通输入猜控制权。提示不抢焦点、不遮挡主内容，页面装饰不能授予 Agent 控制权。

## Browser RSI 记录与回放可达性

- 操作历史是工作面的一等入口：没有新操作时也能打开，重启后仍能看到已完成、已停止和需要复核的记录。当前 Browser 的即时投影与 durable 历史不得各自维护一套语义；选择某条历史后，时间线、来源 Agent、页面身份和回放计划仍指向同一个 operation identity。历史列表和订阅 backlog 可以有界，但呈现窗口不能删除 durable 操作身份或步骤；活跃和结果未知的操作继续可见，窗口外的原记录仍可按准确身份查询，重启不会用新操作替代它。
- 回放计划必须保留所有已观察到的步骤。需要重新输入、权限确认、外部应用交接、脚本或协议逃生口等人工闸门可以阻止执行，但不能从预览和审计记录中消失，也不能让前面的动作先执行后才发现后面不可执行。旧记录存在步骤缺口、执行结果未知或没有安全的回放贡献时，保留原事实并说明复核动作；不能过滤后面的缺口或不可执行步骤，生成貌似完整的计划。缺步骤的原操作不得执行整轮或单步回放，Main 在派发前复核原记录；原操作含人工闸门或不可执行贡献时，不能靠调用者剥去阻断说明或选一个看似安全的单步绕过。拒绝只作用于这次回放，原页面、操作查询和健康 Agent 保持可用。
- 记录或投影写入失败属于流程状态：健康 Browser 继续工作，同时在操作条、历史入口或服务窗持续说明“记录不可用”和恢复动作；不能静默降级，也不能把空历史伪装成“没有操作”。
- 停止、接管、交还和单步回放必须通过同一条 Main-owned 控制链，拥有清晰的下一步和取消路径；Renderer 只能消费事实，不能自己推断某个回放已经成功。

## 原生 Browser 与 Agent 身份浮层

Agent 头像的 hover/focus 详情属于可跨 Region 阅读的非模态身份浮层，沿同一共享浮层协议呈现；原生层级、页面可见性和输入边界统一引用本页[《浮层让位与输入层级》](#浮层让位与输入层级)，不另持手动遮挡租约或第二份 Browser 可见状态。

### Browser 视口与尺寸调整

Browser 在窗口或分栏尺寸调整期间保持最近一次有效画面。Renderer 暂时得到零宽/零高或未完成布局时，属于几何过渡，不得把 Browser 当成关闭而调用隐藏；等下一次有效矩形到达后直接更新边界。真实不可见、明确切换或停放，以及截图／选择工具所需的临时遮挡，沿原可见性与工具归属处理。错误状态本身不构成隐藏授权：媒体捕获、呈现登记、观察或恢复未确认时，保留原页面、输入与服务窗；失败及重试边界见本页[《多位置呈现、局部遮挡与输入交接》](#多位置呈现局部遮挡与输入交接)。尺寸调整不能触发 Browser 销毁、重新导航或空白闪烁。

Viewport 固定预设按菜单声明设置原页面的模拟视图尺寸，完整适配当前 Pane；改变 Pane 尺寸后重新适配，Responsive 恢复跟随当前 Pane。任一模式选定后，用户仍能重新打开原 Viewport 菜单或窄 Pane 的 More，使用指针或键盘切换其他模式；进入 Mobile 不使后续切换失效，也不要求先调整窗口、刷新或重建 Browser 才能继续。模式与适配均作用于同一 Main-owned Browser，不改变 App 窗口、页面导航、Profile、草稿或兄弟页面；缩放后的实际画面与原生输入仍正确对位。页面自身有无 viewport meta 都沿标准浏览器布局，不注入 meta、伪造 UA 或改写页面来凑预设尺寸。选中状态对应原生设置实际成功的模式，应用失败说明失败并保留此前已确认模式与原页面，不发布未应用的新选择。

Viewport 直接入口与 More 的二级菜单共用相同选择与已应用状态。设备尺寸按手机、平板、桌面分组，提供常见型号尺寸、Portrait／Landscape 和自定义宽高；方向切换交换实际宽高，自定义尺寸沿同一 Main owner 设置、适配和恢复。设备名仅说明参考尺寸，不宣称等同真实硬件、UA、触摸能力或操作系统。


## 破坏性 Browser 操作的作用域与人工批准

- 清理 Profile 数据、删除 Profile 或登出等不可逆操作必须带明确的操作作用域；本轮最小闭环只允许用户删除一个指定的非默认 Profile，不能把整个 Browser 或所有 Profile 作为隐含范围。
- 破坏性操作必须经过用户在当前界面明确确认。调用入口传递结构化批准事实（操作、作用域、目标 Profile），主进程再次校验目标未被打开的 Browser 使用、不能是默认 Profile，并拒绝缺少批准事实的请求。
- Agent 浏览器自动化不能借用人的 UI 确认；没有专用的人批准事实时必须返回类型化拒绝，健康 Browser 与其登录态保持不变。


## 多位置呈现、局部遮挡与输入交接

启动恢复 Browser 或切换 Focus 等工作面时，未被明确选中的原生页面不得越出其展示位置、遮挡主界面或截走输入。媒体准备与采集等待同样遵守此边界，不因预览尚未就绪把原页面暴露在工作面上方；原页面、工作面、Session 与恢复路径保留。

设置只遮住当前背景呈现绑定：该绑定的原生 Browser 画面与输入不可见／不可命中，其他合法可见绑定继续按其实际目标呈现。Focus、Space、Survey、Recall、Mote 不赋予实体独占归属；关闭设置返回原绑定，不销毁实体、不重建原页面、不改变共享 Tab／Region／布局、Session／Run、导航、页面输入或草稿。不通过 CSS 遮盖、全实体隐藏或把实体回迁唯一宿主代替局部遮挡；Mote 明确显示在设置之上的绑定继续可操作。

共用 Browser 工作面首次显示不以 Space、Survey 或其他入口名称决定资格。当前明确选择、准确位置与真实可见几何共同决定原生初始化；隐藏注册与未确认激活不消耗后续恢复机会。显示恢复复核原选择，沿原页面与媒体 owner 继续，不重建网页、标签或登录上下文；被动镜像保持原输入归属。仅浏览工作面的导航、切离再返回与重显保留准确 Browser 的 Agent 控制，继续提供可读的原页面或预览；观看不取得网页输入权，也不授权修改执行 Viewport。Agent 正常持有输入、原生输入展示暂不迁移或已有输入隔离，本身均不是登记、采集或播放失败，不能因此要求 Retry 或显式接管才能继续观看；本次真正改变网页输入归属或执行尺寸的操作仍沿原控制边界判定。真实采集未确认保留原页面、地址和导航，并在本页提供重试同一展示的动作；重试不重复导航或创建资源。

同一原生 Browser 的多处画面跟随其活体页面正常导航，媒体请求者 App 文档失效、原生来源资源替换／释放或最后可见绑定撤去时收其媒体资源，局部撤去不损其他合法绑定，媒体流程未确认时保原 Browser 可工作并明确说明，媒体撤销不解释为关闭实体。媒体预览不是原页面加载、导航或人工输入的前置条件；同一次采集失败、拒绝或超时后，保留原页面与持续服务窗，布局或尺寸变化不得自动反复申请采集或权限，沿原服务窗提供明确重试，由人显式发起。 整个 Tab 的准确展示包含其中实际可见的 Browser 兄弟 Region，不因当前选择引用指向同 Tab 的 Agent Region 而排除其原页面。有效的显式选择意图独立于几何是否变化：相同正面积下的新选择仍消费当前原生呈现，采集失败不阻止这一交接；被动呈现与恢复保留 Composer／编辑器输入焦点，hover 不自动取得原页面输入归属，过期或撤去的选择不复活。

同一位置已经由 Main 确认的原生页面提供当前画面与输入时，该位置不持续消费被原生页面完全遮住的媒体预览。此边界只消费准确原对象、当前展示租约与真实呈现回执，不从期望选择、DOM 可见性、标题或页面内容猜原生归属。原预览帧、共享媒体与其它合法被动镜像继续保留；恢复预览不降清晰度或动态节奏，不重新导航或取得输入权。未确认、交接在途或原生呈现让位时，保留原媒体画面与恢复路径，不用观察缺口关闭原页面或健康 Agent。

同 Browser 的捕获由真正可见的展示共享；某个展示隐藏或被遮挡后，只释放自身的视频接收，不停止其他展示所用的原 stream 或页面。重显接回原展示；失败时仍保留的能力不能冒充零成本。

保留帧只属于原媒体来源，来源更换或展示结束即释放；恢复预览以该来源真实新帧接替，不能把旧帧当作新来源已就绪。保留帧失败仍保原预览和可达重试，不能停止原页面或共享媒体。

当前控制权允许人工网页输入时，用户从同一 Browser 的被动显示位置第一次点击原网页控件，这一击应准确一次送到同一个原生页面；只迁画面、只换焦点或要求再点一次都不算完成。Agent 操作中的被动位置同样消费[输入隔离](#agent-操作可见性与输入隔离)，不因切换呈现绕过显式接管。输入意图与本次准确展示位置、原页面及其当前可见范围绑定，旧页面、过期意图、隐藏位置或未确认坐标不能替用户点到另一个页面。查看、渲染与 hover 不接管输入；媒体可见不冒充原生可操作。输入交接未确认时保原 Browser 健康可工作，持续说明失败步骤、仍可使用的原位置和恢复动作，不停页、不销毁实体、不重建 Run，不静默补点或自动重放。


## 浮层让位与输入层级

浮层让位是共享宿主默认成立的能力，新增浮层沿原协议消费，不逐功能补手动租约。

浮层默认沿共享宿主与浮层库的 Portal/打开态协议呈现，不依赖各组件申请手动遮挡租约，也不维护具体组件清单或扫描应用正文。自定义浮层由承载完整背景、圆角和命中区域的实际绘制外框声明打开态；透明内层的列表等语义不能代替外框的完整投影范围。与原生 Browser 的实际交叠、可见性和输入行为只引用[《Browser 任务能力与可复用资产》](browser-workface.md#browser-任务能力与可复用资产)，新增浮层不复制该合同。

非模态浮窗发起的窗口级确认、选择、菜单与输入弹层须完整可读、可命中。DOM、HTML top layer 与原生 Browser 合成必须消费同一所属作用域和真实打开顺序；不能只靠普通 DOM 的 z-index、逐功能手动隐藏或另一套业务状态解决遮挡。较高层持有当前焦点、键盘与 Escape，背景浮窗不截走其操作；模态打开及其原生画面准备期间，背景 Mote、Browser 与普通工作面均不接收点击而改变对象、Tab/Region 或执行目标。取消／关闭后沿原准确 document 中的入口与较晚用户焦点返回，保原浮窗所选对象、Tab/Region、非空草稿和健康 Run。危险确认仍先取消、忙碌不重复执行，原停止、保留 Session 与关闭 View 的后果不变。

弹窗管理从底层职责保证同类行为，新增业务弹窗默认复用，不由各功能重复补丁。网页控制权与模态阻挡人工背景输入是独立事实：前者仍归准确 Browser 的输入 owner，后者只持续到本次呈现结束；关闭模态不解除仍有效的 Agent 控制隔离，打开模态也不撤销已授权的程序输入。原生人工命中隔离沿 Browser owner 的原生输入表面实现，不能在原网页入口无差别吞掉合法 CDP 输入，更不能返回成功而实际丢弃动作。

共享模态持有内容和附件共同的焦点与关闭边界；可滚动的绘制表面不代替这份归属。没有可聚焦控件、最后一个控件撤去或暂不可用时，焦点仍能落到当前模态的真实可聚焦节点。IME 拥有的 Escape 留给组合输入，普通 Escape 只关闭最上层；业务的忙碌和取消约束由原调用者提供，共享层统一组合，不要求每个表单重复实现。

每个模态展示的必需内容、遮罩和模态输入边界属于同一个呈现单元。原生适配不得先展示遮罩再等待内容，也不得因内容校验、预算或绘制失败留下孤立遮罩、不可见内容或继续圈住焦点的空模态。失败退出该次模态展示，持续说明失败步骤并提供重试或取消；原待确认意图、准确目标、已输入草稿及仍在进行的原操作保留，重试只重建呈现，不重复停止、提交或其它业务副作用。取消由用户明确选择；不能关闭健康 Browser 或用不可恢复的工作面替换掩盖失败。

菜单、tooltip、身份详情与图片等子弹层须保留所属呈现作用域。非模态附件位于所属内容之上、后开的窗口模态之下；新的窗口模态按真实打开顺序成为同 document 的窗口兄弟。附件的失败或关闭只收口该附件，不撤销健康父模态。现有非模态 popover 不因复用公共组件变为模态。遮罩在原生侧只补 Main 确认的 Browser 像素，不再次压暗已经由 Renderer 遮罩覆盖的区域。

窗口变窄、变矮、最大化、系统全屏、缩放、切换显示器，以及工作面移入独立窗口或返回后，所属 document、层序、坐标、命中、焦点与退场责任继续一致。纯位置变化与实际绘制内容更新都须及时更新所属原生投影；绘制更新不以 DOM 或几何变化为前提，只改变呈现，保留原操作、准确目标、输入与草稿。隐藏、关闭或撤去的弹层释放该次投影、命中区域与相关绘制更新。共享机制只观察实际打开的弹层及其锚点、绘制和相关窗口事实，不扫描终端／编辑正文，不随无关 Session 数量扩大工作。

系统文件／目录选择、保存与确认框同样归属于发起操作的准确工作面窗口。跨 document 保留的原组件须携带其当前窗口身份与代次，由已有窗口 owner 解析原生 parent；不能把共享 IPC sender、主窗口或当前系统焦点当作发起位置。过期窗口仅拒绝该次展示并在原入口说明，保留原输入、请求和健康工作面，用户可从当前归属重新发起；取消及业务后果沿原操作。

嵌套浮层按各自真实打开、关闭和退场事实收口；关闭下拉不关闭仍打开的对话框，退场内容不再占用原生命中区。协议无法确认的浮层明确暴露限制，不以手动全局隐藏 Browser 作为长期后备路径。

Escape、点击外部、失焦、选中项、组件卸载与异常路径都退出对应浮层；原工作面保留与恢复仍沿[《Browser 任务能力与可复用资产》](browser-workface.md#browser-任务能力与可复用资产)的同一合同。
