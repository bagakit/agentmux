# Launcher 工作起点

本文定义 New Tab／Launcher 的环境选择、可收起工具、未发送草稿、Mote 创建委托与 Resume。它是一个原 Region 中的工作起点；应用启动大屏与 Session 恢复沿[恢复合同](session-recovery.md)，视觉沿[Launcher 呈现](../presentation/spaces-and-layout.md#初始-launcher-的现代工作台密度)。已确认约束不代表实现或安装已验收。

## 环境、目录与文件引用


- **先明确在哪工作，再立即开始。** 创建入口可选择已配置的本机或远端 Host 及该 Host 上已登记的真实项目目录，提交前可读当前机器与目录；展开可查看完整路径及真实连接、探测观察。选择、显示与实际创建请求使用同一个执行目标，不只更换机器标签，也不把本机目录套到远端。执行目标与当前展示落点分开，选择未来创建目标不迁移、重建或停止已有 Session/Run，不改其它 Region 的执行身份；原未发送输入、名称与选项保留。明确选择的项目与 Agent 沿该 Launcher Region 的原持久 owner 保存，保存回执、Agent 或 Terminal 启动失败重挂及普通进程重启后仍是同一选择，不能按 Tab 的展示项目覆盖执行目标。Host 尚无已登记目录时给出原项目登记入口，不隐式部署服务。环境信息复用已有配置与 Runtime/discovery，配置存在、观察未知与已连通不能互相代称；健康边界沿[联邦 Runtime 与远端恢复合同](session-recovery.md#联邦-runtime-与远端恢复边界)。

- **目录沿项目已有的路径表示选择。** 启动页目录摘要与展开详情遵循既有路径转换设置，规则唯一见[《路径显示与复制》](spaces-and-layout.md#路径显示与复制)：仅已确认本机路径可按真实本机 home 显示为 `~`，选择绝对路径时给完整路径；远端、其他用户和未知 home 保持原路径。表示变化不改 Workspace 实际目录、Host、warm Terminal key、启动、Resume 或 Mote 委托的资源事实，不另加路径转换设置或第二份转换逻辑。摘要、列表及悬停路径都沿同一表示偏好；完整原始地址仍可在同一环境的明确 Full path 详情按需查看或复制，缩写不隐藏实际执行目录。

- **文件引用属于当前执行机器。** 本机文件选择沿已有系统入口；远端选择沿所选 Workspace 的原文件能力浏览和引用真实项目文件，不用本机文件对话框或缓存地址冒充远端文件。尚无跨机器附件交付时，图片粘贴保留正文并明确说明文件没有送达，提供当前项目文件引用入口；不插入不可达的本机路径，不静默改回本机，也不因此封闭原启动能力。异步结果的来源约束沿[会话输入](conversation-input.md)，不另建附件或草稿账本。

## Agent 选择、选项与草稿


- **Launch options 随当前 Agent 按需展开。** 默认以紧凑动作与已选状态摘要呈现，未修改时不重复选项个数和 Provider defaults。可选 Agent 名与 Tab 名属于按需配置，不占据常驻双输入行。Prompt、名称与启动选项沿原 durable 输入 owner 保留；选项按准确 Launcher Region 与 Provider 隔离，切 Provider 不串用，返回原 Provider 仍保留其显式选择。真正首次启动、空 Tab Group 尚无 Tab / Region 时，同一工作起点的原始未发送输入与选择在建立准确 Launcher Region 时保全归属，包括 Prompt、名称、各 Provider 配置及辅助工具的草稿与既有创建引用。启动失败回到该 Region 后仍可继续编辑和恢复原工作，建立工作面不得改变用户所选全局空间或把未发送稿误当已消费。展开、关闭、Region 变窄、pending 卸载后失败重挂以及进程重读都保留未发送输入和已选配置，不能恢复 Prompt 却悄悄改用 Provider 默认。只有成功请求确实使用且此后未改的原记录可以被消费，晚成功不得吞掉新编辑；其他 Mote 或上下文的启动不消费原 Mote 未发送草稿。Provider describe / argv 分层、未声明不渲染与启动姿态语义沿[《Provider Launch Option》](agent-capabilities-and-messaging.md#provider-launch-option)，不加具体厂商分支。

## 工具开合与 Browser／Note


- **每块内容可以决定是否展开。** Agents、Terminal、Browser 和 Note 有可辨的关闭 / 收起、展开与恢复入口；关闭一块只是收起它的呈现，不删除草稿、持久化工作面或停止健康 Run。Agents 收起后保留当前选择，并有可达的恢复 / 启动入口；Terminal 收起后有真实打开动作，展开复用同一个 warm terminal。

- **预热只服务准确目标。** 自动预热失败后，本次 Launcher 不因预热槽清空而连续重发同一 Host／目录的启动；保留完整输入与原显式 Terminal 启动。真实预热成功后被使用可补充原槽，目标资源变化可按新目标尝试，不复制 Runtime 或把失败猜成健康 Run 不可用。

- **预热不限制显式打开。** 预热命中、在途或已被认领只影响复用，不能阻断另一个 Region 的 Shell 打开；不同 Region 使用各自准确的原请求与 Run。同一 Region（或尚无 Region 的空 Tab Group）同次打开的重复动作幂等，不重复创建。原请求晚确认遇展示关闭或替换时，保留可核对的请求与健康 Run，不复活旧 Region，也不因此停止候选。预览与 resize 的单消费者归属只约束呈现，不绑定执行身份。 观察释放不能停止或清除已被显式打开认领的候选及原请求；从未认领的自动预热仍按原资源治理释放。

- **默认展开不冒充用户偏好。** Space 打开初始页且没有显式偏好时，Agents 默认展开，直接呈现所有已配置且当前 Host 未明确判为 missing 的 Executor，不只露出最近一个；检查中、检查失败或状态未知不当作未安装，沿原事实提示。没有配置 Agent 时提供可发现的相应 Settings 配置动作，原输入、Resume 与其他健康工具仍可用。最近选中的 Executor 继续高亮，不因完整阵容呈现而另选对象。普通初始页的 Terminal 默认展开，仅 Mote 与 Survey 中展示的初始页默认收起；判定来自本工作面的真实展示归属，不按全局当前页面、Workspace 名或是否为 Scratch 猜宿主。默认仅补未明确设置的部分，不写成用户偏好；已有明确 expanded / collapsed / hidden 继续优先，切展示位置不清草稿、不重建或停止 warm Terminal。Browser 与 Note 默认收起；用户主动收起或关闭 Agents 后尊重原偏好，收起的 Agents 以紧凑入口呈现当前选择、展开与 Resume；先展开真实 Agent 输入与配置上下文，再呈现 Options、Mote 创建委托与直接 Launch 动作，不在没有 Agent 输入框的默认工作面保留空白启动底栏。收起不等于移除入口。Browser 展开后在同一工具行直接输入地址或搜索词；Note 可展开输入真实笔记并通过既有笔记动作打开。已有明确显示偏好继续尊重，在重载和进程重启后保持，未保存时明确提示，不静默声称已记忆。

- **Browser 与 Note 都有完整动作结果。** Browser 输入按已有 URL / search 规则解析，提交进入同 Launcher 目标的真实 Browser；不得把搜索框画成没有导航的装饰。Note 展开后的输入、打开成功或失败与原稿保留可验证，不能把草稿存入无法打开的孤立临时区域。存在正文时，主要打开动作使用同一保存现稿意图；独立空白创建明确表达并避免重复入口，不能用相近的打开动作让用户误以为当前稿已提交。原 Launcher Tab 与未消费稿保持可回。关闭部分、变窄、切 Tab 或启动失败后仍能继续原稿。

## Mote 创建委托与目标


- **Mote 联动明确目标和创建意图。** 入口表达“让 Mote 帮我创建”，旁边能选择已有真实 Mote 并读出目标名称；显式点击才把当前完整请求与真实项目上下文交给所选 Mote 一次。原 Mote 已有 Agent 时沿其原输入动作，尚在 Launcher 时沿已有公开 Agent 启动能力；不另建影子 Mote、第二条启动通道或隐式改项目。空请求只打开所选 Mote 供描述，不能发送无内容。原 Launcher 草稿、原 Mote 未发送草稿与健康 Session 保留；权限仍由原交互处理，不自动批准。排队 / 提交表示委托已保留或交付，不等于对象已创建；失败、未知与等待有真实目标和原因，较晚选择或来源变化后旧异步操作不能错投或抢焦点。

- **创建目标记住最近明确选择。** Create with Mote 在用户选定一个真实 Mote 后，以它作为其他 Launcher 和下次打开的默认目标，重载及进程重启后仍保持；没有明确选择时沿原默认 Mote 身份。该单一创建偏好由已有 Launcher UI owner 保存，只记录准确 Mote 身份，不复制目录、头像、Tab / Region 或 Session / Run。浮窗浏览、hover 和其他工作面的导航不改写这项偏好，Launcher 内选择本身不打开或移动浮窗、不启动 Agent、不改执行焦点。创建入口的图标消费所选 Mote 的同一已保存头像；名称、头像与实际交付目标保持一致。保存失败保留当前内存选择与原草稿，明确未保存，不声称下次已经记住。

- **归档目标仍是同一创建目标。** 已保存或当前明确选择的 Mote 归档时，Launcher 保留原身份、可用创建入口与可发现的原地恢复动作；不因退出常用名册而替换成另一位 Mote，也不把归档当 Session 终局或要求先恢复才能使用健康 Agent。新选择的推荐、确认写入、未知与失败沿[《Mote 归档与恢复》](motes-and-coordination.md#mote-归档与恢复)；目录暂不可读或找不到原记录时保原引用并说明未知，不按名称或名册首项借目标。归档 / Restore 请求和失败反馈归属准确 Mote；切换目标或旧请求晚回复后，保留原失败对象和原因，不把它挂到新健康目标的当前状态下，也不静默抹掉原失败。测试与实际界面验证须包含默认或已保存目标归档、长名称、窄 Region 和恢复失败，核对创建目标、原草稿与健康 Run 保全。

## Resume 与交互连续


- **Resume 信息够用且诚实。** 范围与恢复边界沿[《启动页 Resume 快捷入口》](session-recovery.md#启动页-resume-快捷入口)。候选同时可识别实际 Agent 名、Provider / Executor、所属项目与 Host、最近活动、稳定 Session ID，以及来自已保留记录的 recap / 请求摘要；缺摘要明确无可用 recap，不从 Provider、时间或名字编造。完整 ID / 路径可按需查看或复制，显示名永不当恢复 key。列表、计数、过滤与被选恢复对象同源，当前项目零候选仍能切全部项目。查找范围与有界摘要读取只见上述 Resume 合同，不以未读取内容作搜索承诺。

- **交互先兑现，动态随真实动作。** Agent 选择和部分开合由原控件与原状态立即兑现；键盘 Tab、Enter / Space 与浮层 Escape、关闭返回焦点沿既有可访问控件，不等待动效才允许输入或提交。Browser 收起或工具关闭移除原控件后，焦点交回同一对象在本 Launcher 的展开 / 恢复入口，不能落到 BODY 让用户重新寻找位置。Host / Options 的有限退出呈现不能继续接收点击、Tab 或旧提交；快速关闭重开、切 Agent 和尺寸变化后，旧完成事件不得关掉新面、覆盖真实选择、丢草稿或抢焦点。选择连续反馈只跟随本次真实目标，hover 不选择，未知环境不冒充已连接；动效不重挂编辑器、Terminal 或复制 Runtime / draft / selection owner。原选中 Agent、Options、名称、Prompt、Browser / Note 草稿和健康 Run 保留。截图、文件或 Skills 选择器的异步结果沿准确来源 Region / 草稿归属，来源已改变时不得写入后来的输入或抢焦点；原引用与失败事实保持可追溯。当前 Launcher 只订阅自己实际使用的输入与名称，不因无关 Session 更新而放大 retained 工作面的局部观察或渲染工作。减少动态、Launcher / document 隐藏或 retained inert 时停止装饰动态及无关局部观察，按当前状态立即呈现可读静态反馈，临时退出内容确实释放；不以动画终止事件缺席阻断原动作。视觉与材质复用唯一见密度 SSOT 同节。

## Region 适配与重启保全


- **Region 自身决定适配。** 宽、窄、矮以及连续分割下，主输入和启动、Resume、环境与恢复入口可达，没有横向撑破、双重滚动陷阱或弹层被 Region 裁掉。矮 Region 的起点首屏优先保留完整主输入与主动作，装饰间距和辅助阅读面不能先占预算而把空请求的启动动作挤到可见区外；展开辅助面仍保持原偏好与可达滚动。偏好展开状态与当前宽度是不同事实；尺寸临时收敛不得抹掉用户偏好或重建工作对象。主 Composer 沿既有整框可编辑与草稿身份合同。

- **重启恢复保全先于界面优化。** 同一次进程重启后，原 Tab / Tab Group / Region / 焦点 / 分割布局先按 Core durable 状态恢复，Launcher 部分偏好和未发送草稿保留。健康 Run 自动接回；已结束或丢失 Run 的恢复时机、按需执行以及 Mote 固定主对话的例外，唯一遵循[《冷启动按需恢复》](session-recovery.md#冷启动按需恢复p0-末位)，不因 Launcher 可见或草稿存在批量启动 CLI。临时空快照、超时和探测未知仍保留原工作面并用服务窗说明，只有 Core 终局事实允许移除投影。宽窄视觉验收必须以实际工作面为输入，且核对健康 Run 没有因开合、尺寸和联动被停止或重复创建。

视觉、密度、材质和控件层级唯一见密度 SSOT[《初始 Launcher 的现代工作台密度》](../presentation/spaces-and-layout.md#初始-launcher-的现代工作台密度)；本节只定义行为与约束。
