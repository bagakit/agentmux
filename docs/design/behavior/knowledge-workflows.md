## Survey、临时 Zone 工作面与知识入口

Survey 是 Know 下明确创建或保存的浏览／研究入口，须让普通用户直接当日常浏览器使用，初步结果可收进 Recall 或整理到知识库 Topic；具体层级与整理关系遵守[《Topics 知识库的层级与沉淀》](spaces-and-layout.md#topics-知识库的层级与沉淀)。此约束取代所有 Browser 自动发现入列及以多 Topic 勾选作为主流程的旧模型。单向是成果整理流程，不是实体单一归属；Zone／Tab／Region 的身份、多处展示与生命周期仍只见[《Zone→Tabs→Regions 的实体与展示绑定》](spaces-and-layout.md#zonetabsregions-的实体与展示绑定)。搜索和知识管理可继续扩展，不以未实现的知识库界面阻碍正常浏览。

Survey 的进入来自明确的浏览／研究创建意图，不来自某个项目存在 Browser 的事实。普通浏览不要求先建立研究 Item、选择项目、Notebook 或 Topic；左侧以 Browser 浏览／研究入口为起点，不列 Notebook、Note 页面目录或知识模式切换。记录与沉淀由显式成果动作进入 Recall 或 Topic；原研究已有的 Note／混合 Region 继续可达，Group／Region 和其他内容在研究中按需使用。底层复用现有 Zone 工作面，不要求用户先理解这些结构才能打开网页。独立选择、跨上下文打开及分别恢复只见[Work、Survey、Recall 与 Mote 的导航上下文](spaces-and-layout.md#worksurveyrecall-与-mote-的导航上下文)。

### 研究的创建与身份

- **项目 Browser 不自动属于 Survey。** 其他项目、对话、Topic 中用户或 Agent 打开的 Browser 不因 Browser 存在、导航、操作、选择、目录或展示关系而自动入列。Survey 列表只消费明确在 Survey 创建或保存的浏览／研究入口；项目 Browser 是原项目的一块内容。纯 Agent、Terminal、File、Note 和 Mote 亦不因有内容或没有 Topic 自动成为研究。已明确保存的 Survey 内容及旧恢复引用保全；改变资格不清实体、草稿或健康 Run，不从发现事实补造创建记录。
- **研究入口与实体身份分开。** 已明确创建的研究沿原 Zone 引用承载原 Tab／Region；同一研究不因多个页面或位置重复入列。浏览页和研究入口按真实创建范围表达，不用标题、URL、路径或 Zone 类别猜身份。关闭最后一个 Browser 不删除该研究的 Note 或已保存内容。未知创建／保存事实保准确引用与恢复说明，不把全部 Browser 当成研究，也不把暂缺目录当作实体已删除。
- **最后一个 Tab 关闭时收起研究入口。** 用户明确关闭研究的最后一个 Tab，且关闭提交后的准确成员事实确认无剩余 Tab 时，同时移除该 Survey item 的列表引用及其自身选择，沿原偏好持久保存；不删除 Zone、绑定或已保存成果。只解除一处展示、关闭失败、仍有其他 Tab／Region 或成员事实未知时保留原入口；恢复中的空快照不代表用户关闭。
- **项目的进一步研究是创建。** 项目 Browser 提供明确「在 Survey 进一步研究」动作，创建独立的 Survey 研究及其 Browser／Tab，以原网页的可确认上下文作为来源，不把原项目 Zone 改为 Survey 项或复用其页面身份冒新建。原项目页面、导航、布局与输入保留；后续两边不自动同步归属或操作。来源引用与实际复制内容可分辨，不声称复制完整表单、历史栈或原生现场；不自动发送、启动或续跑 Agent。失败或未知保原页、当前输入和原创建意图，已建但显示失败可恢复同一对象，不盲目重建。
- **研究工作面复用原组件。** 明确研究以稳定 Zone ID 调用同一公共工作面，加载原成员与现有布局；Tab／Region 选择只是呈现偏好，失效展示坐标不阻止打开，复用 Space 的 Tab 栏、Group／Region 分割、内容与控制；Browser 是默认起点，其他内容按需可达。不另造实体、布局或 Runtime；多处展示、遮挡与输入只遵守公共合同。
- **日常浏览先完整可用。** 打开 Survey 可直接输入地址或搜索，不以选择项目、Topic 或理解 Zone 为前置。普通新标签页直接呈现 Browser 并让地址输入可达，不先强迫经过通用 Agent Launcher。沿原 Browser owner 完成导航、前进／后退、刷新、标签切换／关闭／重新打开、基础编辑与明确快捷键；日用的历史、书签、Profile、登录、弹窗、下载与权限按真实能力可达或诚实说明缺口。已有页在原 browserId／Region 内导航，不每次提交另开页或跳到 Space。普通重启先恢复原标签和布局，再以保存的 Profile 资源身份恢复原 Browser；现存健康页面保持其实际 Profile，未知或失效 Profile 不自动换身份，原工作面保留并说明失败。新的普通浏览沿 Main 已提供的 Scratch 资源上下文创建，已有研究沿其准确资源创建；不跟随当前项目或猜第一个目录，不能让“先去 Space 选项目”阻断正常起步。空白或取消不新增动作；失败保输入与原内容，迟到结果不抢后发选择，不按具体站点或厂商特判。
- **Survey 提供起始页场景配置。** Survey 的默认空白起始页主标题为 **AMUX - Survey**，主副标题、图标、背景图与历史展示使用[通用 Browser 起始页合同](browser-workface.md#browser-空白起始页)，不由 Survey 另建导航或历史机制。场景配置不让其他工作面的 Browser 自动属于 Survey，也不改变原研究、页面、布局或资源身份。
### 成果收集与准确位置

- **成果明确输送到 Recall 或 Topic。** 「保存到 Recall…」沿原 Note／Notebook 和文件 owner，将用户确认的记录保存为准确 Notebook 中的页面；没有明确 Notebook 时使用「随手记」。创建时保可确认网页 URL、标题、时间与原空间来源，保存成功提供打开原页面的明确动作，默认保当前 Browser 与 Survey 选择；不能先切知识目录才能记录，也不重复创建同一次未确认操作。已有 Note 的收纳保 Note／Block、正文和来源身份，不复制另一份正文。「整理到 Topic…」：用户选择准确目标与明确的研究范围，让所选成果在目标 Topic 可见、可继续工作。新 Topic 与已有 Topic 的整理关系只见前述知识库合同，不再把 Topic 作为包住研究 Zone 的 Space。复用原实体／关系 owner；已有研究从开始即可由 Zone 承载，整理不为更换入口重发 Zone／Tab／Region／Note／Block 身份，不复制 Runtime 或改执行 cwd、Profile 与无关绑定。保存与目标展示的真实结果可辨；取消无写入，失败或持久保存未确认保原研究与恢复入口，不提前移除内容。Topic 中打开、浏览或更新成果不会反向自动创建 Survey 研究。
- **单向工作流不改变公共多绑定能力。** 整理成果、打开目标 Topic、修改其展示绑定是不同动作；通用模型允许同一实体有多个合法绑定，但不据此让 Survey 成为所有位置的 Browser 汇总。目标 Scope 与已有关系完整可达，准确导航沿原位置引用，不取第一个位置或由 cwd 猜展示目标。来源项目跳转指向真实来源，进一步研究创建新的研究，二者不可混成返回／收集按钮。
- **位置选择展示可读信息并保准确目标。** 明确导航到多个原位置中的某一个时，名称、位置与真实内容类别须让人区分目标；同名目标仍可分辨，不把 Group／Tab／Region 的原始 ID 串铺成主要可见文案。技术 ID 按需可达，选择仍使用原精确引用；未知名称或位置明确说明，保留选择与恢复入口，不猜第一个位置、用显示文字造身份或删掉消歧控件。文案变化不改变原动作 owner、实体、组成、保存分割、草稿或运行状态。
- **反馈保留当前工作。** 创建研究、整理到 Topic 和明确打开只改变各自动作的对象与绑定；无关引用、布局、选区与草稿保持。写入本地、请求刷新和磁盘保存未确认分别表达，不冒持久成功或为流程失败回滚原树。收起 Survey 展示或取消一绑定不删除成果、其他绑定或 Topic，不停止 Run。Browser 管理在所在工作面可达，打开工具不把项目原 Zone 导航成 Survey 研究。
- **当前操作按对象表达。** Browser 正由 Agent 操作只取 Main 确认的当前 driving 和可信操作者；人拥有控制时称「人可操作」，不猜正在输入。Agent 工作中只取 Core 已确认语义，Run 活着不等于 working。多对象摘要有明确范围，能到原 Region；混合、缺失、释放、不可用或恢复未确认如实说明，不画整 Zone 的虚假单一操作者。
### 恢复、保存与消费成本

- **相关成本与草稿连续。** 目录和关系数不增加内容消费者；只有公共接口确认实际显示的 Group 当前 Tab 或直接 Region 才消费相应内容。未选成员或仅存在的引用不新增 Terminal 字节、历史、fit / resize、Native 可见或保活工作。遮挡、焦点和实际尺寸消费同一公共事实，连续阅读遵守[《Terminal 连续向上阅读历史》](terminal-reading.md#terminal-连续向上阅读历史)。原 Browser bar、Profiles、标注和管理仍作用于确切 Browser / 资源 Workspace，显式保存、失败草稿、并发检查及不自动发送继续成立。
- **恢复原对象与入口。** 原持久化入口保存稳定实体、多个 Topic 关系、位置与各工作面的明确引用；真实二进程重启读回含非第一跨项目入口，不按资源 Workspace 剪掉展示关系。原组成、布局、草稿和空间焦点先恢复；Core / ctxmux 的续接与合法新 Run 按事实表达，Browser 瞬态能力由原 owner 重建。空快照、发现或握手未确认保对象、关系与服务窗，不跳到第一处、重播绑定或创建替代 Session；只有原 owner / Core 的终局事实移除对应投影。

### 列表与工作面的操作范围

- **列表宽度与开合属于本地呈现偏好。** 列表支持明确收起和恢复、有界指针与键盘调宽；开合与宽度沿原 UI 偏好持久化，切回与普通重启恢复。调宽或收起不改 Zone／Tab／Region 的实体、关系、原分割比例、当前选择或工作面布局，不导航、创建、关闭或启动内容。存储未知保当下呈现与原对象，原服务窗说明恢复动作；窄窗仍可到关键操作。紧凑信息与视觉层级唯一见[《Survey 的 Zone 工作面与液体玻璃》](../presentation/spaces-and-layout.md#survey-的-zone-工作面与液体玻璃)。
- **列表平铺，不按项目分组。** Survey 平铺原 Item，保持原集合顺序与 Zone 身份，一 Zone 一项；不再按项目、Scratch 或未知来源加组头、重排或重复 Item。项目、host、路径与 worktree 沿原 Details 按需可达，明确打开来源仍指向准确资源 Workspace。来源未确认时保原 Item、选择、展示绑定与恢复引用，不猜归属、不删项。平铺只改变呈现，不改变明确创建／保存资格、Topic 关系、实体、布局、执行目录或 Run；标题、控件与持续说明的密度只见[《Survey 的 Zone 工作面与液体玻璃》](../presentation/spaces-and-layout.md#survey-的-zone-工作面与液体玻璃)。 显式列表成员与当前选择沿原本地 UI 偏好存储及时提交，正常退出与冷启动恢复同一成员、顺序与稳定 Zone 引用；不能只保内存或等下一次无关编辑才保存。Zone／Tab／Region 与布局仍由 Core 持久空间 owner 负责，暂缺图或 Host 元信息不删除已保存列表。保存未知保当下列表与原工作面，持续说明并可沿既有保存入口重试。
- **探索名称与起手动作清楚。** 普通浏览以网页和标签导航表达；明确研究时，左侧研究入口与右侧内容标签的范围可辨。“新标签页”“新研究”与“保存到 Recall”必须明确区分，不强迫普通新标签页先建立研究。探索可明确命名，名称沿[显示名与身份](spaces-and-layout.md#显示名与身份)的同一名称 owner、版本与确认合同保存，只是 Survey 展示名称，不改变 Zone 身份、资源、内容、其他展示绑定或 Run；未命名时使用确认内容的可辨名称或诚实的未命名提示，不把所有标签页／分屏名拼成长标题，也不选第一个成员冒充整次探索。中央网页输入继续保留；全局笔记管理在 Recall；当前浏览的记录通过「保存到 Recall…」可发现，研究中的就地新建沿下述条目动作进入原 Note owner，沿原创建、文件、位置与恢复 owner 执行。新建失败、未知写入或已写但未显示时继续恢复同一创建意图，不再创建替代对象；后来选择与原工作始终优先。 唯一已确认的原位置可直接打开，即使该内容尚未在 Space 激活；多个、未知或不完整的位置仍明确选择，不以列表顺序、资源项目或第一个 Group 推断目标。

- **创建入口与原研究动作各有准确目标。** 左侧底部固定的「+」用于新建 Webpage，列表滚动或收起时仍可达；沿原 Browser 创建与失败恢复 owner，不以悬停或展开浮层触发创建。每个已打开的浏览／研究条目在 hover、键盘焦点或触屏菜单中提供「New Note」「New Agent」，动作属于被操作的那个条目，而非碰巧当前选中的另一条目。创建意图固定被操作条目的原来源和准确位置；存在多个合法位置时保该条目已确认的位置或让人明确选择，不猜第一个位置。New Note 沿既有 Survey 保存到 Recall 的 Note／Notebook／文件 owner，将正文保存到默认托管笔记库中的准确 Notebook，可明确保存并打开 Recall；来源仍引用被操作条目，不把笔记库资源强塞进原 Browser Zone 或放宽原 Note 创建目标校验。既有外部资源边界不变。New Agent 在原条目准确 Zone／资源上下文与 Tab／Group／Region 进入既有 Launcher 和 Agent 创建／启动选择，不直接运行默认 Executor；悬停和选择条目不自动发送输入、启动或续跑 Session。已建但显示失败恢复同一对象，未知目标保原内容与草稿并提供就地恢复；不为入口移动重发 Zone／Tab／Region、Session 或 Run 身份，不改执行 cwd。
- **收起保可用的图标导航。** 左栏收起为连续图标 rail，已打开条目保原顺序、选中与完整可访问名，仍能选择原条目及打开准确的创建／成果动作；不是清空列表后只留展开按钮。网页标识沿[Browser 工作面](browser-workface.md#browser-工作面-1)的真实 favicon 事实，其他内容用原类型图标。展开恢复既有宽度和目录状态，不重建页面、剪混合 Region、改选择、丢输入或停健康 Run。
- **探索动作留在左侧。** 整理和成果收集属于所选 Survey Item，入口位于左侧探索导航，以「保存到 Recall…」「整理到 Topic…」表达目标；Survey 左侧不提供独立 Notebook／页面目录，与新探索的创建范围可辨；Tab 上方不再承载这两项动作。左栏收起后仍有左侧可达入口，显示菜单或保存成果沿同一原目标、创建与恢复 owner，不复制动作、不改变实体、布局、选择、草稿或 Run。右侧只保留本次内容呈现范围的控制，以及持续可发现的未知／失败恢复说明。
- **条目右键沿原操作。** Survey item 的右键、ContextMenu 键及 Shift+F10 打开现有产品操作菜单；动作针对被操作的原 Zone，不借另一当前选中 item。仅打开或取消菜单不改当前选择、工作面或执行；Escape 回到原行，进入改名或操作面时交接焦点。名称编辑期间保原文本剪贴菜单。展开与收起的条目都可达；创建、收集与成果动作继续使用原 owner，当前 panel 动作仅在该条目有准确当前 panel 时提供。
- **工作面从窗口顶边开始。** Survey 不保留独立的重复标题栏；原 Tab／Group 工作面与左侧导航直接使用顶部空间，必要的窗口控制沿共享窗口 chrome 可达。左栏展开、收起、调宽及多个 Group 时，都不能让系统窗口按钮遮住内容标签或动作。该调整只改变呈现，保原实体、准确位置、分割、选择、编辑草稿与 Run；返回 Space、Settings 遮挡和普通恢复仍沿原 owner。视觉与密度只见对应视觉合同的 Survey 章节。

视觉、密度和玻璃唯一见[《Survey 的 Zone 工作面与液体玻璃》](../presentation/spaces-and-layout.md#survey-的-zone-工作面与液体玻璃)。公共展示能力与 Survey 调用分别按实际候选验收，未完成的能力保持为缺口；Survey 不另建公共绑定引擎、Runtime 生命周期、收藏数据库或内容索引引擎；明确收集只持原 UI 展示引用。

## Recall、Notebook 与块知识

Recall 表达积累、连接与回顾知识，与 Survey 并列。Survey 左侧不再承载 Notebook／Note 目录，也不通过顶部模式切换才能进入笔记；Recall 直接进入当前 Notebook 的页面组织：恢复已保存的 Notebook 选择，尚未选择时使用「随手记」；当前 Notebook 信息是创建与切换 Notebook 的入口；已保存目标暂不可用时保原引用与恢复说明，不擅自换成另一个 Notebook。Notebook 是持久页面集合，Note 是页面内容，Tab／Region 是查看位置；关闭查看不删除页面，目录不从活跃窗口或已打开文件反推完整知识。

- **Notebook 与页面各有明确范围。** 顶部当前 Notebook 信息打开就地浮层，显示准确当前选择、可查找的既有 Notebook 与创建动作；命名并明确提交才新建，取消无写入。切换 Notebook 只改变 Recall 的导航上下文，不搬页面、清编辑稿或改 Survey 选择；迟到创建／读取结果不抢后来选择。默认左侧只显示当前 Notebook 的页面树，就地新建、搜索和查看已归档内容，不混入 Browser、空白 Launcher 或未登记文件。页面父子关系、移动与归档沿原 Notebook owner；删除 Notebook 须确认准确对象，页面及原层级转入「随手记」，保正文、归档、来源与轨迹。归档不删除正文或关闭原工作面，恢复父页面不清子页面独立归档。
- **围绕准确页面与 Agent 协作。** Note 目录行的产品右键菜单提供 `Talk with Agent`，动作绑定被操作的 Note，而非另一个活动页面。选择后打开该原 Note，在其右侧原工作面分割中启动实际 Agent；必要的执行器选择沿现有启动交互，单有 Launcher 或输入草稿不冒称 Agent 已启动。原 Note／Block、文件、Zone／Tab／Region、未保存编辑和其他健康 Agent 保留，展示位置不改变既有执行目录语义。注入上下文包含可确认的 Note 身份、标题、Notebook／来源与准确资源，以及该页面当前内容和保存状态；编辑稿快照明确未保存，未读内容或不可用资源明确未知，不能冒充磁盘内容。基本操作说明沿原文件读取、revision-aware 保存及 Notebook 目录操作，保稳定 Note／Block 身份；讨论不自动保存、改写或覆盖原输入。目标失效、启动失败或投递未确认分别保原页面、已创建 Agent 和同次操作事实，迟到结果不抢后来导航或覆盖后来输入，重试不盲建替代 Session。
- **树、卡片和图谱消费同一目录。** 树是默认导航，卡片与图谱是可明确选择的当前 Notebook 页面目录视图，不是新的 Notebook 或内容归属。Recall 的 Notebook 导航常驻 Graph 入口，即使正在打开页面也能一步进入当前 Notebook 图谱，无须先返回目录；准确 Note 的正文顶部可直接切换 Note／Graph，范围与 Notebook 图谱可辨。三种视图沿相同的 Notebook／Note 身份、搜索与归档范围打开原页面；改变视图不创建副本、不改父子关系或替换已有编辑工作面。卡片只摘要真实页面信息；图谱在可拖动、平移与缩放的关联画布中消费原目录和正文关系，具体范围、定位、恢复与成本沿下列画布合同。
- **画布以 Note 卡片逐层展开。** 当前 Notebook 的页面是目录起点；对准确 Note 展开关联时，默认只加入一层邻域，再由明确动作继续展开。没有既存画布布局且未启用搜索或归档筛选时，进入 Notebook Graph 即明确查看各起点的一层出入关联；已有展开／收起选择继续恢复，筛选后的目录保原范围，直到用户明确展开。画布始终提供一次动作展开当前起点全部一层关联的入口，不要求逐卡查找反向或跨 Notebook 关系。跨 Notebook 的邻接页面仍保原收纳与准确资源，不因出现在画布中被移动。Note 卡片作为内容分组，默认直接展示当前可见关系所涉及的准确原块摘录，无需逐卡开启正文或滚动全文寻找；同一原块去重，完整正文按需打开以补上下文。选择一条关系后能对照来源与目标内容，并沿稳定 Note／Block 身份定位原文；页级目标明确表达整页，不以任意首块替代。原创建／最近编辑作者及出入引用沿原身份呈现。选择、展开或收起不复制正文、创建替代页面、自动保存草稿或启动 Agent；明确打开原文复用原页面、文件和工作面 owner，保原编辑输入与其他健康 Run。
- **画布关系可追溯到原块。** 目录父子、行内页／块链接、结构块引用与嵌入是可区分的有向关系；同一对 Note 的同类关系可聚合显示，但须保实际数量、每个引用 occurrence、来源包含块及准确页／块目标，能展开来源并返回原块。两个方向或多种类型的关系不能因重叠而只剩一条可辨边；Note 的出入数量反映本次观察中的真实关联，当前未展开的邻接可发现，数量范围与未知状态清楚。反向来源沿原前向引用派生，不保存第二关系账本；重复展示不增加计数，不依据同名首候选或共同 Topic 猜边。未读取、外部、不可用、缺失与重复身份分别沿原 owner 的确认结果表达，未知不冒充零关联或已删除，也不合并重复身份替代准确目标。图与展开正文各带本次真实修订和观察范围，不伪装跨文件原子快照；未保存稿与已保存关系可辨，图刷新不覆盖后来编辑输入，后续资源或内容变化时保原目标与恢复入口。
- **画布布局是可恢复的呈现状态。** 拖动节点、平移和缩放只改变展示，不改 Note／Block、引用、目录父子或执行 cwd。原 client 呈现持久化按准确持久 Notebook／Note 范围保存手动节点位置、视口与展开状态；切换目录视图、离开 Recall 或进程重启后可继续同一画布。没有已存视口且用户尚未移动视图的首次进入，初始取景保当前 Note 与可容纳的直接来源、目标同屏；完整邻域超出可阅读视口时先取当前 Note 附近内容，保原关系范围和继续探索入口，不自动适应全图。居中当前 Note 仍为明确动作。刷新图数据、展开邻域或正文修订只安排尚无位置的新节点，保既有手动位置、视口与展开选择，不自动重新排版或适应全部节点；重新布局与适应视图均为明确动作。筛选、收起、暂不可用或观察未知不删除原保存状态，也不以空画布冒恢复完成。
- **画布与 CLI 消费同一关联事实。** GUI 图谱和公共 CLI／RPC 复用原 Notebook／Note 观察 owner，从 durable 目录和准确文件读取同一父子关系、引用 occurrence、嵌入及 complete／partial／unknown 事实；不以当前打开的文件或画布节点反推完整关系。正常公共入口须能调用实际观察 owner，目录查询可用不代签图谱或链接解析可用。只有实际可见的画布需要时才读取或刷新相关事实；隐藏时不扫描、轮询或订阅无关内容，拖动、平移、缩放及保存呈现状态不重扫正文或订阅 Session／Terminal。已有观察足以展开当前一层时直接复用；新增范围或确认修订才向原内容 owner 发出必要读取。读取或持久化未确认保可用画布、手动布局、原身份和非阻断恢复说明，不关闭健康 Agent。
- **统一收纳不复制正文。** 默认新建页面使用配置的笔记库，准确 Notebook 内创建就加入该 Notebook，否则加入「随手记」。Notebook 主收纳、跨 Notebook／Topic 引用、空间展示与实际文件地址可辨；更改 Notebook／页面层级不会搬文件或重发 Note／Block。目录允许引用已有项目或远端 Note，保原 Host、资源地址与权限，不因全局目录复制到本机。
- **原工作面可直接继续。** Recall 沿稳定原 Zone／Tab／Region 和文件 owner 打开、重开页面，复用原分割、编辑器与块引用；独立选择与跨上下文打开只见[导航上下文](spaces-and-layout.md#worksurveyrecall-与-mote-的导航上下文)。Note 正文可在原研究中继续显示，分离模块不搬走旧混合布局、不移除真实保存的研究入口、不停止 Run。未登记旧笔记与原 Launcher 草稿继续从原位置可达，不为收敛目录删除内容。
- **块是可独立引用的内容。** Note 与语义块有持久稳定身份，修改、排序、缩进、折叠、标题或路径改变不重发身份；复制正文与引用原块是明确不同动作。引用和嵌入只持准确目标，显示同一原内容；被引用块可返回原位置，修改在原内容 owner 生效。未知／重复身份、缺失目标或循环保原引用与内容并说明事实，不猜同名对象、自动回填副本或无限展开。
- **正文可直连页面、标题与块。** `[[页面名称]]` 表示原 Note 页面，`[[页面名称 #标题或块身份]]` 表示该原页内的准确块；`#` 两侧可有空格，名称内的字面 `#` 可转义。页链接不借用首块身份。可读名称只是语义查询与显示，原目录、原正文及准确资源确认目标；选择后保存稳定 Note／Block 与 occurrence 身份，页面／标题改名、块排序或文件搬迁不重按旧名字猜目标。同名页、同页重名标题、重复身份、未读取或不可用目标分别表达歧义或未知，保原输入和选择／刷新路径，不能自动选首候选。
- **输入与读取共用规范链接。** 行内链接、结构块引用及嵌入由原 Note schema／parser、原文件 writer 和规范回执贯通，手输、粘贴与公共文件写入消费同一语法和解析结果；代码块、行内代码及转义文本不制造引用。已确认目标只按持久身份引用，未确认查询保留为未绑定链接且不阻断合法正文保存；观察、阅读或索引不暗改正文。原观察 owner 可在一次图谱读取中，依据该次 durable 目录和准确原文件确认未绑定查询的唯一页／块目标，供画布、反链及 CLI 共同展示；该只读解析保原查询、来源位置与修订，不铸造持久 occurrence、不回写正文，也不重新按名称绑定已有稳定目标。同名页、重名标题、重复身份、缺失或未知原文件不授予目标，保原查询与准确未确认结果，不能让 Renderer 自行猜边或借第一次候选代签。反链从同一前向 occurrence 派生，保来源 Note、包含块及页／块目标；删除一次原引用只移除该 occurrence，不改目标正文或其他来源。
- **补全、反链与跳转按需。** `[[` 的页面候选只读取 durable 目录，显示原 Notebook／来源；明确目标页后，`#` 才读取该原页标题与块，候选与确认结果沿同一可复用 Note owner。关闭补全、隐藏阅读或输入改变会取消原观察，迟到结果不覆盖后来输入或选择；按键、光标、画布手势不逐次重扫全部正文。页与块点击沿原文件／工作面导航保原草稿和准确目标，未确认目标不跳替代文件。明确打开原块须使其在当前可用工作面可读，必要时只展开其折叠祖先；尚未显示时保准确目标与恢复入口，不提前确认定位完成。被动恢复选择不触发滚动、展开或焦点转移。若提供创建未命中页面，只能通过显式动作复用原创建 owner；解析、图谱与后台观察不自动建页。正文旁的反链按需读取完整目录中的原来源，范围与保存状态可辨，不把已加载文件集合称作全图。
- **块作者来自真实写入。** 每个语义块可查询创建者与最近内容编辑者，二者分别保原可信操作者和记录时间。原文件 owner 按稳定块身份及实际内容变化归因；未修改块保原归因，创建者不因后来修改、排序或展示位置变化被替换。Agent 身份来自已认证 Session，不能由正文、名称或客户端自报字段冒充；人类写入可在界面省略身份标签。旧内容未记录的作者和观察不到的写入身份明确未知，不把缺字段推成已核人类，也不因归因未知拒绝既有合法保存。正文、来源、引用、Note／Block 身份与后来未保存输入继续保留，规范保存正文与返回 revision 须一致。
- **关注是显式持久关系。** 人或 Agent 可关注、取消关注准确 Note，并查询该文档的关注者；变更只作用于当前可信操作者自己的关注关系，不允许通过传入别人的身份代关注或取消。关注由原 Notebook owner 持久保存，关闭页面、Agent 暂不可用或进程重启不自动移除；缺失或不可用的身份保原关系并表达未知。关注不冒称当前正在查看、编辑或在线，不从文件 watcher、活跃 Region 或健康 Run 推断在场；保存关注不自动授权消息、通知或运行 Agent。
- **Agent 可读改原页面并观察关联。** 公共 CLI／RPC 可读取准确 Note 正文及其保存 revision，通过原文件 owner 修改正文，查询明确范围内的目录父子边、行内页／块链接、结构块引用、嵌入与反向来源。图从 durable 目录按需读取原文件派生，不以当前打开页面冒整个范围；返回实际读取范围、未读取／失败／重复身份和部分／未知结果，不能用漏读代签零关联。正文仍唯一保存，引用图不维护第二正文或关系 Store；通用 help／skill 须发现 Note 编辑、稳定身份、可信归因、关注及关联查询的准确操作与未知回执处理，不能只在专属谈话入口才提供说明。
- **正文只有一个 owner。** 规范 Note 内容及其结构、身份和前向引用由准确资源的文件 owner 唯一持有，块视图、源码、显式导出和索引消费同一事实。双向链接是前向引用的派生来源视图，不维护第二关系账本；展示在多处不重复计算内容关系。索引未确认表达读取／部分／未知，不假称零引用或改正文。
- **创建与保存结果诚实。** 一次新建或收集意图保同一草稿、目标与身份；只有确认真实名字冲突才重试，权限、满盘、不可用或未知不自动换名重放。已创建而显示失败提供打开同一对象，未知保原创建目标和恢复入口。等价空间选择刷新不构成后来导航，真实后来编辑与导航继续优先，迟到成功不清新稿或抢选择。原文件的 revision-aware 保存、冲突、观察和显式确认继续成立；默认托管创建目录由笔记库 owner 确认，明确外部资源创建沿其原目录，不从 Topic 关系、当前项目或展示 Group 猜物理地址。
- **来源与轨迹独立于活跃页面。** 创建时保存真实可确认的 URL、标题、时间与可信操作者；未知标题或操作者明确未知，空间引用仅补现场。创建、收纳、移动、整理和目录搬迁的实际结果沿原 operation identity 留记录，保前后引用及确认状态；关闭网页后仍可查询并打开其保存来源，不依靠现存 Browser 找回 URL。来源可追加，历史不按今天名称重写，不作浏览全量埋点或额外正文版本系统。
- **恢复与成本沿原 owner。** 重启分别恢复 Notebook／页面、原工作面、块选择和未保存输入，再从同一持久内容恢复索引；各展示绑定的块选择分别恢复，不默认抢 DOM 焦点。未知目标保元信息和服务窗，不猜首页面／首块，读取未确认不删除或新建替代 Note。索引仅随相关内容修订更新，不因目录、Topic 或引用数增加无关 Agent／Terminal 读取、订阅或 fit。笔记目录查询、来源与实际操作沿既有 `notebook.ls`／`notebook.inspect`／`notebook.apply` 共用 Core 业务 owner；公开导航须能明确选择 Recall，原文件读取与修订保存不另造一套内容运输。

## 笔记目录、设置与搬迁

默认托管笔记库为当前宿主用户的 `~/.agentmux/notes`。托管 `.note.json` 正文和 `notebooks.json` 目录元数据共同位于该目录；Notebook 页面树是逻辑收纳，不要求同名物理子目录。目录及备份仍由 Core Notebook owner 持有，正文仍由文件 owner 持有；Session／Run 与 durable spatial state 不迁入笔记目录，UI 偏好和未保存稿也不冒充正文文件。

Settings 的笔记设置可查询并更改实际笔记目录，委托同一 Core 笔记目录 owner 保存，正文仍由文件 owner 持有；默认与当前实际目录、待提交目录各自可辨。更改目录是迁移这一个托管库的动作，不是只切指针到空目录或创建另一份库。默认位置调整、旧存量纳入与以后人工更改目录复用同一迁移机制，不另留一次性脚本、旧目录回退或双写 owner。

- **迁移范围准确。** 迁移托管正文、目录、必要备份及已确认的持久文件引用；首次调整把旧默认 Scratch 中已登记的本机 Note 逐文件纳入新库，并读取原 state 中的 Notebook 目录。项目及远端 Note 的外部引用保原资源；不搬整个 Scratch、项目、Topic 或 Mote 目录，不改 Agent cwd、Session／Run、原 Zone／Tab／Region 或 Browser Profile。未知资源不猜成托管文件，原内容与引用保留并可说明。
- **校验后才发布新地址。** 核对源库身份、目录 revision、托管文件的 Note／Block 身份与真实字节，再准备目标、校验持久写入并更新目录、已打开文件、草稿及空间引用中的准确资源地址。只有原库与目标、引用更新和实际配置提交均确认，才报告搬迁完成。原 Notebook／Note／Block、来源、历史、空间实体、分割与块选择保留；不是把新目录为空当已搬迁，也不能只改设置而让原页面找不到文件。
- **并发与未保存输入保全。** 搬迁沿原 revision 和本次 operation identity 对账；用户后来编辑的未保存稿、冲突基线与真实归属保持，不能拿磁盘旧内容覆盖新稿、错写旧地址或吞掉输入。文件变化、路径冲突、不可写、满盘、断连和保存未知明确返回失败或未确认，保原可读库、地址及恢复动作，不覆盖目标的不同内容、不静默改指针或盲重放。较晚的设置请求与导航继续优先，迁移不强制重启或停止健康 Agent。
- **跨进程可继续确认。** 原操作保可查询的源／目标、范围和阶段，未知或进程中断后能沿同一迁移继续校验及收尾，不重建空 Notebook 或新身份。只在目标及引用的耐久性已确认后清理本次确切受管旧文件；未确认前保原字节和恢复入口，其他用户文件不因目录切换被清理。
- **GUI 与公共接口同一机制。** 配置查询、更改目录、操作对账须沿现有 Settings 领域的 typed RPC／CLI 可发现和可执行；Notebook／文件的查询和操作继续复用原领域。Agent 读取准确实际目录及保存／搬迁回执，不从 cwd 或 UI 显示猜目录。缺少相关公开结果或动作时在同一交付中扩展原 Settings 方法、发现、help 与真实消费，不能只交付设置输入框。
