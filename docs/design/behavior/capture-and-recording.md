# 截图与录制

本页统一持有系统截图、Browser 页面截图、共享图片编辑与图像交付的产品要求。录制与长截图先记录评估范围，不因进入本页成为本批执行任务；本页也不声明能力已实现、安装或验收。原生系统身份、权限与签名仍归[AgentMux 原生层](native-desktop.md)，Browser 导航与控制归[Browser 工作面](browser-workface.md)，草稿与发送归[输入与邮箱](conversation-input.md)。

用户要把屏幕或页面上的问题变成准确、可编辑、可交付的证据。主要路径是选择来源、确认同一次捕获、按需标注，再明确选择复制、附原草稿、另存或贴图；简单截图保留直接完成的路径。捕获对象、捕获画面、编辑原稿、处理后产物和一次交付的回执分别可辨，不让方便的输出动作改变执行对象或授权。

## 交互与职责

- 原生层提供准确 OS 来源、人工选区、像素与原 operation；Desktop 宿主持有窗口、外围焦点、剪贴板、准确文件和原草稿接收者。Core 的公共能力保持类型安全、可发现与可对账，不依赖 UI，也不复制平台的像素、窗口或编辑 Store。
- Browser 自身页面采图和系统桌面采图是不同来源；同图编辑与最终图合成复用，不能把来源统一理解为一律需要系统录屏权限。图像上的标注只表达本次观察，不授予页面、Agent 或系统输入控制权。
- 界面按 AgentMux 自身主题、语义图标、控件尺度和紧凑层级设计；捕获、编辑、交付的主次从上述用户任务与对象确定。用户流程不借外部产品名解释动作；参考研究与实际采纳的来源、许可、版权声明继续留在工程记录，不以原创呈现掩去来源义务。
- 具体视觉与可访问交互由[系统截图选区呈现](../presentation/conversation-input.md#系统截图选区)及[共享标记呈现](../presentation/browser-workface.md#browser-任务工具与证据的紧凑呈现)持有；本页不另写一份图标或样式规范。

## 截图与图像来源

- Message Tool 保留人工拖框选区、取消、保存和原草稿插入体验。原生选择给出明确 captured／cancelled／failed 结果；无图片、无响应或退出状态缺失保持未确认，不能冒充取消。失败保原草稿、附件、Session 目标与可用输入。
- 应用窗口、显示器和选区采图使用准确的 OS 图像来源；多屏、负坐标、HiDPI 与像素尺寸在同一坐标合同中解释。现代系统使用当前支持的原生采图 API，按实际系统版本处理 API 可用性，不因照搬上游最低版本丢掉已有能力。
- Browser 截图仍遵守[Browser 工作面](browser-workface.md)的原页面、导航、视口、GUI／CDP 来源与生命周期合同。隐藏、被遮挡、移动设备模拟和未获系统录屏许可的网页采图保持可用；统一图像入口不改变这些资格。
- 图片资源、PNG 与剪贴板动作返回实际保存／写入结果。系统截图、Browser 截图标注、图片预览和 Composer 继续使用原资源、编辑及发送 owner，不建立第二份图像或草稿 Store。

## 截图结果与悬浮贴图

- 处理后的同一图像提供明确的 PNG 另存和悬浮贴图。PNG 另存由本人选择准确文件位置，默认文件名包含捕获时刻且不覆盖已有文件；HiDPI 图像可显式选择按逻辑尺寸（1x）导出，默认保留实际像素；另存使用实际裁剪、遮盖和导出像素，不携带未处理原图、编辑历史或可编辑原稿；自动存给原草稿的内部文件不冒充本人已另存。保存取消保留原图、标注与原草稿；写入、冲突、失败及 unknown 分别沿准确文件 owner 的回执表达，不自动重试未知写入，不因另存成功重发或改投草稿。
- 贴图显示本人明确选择的这次最终处理图，是临时对照窗，不是新 Browser、Session 或实时来源。贴图默认出现在原选区位置并夹取在可见工作区内；窗口可置顶、移动、等比缩放（含滚轮）、调整不透明度、复制、另存、拖出为 PNG 文件和明确关闭；鼠标穿透由本人显式开启，穿透期间贴图自身仍保留可见、可命中的恢复入口与键盘关闭；关闭只释放该贴图资源，不取消原编辑、撤销已完成的输出或关闭来源工作面。编辑器后来变化不偷偷更新已有贴图，复制和另存继续取该贴图自己的像素。临时性质可辨，留存由本人显式另存；不建后台截图库，不因数量、超时或原来源结束而静默替人关闭图像。
- 贴图的公共调用与 GUI 连接同一 Desktop owner，提供创建、准确查询及关闭的 typed 能力与可发现 CLI；Core 只持类型、解析与委托，不依赖 Electron 或维护窗口 Store。目标以准确 Host、贴图身份和原 operation 对账，未知创建／关闭不得靠当前窗口是否存在推成原回执，不自动重放。图像只来自本次授权 PNG，不由 URL、标题或任意文件路径触发抓取；宿主未提供窗口能力时明确 unavailable，其他图像与 Agent 能力继续保留。
- 各输出分别记录本次图像和操作结果，保留已有成功目的地与未知操作身份；失败在原动作附近说明并保留图像、编辑和退出路径。贴图、PNG 另存、原稿保存及剪贴板不改变准确草稿接收者，不因窗口焦点变化推断 Agent 身份或发送授权。图像编辑与合成仍唯一复用[共享图片编辑能力](#共享图片编辑与标注)。

## 系统截图快捷键与选区

- macOS 的系统全局截图快捷键为 `⌘⇧2`；Survey、其他工作面、其他应用前台以及 AgentMux 最小化时都可呼出，不要求存在、挂载或选中 Message Tool。Desktop Main 注册与释放按键，原生层只负责同一次人工选区。Settings 的 Keyboard shortcuts 与 Capture 提示消费同一声明，清楚标识系统全局作用域；注册失败给出局部状态和恢复说明，原 Capture 按钮继续可用。
- 本人确认完成的截图始终复制到系统剪贴板。只有快捷键触发当下准确聚焦可编辑的本机消息输入框时，才同时插入那份草稿；没有聚焦输入框时只进剪贴板，不沿用上次输入框，不创建 Session 或草稿，也不切换 Survey、恢复最小化窗口或唤回无关工作面。输入框 Capture 按钮仍显式指向自己的草稿。
- 可选的草稿接收者在触发时固定原工作面 document 世代、Composer scope、editor 与插入位置；输入焦点和窗口前台分别消费真实焦点事实，不靠标题、Session 名称或较晚焦点另选目标。选区或编辑期间焦点变化不改投；原稿关闭、换代或不再可编辑只影响该次附图，不能阻断独立截图、编辑和剪贴板交付。正文、附件、Undo、原 Session 与健康 Run 保持。
- 选区后默认仍可直接完成，另有明确的快捷标注入口进入共享编辑面：选区完整位于一块显示器时，编辑面在原选区位置以同一冻结图像和像素尺度原位呈现；跨显示器、宿主无法原位或本人展开时进入独立轻量编辑窗，开在选区所在显示器并就地说明原因；不强制每次截图经过第二次确认，也不恢复最小化主窗口。交接沿同一冻结图像与选区，保持图像方向、裁剪范围、已知来源与可见反馈的连续性，不以再次采图、白屏闪跳或换成后来画面取得编辑底图。系统截图编辑复用 Browser 截图的绘图、文字、形状、裁剪、像素化、实色遮盖、缩放与 Undo／Redo；不在原生层复制另一套标注模型、渲染器或工具状态。原生选区工具条可显示宿主声明的快捷标注入口，只回传一次性、类型明确的起始工具意图；贴图与另存 PNG 作为直接输出动作，回传一次性、类型明确的输出意图，由宿主以同一冻结选区的像素执行，原生层不写文件、不开窗口；交接后工具、属性与历史唯一由共享编辑器持有，原生层不保存、不回读也不据此绘制。原位交接期间原生只保留同一冻结底图作只读背景，直至宿主显式释放、原连接断开或本人取消；背景不接收标注、不重新采图，也不阻断独立查询与剪贴板。原位编辑面在其整个存续期内保留该背景，选区外始终是同一张暗化冻结画面；编辑面关闭后才释放，结束动作中原位编辑面与背景同时退出，不让实时桌面先于编辑面露出或残留。编辑面结束（完成、取消或关闭）时前台回到截图开始前的应用，不停留在 AgentMux 或恢复主工作面。已有截图编辑面未结束时再次触发快捷键，将该编辑面带到前台并说明，不静默无反应，也不开启第二次选区。通用图片编辑能力唯一合同见[《Browser 页面截图与标记》](#共享图片编辑与标注)，系统截图不伪造页面 URL、DOM 或 Browser 来源。原生选区只在宿主明确支持编辑时提供类型明确的编辑交接意图；公共纯采图命令不因此打开编辑窗或改变 captured／cancelled／failed 含义。原生选区、图像编辑和结果交付各有唯一 owner，不增加后台截图库、Session 身份或额外配置。
- 剪贴板与草稿附图消费同一次最终图像，不能一处是编辑后结果、另一处是未处理原图。复制、保存与附图各自按实际回执表达；其中一项失败保留已经成功的结果与可用编辑，提供准确恢复出口，不自动重截或重放不确定操作。选区／编辑取消不交付未确认图像，不插入草稿，不将其他应用切回 Desktop；迟到结果不写入新草稿或重开已取消的编辑器。
- 拖动形成选区后停留在调整阶段，支持内部拖动、边角缩放和重新框选；尺寸随实际区域更新。`Enter`、确认按钮或选区内双击完成，`Esc` 或取消按钮退出；选区外右键清除当前选区回到框选，未选区时右键退出；键盘微调区域位置。显示器结构未变时，可复用本 Desktop 进程内上一次确认的选区几何作为新的冻结选区起点，仍由本人确认完成。Capture 提供 3／5／10 秒延时入口，倒计时可见、可取消，期间不冻结、不抢前台，结束后进入同一冻结选区。一次物理选区只完成一次；工具栏点击不得变成新的框选。
- 本人可在主屏或任一副屏的当前可见 Space 开始人工选区；macOS 的“显示器具有独立的空间”设置不改变各屏的选区资格。跨屏框选、调整及工具栏操作共用同一原请求与一次确认／取消，不因屏数增加请求或重复交付。选区与工具栏始终位于实际显示器可见范围，多屏负坐标、不同缩放比例和边缘位置沿原全局坐标合同处理。增强不改变 `native.capture` 的 selection 请求与 captured／cancelled／unknown 语义，CLI 与 GUI 复用同一原生实现；草稿焦点和全局按键属于 Desktop，不进入 Core。
- 人工选区在本次准确显示器来源的冻结画面上进行；移动、调整和结果裁剪使用该次捕获，动态桌面或后来光标位置不改变已见底图。捕获时刻与缺失范围如实表达，不承诺多屏像素来自同一瞬间；不可用来源不拿别屏图片填补，保留其他健康来源，跨越缺失区域的那次结果明确说明不能完整取得。显示器结构或坐标关系变化使原选择不再可解释时，只结束本次无效选择并说明重新选择动作，不暗中重截或改投屏幕。
- 选区提供像素放大镜、准确坐标、实际输出像素尺寸及显式取色。系统全局点、屏幕局部像素与 PNG 像素的单位和来源可辨，HiDPI／混合缩放下按实际合成变换显示，不能把 pt 尺寸冒成 px。取色只读取本次冻结像素，明确显示 HEX／RGB；复制色值是独立显式动作，不由指针移动改写剪贴板，也不从较晚桌面取色。
- Capture 的 GUI 入口可明确选择区域、整屏或窗口，复用原 `native.capture` 的 selection／display／window 能力。整屏与窗口选择来自同一 Host 原生 owner 返回的准确显示器 ID、进程身份及窗口 ID，名称和缩略图仅帮助辨认；捕获前复核原目标，失效只拒绝该次目标，不按标题或排列位置换成另一个窗口。选择模式不暗改原草稿、抢回主窗口、授予新权限或增加新的采图实现；公共 RPC／CLI 的发现、原请求与真实回执继续可用。
- 系统截图编辑宿主接通共享组件已有的原稿保存／重开及 Copy context，复用原文件与剪贴板 owner。独立系统截图不存在准确 Workspace 时，由本人明确选择保存／读取位置，不借最后使用的 Browser 或 Workspace 补身份。context 只描述原图、裁剪／导出变换、编号范围及备注和确知的本次系统来源，缺失保持未知；不编造 URL、DOM 或 Browser 身份。原稿与处理后产物、重开与复制的保全边界沿共享编辑合同，任何附图或发送仍以原准确目标及本人明确动作为准。

## 共享图片编辑与标注

- 标记后的图像仍是原 Browser 同一次页面观察的产物，不重建第二份截图生命周期。页面截图只取原页面，不以系统屏幕选区或音频采集授权作为前置，也不暗中切换成系统选区截图；系统截图入口的副本身份、授权、取消与失败边界只引用[《Message Tools 失败反馈与 Browser Region 选中态》](conversation-input.md#message-tools-失败反馈与-browser-region-选中态)。普通图像由本人显式复制、另存 PNG 或贴图，可编辑原稿由本人显式保存；均不自动并入 prompt。PNG 与贴图的实际像素、文件回执和独立生命周期统一见[《截图结果与悬浮贴图》](#截图结果与悬浮贴图)，不为 Browser 再造输出 owner。
- 图片标注组件编辑宿主明确提供的同一张图像及其原图尺寸，自身不持有 Browser、Agent 或文件身份，不自行捕获、读取宿主资源、写剪贴板或发送消息。宿主持有准确来源、捕获／读写资格、原生页让位与恢复、外围焦点交接及动作回执；组件边界不产生第二份页面、文件或编辑文档事实。Browser 与系统截图共同消费该组件及同一合成实现，Browser 原稿文件操作仍由具备准确 Host／Workspace／路径的宿主提供，独立系统截图使用上文本人明确选择的文件；缺少页面或文件身份不妨碍通用图像编辑和复制。
- 图片标记保留画笔、高亮、箭头、矩形、圆与文本，可明确选择、移动、删除或擦除已有标注；擦除只作用于标注，不破坏截图底图。已有区域形状可再次调整大小，箭头可改端点，已有文字可再次编辑；一次手势或文字提交形成一次可撤销编辑。矩形／椭圆绘制可用 Shift 约束为正方形／正圆，箭头可用 Shift 约束方向，释放约束恢复原自由绘制；约束在原图坐标成立，不随缩放改变几何。文本允许显式换行，输入、二次编辑、选择边界、预览、最终 PNG 与原稿使用一致的多行排版并保留原正文；IME、换行、提交和丢弃各有明确操作，不让文字输入的 Enter 冒成截图完成。裁剪限定本次导出的区域，像素化与实色遮盖均实际合成到预览和最终产物，不只覆盖一层可移走的 UI。像素化同时支持区域和刷涂；连续刷涂按一次手势形成一次 Undo，缩放和平移后仍处理实际命中的原图像素。标注、属性编辑与裁剪共用本次编辑的 Undo／Redo。
- Fit、原尺寸查看、放大缩小与平移只改变观察视口，不改原图坐标或导出内容；缩放和平移后选择、绘制、二次调整和文字输入仍命中实际图中目标。预览、裁剪后的图像和输出范围使用一致的坐标变换。选择一条编号批注能够将对应图像区域带回可见范围，定位不改其几何、显示编号或备注，也不导航原 Browser。
- 常用标注不要求先切换工具：在任意绘图工具下按住已有标注即选中并可移动或调整，在空白处才以当前工具新建；新建形状自动成为选中对象，颜色、粗细与字号调整直接作用于它。位移不足阈值的单击不提交零尺寸形状；编号工具的单击放置编号，并在编号旁就地输入备注。最近使用的工具与样式在本 Desktop 进程内沿用，不落盘、不成为设置。
- `Esc` 逐级退出：依次结束文字草稿、进行中的手势、对象选中与非默认工具；本次存在尚未经任何输出确认的标注或修改时，关闭前就地要求再次确认并说明将放弃的数量，确认前不丢失标注。
- 标注颜色同时提供预置与显式自定义的不透明色值，作用于当前工具或准确选中对象，预览、最终图和原稿保持同一值；不以换色触发额外绘图、采图或复制，也不增加全局配色配置。
- 编号批注把图中准确区域与用户备注关联，形状身份与显示编号分别保留；编号、范围和备注随同一实际标注列表生成。现象／期望／要求提供可选的轻量正文模板，允许自由文字与空项，不成为保存、复制或继续绘图的必填门槛；正文只表达用户提供的信息，不授予权限，也不冒充网页 DOM、认证来源或操作完成事实。
- Copy PNG 与 Copy context 分别复制处理后的图像与可供 Agent 阅读的结构上下文，本人明确选择，不自动发送给 Agent。非文字输入时 `Enter` 或 `⌘C` 执行主交付。独立编辑窗与 Browser 宿主在复制、PNG 另存或贴图成功后保留原编辑器及标注，用户可继续编辑或分别、重复输出，再明确 Cancel 退出；原位编辑面的主交付成功后关闭本次编辑面并释放冻结背景，另存、贴图与 Copy context 仍保留原位编辑面；临时隐藏或切到其他 Tab 保留本次图像标注和备注，隐藏的编辑器不接管其他工作面的按键或持续绘图。成功确认只对应本次实际操作回执，不表示后来修改也已输出。上下文说明同次捕获的页面来源 URL／title／viewport、原图尺寸、裁剪和导出坐标关系，以及编号＋范围＋备注；来源或坐标未知明确缺失，不借较晚页面、不从图像猜 DOM／selector 或认证页面自述。像素化与实色遮盖区域均不附备注或被遮内容上下文，裁剪外与未处理底图、编辑历史不进入本次处理后输出；刷涂像素化也遵守同一过滤与合成规则，不以像素化承诺秘密绝对不可推断。图像处理或任一输出失败分别如实反馈，不冒另一项成功。
- 显式保存的可编辑文档保留继续编辑所需的图像、原图尺寸、标注身份与几何、正文、裁剪及已知捕获来源；重开后能够继续修改并导出，不能只存处理后 PNG 冒充可编辑。原稿可含被遮原图与可修改的遮盖，保存入口须明确其与脱敏交付的区别，不默认随处理图／context 附送。文件内容不得触发脚本、网络抓取或任意本机资源读取；重开使用文档原有来源，未知仍未知，不以当前页面补造或重放旧操作。
- Browser 保存和重开复用准确 Host／Workspace／路径上的原用户文件能力，独立系统截图的文件选择沿上文系统宿主边界；修订、冲突、unknown、外部变更与保留新草稿均沿[《Revision-aware 保存与外部冲突》](files-and-git.md#revision-aware-保存与外部冲突)。未确认写入不显示已保存，较晚回执不清除后来修改；读取、格式版本、图像解码或标注校验失败保留当前编辑，不以半解析数据替换。超出实际文件或图像预算时只说明本次保存／重开不能完成，保留可用绘图、处理后复制与退出；不静默截短原稿或增加后台截图库。
- 人工连续绘图、工具选择和取消保持可操作，不能因截图预览、标记绘制或原生投影重绘而吞掉真实输入、截断笔画或让退出等待流程完成。绘制与输入更新仅作用于本次编辑器和相关事实，不让无关 Browser、Session 或工作面承担持续绘图成本；正常与窄分割、长笔画及缩放后用实际 Native Renderer 验证响应与最终产物，不以静态画面或模拟 Canvas 代签流畅。
- Cancel 退出本次标记并回到原 Browser 页面，原 Browser 身份、Profile、地址、工作面与健康 Run 保留；退出不要求重新创建或导航原页，不以编码或复制 busy 禁用取消。较晚的图像处理、绘制或复制结果不得重新打开已取消的编辑器，也不覆盖后来的截图。取消尚未提交的复制不写剪贴板；已经交给原剪贴板 owner 的写入按实际回执表达，结果未知不称未发生、不自动重试或伪造撤销。编码或复制失败就地说明，仍保留当前可用绘图与退出路径。

## 资源、权限与验收

- 同一次选区的占用覆盖实际像素生产与 PNG 结果；观察等待超时或发出取消请求不代表异步生产者已退出。原生产者仍活跃时只约束新的人工选区，独立查询和剪贴板继续可用；占用随生产者真正结束释放，不因请求回执已返回而提前解锁。

原生权限、签名、实际责任进程、连接私有性及恢复边界继续沿[原生层权限、签名与生命周期](native-desktop.md#权限签名与生命周期)，不因编辑器或输出形态改变而新增授权门槛。相关消费者的采集、绘图和贴图成本分别量测；冻结不成为持续采桌面的后台任务，隐藏编辑器停止本次绘制订阅并保留原图像／标注，贴图关闭释放自身订阅和像素资源，工作量不随无关 Session 增长。

验收同时覆盖真实系统与 Browser 宿主、公共能力的实际调用、准确来源／坐标／最终产物、取消和失败保全。原生 AppKit／WindowServer、跨屏混合尺度、前台恢复与权限连续性沿[原生完成边界](native-desktop.md#完成边界)保留；模拟布局、源码或编译不代签真实物理表现。视觉按[独立 Agent 看图评审](../../guides/agent-visual-e2e-review.md)，实现按[测试策略](../../testing/strategy.md#任务验收与假绿防护)验证，记录候选的触发响应、连续输入、峰值图像内存与结束释放。缺证如实说明，不以一次静态截图、安装成功或其他消费者通过代签。

## 录制与长截图评估

用户已提出 GIF 与滚动截图的需要，本节保存待评估方向，不授权开始录制、滚动原内容或加入本批实现。以下三类产物与来源不同，评估和后续确认分别进行：

| 方向 | 要解决的问题 | 仍需评估与确认 |
| --- | --- | --- |
| OS 选区 GIF | 把准确屏幕区域的一段动态变化交给人或 Agent 看 | 选区及多屏变化、开始／停止／取消、时长与采样节奏、色彩与清晰度、内存/编码成本、文件留存及失败恢复；录制期间的来源、系统授权和结束事实不能由普通截图回执代签 |
| Browser 整页长截图 | 保存原页面超出 viewport 的内容，便于长文、报告或界面审阅 | 原页面渲染／截图协议的整页或越界捕获能力、固定定位内容、虚拟滚动与未渲染部分、尺寸成本及准确范围；可直接从原渲染源取得时不默认通过系统滚动改变网页 |
| 系统滚动拼接 | 为任意可滚动应用组合一张长图 | 是否需要实际滚动输入、准确控件/窗口目标与用户授权、重叠对齐、动态内容与固定头、原阅读位置/输入保全、部分结果及中止；不能假设它与 Browser 整页采图共享算法或权限 |

可研究已有维护项目的区域录制组织方式、独立 GIF 编码器，以及浏览器截图协议的整页捕获机制；具体库、协议参数、依赖与适用范围由源码和实际实验核定，不能用项目声明代替效果或性能证据。评估结果先区分能力已有、缺口、可行选择与未知，再由本人确认范围和期次，随后更新本页及同 Closure 执行计划。普通截图、原编辑和健康工作面继续可用，不为这些未决方向预埋额外配置、常驻录制进程或第二份事实库。
