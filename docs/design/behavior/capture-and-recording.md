# 截图与录制

本页统一持有系统截图、Browser 页面截图、共享图片编辑、图像交付与工作面自截图／录制的产品要求。OS 选区 GIF 与滚动长截图的行为合同见后文；本页也不声明能力已实现、安装或验收。原生系统身份、权限与签名仍归[AgentMux 原生层](native-desktop.md)，Browser 导航与控制归[Browser 工作面](browser-workface.md)，草稿与发送归[输入与邮箱](conversation-input.md)。系统截图的录屏授权判定与授权连续性由本页[《资源、权限与验收》](#资源权限与验收)持有。

[返回交互合同](../agentmux-desktop-interaction.md) · [同主题视觉](../presentation/capture-and-recording.md)

用户要把屏幕或页面上的问题变成准确、可编辑、可交付的证据。主要路径是选择来源、确认同一次捕获、按需标注，再明确选择复制、附原草稿、另存或贴图；简单截图保留直接完成的路径。捕获对象、捕获画面、编辑原稿、处理后产物和一次交付的回执分别可辨，不让方便的输出动作改变执行对象或授权。

## 能力范围

本页定义的能力分为以下几组，各项的行为合同在下文对应章节；执行次序、状态与验收由 Feature Tracker 持有，不在本页维护。每一组都复用同一标注器以及原生／Browser 的原采集来源。

| 组 | 能力与边界 |
| --- | --- |
| 采集与选区 | 系统全局快捷键与直接完成、准确原草稿、取消与焦点归还、跨屏／负坐标／HiDPI、公共纯采图、冻结底图与连续反馈、放大镜／坐标／实际像素尺寸／取色、窗口／整屏 GUI、延时与同次截图续接、选区内双击完成、来源缩略图、编辑窗内重新截取 |
| 编辑与标注 | 选区上原位标注、轻量浮动工具条、免切换标注、对象二次编辑、裁剪、Undo／Redo、刷涂像素化、Shift 约束、多行文字、自定义颜色、`Esc` 保全尚未输出的标注，以及[对象级编辑、指示类修饰、智能吸附、魔棒与调色](#共享图片编辑与标注)；服务于把问题指给人或 Agent 看，不建图层面板、混合模式或通用修图工作流 |
| 交付 | PNG 另存（含捕获时刻命名与 1x 导出）、临时贴图（原位、不透明度、鼠标穿透、缩放、拖出）、系统宿主的原稿与 context、遮盖过滤、原稿保真及文件修订、键盘交付、编辑结束后归还前台 |
| 工作面自截图与录制 | Agent 观察准确 App 窗口或 Region 的 PNG 与录制产物，见[《工作面自截图与录制》](#工作面自截图与录制)；与 OS 选区 GIF 是不同来源和授权 |
| 连续采集 | OS 选区 GIF 与手动滚动截图，见[《GIF 与滚动截图》](#gif-与滚动截图)；用户显式选择模式并开始采集，不按普通截图自动录制或滚动 |
| 后续候选 | Browser 整页长截图与 Browser 选区 GIF、颜色历史、快捷键自定义；各项先在本页写出行为合同再实现 |
| 不扩展 | 录屏管理平台、后台截图库、默认自动上传；新需求由本人确认，不从某个技术依赖推导范围 |

## 交互与职责

- 原生层提供准确 OS 来源、逐屏冻结像素与原 operation；Desktop 宿主持有截图覆盖面（人工选区、放大镜、工具条与原位标注）、窗口、外围焦点、剪贴板、准确文件和原草稿接收者。Core 的公共能力保持类型安全、可发现与可对账，不依赖 UI，也不复制平台的像素、窗口或编辑 Store。
- Browser 自身页面采图和系统桌面采图是不同来源；同图编辑与最终图合成复用，不能把来源统一理解为一律需要系统录屏权限。图像上的标注只表达本次观察，不授予页面、Agent 或系统输入控制权。
- 界面按 AgentMux 自身主题、语义图标、控件尺度和紧凑层级设计；捕获、编辑、交付的主次从上述用户任务与对象确定。用户流程不借外部产品名解释动作；参考研究与实际采纳的来源、许可、版权声明继续留在工程记录，不以原创呈现掩去来源义务。
- 具体视觉与可访问交互由[系统截图选区呈现](../presentation/capture-and-recording.md#系统截图选区)及[共享标记呈现](../presentation/browser-workface.md#browser-任务工具与证据的紧凑呈现)持有；本页不另写一份图标或样式规范。

## 截图与图像来源

- Message Tool 保留人工拖框选区、取消、保存和原草稿插入体验。原生选择给出明确 captured／cancelled／failed 结果；无图片、无响应或退出状态缺失保持未确认，不能冒充取消。失败保原草稿、附件、Session 目标与可用输入。
- 应用窗口、显示器和选区采图使用准确的 OS 图像来源；多屏、负坐标、HiDPI 与像素尺寸在同一坐标合同中解释。现代系统使用当前支持的原生采图 API，按实际系统版本处理 API 可用性，不因照搬上游最低版本丢掉已有能力。
- Browser 截图仍遵守[Browser 工作面](browser-workface.md)的原页面、导航、视口、GUI／CDP 来源与生命周期合同。隐藏、被遮挡、移动设备模拟和未获系统录屏许可的网页采图保持可用；统一图像入口不改变这些资格。
- Browser 页面 PNG 默认只包含网页自身内容，截图期间原子排除宿主自有的 Agent 控制绿框、操作光标与调试装饰；不能通过交还控制、暂停真实输入隔离、删除网站节点或截图后裁掉网页边缘取得干净图。失败、取消与导航更换后恢复原宿主展示，原 Browser、输入、焦点、视口与控制权保持。后台、被遮挡和可见页面沿同一原截图 owner，不为采图选择或移动工作面。
- 页面截图支持准确的可见区域与明确像素密度，并返回实际 PNG 尺寸、区域和观察到的原视口；不以截图成功代签业务数据或页面加载成功。区域定位、就绪条件、像素预算和不支持的范围由实际公开能力说明，定位失败不静默改截另一元素或整页。CLI 与 SDK 复用同一 Browser 页面截图及原操作回执，CLI 可输出到调用者指定的本机新 PNG 文件；不覆盖已有文件、不自动上传，不要求调用者自行拼裸 CDP、解码或修图才能得到干净产物。
- 图片资源、PNG 与剪贴板动作返回实际保存／写入结果。系统截图、Browser 截图标注、图片预览和 Composer 继续使用原资源、编辑及发送 owner，不建立第二份图像或草稿 Store。自动粘贴图片的短文件名、完整内容摘要、同图对账与既有文件保全沿[输入与邮箱](conversation-input.md#message-tool-粘贴保持光标与草稿)。

## 截图结果与悬浮贴图

- 处理后的同一图像提供明确的 PNG 另存和悬浮贴图。PNG 另存由本人选择准确文件位置，默认文件名包含捕获时刻且不覆盖已有文件；HiDPI 图像可显式选择按逻辑尺寸（1x）导出，默认保留实际像素；另存使用实际裁剪、遮盖和导出像素，不携带未处理原图、编辑历史或可编辑原稿；自动存给原草稿的内部文件不冒充本人已另存。保存取消保留原图、标注与原草稿；写入、冲突、失败及 unknown 分别沿准确文件 owner 的回执表达，不自动重试未知写入，不因另存成功重发或改投草稿。
- 贴图显示本人明确选择的这次最终处理图，是临时对照窗，不是新 Browser、Session 或实时来源。贴图默认出现在原选区位置并夹取在可见工作区内；窗口可置顶、移动、等比缩放（含滚轮）、调整不透明度、复制、另存、拖出为 PNG 文件和明确关闭；鼠标穿透由本人显式开启，穿透期间贴图自身仍保留可见、可命中的恢复入口与键盘关闭；关闭只释放该贴图资源，不取消原编辑、撤销已完成的输出或关闭来源工作面。编辑器后来变化不偷偷更新已有贴图，复制和另存继续取该贴图自己的像素。临时性质可辨，留存由本人显式另存；不建后台截图库，不因数量、超时或原来源结束而静默替人关闭图像。
- 贴图的公共调用与 GUI 连接同一 Desktop owner，提供创建、准确查询及关闭的 typed 能力与可发现 CLI；Core 只持类型、解析与委托，不依赖 Electron 或维护窗口 Store。目标以准确 Host、贴图身份和原 operation 对账，未知创建／关闭不得靠当前窗口是否存在推成原回执，不自动重放。图像只来自本次授权 PNG，不由 URL、标题或任意文件路径触发抓取；宿主未提供窗口能力时明确 unavailable，其他图像与 Agent 能力继续保留。
- 各输出分别记录本次图像和操作结果，保留已有成功目的地与未知操作身份；失败在原动作附近说明并保留图像、编辑和退出路径。贴图、PNG 另存、原稿保存及剪贴板不改变准确草稿接收者，不因窗口焦点变化推断 Agent 身份或发送授权。图像编辑与合成仍唯一复用[共享图片编辑能力](#共享图片编辑与标注)。

## 系统截图快捷键与选区

- macOS 的系统全局截图快捷键为 `⌘⇧2`；Survey、其他工作面、其他应用前台以及 AgentMux 最小化时都可呼出，不要求存在、挂载或选中 Message Tool。Desktop Main 注册与释放按键并呈现同一次人工选区，原生层只负责该次逐屏冻结像素。Settings 的 Keyboard shortcuts 与 Capture 提示消费同一声明，清楚标识系统全局作用域；注册失败给出局部状态和恢复说明，原 Capture 按钮继续可用。
- 截图有「不含 AgentMux」与「含 AgentMux」两种底图：`⌘⇧2` 默认显示含 AgentMux 窗口的底图，多按 Option 的 `⌥⌘⇧2` 默认显示不含 AgentMux 窗口的底图（不占用 macOS 自带的截图快捷键），两者都由 Settings 的 Keyboard shortcuts 与 Capture 提示消费同一声明。一次截图同时冻结这两份底图，覆盖面出现后按 `Tab` 在两份之间切换，已有选区、标注与撤销历史原样保留；切换只换底图，不再移动、隐藏或重新显示任何窗口，也不重新抓取。支持按窗口排除的原生采图路径直接取得不含 AgentMux 的底图，不让 AgentMux 窗口为了第二份底图而可见退场；默认含 AgentMux 的截图不得出现这类可见闪烁。系统原生能力不足以无闪烁取得另一份底图时，保留当前可用底图并明确限制，不以另一份冒充。没有可见 AgentMux 窗口时两份底图是同一份，不重复抓取。其中一份不可用或仍在准备时保留另一份并就地说明，不以另一份冒充。
- 本人确认完成的截图始终复制到系统剪贴板。只有快捷键触发当下准确聚焦可编辑的本机消息输入框时，才同时插入那份草稿；没有聚焦输入框时只进剪贴板，不沿用上次输入框，不创建 Session 或草稿，不出现要求先选择 Agent 的阻断界面，也不切换 Survey、恢复最小化窗口或唤回无关工作面。输入框 Capture 按钮仍显式指向自己的草稿。
- 可选的草稿接收者在触发时固定原工作面 document 世代、Composer scope、editor 与插入位置；输入焦点和窗口前台分别消费真实焦点事实，不靠标题、Session 名称或较晚焦点另选目标。选区或编辑期间焦点变化不改投；原稿关闭、换代或不再可编辑只影响该次附图，不能阻断独立截图、编辑和剪贴板交付。正文、附件、Undo、原 Session 与健康 Run 保持。
- 选区、放大镜、工具条与标注是同一个截图覆盖面：Desktop 在每块显示器上以一个透明、不夺前台的覆盖窗口呈现该屏的冻结画面；覆盖窗在释放输入和显示前启用系统内容保护，后续底图抓取不得递归拍入覆盖窗自身。选区就是共享编辑器在该屏冻结图上的裁剪范围。一次选区只在一块显示器内，可在任一屏开始，不跨越显示器边缘；整屏与窗口另由 Capture 的显式来源选择取得。选区后默认仍可直接完成；点工具条上的任一标注工具即在选区原位开始标注，不更换窗口、不重新渲染底图，也不跳到另一个编辑窗；本人以 `⌘E` 展开时才进入独立轻量编辑窗，开在选区所在显示器。不强制每次截图经过第二次确认，也不恢复最小化主窗口。工具、属性、历史与输出只有共享编辑器一份，覆盖面与独立编辑窗共用同一实现，原生层不持有任何标注、工具或呈现状态。贴图与另存 PNG 作为直接输出，以同一冻结选区的处理后像素执行，不经过独立编辑窗。覆盖面结束（完成、取消或关闭）时前台回到截图开始前的应用，不停留在 AgentMux 或恢复主工作面。已有截图覆盖面或编辑窗未结束时再次触发快捷键，将其带到前台并说明，不静默无反应，也不开启第二次选区。通用图片编辑能力唯一合同见[《共享图片编辑与标注》](#共享图片编辑与标注)，系统截图不伪造页面 URL、DOM 或 Browser 来源。公共纯采图命令不因此打开编辑窗或改变 captured／cancelled／failed 含义。逐屏冻结像素、截图覆盖面与编辑、结果交付各有唯一 owner，不增加后台截图库、Session 身份或额外配置。
- 剪贴板与草稿附图消费同一次最终图像，不能一处是编辑后结果、另一处是未处理原图。复制、保存与附图各自按实际回执表达；其中一项失败保留已经成功的结果与可用编辑，提供准确恢复出口，不自动重截或重放不确定操作。选区／编辑取消不交付未确认图像，不插入草稿，不将其他应用切回 Desktop；迟到结果不写入新草稿或重开已取消的编辑器。
- 拖动形成选区后停留在调整阶段，支持内部拖动、边角缩放和重新框选；尺寸随实际区域更新。`Enter`、确认按钮或选区内双击完成，`Esc` 或取消按钮退出；选区外右键清除当前选区回到框选，未选区时右键退出；键盘微调区域位置。每次新的截图从空白选区开始，不自动恢复上一次确认或调整的选区几何；同一次截图内的底图切换与独立编辑窗展开／返回保留当前选区、标注与历史，Copy 后的 Retake 通过同一次 capture 的显式续接恢复原选区，不把该续接留到下一次全新截图。Capture 提供 3／5／10 秒延时入口，倒计时可见、可取消，期间不冻结、不抢前台，结束后进入同一冻结选区。一次物理选区只完成一次；工具栏点击不得变成新的框选。
- 本人可在主屏或任一副屏的当前可见 Space 开始人工选区；macOS 的“显示器具有独立的空间”设置不改变各屏的选区资格。各屏覆盖窗口共用同一原请求与一次确认／取消，不因屏数增加请求或重复交付；选区开始的那块屏承载本次选区，其他屏的覆盖面只显示冻结画面与取消入口。选区与工具栏始终位于该屏可见范围，提示、工具条、尺寸标签与放大镜避开该屏顶部的摄像头刘海等系统遮挡区，选区本身仍可贴到屏幕顶边，负坐标、不同缩放比例和边缘位置沿原全局坐标合同处理。公共 `native.capture` 的 selection 请求与 captured／cancelled／unknown 语义保持，CLI 与 GUI 复用同一截图覆盖面；草稿焦点和全局按键属于 Desktop，不进入 Core。
- 人工选区在本次准确显示器来源的冻结画面上进行；移动、调整和结果裁剪使用该次捕获，动态桌面或后来光标位置不改变已见底图。捕获时刻与缺失范围如实表达，不承诺多屏像素来自同一瞬间；不可用来源不拿别屏图片填补，保留其他健康来源，不可用的屏幕在其覆盖面上就地说明，不能在其上选区。显示器结构或坐标关系变化使原选择不再可解释时，只结束本次无效选择并说明重新选择动作，不暗中重截或改投屏幕。
- 选区提供像素放大镜、准确坐标、实际输出像素尺寸及显式取色。系统全局点、屏幕局部像素与 PNG 像素的单位和来源可辨，HiDPI／混合缩放下按实际合成变换显示，不能把 pt 尺寸冒成 px。取色只读取本次冻结像素，明确显示 HEX／RGB；复制色值是独立显式动作，不由指针移动改写剪贴板，也不从较晚桌面取色。
- Capture 的 GUI 入口可明确选择区域、整屏或窗口，复用原 `native.capture` 的 selection／display／window 能力。整屏与窗口选择来自同一 Host 原生 owner 返回的准确显示器 ID、进程身份及窗口 ID，名称和缩略图仅帮助辨认；捕获前复核原目标，失效只拒绝该次目标，不按标题或排列位置换成另一个窗口。选择模式不暗改原草稿、抢回主窗口、授予新权限或增加新的采图实现；公共 RPC／CLI 的发现、原请求与真实回执继续可用。
- 系统截图编辑宿主接通共享组件已有的原稿保存／重开及 Copy context，复用原文件与剪贴板 owner。独立系统截图不存在准确 Workspace 时，由本人明确选择保存／读取位置，不借最后使用的 Browser 或 Workspace 补身份。context 只描述原图、裁剪／导出变换、编号范围及备注和确知的本次系统来源，缺失保持未知；不编造 URL、DOM 或 Browser 身份。原稿与处理后产物、重开与复制的保全边界沿共享编辑合同，任何附图或发送仍以原准确目标及本人明确动作为准。

## 共享图片编辑与标注

- 标记后的图像仍是原 Browser 同一次页面观察的产物，不重建第二份截图生命周期。页面截图只取原页面，不以系统屏幕选区或音频采集授权作为前置，也不暗中切换成系统选区截图；系统截图入口的副本身份与授权边界见本页[《资源、权限与验收》](#资源权限与验收)，Message Tool 内的取消与失败边界只引用[《Message Tools 失败反馈》](conversation-input.md#message-tools-失败反馈)。普通图像由本人显式复制、另存 PNG 或贴图，可编辑原稿由本人显式保存；均不自动并入 prompt。PNG 与贴图的实际像素、文件回执和独立生命周期统一见[《截图结果与悬浮贴图》](#截图结果与悬浮贴图)，不为 Browser 再造输出 owner。
- 图片标注组件编辑宿主明确提供的同一张图像及其原图尺寸，自身不持有 Browser、Agent 或文件身份，不自行捕获、读取宿主资源、写剪贴板或发送消息。宿主持有准确来源、捕获／读写资格、原生页让位与恢复、外围焦点交接及动作回执；组件边界不产生第二份页面、文件或编辑文档事实。Browser 与系统截图共同消费该组件及同一合成实现，Browser 原稿文件操作仍由具备准确 Host／Workspace／路径的宿主提供，独立系统截图使用上文本人明确选择的文件；缺少页面或文件身份不妨碍通用图像编辑和复制。
- 图片标记保留画笔、高亮、箭头、矩形、圆与文本，可明确选择、移动、删除或擦除已有标注；擦除只作用于标注，不破坏截图底图。已有区域形状可再次调整大小，箭头可改端点，已有文字可再次编辑；一次手势或文字提交形成一次可撤销编辑。矩形／椭圆绘制可用 Shift 约束为正方形／正圆，箭头可用 Shift 约束方向，释放约束恢复原自由绘制；约束在原图坐标成立，不随缩放改变几何。文本允许显式换行，输入、二次编辑、选择边界、预览、最终 PNG 与原稿使用一致的多行排版并保留原正文；IME、换行、提交和丢弃各有明确操作，不让文字输入的 Enter 冒成截图完成。裁剪限定本次导出的区域，像素化与实色遮盖均实际合成到预览和最终产物，不只覆盖一层可移走的 UI。像素化同时支持区域和刷涂；连续刷涂按一次手势形成一次 Undo，缩放和平移后仍处理实际命中的原图像素。标注、属性编辑与裁剪共用本次编辑的 Undo／Redo。
- Fit、原尺寸查看、放大缩小与平移只改变观察视口，不改原图坐标或导出内容；缩放和平移后选择、绘制、二次调整和文字输入仍命中实际图中目标。预览、裁剪后的图像和输出范围使用一致的坐标变换。选择一条编号批注能够将对应图像区域带回可见范围，定位不改其几何、显示编号或备注，也不导航原 Browser。
- 常用标注不要求先切换工具：在任意绘图工具下按住已有标注即选中并可移动或调整，在空白处才以当前工具新建；新建形状自动成为选中对象，颜色、粗细与字号调整直接作用于它。位移不足阈值的单击不提交零尺寸形状；编号工具的单击放置编号，并在编号旁就地输入备注。最近使用的工具与样式在本 Desktop 进程内沿用，不落盘、不成为设置。
- `Esc` 逐级退出：依次结束文字草稿、进行中的手势、对象选中与非默认工具；本次存在尚未经任何输出确认的标注或修改时，关闭前就地要求再次确认并说明将放弃的数量，确认前不丢失标注。
- 对象级编辑：可框选或 Shift 点选多个标注，统一移动、对齐、分布、改样式、复制粘贴或删除；层序前移／后移与置顶／置底只改变标注相互遮挡，不改动底图；锁定的标注不响应选中与移动。复制粘贴只在本次编辑内的标注之间进行，不读写系统剪贴板中的图像。
- 指示类修饰：模糊以可调强度柔化区域，与像素化、实色遮盖同属遮挡类，处理后输出同样过滤其内容与备注；放大标注把原图一块区域以可调倍率放大到一个可移动的气泡并用引线连回原处；聚光灯暗化其余区域、只突出所选区域；编号在增删后保持连续，可显式重排。放大与聚光灯作用于导出结果，并在原稿中保持可编辑。
- 智能吸附：截图覆盖面在指针悬停时高亮其下的应用窗口边界，单击即以该窗口在本屏可见的边界作为选区；拖动选区与绘制、移动标注时吸附到窗口边缘、选区边缘与其他标注的边与中心，按住 `⌘` 暂时关闭吸附。窗口边界来自同一 Host 原生 owner 返回的准确窗口几何，不从像素猜测。
- 魔棒与调色：魔棒按颜色相近程度在冻结像素上选出一片连续区域，容差可调，所选区域可直接转为遮挡、高亮或聚光灯的范围；亮度、对比度、饱和度与锐化作为整图或所选区域的可撤销调整，预览与导出一致，原稿保留原图与调整参数。滤镜只服务于让问题更清楚，不建图层面板、混合模式或通用修图工作流。
- 标注颜色同时提供预置与显式自定义的不透明色值，作用于当前工具或准确选中对象，预览、最终图和原稿保持同一值；不以换色触发额外绘图、采图或复制，也不增加全局配色配置。
- 编号批注把图中准确区域与用户备注关联，形状身份与显示编号分别保留；编号、范围和备注随同一实际标注列表生成。现象／期望／要求提供可选的轻量正文模板，允许自由文字与空项，不成为保存、复制或继续绘图的必填门槛；正文只表达用户提供的信息，不授予权限，也不冒充网页 DOM、认证来源或操作完成事实。
- Copy PNG 与 Copy context 分别复制处理后的图像与可供 Agent 阅读的结构上下文，本人明确选择，不自动发送给 Agent。非文字输入时 `Enter` 或 `⌘C` 执行主交付。独立编辑窗与 Browser 宿主在复制、PNG 另存或贴图成功后保留原编辑器及标注，用户可继续编辑或分别、重复输出，再明确 Cancel 退出；截图覆盖面的主交付或贴图成功后关闭本次覆盖面，贴图即本次最终输出，不在仍打开的覆盖面上叠出同一选区的第二份图像；另存与 Copy context 仍保留覆盖面；临时隐藏或切到其他 Tab 保留本次图像标注和备注，隐藏的编辑器不接管其他工作面的按键或持续绘图。成功确认只对应本次实际操作回执，不表示后来修改也已输出。上下文说明同次捕获的页面来源 URL／title／viewport、原图尺寸、裁剪和导出坐标关系，以及编号＋范围＋备注；来源或坐标未知明确缺失，不借较晚页面、不从图像猜 DOM／selector 或认证页面自述。像素化与实色遮盖区域均不附备注或被遮内容上下文，裁剪外与未处理底图、编辑历史不进入本次处理后输出；刷涂像素化也遵守同一过滤与合成规则，不以像素化承诺秘密绝对不可推断。图像处理或任一输出失败分别如实反馈，不冒另一项成功。
- 显式保存的可编辑文档保留继续编辑所需的图像、原图尺寸、标注身份与几何、正文、裁剪及已知捕获来源；重开后能够继续修改并导出，不能只存处理后 PNG 冒充可编辑。原稿可含被遮原图与可修改的遮盖，保存入口须明确其与脱敏交付的区别，不默认随处理图／context 附送。文件内容不得触发脚本、网络抓取或任意本机资源读取；重开使用文档原有来源，未知仍未知，不以当前页面补造或重放旧操作。
- Browser 保存和重开复用准确 Host／Workspace／路径上的原用户文件能力，独立系统截图的文件选择沿上文系统宿主边界；修订、冲突、unknown、外部变更与保留新草稿均沿[《Revision-aware 保存与外部冲突》](files-and-git.md#revision-aware-保存与外部冲突)。未确认写入不显示已保存，较晚回执不清除后来修改；读取、格式版本、图像解码或标注校验失败保留当前编辑，不以半解析数据替换。超出实际文件或图像预算时只说明本次保存／重开不能完成，保留可用绘图、处理后复制与退出；不静默截短原稿或增加后台截图库。
- Browser 原稿记录原页面地址、标题、视口与视口观察说明作为历史来源。指定采图区域和宿主浮层排除状态随该次截图回执保留。
- 人工连续绘图、工具选择和取消保持可操作，不能因截图预览、标记绘制或原生投影重绘而吞掉真实输入、截断笔画或让退出等待流程完成。绘制与输入更新仅作用于本次编辑器和相关事实，不让无关 Browser、Session 或工作面承担持续绘图成本；正常与窄分割、长笔画及缩放后用实际 Native Renderer 验证响应与最终产物，不以静态画面或模拟 Canvas 代签流畅。
- Cancel 退出本次标记并回到原 Browser 页面，原 Browser 身份、Profile、地址、工作面与健康 Run 保留；退出不要求重新创建或导航原页，不以编码或复制 busy 禁用取消。较晚的图像处理、绘制或复制结果不得重新打开已取消的编辑器，也不覆盖后来的截图。取消尚未提交的复制不写剪贴板；已经交给原剪贴板 owner 的写入按实际回执表达，结果未知不称未发生、不自动重试或伪造撤销。编码或复制失败就地说明，仍保留当前可用绘图与退出路径。

## 资源、权限与验收

截图呼出的首帧只消费本次实际冻结画面，准备界面不应串行等待无关工作，不能复用上次像素或丢弃当前编辑来缩短等待。当前快捷键选中的底图与覆盖面已经就绪时可先显示，另一份同次底图继续准备；另一份尚未就绪时切换入口明确表达准备中，不阻断当前可用画面，也不拿旧图或另一来源顶替。首次／再次与单屏／多屏的触发、原生返回、数据准备、Renderer 呈现和显示阶段应可分别量测；Desktop 诊断保留最近一次不含截图像素或草稿正文的小型耗时记录，正常启动方式下也可读取。诊断失败只影响本次观测，不阻断健康截图；性能结论绑定实际候选和采集条件，受控输入不代签真实 OS 采图。

- 同一次选区的占用覆盖实际像素生产与 PNG 结果；观察等待超时或发出取消请求不代表异步生产者已退出。原生产者仍活跃时只约束新的人工选区，独立查询和剪贴板继续可用；占用随生产者真正结束释放，不因请求回执已返回而提前解锁。

原生权限、签名、实际责任进程、连接私有性及恢复边界继续沿[原生层权限、签名与生命周期](native-desktop.md#权限签名与生命周期)，不因编辑器或输出形态改变而新增授权门槛。在这份通用合同之上，系统截图的录屏授权还须满足：

1. 截图按实际截图通路的真实结果处理：已授权时能完成，不反复请求系统授权。
   - 改善 AgentMux 内部文案不能冒充修好了授权故障，也不能让用户重复授权来代替根因验证。
   - 当前 Electron 的授权读数不能单独证明系统截图命令被拒绝；已授权、unknown 或授权读取失败都不得被误挡。
   - 只有真正未授权时，才在原工具旁准确说明当前副本、恢复动作和重试；不自动重复请求系统授权，不重置权限，也不替用户授权。
2. 重启或重复打开系统设置，不能代替“同一个已授权的实际运行副本能截图”的验证。
3. “已授权”必须绑定实际运行副本和系统使用的签名身份。
   - 设置开关已开、安装包自身签名校验通过，都不能单独证明当前副本有截图授权。
   - 交付更新须保持可延续的授权身份，不能靠每次重新打包后让用户重复授权。
   - 首次从 ad-hoc 签名换到合法签名时，旧授权是否适用于新身份，按系统实际结果说明，可能需要本人明确授权一次；这次身份过渡不冒充后续更新的授权连续性。
   - 后续同一合法 signer 与 designated requirement 的更新，须由实际系统授权匹配来证明；不得弱化或伪造 requirement、重置权限库或替用户授权来伪装连续。

相关消费者的采集、绘图和贴图成本分别量测；冻结不成为持续采桌面的后台任务，隐藏编辑器停止本次绘制订阅并保留原图像／标注，贴图关闭释放自身订阅和像素资源，工作量不随无关 Session 增长。

验收同时覆盖真实系统与 Browser 宿主、公共能力的实际调用、准确来源／坐标／最终产物、取消和失败保全。原生 AppKit／WindowServer、跨屏混合尺度、前台恢复与权限连续性沿[原生完成边界](native-desktop.md#完成边界)保留；模拟布局、源码或编译不代签真实物理表现。视觉按[独立 Agent 看图评审](../../guides/agent-visual-e2e-review.md)，实现按[测试策略](../../testing/strategy.md#任务验收与假绿防护)验证，记录候选的触发响应、连续输入、峰值图像内存与结束释放。缺证如实说明，不以一次静态截图、安装成功或其他消费者通过代签。

## 工作面自截图与录制

Agent 在产品内自举时，按准确的 App 窗口及文档代次观察整窗，或指定准确 display Workspace／Group／Tab／Region 取得当前已呈现区域。Desktop 持有原窗口、Region 呈现几何、实际像素与采集生命周期；Core 提供与 UI 无关的公共类型、严格解析和对象 CLI，原 `app.window.ls` 与 `space inspect` 用于发现身份。采集不按标题、cwd、当前焦点或首候选选择对象，不为观察切页、聚焦、恢复、创建或移动工作面。

- PNG 来自该次 Renderer 及实际原生 Browser 子视图；保留各来源和采集起止时间，不把多层合成称作物理同时曝光。Region 裁剪来自准确原呈现位置，并在采集前后核对原身份和几何；未呈现、被覆盖、文档更换或来源未确认时说明该次观察缺口，不补旧帧、不借系统截图冒充。
- 录制复用同一像素源。开始、观察、停止与读取沿一个原 operationId 和原调用者，重复开始只观察原操作，不重新录制。录制有明确最大时长、采样节奏、像素和编码内存预算；预算由实现发现及回执说明，只约束该次采集，不扩散为 Agent、手动操作或普通截图的门禁。帧按实际时间记录，采集串行且不因无关 Session 增加工作量。
- 开始与停止均有可观察回执；结束释放该次采集与编码资源。断线不停止原业务，也不自动重放开始；可以查询和停止原录制。重启保留原操作、已保存产物与真实未完成状态，不把中断录制补成成功。缺少原操作明确未知，不推断其从未发生。
- 编码产物由 Desktop 存入自己的应用状态目录；公共读取返回该原产物，CLI 只向调用者明确指定的本机新文件写出，不覆盖现有文件，不往用户项目注入素材或自动上传。PNG、WebM、摘要和真实采集来源分别报告；无实际可解码像素不报完成。普通截图编辑、贴图、Agent/Run、原草稿与输入继续沿原 owner；录制失败只说明该次失败及读取/停止路径。
- 采集入口不授予额外权限，不允许 Agent 通过操作 App 的卡片冒充人的权限决定。既有语义操作仍走原公共控制，像素只供观察和产物，不能从画面文字或位置推导控制资格。共享图片编辑后续接入只复用本采集来源，不复制录制事实。

## GIF 与滚动截图

消息输入区保留单一 Capture 入口，打开同一次截图覆盖面后选择截图、滚动截图或 GIF；窗口、整屏与延时也在截图组件内发现。切换模式保留当前选区，不凭模式切换自动开始录制或交付。公共采集方法继续表达原业务能力，入口调整不改变原草稿和公共调用。

Capture 菜单提供滚动截图与 GIF 录制。两者先选定一块屏幕上的准确区域，再进入明确开始、停止、取消与回放；普通选区确认不隐式授权持续采集。实时预览只呈现已确认的拼接内容。选区、预览、采集控件和悬停提示由同一覆盖面承载，按准确窗口 ID 从原生像素来源中排除，不靠隐藏窗口或重拍覆盖。单次采集与导入的 PNG 帧合计预算为 64 MB，长图合成沿用 PNG 交付边界（最长边 16,384 像素、最多 32 百万像素、编码后最多 18 MiB），GIF 编码预算为 64 MB；达到该次资源预算时说明原因并保留已有帧供结束、导出或撤回，不影响其他截图和健康工作面。采集串行，按真实完成时间保留帧和间隔，失败保留已有帧及重试、结束路径，不冒充完整产物。原草稿接收者在触发时固定，不因回放窗口焦点改投。

滚动截图由本人手动滚动来源；在选区内显式开始后直接进入连续采集，不再要求从大回看窗二次开始。沿用原截图覆盖面与选区工具条的位置，撤掉冻结底图和遮罩；预览随同原覆盖面呈现，进入滚动时不创建采集窗、预览窗或边框窗。选区边框和工具条原位保留，工具条收为停止、取消与进度；除工具条实际命中区域外，覆盖面鼠标穿透，点击、滚轮和键盘仍由真实来源应用正常处理。采样真正失败时也先原位说明原因并保留重试和停止入口，不用回看窗遮住来源。选区冻结图只用于预览，首次开始以真实采样建立长图首帧，不能拿等待选区期间的旧画面判定滚动。采集自动去重并匹配重叠区域；暂时无法确认重叠时跳过该候选、保留已确认帧并在控制条提示本人回到有重叠的内容，继续等待可匹配采样，不因一次对齐失败退出采集态。停止后才进入长图回看，同时保留逐次采集的入口。仅在匹配可信时拼接，重复帧不增加高度；少量局部变化且零位移仍是最可信对齐时继续等待滚动，不因光标或闪烁误停；不确定或动态区域提示本人调整，保留原帧供撤回，不凭猜测悄悄接错。不会向原应用注入滚动输入，也不会重置原阅读位置。完成后复用共享图片编辑和 PNG 交付。

滚动停止后的回看以已合成的长图为主体，提供明确「确认」进入原图片编辑与交付；回看不再以首次「开始滚动截图」作主动作。「重新截图」为次要入口，重新选择区域并建立新首帧，不追加原长图；新选区取消或建立失败时，保留原回看、已确认帧和逐次采集入口。未确认的回看关闭先给出继续回看或放弃结果的明确选择，不能把普通关闭默认为完成交付。确认失败保留预览和重试入口。

GIF 录制有可见的开始与停止，停止后可播放、暂停、逐帧定位并把当前帧标为关键帧。每个关键帧可添加、修改或删除文字备注。时间轴显示帧号与时间，帧序号在文件内从 0 起计、界面从 1 起计；二者对应固定。备注、关键帧号、实际帧间隔和格式版本嵌入 GIF 的 Application Extension，随同一文件导出；重新打开该 GIF 恢复回放与备注，无需伴随文件。普通 GIF 阅读器仍可播放；不支持元数据的重编码工具可能丢弃扩展，不能声称任意转存保留。

GIF 备注供回看表达，不改变原采集像素或 Agent 的控制事实。文件另存、草稿附图与原操作分别对账；关闭回看后，已完成的原操作仍可读取。相同操作身份的并发请求共用一次选区。长图确认后的复制与草稿保存沿用同一目的地回执，重试保留已完成和结果未知的写入，不自动上传、不覆盖已有文件。Core 暴露类型、严格参数与回执，Desktop 持像素采集、连续采集窗口、编码和保存；CLI 和 GUI 消费同一 owner。Browser 整页截图仍沿其原页面协议范围，不以系统滚动拼接冒充。连续采集沿用选区真正选中的底图来源；不含 AgentMux 时以准确窗口身份排除宿主窗口，不得以含宿主的后续帧冒充。

## 截图后的文字处理

OCR 与敏感信息建议位于截图后的共享编辑面板。macOS 复用系统本地文字识别，不随安装包附带模型或引入云调用。只处理本人显式选择的当前图片；文字及位置为识别结果，不冒充原始文本或控制事实。敏感信息建议复用识别位置与有限格式规则，由本人选择遮盖，不声称检测无遗漏。普通图像输出不携带被遮盖的原图或识别文本元数据，原稿与普通导出的既有区分保持。

不支持的平台、原生能力明确缺失、图片尚未加载或当前动作处理中，相关按钮置灰；hover 与键盘聚焦均通过浮窗说明具体原因和恢复动作。未知或一次识别失败给出局部状态及重试，不将观察失败永久判为能力缺失；普通图片编辑、复制与保存继续可用。对比、拼图与叠图适合截图后的编辑面板，目前仅为候选，不在选区中增加工具。
