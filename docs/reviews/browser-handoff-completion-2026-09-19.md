# Browser 通用交接与操作提示闭环

Review: approved

授权依据：用户在明确得知异步失败、泛化残留、实机与验收记录缺口后要求「彻底完成吧」，并要求操作指示参考成熟浏览器的交接设计。本计划仅落实上述已确认范围。

Owner：Desktop Main 拥有导航、系统交接结果和人接管事实；Renderer / 页面状态条只显示。没有站点分支，不引入新 Runtime 或配置框架。

验收：生产 BrowserViewManager 的真实 Electron 导航与 frame 事件、系统交接成功/失败、记住选择与失败反馈；单位测试覆盖异步时序；关键实现变异变红并核对生产调用。视觉参考的行为依据为浏览器控制权交接 API 及当前产品状态，视觉结果另留截图，不能把参考文档当视觉观察证据。
