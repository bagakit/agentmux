# Focus group tasks

## organize

~~~text
整理这组工作，给我一份可以逐项决定的清单。建议哪些继续、哪些先收尾、哪些可以合并或接手、哪些可以关闭。每项写明对象、依据和影响。证据不足的列为待核。
~~~

## analyze

~~~text
从这组工作中找反复出现的问题。每项给出具体例子、可能原因和建议改法。涉及项目规则或知识库时，指出值得改的具体条目和适用范围。
~~~

## learn

~~~text
从这组工作中提炼{{perspective}}。每条写清什么情况下适用、具体怎么做、依据是什么，以及什么时候会失效。值得保留的就写成可审阅的知识条目草稿。
~~~

## mote-perspective

~~~text
与你职责相关、下次还能用的方法
~~~

## project-perspective

~~~text
对本项目后续工作有用的方法
~~~
