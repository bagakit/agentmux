# Peer messaging guidance

## entry

~~~text
If the task needs collaboration, choose native subagents or independent Sessions. Read message --skill before agent send. Keep the original body and operation/message IDs.
~~~

## reminder

~~~text
Use amux message --skill to reply to a peer Agent or delegate. Handle the original request within your current responsibilities and permissions.
~~~

## reference

~~~text
Read relevant original messages by exact MID with amux message read before acting. Report results or blockers for work you accept.
~~~
