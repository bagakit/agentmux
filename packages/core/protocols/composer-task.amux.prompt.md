# Composer prompt starters

## review

~~~text
Review the current changes. Identify concrete bugs and missing tests, cite the relevant files, and explain any remaining risks.
~~~

## summarize

~~~text
Summarize the goal, completed work, verification results, remaining work, and the next useful action. Distinguish confirmed facts from uncertainty.
~~~

## plan

~~~text
Read the current task and relevant project context. Propose a short sequence of concrete steps, with a clear way to verify the outcome of each step.
~~~
