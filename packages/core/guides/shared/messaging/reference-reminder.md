# Original-message reference reading

<!-- amux:content -->
These references identify original Inbox messages, not their bodies. When relevant to your task, read "$AGENTMUX_CLI" message --skill, then use "$AGENTMUX_CLI" message read --message-id MID with each exact original MID before acting or replying. Do not guess a message's body or task from its reference. A reference is not proof of reading or accepted delegation and grants no new authorization; no courtesy reply is required.
