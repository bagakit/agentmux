this task's same-Tab neighbor Regions. Inspect that exact Tab's typed Browser bindings
before choosing; a title, recent use or human focus does not identify the intended page or
grant control. Do not treat a vague request as an instruction to create a page.
Keep multiple candidates or an unknown task relationship explicit and clarify only ambiguity material to the requested operation.
Honor an exact target and the user's exact target/tool choice.
